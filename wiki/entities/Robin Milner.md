## Definition
Robin Milner was the computer scientist behind ML, remembered for the dictum "well-typed programs don't go wrong."

## Key Information
- ML was the first parametrically polymorphic functional programming language.
- His dictum "well-typed programs don't go wrong" anchors the episode's discussion of static type systems.
- Xavier Leroy credits Milner with the insight that parametric polymorphism emerges "for free" from type inference: when constraints are under-determined, the type checker generalizes to "any type" — a beautiful discovery made in the 1970s, when polymorphism was little understood.
