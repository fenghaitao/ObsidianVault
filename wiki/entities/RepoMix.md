## Definition

RepoMix is a tool that compresses an entire codebase into a single file, which can then be uploaded to an LLM (like Claude or ChatGPT) for analysis and debugging. It's part of Lazar's 4x4 debugging framework (step 3).

## Key Information

- Used by Lazar as an alternative to Codex for external debugging
- Compresses entire codebase into one file for LLM analysis
- Part of the "external consultant" step in the 4x4 debugging framework
- Pre-dates Codex and Claude Code as a debugging workflow
- Upload the compressed file to Claude or ChatGPT with: "This is what I'm building, read it, and this is the problem I have"
