## Definition

Caffeinate is a macOS utility that prevents a Mac from going to sleep. It is used by developers to keep long-running processes active, such as multi-hour Codex coding tasks.

## Key Information

- macOS utility to prevent sleep
- [[Kiti Bottom]] discovered it from teammates at OpenAI
- Used to run long [[Codex]] tasks locally for 4-5 hours without interruption
- Combo use case: Codex + Caffeinate to let the agent work overnight
