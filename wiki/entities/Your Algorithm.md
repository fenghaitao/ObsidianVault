## Definition

"Your Algorithm" is an [[Instagram]] feature (posted about publicly by [[Adam Mosseri]] shortly before this interview) that lets users see and adjust the topics/interests the recommendation system has inferred about them.

## Key Information

- Works by taking everything a user has interacted with, mapping it into an embedding space (a high-dimensional "map" where similar content clusters together), and using an LLM to describe a given cluster in plain language (Mosseri's example: "deep pour-over coffee snobbery").
- Users can view inferred topics and add or remove them, giving people some agency back over personalization in a recommendation-dominated feed.
- Positioned by Mosseri as an early step in a longer roadmap: future versions could let users make non-topical requests too (e.g., "I want more fun content," "I want to see my friends more," "I don't want to see seven photos of the same type in a row").
- Mosseri notes the public reaction to his post about the feature/agency topic was heavily negative in the comments, which he frames as "part of the job" given how contentious platform-design debates tend to be.
- Illustrates the broader point that embeddings underlie essentially all LLM technology, and that LLMs are newly making previously "illegible" recommendation artifacts (raw embedding vectors) describable in natural language.
