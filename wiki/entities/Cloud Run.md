## Definition
Cloud Run is Google Cloud's serverless compute platform that AI Studio's "Build" feature uses for one-click app deployment, allowing apps created in AI Studio to be deployed directly to production.

## Key Information
- Google Cloud's serverless compute platform
- AI Studio's Build feature supports one-click deploy to Cloud Run
- Enables apps built in AI Studio to go from prototype to production deployment
- Paige Bailey refrained from deploying the demo app to avoid burning quota
