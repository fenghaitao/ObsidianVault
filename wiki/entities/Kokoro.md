## Definition
Kokoro is an on-device text-to-speech (TTS) model. Neil Zeghidour described it as a "good one" among existing on-device models, but noted it lacks voice cloning capability — a key differentiator for Gradium Phonon.

## Key Information
- On-device TTS model
- Described as "good" among existing on-device models
- Does not have voice cloning capability
- Used as a benchmark comparison for Gradium Phonon
- Represents the state of on-device TTS before Gradium Phonon
