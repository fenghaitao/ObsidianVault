# Next.js

## Definition

Next.js is a React-based web framework by Vercel for building full-stack web applications. It serves as the deployment target for the Workflow DevKit demo coding agent.

## Key Information

- **Creator**: Vercel
- **Type**: React framework
- **Key Features**:
  - API routes for backend endpoints
  - Server-side rendering and static generation
  - Integration with Vercel's deployment platform
- **Workflow Integration**: The Workflow DevKit provides a `@workflow/next` package with a `withWorkflow` compiler extension and TypeScript plugin for Next.js projects
