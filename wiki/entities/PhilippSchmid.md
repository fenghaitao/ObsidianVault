## Definition
Philipp Schmid is a developer experience engineer at Google DeepMind, covering the Gemini API and Google AI Studio. He presented the Gemini Interactions API portion of the "Building Conversational Agents" workshop at the AI Engineer conference.

## Key Information
- Works on developer experience at Google DeepMind
- Covers the Gemini API and Google AI Studio
- Originally German
- Presented the Gemini Interactions API hands-on session, demonstrating how to build a coding agent with file and bash tools
- Introduced the Interactions API as a unified API replacing Generate Content, with server-side state management and implicit caching
- Demonstrated agent skills installation for Gemini APIs, and building a coding agent using Gemini 3 Flash with the Interactions API skill
- Showed how server-side state management improves cache hit rates by 2-3x
