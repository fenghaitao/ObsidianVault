## Definition
Philipp Schmid is a developer experience engineer at Google DeepMind, covering the Gemini API and Google AI Studio. He works on everything related to agents on Gemini and the Gemini API, observing agent-building challenges both internally at Google and externally.

## Key Information
- Works on developer experience at Google DeepMind, covering the Gemini API and Google AI Studio
- Works on everything related to agents on Gemini/Gemini API
- Originally German
- Observes agent-building challenges daily, both internally at Google and externally with customers
- Presented the Gemini Interactions API hands-on session, demonstrating how to build a coding agent with file and bash tools
- Introduced the Interactions API as a unified API replacing Generate Content, with server-side state management and implicit caching
- Demonstrated agent skills installation for Gemini APIs, and building a coding agent using Gemini 3 Flash with the Interactions API skill
- Showed how server-side state management improves cache hit rates by 2-3x
- Presented "Why (Senior) Engineers Struggle to Build AI Agents" identifying five paradigm shifts: text as state, handing over control, errors as inputs, unit tests to evals, and agent-ready APIs
- Articulated core principles: trust but verify, stop fighting the model, preserve meaning, design for recovery, evaluate don't just assert, build to delete
- Maintains a blog with code examples on agent engineering topics
