## Definition
Voyage is a provider of embedding models, including the Voyage code model (Voyage code 3) used by TurboGrep to embed code chunks for semantic search.

## Key Information
- Provides embedding models optimized for code
- Voyage code 3 is the model used by TurboGrep for embedding codebases
- Used in the semantic code retrieval benchmarking experiments presented by Kuba Rogut
- The embedding model's quality is critical for semantic code search — good comments and documentation in code help embeddings capture meaning
