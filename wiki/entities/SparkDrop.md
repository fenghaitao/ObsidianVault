## Definition

SparkDrop is Brian Casel's custom-built content pipeline application. It manages the lifecycle of content ideas from initial sparks through development (flames) to scheduled publication. Both Brian and his AI agents interact with it — Brian via the UI, agents via a private API.

## Key Information

- Content lifecycle: Sparks (new ideas pitched by agents) → Flames (drafts in development) → Scheduled/Published.
- Brian reviews sparks, can revise, comment, or greenlight for development.
- Agents submit ideas via API endpoints; Brian interacts via the web UI.
- Claude Co-work agent runs content development skill every morning at 6 AM, submitting new sparks and developing drafts.
- Includes training data on Brian's voice, preferences, and topics.
- Agents can post comments, create learnings from Brian's feedback, and fold learnings back into training.
- Available as a starter kit / build kit for Builder Methods Pro members.
- Has a public marketing page at sparkdrop.co (built using Brian's app marketing page skill).
