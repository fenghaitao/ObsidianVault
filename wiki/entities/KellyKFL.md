## Definition
Kelly KFL is an engineer at Fiverr who documented their journey of building and then aggressively curating an MCP server from 188 tools down to 5, cited by Jeremiah Lowin as a case study in MCP server design.

## Key Information
- Works at Fiverr
- Wrote two blog posts approximately one month apart (October and November 2025)
- First post: built a Fiverr MCP server growing from a few basic tools to 155-188 tools
- Second post: curated that same server from 188 tools down to 5
- Lowin describes the two posts taken together as telling "a really interesting story about making something work and then making something work well"
- Long-time acquaintance of Jeremiah Lowin
