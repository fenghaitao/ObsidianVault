## Definition
Sunil Pai is an engineer at Cloudflare who builds AI agents for the Agents SDK. He is the creator of PartyKit, an open-source tool for real-time multiplayer apps. He presented on "code mode" at the AI Engineer conference.

## Key Information
- Works at Cloudflare building agents for the Agents SDK
- Creator of PartyKit, an open-source tool for real-time multiplayer applications
- Presented at AI Engineer conference on "code mode" — the paradigm of LLMs generating executable code instead of JSON tool calls
- Describes code mode as enabling single-shot execution with looping, state, sequencing, and parallelization
- Advocates for capability-based security: start with zero capabilities, grant explicitly
- Uses V8 isolates at Cloudflare for sandboxing due to fast startup and ~10 years of security hardening
- Identifies as a React programmer and discusses implications of generative UI for UI developers
- Coined the phrase "inhabiting the state machine" to describe agents that read/write system state directly
- Argues that the distinction between programmers (who have code/infinite power) and non-programmers (who get buttons/forms) is breaking
