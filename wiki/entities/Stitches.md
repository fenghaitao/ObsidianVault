## Definition
Stitches is a design/product application (an Angular app) that uses the tldraw SDK for its annotate mode, where users can draw on and annotate designs.

## Key Information
- Angular application
- Uses tldraw SDK specifically in its annotate mode
- Referenced by Steve Ruiz as an example of tldraw SDK integration in a production app
- Noted that while Stitches' main canvas is not built with tldraw, the annotate mode is
