## Definition
Greptile is an AI-powered code review tool used by the Paperclip open-source project for first-pass code reviews on community contributions. It integrates with GitHub to automatically review pull request changes.

## Key Information
- AI-powered code review tool
- Used by the Paperclip open-source project for first-pass code reviews on community pull requests
- Integrated into Paperclip's routines: a routine uses the Greptile skill after submitting a PR to review changes on GitHub
- Helps manage the high volume of community contributions Paperclip receives
