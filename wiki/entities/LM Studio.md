## Definition

LM Studio is a desktop AI studio application for downloading, running, and managing local language models. It supports multiple inference engines (MLX, Llama CPP) and can serve models locally via OpenAI-compatible or Anthropic-compatible APIs. It acquired Locally AI.

## Key Information

- Desktop application for downloading and running local models directly from Hugging Face
- Supports multiple inference engines: MLX and Llama CPP, allowing comparison between them
- Can open a local server with OpenAI-compatible or Anthropic-compatible API response formats
- Enables connecting any app to locally hosted models via standard APIs
- Acquired Locally AI (announced at aiDotEngineer conference, April 2026)
