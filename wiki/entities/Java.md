## Summary

A widely-used object-oriented programming language running on the JVM (Java Virtual Machine). Steve Huynh noted that Java has been a dominant language at Amazon, and that while it is "not very sexy right now," becoming an expert in Java or JVM-based languages is a valid career strategy. He emphasized going deep—understanding the JVM, garbage collection tuning, and internals—rather than just surface-level knowledge.

## Key Details

- Runs on the Java Virtual Machine (JVM)
- Very verbose language, but IDE tooling helps with boilerplate
- A dominant language at Amazon
- Steve advises going deep: understanding the JVM, garbage collection, and bytecode, not just surface-level syntax
- Lombok is a library used to reduce boilerplate (auto-generating getters/setters)
