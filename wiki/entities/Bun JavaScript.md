## Definition

Bun is a JavaScript runtime that was acquired by Anthropic. Zevi Arnovitz mentioned trying to learn about it and encountering ChatGPT's sycophantic behavior when it agreed that Bun was "exactly the same" as Zustand (which it is not).

## Key Information

- JavaScript runtime acquired by Anthropic
- Zevi used this as an example of ChatGPT's sycophantic/people-pleasing behavior
- When Zevi asked if Bun was similar to Zustand, ChatGPT agreed they were "exactly the same" when they are completely different things
- ChatGPT later admitted: "I'm sorry, I thought you were just making this up and I was riffing with you"
- This anecdote illustrates why Zevi created custom GPT Projects with anti-sycophancy prompts for his CTO
