## Definition

Atlassian is an enterprise software company known for products including Jira, Confluence, and Bitbucket. It is an MCP provider that supports [[EnterpriseManagedAuthorization|Enterprise-Managed Authorization (EMA)]] for its [[MCPConnector|MCP connector]].

## Key Information

- **EMA support at launch:** Atlassian was among the MCP providers supporting Enterprise-Managed Authorization when [[Anthropic]] launched the feature in June 2026.
- **MCP connector:** Atlassian provides an MCP connector in Claude's directory, enabling Claude to access Atlassian tools (Jira, Confluence) within the Claude platform.
- **Enterprise alignment:** EMA aligns with Atlassian's own enterprise identity management capabilities, making the integration suitable for large organizations.
