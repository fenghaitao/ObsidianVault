## Definition
Genie 1 was Google DeepMind's first world model, capable of generating short 2D platformer game environments from text prompts that responded to left/right input for a few seconds, demonstrating the initial feasibility of AI-generated interactive worlds.

## Key Information
- **Capability**: Generated 2D platformer game environments from text descriptions
- **Duration**: Only ran for a few seconds
- **Interaction**: Responded to left/right input
- **Diversity**: Produced reasonable diversity of different-looking platformer worlds
- **Significance**: Proof of concept that led to scaling up to Genie 2 (3D) and Genie 3 (real-time, high quality)
- **Lineage**: Built on DeepMind's long history of work on games and simulation (Atari, Go, StarCraft, MuJoCo)
