## Definition

BrainDown is Brian Casel's custom-built markdown file editor and viewer. It integrates with Dropbox and is designed for reading and managing markdown files that AI agents create and share, particularly agent reports and summaries.

## Key Information

- Custom-built application for editing and reading markdown files.
- Integrates with Dropbox for file storage and sync.
- Used as the primary interface for reviewing agent-generated reports (SEO reviews, PR reviews, daily summaries).
- Agents create markdown files with checkboxes for Brian's approval; Brian checks boxes in BrainDown, and agents read the updated files on their next run.
- Available as a build kit / starter kit for Builder Methods Pro members.
- Has a public marketing page at braindown.app.
