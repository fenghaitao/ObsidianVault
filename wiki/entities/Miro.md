## Definition
Miro is an online collaborative whiteboard platform. Referenced in the Demand-Driven Context workshop as the destination for endless documentation gap tickets that never get resolved — the "endless Miro board" problem that Demand-Driven Context aims to solve.

## Key Information
- Used as a metaphor for the traditional approach to documentation gaps: putting tickets on a Miro board saying "this is missing, I need to add it" without ever actually resolving them
- The Demand-Driven Context methodology provides a faster, better way to discover and resolve documentation gaps than the "endless Miro board" approach
