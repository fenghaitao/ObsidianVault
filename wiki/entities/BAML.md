## Definition
BAML is a prompt formatting notation and adapter for LLMs that provides a more human-readable and token-efficient alternative to JSON schema formatting, supported as an adapter in DSPy.

## Key Information
- BAML formatting is more intuitive and token-efficient compared to JSON schema dumps.
- Testing by community member Pashant showed BAML adapters can improve performance by 5-10% depending on the use case.
- DSPy supports BAML as an adapter option, allowing format changes without modifying program logic.
- The BAML adapter is an example of how DSPy's adapter abstraction enables experimentation with different prompt formats.
