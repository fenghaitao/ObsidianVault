## Definition
Vertex AI is Google Cloud's machine learning platform that provides access to foundation models including Anthropic's Claude 3.5 Sonnet, and custom document retrieval capabilities for internal documents without requiring a vector database setup.

## Key Information
- Google Cloud's ML platform
- **Claude 3.5 Sonnet availability**: Available on Vertex AI, reflecting Anthropic's multi-platform strategy
- Provides tools for retrieval on custom internal documents
- Allows document retrieval without necessarily setting up a vector database
- Complements AI Studio's URL context feature for public documents
