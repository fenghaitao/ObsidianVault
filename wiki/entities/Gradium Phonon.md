## Definition
Gradium Phonon is an on-device text-to-speech (TTS) model from Gradium AI that runs on a smartphone CPU (not GPU), with fewer than 100 million parameters. It includes voice cloning and aims to enable consumer voice applications at zero API cost with full privacy through local processing.

## Key Information
- On-device TTS model from Gradium AI
- Runs on smartphone CPU (not gamer GPU) — "on-device" means phone CPU
- <100 million parameters — very small model
- Better than all existing on-device models as of May 2026
- Includes voice cloning (unlike Kokoro, a competing on-device model)
- Goal: enable consumer voice apps that can scale without API costs
- Local processing means total privacy — no cloud servers, no waiting
- Open to private beta
- Demo showed high-fidelity neural speech running locally
- Designed to solve the TTS cost problem that burns startup fundraising
