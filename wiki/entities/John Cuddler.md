## Definition

John Cuddler is the source of the Capability → Value → Scale framework that Elena Verna references to explain the stages of technology adoption.

## Key Information

- Created a framework describing how software evolves: Capabilities stage (what is possible to create) → Value stage (how do I get value) → Scale stage (which aspects of my life/work can this scale into)
- Elena Verna says this framework is "completely stuck in my mind"
- According to this framework, vibe coding is currently in the Capabilities stage because everyone is exploring what can be built
