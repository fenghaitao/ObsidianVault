# Peter Wielander

## Definition

Peter Wielander is a speaker from Vercel who presented the Workflow DevKit at aiDotEngineer. He demonstrated how to transform a standard AI coding agent into a durable, production-ready workflow-based agent using the Workflow Development Kit and Vercel AI SDK.

## Key Information

- **Organization**: Vercel
- **Role**: Presenter and developer advocate for the Workflow DevKit
- **Known for**: Demonstrating how to add durability, observability, resumability, and human-in-the-loop capabilities to AI agents with minimal code changes using the Workflow DevKit
- **Presentation**: "Building durable Agents with Workflow DevKit & AI SDK" (2026-01-06)
