## Definition

Superpowers is a skills framework integrated into Claude that structures the brainstorm-then-plan steps for software development. It provides a disciplined approach to moving from ideas to implementation by separating brainstorming from planning phases.

## Key Information

- Available as a Claude plugin at [claude.com/plugins/superpowers](https://claude.com/plugins/superpowers).
- Used by hackathon winner Alexis Chapellier (Wrench Board) to structure his development process: starting in Claude Design with Superpowers-driven brainstorming, sometimes running brainstorms in parallel to make progress on different fronts, then handing off to Claude Code.
- Integrates with Claude Design's built-in button that shares the project directly to Claude Code.
- Embodies the pattern of separating thinking/planning from coding, which multiple hackathon winners independently identified as critical to their success.
