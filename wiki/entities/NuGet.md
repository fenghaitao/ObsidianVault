## Definition

NuGet is the package manager for .NET. It grew out of a Microsoft effort to compete with package ecosystems like Ruby gems and WordPress/Drupal plugins.

## Key Information

- The founding team was David Fowler (first engineer), architect David Ebbo, and Phil Haack, formed after a meeting led by Scott Guthrie about building a .NET package manager
- The first version was an in-browser, WordPress-style package manager that eventually became the core .NET package tool
- Fowler's work on NuGet drove his early strong reviews and first promotions, and its continuing adoption became part of his later "deferred impact" toward distinguished engineer
- It was part of the broader .NET Core-era rebuilding of the .NET ecosystem from scratch
