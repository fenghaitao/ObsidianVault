## Definition
Arize AX is the commercial/enterprise version of the Arize platform, distinct from the open-source Phoenix. It provides enterprise-grade features including compliance, team management, production monitoring, and advanced analytics.

## Key Information
- Enterprise product separate from the open-source Phoenix
- Features not available in Phoenix: SOC 2 compliance, SAML/SSO, multi-team support, session-aware agent tracing (entire user session from login to logout), Arize DB for billions of traces, AI assistant called Alex, graphical agent representations, metrics, dashboards, and monitoring
- Online eval execution: evals can run on the platform itself (Phoenix runs evals on the client)
- Designed for companies "very touchy about their data" and those running production agents at massive scale
- Phoenix users should not confuse AX with Phoenix — signing up on the Arize homepage defaults to AX
- Session-aware tracing goes beyond individual agent turns to capture entire user sessions
