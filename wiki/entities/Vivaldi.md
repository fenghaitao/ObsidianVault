## Definition
Vivaldi is a web browser whose SQLite database stores reading history, used as a read-only data source in the Fulan personal AI system for tracking what articles the user has been reading.

## Key Information
- Used as a read-only data source in Fulan for tracking reading activity
- The system queries Vivaldi's SQLite database to find most-read articles and still-open tabs
- Combined with Clay CRM data to suggest which contacts might be interested in discussing specific articles
- Represents the "browser" source in Fulan's six-source read-only architecture
