## Definition
MCPUI is the original project released by Ido Salomon in May 2025 that pioneered passing UI over the Model Context Protocol. It later evolved into MCP Apps, the first official MCP extension, after partnering with Anthropic and OpenAI.

## Key Information
- Released by Ido Salomon in May 2025
- Core concept: take UI and find a way to pass it over MCP, enabling both UI delivery and bidirectional communication between the UI and the host
- Included community SDKs for building MCP UI servers and clients
- Motivation: we don't need to throw away everything we know about UI and UX to enter the world of agents — we can adapt and preserve branding and identity
- Early adopters included Shopify (millions of stores) and Hugging Face (all Spaces as MCPUI widgets)
- Evolved into MCP Apps after partnering with Anthropic and OpenAI
- The MCP UI SDK remains the recommended client SDK for hosts wanting to support MCP Apps
