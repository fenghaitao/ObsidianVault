## Definition

DataExpert.io is an educational platform created by Zach Wilson that teaches data engineering, data science, and SQL. It offers free content including a set of SQL coding challenges.

## Key Information

- Created and run by Zach Wilson
- Offers a free account with access to data engineering and data science content
- Features a SQLite code project with 50 SQL questions that are described as "really hard" and free to try
- Zach asked for feedback on the platform during the panel's closing remarks
