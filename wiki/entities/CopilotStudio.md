## Definition

Copilot Studio is Microsoft's low-code platform within Microsoft 365 Copilot for building, orchestrating, and managing enterprise-grade AI agents. It allows organizations to create custom agents, select AI models, define multiagent workflows, and configure prompt tools.

## Key Information

- Part of the [[Microsoft365Copilot]] platform.
- Supports model selection: as of September 2025, [[Claude4Sonnet]] (Claude Sonnet 4) and [[Claude4Opus]] (Claude Opus 4.1) are available alongside existing model options.
- Supports **multiagent systems**: agents can be composed into workflows where different models handle specialized tasks.
- Supports **prompt tools**: configurable prompt components for agent customization.
- Targets enterprise use cases: workflow automation, deep reasoning, flexible agentic tasks.
- Organizations access Claude in Copilot Studio by opting in through Microsoft's Frontier Program.
