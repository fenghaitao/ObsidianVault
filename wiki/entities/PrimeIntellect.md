## Definition
Prime Intellect is an AI company that created Verifiers, an open-source library for building reinforcement learning environments for LLM agents. They also develop Prime RL, a training framework that integrates with Verifiers.

## Key Information
- Creator of Verifiers, an open-source library for building RL environments for LLMs
- Developer of Prime RL, a training framework for RL with LLMs
- Aims to fight environment fragmentation in the LLM RL ecosystem
- Supports open-source alternatives to closed-source RL environment markets
