## Definition

Claude Code is Anthropic's AI coding agent, created by Boris Cherny.

## Key Information

- Built on the principle "don't build for the model of today, build for the model 6 months from now"
- Early on it was not great — Boris used it for ~10% of his code; ~6 months later (after the Sonnet/Opus 4 release) it "just worked" and he could use it for about half his code
- Most of Claude Code's own code is now written by Claude Code (80–90%); some Anthropic teams write ~90% of code via Claude Code
- Productivity impact: despite Anthropic roughly tripling in headcount, productivity per engineer grew ~70%
- Usage extends beyond software engineering — data scientists write SQL/DBT pipelines, and non-technical users (about half the sales team) connect it to Salesforce and other data sources
- Team philosophy: hold model-generated and human code to the same quality bar; vibe code only for throwaway/prototype code, otherwise pair with the model (plan mode) or hand-write high-conviction parts
- Plugins were built by a "swarm" of ~20 Claude agents over a weekend
