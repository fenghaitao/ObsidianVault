## Definition
WhisperFlow is a Mac dictation tool that enables voice-to-text input in any application. It is fine-tuned for technical terms and supports context-aware formatting based on the target application. Prince Canuma cites it as an example of a cloud-based dictation tool that could be replaced by on-device alternatives built with MLX Audio.

## Key Information
- **Platform**: Mac
- **Key Feature**: Works in any application with a text cursor — Chrome, Safari, code editors, Slack, email
- **Technical Tuning**: Fine-tuned for technical terms — can dictate code references, file paths, and programming terminology
- **Context Awareness**: Can adjust formatting based on target app (casual for Slack, formal for email)
- **Used By**: Nick Nisi uses it as primary input method, preferring it over Claude's built-in voice mode
- **Comparison**: Nick has used WhisperFlow for ~1 year and prefers it for its universal input capability across all Mac apps
- **On-device alternative**: Prince Canuma suggests similar apps can be built in ~10 minutes using MLX Audio
