## Definition
Ido Salomon is the creator of AgentCraft, an agent orchestrator that applies gaming-inspired patterns to human-agent collaboration. He is also the creator of MCI and creator/co-maintainer of MC apps, building tools that enable developers to work with multiple AI coding agents in parallel.

## Key Information
- Creator of AgentCraft, an agent orchestrator that uses RTS gaming metaphors for managing multiple coding agents
- Creator of MCI (Model Context Interface)
- Creator and co-maintainer of MC apps
- Presented at aiDotEngineer conference in 2026
- Core philosophy: humans are the bottleneck in multi-agent orchestration; gaming patterns (RTS unit management, muscle memory, heat maps) can transfer to productivity tools
- Believes the future of software engineering involves managing agents rather than writing code directly, and that the skills for this already exist in unexpected places like gaming
- AgentCraft is free and experimental, with development driven by community feedback via Discord
- Co-presented at aiDotEngineer 2026 with Liad Yosef on MCP UI and MCP Apps, the first official MCP extension for UI
- Creator of MCPUI (released May 2025), which evolved into MCP Apps after partnering with Anthropic and OpenAI
- Co-creator of MCP Apps, the standardized MCP extension for passing interactive UI over the protocol
- Advocates for a "new web" paradigm where personal assistants compose experiences from atomic UI chunks
