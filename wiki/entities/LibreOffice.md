## Definition
LibreOffice is a free and open-source office suite. In the Claude Agent SDK context, it exemplifies how the bash tool lets agents leverage existing powerful software for document processing without needing custom tools.

## Key Information
- Used as an example of existing software that agents can leverage via the bash tool
- Demonstrates that agents don't need custom document processing tools when they can use established software through bash
- Part of the argument that bash is the most powerful agent tool because it unlocks the entire existing software ecosystem
