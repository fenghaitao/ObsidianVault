## Definition

Operator was an earlier agent feature shipped inside [[ChatGPT]] by [[OpenAI]], designed for autonomous web-based task completion.

## Key Information

- Described by Andrew Ambrosino as a "very cool idea" that "didn't work out," largely because the underlying model at the time wasn't capable enough to execute the agentic-browsing concept well.
- Ambrosino draws a direct lineage between Operator, an agent inside [[Atlas]], and [[Codex]]'s later in-app browser/computer-use features: he argues these are "fundamentally the same feature," and that re-releasing the same concept with more capable underlying models is what eventually made it succeed.
- Used as the central example for Ambrosino's broader point that product teams should not be "stubborn" about abandoning a feature concept just because an early version failed — the concept may simply need to wait for the model to catch up.
