## Definition

SignalR is an open-source .NET library for real-time web functionality, such as server-to-client streaming, built by David Fowler as a nights/weekends side project that became an official Microsoft product.

## Key Information

- Fowler was inspired by Google Docs' co-editing and by the brand-new websockets/socket.io landscape, wondering "can we do this for code?"
- He collaborated with product manager Damon Edwards, moonlighting on it until midnight; it was made open source and started catching on organically
- It was Fowler's "brainchild" and the first project he built from scratch, which earned him his first pseudo-tech-lead role with a team of ~8
- Taught him delegation and scaling through others at a small scale, which he directly applied when architecting .NET Core
