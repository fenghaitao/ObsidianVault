## Definition

StudyMate (also spelled Studymate) is Zevi Arnovitz's weekend project — an AI-powered platform for students to upload study materials and create interactive tests based on their own materials. It was built entirely by Zevi using AI tools with no coding background.

## Key Information

- Built by Zevi Arnovitz as a side project using Cursor, Claude Code, and other AI tools
- Allows students to upload PDFs, select pages, choose number of questions and difficulty level
- Sends uploaded content plus system prompt to Gemini to generate quizzes
- Currently supports multiple choice questions; Zevi demonstrated adding fill-in-the-blank with drag-and-drop live on the podcast
- Provides deep explanations for why each answer was right or wrong
- Making money as a side business
- Zevi also built the Vortex, a dictation product for the Israeli market
