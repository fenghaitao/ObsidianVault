## Definition
NVIDIA Dynamo is a distributed system for disaggregated LLM serving that Vlad Feinberg cites as a place to demonstrate hands-on engineering signal.
## Key Information
- Vlad describes Dynamo as enabling "disaggregated serving"; building a project on or improving these components is an extremely positive candidate signal.
- It complements TensorRT in the NVIDIA serving ecosystem.
