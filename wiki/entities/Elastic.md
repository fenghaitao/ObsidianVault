## Definition

Elastic is the company behind Elasticsearch, a search and analytics engine. They help internal and external teams build agents to interact with Elasticsearch data, and provide official Elasticsearch agent skills for use with AI agents.

## Key Information

- **Product**: Elasticsearch — search and analytics engine with vector search, keyword search, and ESQL query language
- **ESQL**: Elasticsearch Query Language — a pipe query language for filtering, transforming, and analyzing data
- **Agent Skills**: Official Elasticsearch agent skills available for helping agents write valid ESQL queries
- **Internal work**: Helps internal and external teams build agents to interact with Elasticsearch data
- **Philosophy**: Advocates for "low floor, high ceiling" approach to search tools — specialized tools for common operations, general-purpose tools for complex queries
