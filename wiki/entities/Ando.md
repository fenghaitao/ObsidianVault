## Definition

Ando is a company building a workplace messaging platform on [[ClaudeManagedAgents]], using built-in memory to capture how each organization interacts rather than building memory infrastructure themselves.

## Key Information

- Cited by Anthropic (April 2026) as a customer using memory on Claude Managed Agents to replace custom retrieval/memory infrastructure they would otherwise have had to build.
- Uses [[ScheduledDeployments|scheduled deployments]] (June 2026) to keep hiring and sales teams moving: agents autonomously watch channels for proposed next steps, follow up when they're due, and send meeting reminders.
