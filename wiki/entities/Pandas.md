## Definition

Pandas is a high-performance Python data-analysis library whose core is implemented in C++, giving Python an efficient linkage to compiled code.

## Key Information

- Martin Odersky cites pandas (alongside NumPy) as an example of why Python is a "fantastic glue language": it lets Python reach into high-performance C++ libraries with very efficient linkages.
- It is one of the concrete demonstrations that Python's viability rests partly on high-performance work being done in lower-level languages underneath.
