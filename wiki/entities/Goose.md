## Definition
Goose is an AI agent tool and MCP client that supports MCP Apps as a host, rendering interactive UI from MCP servers. It features the Goose Auto Visualizer, which automatically matches and organizes data into predefined visualization components.

## Key Information
- Supports MCP Apps as a host
- Mentioned alongside other MCP Apps hosts (Claude, ChatGPT, VS Code, Cursor, Postman, LibreChat, Spy)
- Part of the growing ecosystem of tools adopting the MCP Apps standard
- **Goose Auto Visualizer**: accepts any type of data, automatically matches and organizes it, and passes it to a set of predefined components for visualization. Represents the static UI paradigm in AI-generated UI
