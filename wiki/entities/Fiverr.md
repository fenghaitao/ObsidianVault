## Definition
Fiverr is a freelance services marketplace whose engineer Kelly KFL documented a case study of MCP server curation, going from 188 tools down to 5.

## Key Information
- Freelance marketplace platform
- Engineer Kelly KFL built an MCP server for Fiverr's services
- The server grew from a few basic tools to 155-188 tools
- Was subsequently curated down to just 5 tools
- This case study is cited by Jeremiah Lowin as an exemplar of the "curate ruthlessly" principle
