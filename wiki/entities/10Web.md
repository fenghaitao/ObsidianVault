## Definition

AI website-building platform ("Tenweb" in the transcript), presented as one of this episode's sponsors, marketed as an AI website generator for WordPress front-end and back-end, positioned as having "pioneered AI website building before ChatGPT."

## Key Information

- Claims over 2 million websites generated via its "VIP coding platform," which it likens to "[[Lovable]] for WordPress front end and backend."
- Supports arbitrary-complexity sites (e-commerce, portfolios, informational sites, blogs) with the full WordPress admin panel and plugin ecosystem.
- Also offers website generation as an API/service for SaaS companies, marketplaces, hosting providers, MSPs, and agencies — including white-label dashboards for agencies/MSPs and self-hostable API builders for hosting providers.
- Ad read directs listeners to 10web.io/lenny with code "lenny" for free credits and 30% off API/white-label solutions.
