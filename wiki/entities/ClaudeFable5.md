## Definition

Claude Fable 5 is Anthropic's most capable generally available model, released as part of the fifth generation of Claude models alongside Mythos 5. It achieves state-of-the-art performance on nearly all tested benchmarks, with particular strength in software engineering, long-horizon autonomy, vision, and knowledge work.

## Key Information

- Released at Code with Claude Tokyo 2026 alongside Mythos 5 (same foundation, safeguards lifted for Glasswing partners).
- **Coding:** highest SWE-bench Pro scores; excels at single-shot correctness on complex problems and long-horizon autonomy (days-long coherent tasks).
- **Code reading:** better at outage triage, repo history analysis, and proactive improvement suggestions than code writing.
- **Knowledge work:** manages financial analysis, documents, slides, spreadsheets end-to-end with professional-grade output.
- **Vision:** industry-best; reads dense technical images, web applications, plots, diagrams, charts.
- **Safeguards:** routes cyber/biology/chemistry requests to Opus 4.8 with clear labeling and Opus pricing.
- **Customer validation:** Cognition (highest Crunchier bench score), Genspark (won head-to-head against all tested models), Rakuten (autonomous operations at scale).
- **Time horizon:** agents can be proactive and handle higher-level goals requiring judgment, collaboration, and proactive taste.
