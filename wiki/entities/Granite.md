## Definition
Granite is IBM's family of open-source AI models, including language models and vision models. Granite models are used throughout the OpenRAG stack — Granite 4 3B as the language model and Granite Docling 258M as the vision language model for document processing.

## Key Information
- IBM's open-source model family
- **Granite 4 3B**: Language model used in OpenRAG demo, run locally via Ollama
- **Granite Docling 258M**: Vision language model for document processing in Docling's VLM pipeline (all-in-one extraction)
- Models can run locally via Ollama
