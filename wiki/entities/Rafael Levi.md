## Definition
Rafael Levi is a speaker from Bright Data who presented at aiDotEngineer on building self-healing web scraping pipelines with LLMs and MCP. He demonstrated how agents can build scrapers instead of parsing every HTML page, saving millions of tokens.

## Key Information
- Works at Bright Data, a web data platform with MCP, proxy infrastructure, and anti-bot technology
- Presented at aiDotEngineer conference, second session (previous session covered MCP for CAPTCHA-protected websites)
- Prefers Claude Code as his agent interface for building and running scrapers
- Runs daily data collections with an LLM that polls every 30 minutes, validates data, and self-heals broken scrapers
- Uses Claude Haiku for browsing agents — sufficient when anti-bot layer handles human behavior mimicry
- Built a personal apartment-hunting listener using Bright Data that found his current home
- Has a restaurant booking listener running for 2+ months waiting for a spot
- Advocates that public data is public data — Bright Data won lawsuits against Meta and X/Twitter
- Available on LinkedIn for questions about web data access
