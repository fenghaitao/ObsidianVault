## Definition
Ian Cooper is the author of the influential talk "TDD Where It All Went Wrong," which critiques how test-driven development has been misapplied in practice, particularly the overfocus on unit tests and code coverage rather than behavioral testing.

## Key Information
- Author of the talk "TDD Where It All Went Wrong"
- The talk critiques how TDD practice drifted from its original intent of testing behavior to testing implementation details
- Recommended by Marlene Mhangami as essential viewing for developers interested in behavior-driven TDD
- His work bridges the gap between traditional TDD and functionality/behavioral testing approaches
