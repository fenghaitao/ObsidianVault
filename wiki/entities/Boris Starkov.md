## Definition
Boris Starkov is an engineer at Eleven Labs who reverse engineered a legacy Viking VOIP phone protocol using Claude Code, enabling the company's phone booth demo at an AI engineering summit. He describes himself as "just a normal software engineer" rather than a security expert, and his talk demonstrates how AI tools make hardware reverse engineering accessible to non-specialists.

## Key Information
- Engineer at Eleven Labs, usually working on voice agents
- Reverse engineered a Viking VOIP phone protocol in "a couple of days" using Claude Code
- Previous attempt by three senior engineers plus ChatGPT (1 year prior) had failed
- Describes his role as "the agent for Claude" — Claude orchestrated, he performed physical actions
- Open-sourced the reverse-engineered protocol as a reusable Claude Code skill
- Presented at aiDotEngineer conference
- Token cost for the reverse engineering: between $10 and $100
- Used UTM on Mac for Windows virtual machine during the man-in-the-middle phase
