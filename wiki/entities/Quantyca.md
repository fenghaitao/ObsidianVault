## Definition
Quantyca is an AI consultancy that designed and built the enterprise-grade registry system for Amplifon's AI platform, including the MCP Registry, A2A Registry, Use Case Registry, AI Gateway, and blueprint repositories for agent development.

## Key Information
- **Role**: AI consultancy specializing in enterprise AI platform development
- **Key Project**: Amplifon's Amplify platform -- a complete enterprise registry and governance system for MCP and A2A agents
- **Team**: Mauro Luchetti (AI Center of Excellence Manager) and Mattia Redaelli (AI Engineer) presented the solution
- **Technical Contributions**: Designed the AI Gateway with Entra ID integration, three-registry architecture (MCP, A2A, Use Case), CICD-integrated blueprint repositories, and the runtime proxy architecture connecting agents through the gateway
- **Blueprint Approach**: Created framework-agnostic A2A server blueprints using interfaces/ports so teams can implement agents in their framework of choice (LangChain, Agno, etc.)
