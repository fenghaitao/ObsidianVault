## Definition

Alan Turing is a mathematician whose foundational paper established the Turing machine and proved that some problems are unsolvable by computers.

## Key Information

- Wigderson notes "one fundamental result starting with Turing's paper is that there are problems that are simply unsolvable by computers" — so the first complexity class is the decidable/solvable problems, which are not all problems.
- The Turing machine is the baseline model of computation that quantum computers generalize (a quantum computer generalizes a randomized Turing machine).
- Martin Hellman recounts that Turing figured out how to build a primitive computer to break the German Enigma machine in World War II; the Germans knew Enigma was breakable but never imagined the Allies would build a machine to break it.
- Turing was "hounded to death" in the 1950s for being homosexual, as depicted in "The Imitation Game"; Hellman contrasts that with modern regret over such treatment.
