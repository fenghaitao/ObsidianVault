## Definition
Apify is a web scraping platform used for extracting content from websites. It was used alongside Firecrawl in the Towards AI deep research agent for scraping web pages provided as research links.

## Key Information
- Web scraping platform for content extraction
- Used in the Towards AI deep research agent alongside Firecrawl
- Part of the content ingestion pipeline: scrape provided links before deep web search
- Chosen for handling diverse website types in the research pipeline
