## Definition
AirSkills is a skills management platform being built by Chris Parsons (Cherrypick). It aims to solve the problems of packaging, versioning, sharing, and managing Claude Code skills across teams and organizations.

## Key Information
- Being built by Chris Parsons under Cherrypick
- Addresses the friction of skills versioning and sharing — current approaches (GitHub repos per skill, submodules, zip files, plugin marketplaces) are all inadequate
- Enables creating skills for organizations, skill bundles, and skill sets for different teams
- Automatically versions and updates skills without requiring everyone to learn Git and GitHub
- Parsons demonstrated an investor memo deck that his startup loop agent produced for AirSkills, including market sizing, problem statements, and pricing analysis
- Described as potentially "the GitHub for AI skills"
- Parsons is exploring whether organizations would pay for "skills governance"
