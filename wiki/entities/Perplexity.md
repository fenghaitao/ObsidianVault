## Definition

Perplexity is an AI-powered search and answer engine. It is mentioned as one of the AI companies that was early to certain patterns — its founders were known for asking ChatGPT before talking to anyone for advice.

## Key Information

- AI-powered search and answer engine
- Cited as an example of a company that was early to AI-native work patterns: its founders asked ChatGPT before talking to anyone for advice
- Included in Lenny's Newsletter "Product Pass" as a sponsor product
- Part of the ecosystem of AI-native companies pushing the boundaries of how work gets done
- Has launched an OpenClaw-like agent product, competing in the AI agent space alongside Manas, Claude (Anthropic's built-in approach), and others
- Perplexity's search API can be used as a web search tool for OpenClaw agents (alternative to Brave and Exa)
- Claire Vo: "Is there one perfect agent experience? No, but everybody's going to take a run at it"
