## Definition
Tempo is a blockchain network and Stripe partner that co-developed the Machine Payments Protocol for enabling programmatic, pay-per-use agent tool interactions settled on-chain.

## Key Information
- Blockchain partner for Stripe's [[Machine Payments Protocol]]
- Transactions settle on the Tempo blockchain (using path USD)
- Stripe replicates a product view of on-chain transaction data in its own system
- Part of Stripe's multi-chain support alongside [[Base]]
- Enables ephemeral, pay-per-use agent tool interactions with on-chain settlement
