## Definition

Apache Flink is an open-source stream processing framework used for real-time data processing and analytics.

## Key Information

- Zach Wilson used Flink at Netflix for detection projects aimed at identifying threat actors
- These detection projects were part of Netflix's "sockless security system" — a fully automated security system without a Security Operations Center
- Zach eventually recognized that the detection work was too ambitious and transitioned to a graph database project that had more reliable impact
