## Definition

TY is Astral's Python type checker, written in Rust. Built into Monty for type-checking AI-generated code before execution. Zanie Blue discussed how TY's LSP features must be reprioritized for agentic consumers — auto-complete matters less, semantic operations (rename, find references) matter more.
