## Definition
Manulife is a financial services and insurance company that is a customer of Adaptive ML, using RL-trained models integrated into existing agent workflows.

## Key Information
- **Use case**: Already had agents in production with settled workflows
- **Approach**: Adaptive ML directly plugged a trained model into the existing agent environment without recreating the workflow
- **Significance**: Demonstrates that RL-trained models can be integrated into pre-existing agent infrastructure
- **Platform**: Uses Adaptive ML's Adaptive Engine
