## Definition

MLX Swift LM is a GitHub repository that provides the Swift package for integrating MLX-powered language models into iOS, macOS, and iPadOS applications. It handles model downloading from Hugging Face and provides a straightforward API for running inference.

## Key Information

- GitHub repo for integrating MLX into iOS, macOS, and iPadOS apps
- Can have a model running in an iOS app in under 10 minutes
- Integrates with Hugging Face to download models directly by passing a model ID
- Supports tool calling natively
- Structured generation is not yet natively supported but third-party packages are emerging
- Used by Locally AI as the underlying framework
