## Definition
Vaibhav Srivastav (VB) is a member of the Developer Experience (DX) team at OpenAI, based in London. He works on helping developers build with and get the most out of OpenAI products, particularly Codex.

## Key Information
- Works on the OpenAI Developer Experience team in London
- Presented the OpenAI Codex Masterclass covering models, sub-agents, code review, and bleeding-edge features
- Joined OpenAI in December (2025), when the leading model was GPT-5.2
- Was a hardcore CLI user before the Codex app launch, but the app became an important part of his workflow
- Personally uses Codex sub-agents for brainstorming features by spinning up multiple agents to explore different implementation approaches
- Uses Codex code review extensively and notes it is used on 100% of pull requests across all OpenAI repos
- Worked with colleague Dom to ship the Cloud Code plugin for Codex
