## Definition
Embedding Gemma is a 300 million parameter text embedding model from Google DeepMind, designed for RAG (Retrieval-Augmented Generation) use cases on device. It demonstrates that high-utility tiny models can serve critical infrastructure roles in AI applications.

## Key Information
- 300 million parameter text embedding model
- Published with the Gemma team in September 2025
- Designed for RAG (Retrieval-Augmented Generation) use cases
- Very strong embedding performance despite small size
- Example of a tiny model with high utility for on-device use cases
- Not technically an LLM (though it uses a transformer architecture internally)
- Part of the broader tiny model ecosystem for on-device AI
