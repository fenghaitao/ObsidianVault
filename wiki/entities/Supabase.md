## Definition

Supabase is an open-source backend-as-a-service platform providing database, authentication, and storage. It is an MCP provider that supports [[EnterpriseManagedAuthorization|Enterprise-Managed Authorization (EMA)]] for its [[MCPConnector|MCP connector]].

## Key Information

- **EMA support at launch:** Supabase was among the MCP providers supporting Enterprise-Managed Authorization when [[Anthropic]] launched the feature in June 2026.
- **MCP connector:** Supabase provides an MCP connector in Claude's directory, enabling Claude to interact with Supabase databases and backend services.
