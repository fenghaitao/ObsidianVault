## Definition

Supabase is an open-source Firebase alternative providing database, auth, storage, and edge functions. They focus on both DX (developer experience) and AX (agent experience), making their platform agentic-friendly through skills and tooling.

## Key Information

- Open-source Firebase alternative (Postgres, auth, storage, edge functions)
- AI tooling team focuses on AX (agent experience) alongside DX (developer experience)
- Uses skills extensively to improve agent performance on their platform
- Pedro Rodrigues is AI tooling engineer leading skills development
- Announced Supabase agent skill publicly at AIE 2026
- Experiments with SSH-based documentation access for agents
- Evals show MCP + Supabase skill outperforms MCP alone across Claude and GPT models
