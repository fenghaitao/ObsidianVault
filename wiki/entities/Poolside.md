# Poolside

## Definition

Poolside is an AI company building proprietary models from scratch to close the gap between models and human intelligence. Their core technical approach combines next-token prediction with reinforcement learning. They operate a full vertical stack from data centers to model training to developer interfaces.

## Key Information

- **Founded**: ~2023 (2.5 years of work as of December 2025)
- **Founders**: Jason Warner and Eiso Kant
- **Core Technology**: Proprietary models trained from scratch using reinforcement learning paired with next-token prediction
- **Current Model**: Malibu Agent (second generation)
- **Next Model**: Third generation coming early 2026, available via own API and Amazon Bedrock
- **Infrastructure**: Building a multi-gigawatt data center campus in West Texas with over 40,000 GB300 GPUs
- **Target Market**: High-consequence code environments (defense, government) initially; expanding to general availability
- **Interface**: VS Code extension with live diff view, plus web and desktop agent interfaces
- **Partnerships**: Open to working with companies for RL and fine-tuning on top of their models
