## Definition

Mozilla's web browser; cited by [[Simon Willison]] as a case study for legitimate AI-driven security research — [[Anthropic]]'s internal security team reportedly discovered roughly 100 vulnerabilities in Firefox and responsibly disclosed them to Mozilla, which released a fix.

## Key Information

- Contrasted by Willison with a growing problem of low-effort AI-generated vulnerability reports (people using ChatGPT to generate plausible-looking but unverified security reports and submitting them to open-source maintainers) — Anthropic's Firefox reports were credible specifically because Anthropic's own security team verified them before disclosure, rather than passing along unverified agent output.
