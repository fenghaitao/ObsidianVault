## Definition
Reachy Mini is a $300–450 open-source robot created by Hugging Face, designed for hackers, researchers, students, and dreamers. It is an expressive, intentionally non-humanoid robot with built-in voice AI capabilities, meant to democratize robot interaction and development.

## Key Information
- Two price points: $300 (basic) and $450 (includes Raspberry Pi and battery)
- Ships unassembled — users build it themselves, learning the full hardware stack
- Fully repairable: any broken part can be ordered and replaced by the user
- Hackable: users 3D-print new parts (antennas, accessories, decorations)
- Voice AI integration: microphone, speakers, echo cancellation, face tracking camera
- Runs the Hugging Face speech-to-speech pipeline for conversation
- Tool dispatching for robot movements and emotions
- Compatible with SO100/SO101 arms and Kiwi mobile base
- 7,500 units shipped as of May 2026
- All software is open source: models, agents, conversation app
- Can be programmed via vibe coding — describe desired behavior and AI generates the code
- Not constrained by programming language — Java, Python, HTML all work
- Design philosophy: intentionally non-humanoid to encourage creative new forms of interaction
