## Definition
GitHub Codespaces is a cloud-based development environment that provides a VS Code instance running in the browser, connected to a container in the cloud with all dependencies pre-installed via dev container configuration.

## Key Information
- **Zero-install development**: Uses dev containers to pre-configure all dependencies — developers don't need to install tools or packages locally
- **VS Code in browser**: Full VS Code instance running in the browser, connected to a running cloud container
- **Pre-configured extensions**: Extensions like AI Toolkit come pre-installed out of the box
- **Cost model**: On organizational repos, costs go to the enterprise account rather than individual users
- **Workshop usage**: Microsoft Foundry workshop uses Codespaces to provide a standardized environment for all attendees
- **Setup process**: Fork repo → create Codespace from branch → wait for VM to initialize → ready to run notebooks
