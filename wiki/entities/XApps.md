## Definition
XApps is the official SDK and repository for MCP Apps, maintained alongside the MCP Apps spec. It provides built-in skills that let coding agents generate MCP Apps without manual coding, and is always kept compliant with the latest spec.

## Key Information
- Official MCP Apps SDK and repository
- Always kept compliant with the MCP Apps spec — both are updated together
- Includes built-in skills so developers can use coding agents to generate MCP Apps without writing code
- Recommended starting point for building MCP App servers
- Active community with issues and contributions
- Part of the official MCP Apps ecosystem with Anthropic and OpenAI
