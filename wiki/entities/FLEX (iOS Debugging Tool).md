## Definition

FLEX is an open-source iOS in-app debugging tool created by Ryan Olson at Flipboard (initially "FL tweaker"); it lets developers inspect an app's live state — classes, methods, properties, network requests, and file system.

## Key Information

- Ryan built it during his Flipboard internship while learning Objective-C, drawn by the language's dynamic runtime that exposes classes/methods/properties at runtime.
- It let developers inspect and tweak app state on demand, view network requests, and see the file system.
- Open-sourced with company approval; it became one of the more popular iOS debugging tools and was used at Facebook and Instagram ("Flex" at Instagram).
- Ryan became less active as maintainer after joining Instagram; a maintainer named Tanner took it over and continued evolving it.
- Ironically, at his Instagram interview no interviewer wanted to look at it, yet a Facebook iOS engineer (Jonathan Dan) noticed the tool and advocated to get Ryan the interview.
