## Definition
Thor Schaeff (also Torsten for German speakers) is a developer experience engineer at Google DeepMind, covering the Gemini API and Google AI Studio. He presented the Gemini Live API portion of the "Building Conversational Agents" workshop at the AI Engineer conference.

## Key Information
- Works on developer experience at Google DeepMind
- Covers the Gemini API and Google AI Studio
- Originally German
- Presented the Gemini Live API hands-on session, including the Live Jukebox DJ demo combining Gemini Live API with Lyra 3 for music generation
- Demonstrated Gemini 3.1 Flash Live, the new native audio model with 97-language support
- Showed Google Search grounding, voice modification via system instructions, and ephemeral token connections
