## Definition

HackerRank is a platform used by tech companies to administer coding challenges and technical assessments during the recruiting process. Ricky used it during his Yelp interview.

## Key Information

- Ricky used HackerRank for a 15-minute coding challenge from Yelp, implementing the merge step of a merge sort in C++
- His code was correct but a segfault caused him to fail; the Yelp engineer later confirmed the code was correct upon re-examination
- The platform's automated evaluation can produce false negatives, making it worth contesting results when confident in one's solution
