## Definition
Android is Google's mobile operating system. Kitze switched back to Android from iOS because Android gives agents full phone control — reading notifications, clearing notifications, installing and uninstalling apps.

## Key Information
- Kitze switched back to Android specifically for agent control capabilities
- Agent can: read notifications, clear notifications, install apps, uninstall apps — "it can do anything on an Android phone"
- Contrasts with iOS: "it can maybe send you a push notification and if Tim Cook allows"
- Google Pixel already launches apps in background and orders coffee autonomously
- Kitze: "I feel like this thing enchanted me. I'm like, 'Who am I? I don't recognize myself anymore.'"
