## Definition

Mobbin (rendered "Mobin" in the transcript) is a design-reference site [[Lazar]] uses to find high-quality UI screenshots and animations to attach as references when prompting AI coding tools, rather than describing desired designs purely in words.

## Key Information

- One of Lazar's four recommended parallel first attempts when starting a new project: pull a good reference screenshot/animation from Mobbin (or [[Dribbble]]) and attach it as input, since most AI coding tools accept file attachments.
