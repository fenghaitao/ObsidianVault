## Definition

Bolt (also referred to as Bolt.new) is an AI-powered app builder and vibe coding platform that lets users build applications by chatting with AI. It was one of the first tools Zevi Arnovitz used when starting his AI building journey.

## Key Information

- One of the tools that inspired Zevi to start building after watching YouTube videos from Japan
- Zevi opened a Bolt account immediately upon returning from Japan and started building
- Like Lovable, Bolt's system prompt was "you're a coding agent" — it was super eager to write code immediately
- Zevi found Bolt was "awesome until I was trying to connect payments to my app and it kind of started losing it"
- Described as part of the same bucket as Lovable, Replit, Base44, and v0 — all vibe coding platforms
- These tools add abstraction layers that take guesswork and hard decisions out for the user, trading control for ease
- Part of Lenny's Newsletter Product Pass (free one-year subscription for annual subscribers)
