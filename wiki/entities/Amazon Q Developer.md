## Definition
Amazon Q Developer is an AI-powered assistant for software development built by AWS, capable of code completion, code explanation, multi-file feature development, and code transformation using agents for complex tasks.

## Key Information
- Much more than a code completion tool — uses agents to perform complex software development tasks
- Capabilities include code generation, code explanation (including legacy code), feature development via `/dev` commands, and code transformation (e.g., Java version migrations)
- Generates change sets (diffs) that developers can review before inserting code
- Integrates into IDEs with a chat interface for conversational development
- Kiro was theoretically funded out of the organization that supports Amazon Q Developer but was built as a distinct product suite
- Has a developer center with examples and tutorials
