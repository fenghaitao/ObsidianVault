## Definition
Dennis Ritchie co-created the C programming language and Unix at Bell Labs, and was a colleague and friend of Bjarne Stroustrup.

## Key Information
- Transcribed in the episode as "Dennis Richie" (and once "Dennis Chief"); correctly Dennis Ritchie.
- Bjarne lunched with him roughly weekly for years; he never said anything negative about C++.
- In his HOPL ("History of Programming Languages") paper, Ritchie pointed to C++ as the obvious successor to C — evidence the "C vs C++ language wars" never existed between the creators.
- Helped design `const` for C++ (originally "read only"/"write only," shortened for the C people).
- Was wary of operator overloading (having to read declarations before knowing a call's meaning), though Bjarne feels it works in practice.
- Modern C function-definition/declaration syntax and call semantics trace back to Bjarne's early C++ "classes" work, so C programmers today use Bjarne's handiwork constantly.
- Proposed the "fat pointer" (pointer plus element count) to C to combat buffer overflows; rejected then for memory reasons, it survives in modern C++ as `span`.
