## Definition
Stanford University is a research institution that partnered with Intercom to independently study the impact of AI adoption on code quality. Their research group analyzed Intercom's codebase and confirmed that code quality metrics have been increasing during the 2x project.

## Key Information
- Has a research group studying AI's impact on software engineering
- Partnered with Intercom to analyze code quality trends
- Independently confirmed that Intercom's code quality has been increasing during AI adoption
- Intercom provides their code to Stanford for analysis
- Used as external validation that AI-assisted development is not degrading code quality
