## Definition

PostHog, a product analytics tool, is used by [[Dan Shipper]] as an example of an ordinary SaaS website he accesses from inside an agent's in-app browser (e.g., in [[Codex]]) rather than directly.

## Key Information

- Cited as a stand-in example ("maybe PostHog or whatever") for any SaaS website a user might browse to from within an agent that has access to the whole computer — illustrating Dan Shipper's prediction that SaaS tools will increasingly be used *through* an agent's browser rather than as a standalone destination, while the SaaS company itself is spared the token cost since the user's own agent tokens are used.
