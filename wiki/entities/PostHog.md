## Definition
PostHog is a product analytics company that offers an open-source analytics platform. It developed the PostHog Wizard, an autonomous coding agent that automatically integrates PostHog into users' projects, processing 15,000 integrations per month.

## Key Information
- Product analytics company with an open-source platform
- Developed the PostHog Wizard, an autonomous coding agent for automated integration
- The Wizard processes 15,000 integrations per month
- Covers inference costs for Wizard users via an LLM gateway
- Uses the Claude Agent SDK to power the Wizard
- Maintains a fleet of "model airplanes" — thin reference implementations across frameworks and languages
- Maintains fresh documentation on posthog.com that agents can load as context
- Received unprompted positive posts on Blue Sky and Twitter from happy Wizard users
- One of the first companies to move their home screen to a chat interface, cited as an example of the 2025 chat agent trend
- Hypothetical voice agent use case: agent joining Zoom calls to correct wrong stats
