## Definition
Antigravity is Google DeepMind's agentic IDE and platform. It presents as a Visual Studio Code-style interface but includes a full agent manager framework underneath, capable of spawning and running multiple agents working on different projects. It integrates planning, browser control, DOM inspection, human-in-the-loop editing, and task completion reporting.

## Key Information
- VS Code-style IDE with built-in agent manager for spawning multiple simultaneous agents
- Features: planning system with implementation plans, browser control (take control of web pages), DOM inspection (look at actual web page structure), human-in-the-loop editing (edit agent plans before execution), task completion reports with screenshots/video
- Agents can rewrite code from scratch based on specs — demonstrated rewriting an entire game generated by a different model
- Scratch pad shows agent notes and reasoning traces during task execution
- Current sub-agent model: agents work on different tracks within a project but aren't obviously coordinating in a massively parallel system
- Used internally at Google/DeepMind for coding in a giant monorepo, being generalized for other use cases
- KP Sawhney is working on re-architecting the deep research agent to use Antigravity's harness for shared-workspace collaboration
- Referenced as having a team behind it — Kevin mentioned as from the Antigravity team
- DeepMind is exploring using Antigravity to orchestrate deep research with each element as a collaborator in a shared workspace, similar to how humans research
