## Definition
Ian Ballantyne is a developer relations engineer at Google DeepMind. He presents and demos Antigravity, DeepMind's agentic IDE and platform, showcasing its capabilities for running multiple agents with planning, browser control, DOM inspection, and human-in-the-loop editing.

## Key Information
- Developer relations engineer at Google DeepMind
- Demos Antigravity: a VS Code-style IDE with built-in agent manager that can spawn multiple agents working on different projects
- Showcases Antigravity features: planning system, DOM inspection, browser control (taking control of web pages), human-in-the-loop editing of implementation plans, task completion reports with screenshots/video
- Demonstrates how an agent can rewrite code from scratch based on a spec, replacing a different model's generated code entirely
- Highlights Antigravity's scratch pad as an agent trace showing what the agent is thinking during task execution
- Notes that current Antigravity sub-agents are not obviously coordinating — agents work on different tracks rather than a massively parallel system
- Envisions future where agent-to-agent communication is efficient and humans act as supervisors on a "digital assembly line"
- Discusses seamless model tiering: when quota is exhausted on one model, the harness should automatically fall back to another without interrupting workflow
- Mentions Kevin from the Antigravity team as a subject matter expert on model tiering
