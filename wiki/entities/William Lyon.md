## Definition
William Lyon is a product manager at Neo4j who built the context graph demo and tools showcased by Zach Blumenfeld, including the context graph financial analyst demo application and the Create Context Graph CLI scaffolding tool.

## Key Information
- Product manager at [[Neo4j]]
- Built the context graph demo application featured in [[Zach Blumenfeld]]'s AI Engineer talk — a financial analyst agent using decision traces, graph embeddings, and hybrid search
- Built the [[Create Context Graph]] CLI tool that scaffolds full-stack context graph applications with a single command
- Work includes integrating graph data science (GDS) for graph embeddings and hybrid search over decision traces
