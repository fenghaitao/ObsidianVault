## Definition

Podscan is Arvid Kahl's SaaS product for podcast monitoring (podscan.fm). It is notable for being 98% coded by Claude, with 3,500 tests and 12-14,000 assertions, built using a systematic AI-powered development workflow.

## Key Information

- Podcast monitoring platform at podscan.fm.
- 98-99% of codebase written by Claude.
- Built with PHP/Laravel using PHP Storm IDE.
- 3,500 tests with 12-14,000 assertions (added via "super delayed TDD").
- Arvid's CLAUDE.md is "sizable" with the Augment library for system prompts.
- Video-to-docs workflow for training Claude on the product.
