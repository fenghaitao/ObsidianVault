## Definition
Agenta AI is an open-source LLMOps platform providing tools for observability, prompt management, and evaluation, covering the full lifecycle of building reliable AI agents.

## Key Information
- Open-source LLMOps platform
- Covers observability, prompt management, and evaluation
- Targets the full lifecycle of building reliable agents
- Founded and led by [[Mahmoud Mabrouk]] (CEO)
- Used in the workshop to: instrument traces for debugging, create annotation queues with reasoning fields, and visualize error type clusters during error analysis
- Supports annotation workflows where subject matter experts label traces with binary verdicts and reasoning
