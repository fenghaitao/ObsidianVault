## Definition

Pamela Fox is a developer advocate at Microsoft/GitHub (reorged to both in 2026). Known for empirical research on MCP tool schemas and agent reliability.

## Key Information

- Presented at PyAI Conf 2026 on improving MCP tool schemas
- Ran systematic evals comparing schema variants (bare strings, descriptions, enums, literals, regex) across multiple models
- Key finding: modern LLMs are good enough that schema strictness matters less than expected, but structured schemas still provide type safety benefits
- Uses PydanticAI and Logfire for agent evals
- Active in FastMCP community, reports compatibility issues that get fixed
