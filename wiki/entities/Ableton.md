## Definition
Ableton is a music production software (DAW). Eric Zakariasson used its interface as a visual reference for building a music agent demo project entirely through AI agents.

## Key Information
- Used as UI inspiration for Eric Zakariasson's music agent demo project
- The demo project was an online music creation tool built entirely by agents without Eric writing any code
- The agent was instructed to make the UI "look like Ableton"
- Eric noted this should probably be codified as a rule for consistent agent output
