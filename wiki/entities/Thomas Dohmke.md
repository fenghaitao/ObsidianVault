## Definition
Thomas Dohmke is the CEO of GitHub, fascinated by software development since childhood in Germany. He has built a career creating tools that accelerate innovation in software development, and oversaw the launch of GitHub Copilot, the first at-scale AI developer tool.

## Key Information
- Current role: CEO of GitHub
- Background: Grew up in Germany, built career around tools for software development
- Key achievement: Overseen the launch of GitHub Copilot, the first at-scale AI developer tool
- Philosophy: "we're not trying to build an AI engineer, we're trying to build AI for engineers" — a human-centric approach
- Leadership approach: Constantly reconfiguring strategy as the AI world changes daily; operating as agile as possible even at 3,000-person company scale
- Personal experience: Grew up with Commodore 64 in the '90s, experienced the open source and internet transformation, and now views AI as another step function in software development
- Metaphor: Defines AI agents as "like an AI dishwasher" — autonomous tools that handle tedious work
- Priority: Wants AI agents that burn down security backlogs, balancing compliance with innovation
- Personal coding: As CEO he rarely codes, but when he does on a Sunday afternoon, he wants to be creative rather than updating dependencies
- Gave Shopify early access to GitHub Copilot in 2021 — a full year before public release — after Farhan Thawar directly contacted him
