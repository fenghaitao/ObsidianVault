## Definition

Tenweb is an AI-powered website building platform, described as "Lovable for WordPress front end and back end." It pioneered AI website building before ChatGPT and has generated over 2 million websites. It was a sponsor of this episode.

## Key Information

- Sponsor of Lenny's Podcast episode 31
- Over 2 million websites generated in the last 3 years
- VIP coding platform for WordPress — users can build any website at any complexity level
- Comes with WordPress admin panel and thousands of ready-to-use plugins
- Offers website generation as an API for SaaS companies, marketplaces, hosting providers, MSPs, and agencies
- SaaS companies can embed it via API so users launch AI-generated sites inside their platform
- Agencies and MSPs can get white-label dashboards to manage clients
