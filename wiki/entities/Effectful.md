## Definition

Effectful is the company founded by Michael Arnaldi that develops and maintains the Effect TypeScript library. The company is researching fine-tuning models on Effect patterns and building tooling for AI-assisted development with Effect.

## Key Information

- Founded by Michael Arnaldi, creator of the Effect library
- Maintains the Effect TypeScript ecosystem (core library, SQL, workflows, clustering, testing)
- Runs the effect.solutions website for AI project quick-start
- Researching: fine-tuning open-source models to use Effect patterns by default, running daily evals to measure code quality improvements from library changes, building a CLI to prefetch patterns optimized per model (GPT vs Claude)
- Considering providing pre-built pattern files for the top 2-3 frontier model families
- Kit Langton built the effect.solutions website
- Evaluating whether to generate patterns on-the-spot per model vs providing static patterns
