## Definition
Adnan Qureshi is a figure in the software development community quoted by Prasenjit Sarkar for the statement that English is now the new programming language, reflecting the shift from IDE-based coding to agentic development where developers instruct agents in natural language.

## Key Information
- Quoted by Prasenjit Sarkar at the AI Engineer Summit
- Stated that software development has shifted from writing code in IDEs to spinning up agents and giving instructions in English
- Characterized English as "the new programming language"
- Described the new workflow: agents generate code, humans review it
- Referenced the transition from traditional IDEs (VS Code, JetBrains) to agentic coding platforms (Codex, Claude, Devin, Gemini CLI)
