## Definition

Sear is Sentry's AI debugging agent. It uses Sentry's context to find root causes of errors, suggest fixes, and open PRs. It also reviews PRs and flags breaking changes.

## Key Information

- Sentry's AI debugging agent
- Uses Sentry's context to determine root causes of errors
- Suggests fixes and opens PRs automatically
- Reviews PRs and flags breaking changes with fixes ready to go
- Works in conjunction with Sentry's error monitoring platform
