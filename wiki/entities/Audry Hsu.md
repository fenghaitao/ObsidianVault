## Definition
Audry Hsu is a representative of RunPod who presented at aiDotEngineer on deploying LLM endpoints in under 5 minutes using RunPod's serverless infrastructure.

## Key Information
- Works at RunPod, a cloud AI infrastructure company
- Demonstrated deploying an LLM endpoint via the RunPod Hub and Serverless product in under 5 minutes
- Walked through the full deployment flow: selecting a Hub listing, configuring vLLM parameters, provisioning an HTTP API endpoint, and sending inference requests
- Showed cold start dynamics (~41 seconds for first request due to container init and model download) and subsequent fast execution (~1.5 seconds)
- Presented RunPod's four-layer product architecture: Pods, Serverless, Clusters, and Hub
