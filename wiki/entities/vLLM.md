## Definition
vLLM is an open-source LLM serving stack that Vlad Feinberg cites as an ideal place for frontier-lab candidates to make visible, useful contributions.
## Key Information
- The serving stack surrounding LLMs is a sophisticated distributed system that maintains KV-cache memory, load balancing, and request queuing — common back-end server problems.
- Contributing to vLLM (or SGLang) or building demonstrations with TensorRT or NVIDIA Dynamo is "an extremely positive signal" to Vlad when evaluating candidates.
- Candidates don't need to improve every case: showing a concrete improvement for a specific setting is enough.
