## Definition
The Excalidraw MCP App is an MCP application that creates a shared canvas where humans and AI agents can collaborate bidirectionally — not just for output and visualization of diagrams, but as a shared artifact where both parties contribute, modify, and interact. It generates interactive diagrams that can be moved, edited, and updated live within chat hosts like VS Code and Claude.

## Key Information
- Built on top of Excalidraw, the open-source virtual whiteboard
- Creates a shared artifact: a canvas where human and agent collaborate in the same space
- Bidirectional: human can click around and modify the UI traditionally while the agent also contributes
- Users can go back and forth with the agent, asking "change this" while also directly manipulating the canvas
- Interactive elements: users can move diagram elements, update text, and interact live within the chat
- Referenced by Marlene Mhangami as a popular MCP App for generating architecture diagrams
- Cloud Code uses Excalidraw MCP Apps for visualizing things
- Represents the "beyond components" future of generative UI: collaborative experiences rather than static or generated output
- Referenced by Ruben Casas as the model for human-agent collaboration interfaces
- Not just for output/visualization — it's a workspace
