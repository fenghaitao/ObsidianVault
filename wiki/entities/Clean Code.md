## Definition

Clean Code is Robert C. Martin's influential book of software-engineering advice whose performance trade-offs Casey Muratori critiques.

## Key Information

- Casey argues Clean Code-style guidance (tiny functions, dynamic dispatch, code that "shouldn't know its types") prevents compilers from inlining, unrolling, and vectorizing.
- He says such books should discuss the performance cost of their advice rather than dismiss it as "usually okay."
