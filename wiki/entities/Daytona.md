## Definition

Daytona is a managed sandbox/compute provider offered as a self-hosted sandbox option for [[ClaudeManagedAgents]], letting customers run Claude agent tool execution on infrastructure Daytona manages instead of building their own sandbox environment.

## Key Information

- Listed alongside [[Cloudflare]], [[Modal]], and [[Vercel]] as one of the supported providers customers can start with when setting up self-hosted sandboxes for Claude Managed Agents (public beta, May 19, 2026).
- Anthropic's docs and a companion cookbook (`anthropics/claude-cookbooks/managed_agents/self_hosted_sandboxes`) cover setting up Daytona as a sandbox provider.
- The source article does not provide further detail on Daytona's product beyond its role as a sandbox provider.
