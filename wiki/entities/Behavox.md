## Definition

Behavox is a compliance and security company that uses [[ClaudeCode]] as its primary AI pair programming tool across its engineering organization.

## Key Information

- Bundled [[ClaudeEnterprise]] with [[ClaudeCode]] and rolled it out to hundreds of developers.
- Describes Claude Code as their "go-to pair programmer," with coding assistance that "consistently outperforms other agents."
- Quote from Artem Pikulin, Senior Manager of Machine Learning Operations: "Its coding assistance consistently outperforms other agents, delivering superior results and value every day."
- Adopted Claude Code via the premium seats model introduced in August 2025, which bundles Claude and Claude Code under one Enterprise subscription.
