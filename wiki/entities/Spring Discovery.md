## Definition
Spring Discovery (transcript: "Spring") is the computational biology / drug-discovery company where Charlie Marsh was the second engineer before founding Astral.

## Key Information
- Charlie had no biology or ML background; as the second engineer he built the software systems for machine learning, working in Python plus some Go and Rust.
- Set out to build "a crazy drug discovery company" focused on aging, using computer vision; later pivoted and joined Genentech (transcript: "Janentech").
- The experience exposed him to many ecosystems and to Python tooling limitations, planting the insight behind Ruff and uv.
