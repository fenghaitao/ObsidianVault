## Definition
A2UI is Google's generative UI protocol, mentioned in the MCP Apps talk as an interoperability target. The MCP Apps team is working on compatibility between MCP Apps and A2UI to build a unified standard for UI in chat apps.

## Key Information
- Google's generative UI protocol
- Interoperability target for MCP Apps
- MCP Apps team doing work to ensure compatibility between the two protocols
- Part of the broader effort to build a unified standard for UI in chat apps
- Represents the declarative/generative UI approach where the host renders components from structured descriptions
