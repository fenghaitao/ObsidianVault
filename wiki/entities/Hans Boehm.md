## Definition
Hans Boehm created a widely used conservative garbage collector and pushed for a garbage-collection interface during C++ standardization.

## Key Information
- Transcribed as "Hans Berm."
- Represented the internal garbage-collection model in the standards committee; his conservative collector is "still used today."
- Bjarne agreed to an interface so using such a collector could be standardized; a GC interface was put into C++ 11.
