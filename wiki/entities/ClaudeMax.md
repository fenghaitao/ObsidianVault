# Claude Max

**Claude Max** is the premium individual user plan for [[Anthropic|Anthropic's]] Claude platform, designed for power users and professionals requiring advanced capabilities.

## Features

Claude Max includes access to:

- [[Research]] — In-depth web and organizational research capability
- [[GoogleWorkspaceIntegration|Google Workspace integration]] — Connection to Gmail, Calendar, and Google Docs
- Advanced model capabilities and higher rate limits
- Early access to beta features
- **Memory (October 2025+):** Persistent cross-conversation memory of professional context and preferences via [[ClaudeMemory|Claude Memory]]. Each project has isolated memory; users can view and edit the memory summary in Settings. [[IncognitoChat|Incognito chat]] is available for sessions that should not be saved to memory.
- **[[Slack]] connector (January 26, 2026):** Connect a Slack workspace so Claude can search channels, DMs, and shared files for context. Also available for Claude Pro as of the same date.

## Availability

Research and Google Workspace integration are available in early beta for Max plans in:
- United States
- Japan
- Brazil

Users can toggle the Research setting in chat to enable the capability.
