## Definition
Siri is Apple's voice assistant. Kitze predicts that a future local Siri with tool capabilities from installed apps could win the AI agent race for mainstream users — no cloud credits, data stays local, phone does things magically.

## Key Information
- Kitze predicts Siri could become a powerful local agent with tool capabilities from installed apps
- Advantages over cloud agents: no credits wasted, data stays local, privacy-preserving
- "Most normies and most people, they'll be completely fine with a local agent like Siri"
- Contrasts with current iOS limitations: "it can maybe send you a push notification and if Tim Cook allows"
