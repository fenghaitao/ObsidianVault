## Definition
Kilo Code (kilo.ai) is an AI coding agent company that builds tools for agentic engineering. Their product features specialized modes (ask, code, architect), context management capabilities, and multi-surface availability (IDE, CLI, mobile, cloud, Slack).

## Key Information
- Website: kilo.ai
- Founded/operated by a team including Brendan O'Leary, who joined over a year before the April 2026 talk
- Key features: ask mode (research-only, cannot write files), code mode (implementation), architect mode (planning)
- Provides at-mentioning for quick context injection (files, commits, terminal output)
- Slash commands for task management and context condensation
- VS Code integration with right-click "add to Kilocode" for selected code sections
- Autocomplete built in for both code and prompting
- Multi-surface strategy: IDE, CLI, mobile phone, cloud agent, Slack
- Focus on OpenClaw and KiloClaw for safe agent usage
- Compiles workflow patterns and trends at path.kilo.ai
- Philosophy: website demos should not show "prompt and a whole lot of code flying by" — emphasizes structured workflow over flashy demos
