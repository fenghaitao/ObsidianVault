## Definition
Augment Code is an AI coding tool whose entire agent system defaults to Gemini 3.1 Pro, selected specifically for its performance and cost profile.

## Key Information
- AI coding tool with an agent system
- Defaults to Gemini 3.1 Pro for its agent system
- Selected Gemini 3.1 Pro for performance plus cost reasons
- Mentioned by Paige Bailey as an example of production adoption of Gemini 3.1 models
- Evaluated but not chosen by Intercom for their 2x project; Intercom consolidated on Claude Code instead
