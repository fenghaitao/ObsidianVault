## Definition
Confluence is Atlassian's enterprise wiki and documentation platform. In the Demand-Driven Context methodology, it is identified as one of the primary sources of institutional knowledge that forms the "monolith" — along with Jira, SharePoint, Slack, and GitHub.

## Key Information
- Part of the institutional knowledge monolith that agents struggle to navigate
- Contains documentation that may be outdated (20%), unreliable (20%), or duplicated (10%)
- Can be connected to the Context Gap Scanner to analyze documentation quality
- The scanner can use Confluence metadata (creation date, last updated, author) to flag stale documents
- Curated knowledge can be published back to Confluence after processing
- When combined with codebase as a knowledge source, conflicts can arise between Confluence docs and code
