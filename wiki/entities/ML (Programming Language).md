## Definition
ML is a strict functional programming language that predated Haskell; OCaml grew out of the ML tradition, and ML was the first parametrically polymorphic functional language.

## Key Information
- Always strict and always had I/O by default — "it wasn't a goal, but that's just the way it worked out."
- The birthplace of parametric polymorphism, associated with Robin Milner's dictum "well-typed programs don't go wrong."
- A strict parallel variant ("parallel ML") is being developed at Carnegie Mellon.
- Predated Haskell; OCaml grew out of the ML tradition.
- SPJ names ML as one of the memory-safe languages that would remove ~99% of internet exploits "by construction."
- Xavier Leroy: Robin Milner's ML-style type inference (collect and solve constraints) lets parametric polymorphism emerge for free, the key invention OCaml inherited.
