## Definition
The Victoria and Albert Museum (V&A) in London is a museum of art and design that has a public API for its collection data, making it particularly well-suited for AI-powered conversational experiences with its objects.

## Key Information
- Has a public API for accessing collection information programmatically
- This API makes it easier to build AI experiences that pull authentic curator-approved data rather than relying on Google search results
- Part of the group of museums (alongside Science Museum and Sainsbury Centre) interested in AI-powered visitor interactions
- Represents how museums see their core IP as databases that can be connected to AI agents
- The availability of a public API addresses the key scaling challenge: moving from AI-generated research to curator-authenticated narratives
