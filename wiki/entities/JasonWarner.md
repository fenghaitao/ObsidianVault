# Jason Warner

## Definition

Jason Warner is the co-founder of Poolside and former CTO of GitHub (2017+). At GitHub, he led the transformation of the platform from a collaborative code host into an end-to-end software development platform, launching products including GitHub Actions, Packages, Code Spaces, and ultimately GitHub Copilot.

## Key Information

- **Role**: Co-founder of Poolside
- **Previous Role**: CTO of GitHub (joined 2017)
- **Notable Achievement**: Led the Office of the CTO at GitHub that incubated Copilot alongside Nat Friedman and others
- **Poolside Mission**: Building models from scratch using reinforcement learning combined with LLMs to close the gap between models and human intelligence
- **Background**: Involved in data center buildouts reminiscent of the late 1990s and early 2000s era
