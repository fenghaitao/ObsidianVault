## Definition

Pinecone is a vector database that Michael Stonebraker cites as faster than user-defined types on text-based vector processing, proof that specialized engines still win.

## Key Information

- Stonebraker cites Pinecone as evidence the "one size fits none" thesis still holds: it is faster on vector workloads than user-defined types on a general-purpose system.
- It illustrates vector processing as another workload that rewards a purpose-built engine rather than a one-size-fits-all database.
