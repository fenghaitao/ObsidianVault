## Definition

Mythical Games is a game development/technology company where Kostiantyn Vlasenko — creator of the Claude Code-built app [[Respiro]] — works as a project manager. Following his experience building Respiro, Vlasenko brought Claude-based workflows into the company internally.

## Key Information

- Vlasenko became an internal advocate for the Claude Code development process he developed while building [[Respiro]], sharing his "Claude folder and workflows" with the engineering team.
- Mythical Games now has a small internal team delivering work entirely through [[ClaudeCode|Claude Code]]; Vlasenko himself now commits code and ships features directly as part of his day job, despite having no formal engineering background.
- Adoption had friction: some engineers found it hard to shift from controlling every line of code to a delegation-based workflow — a cultural/mindset barrier rather than a technical one.
