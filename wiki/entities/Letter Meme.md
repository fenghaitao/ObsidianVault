## Definition

Letter Meme (lettermeme.com) is an AI-powered personal news aggregator built by Sam Lessin that takes all the newsletters he doesn't have time to read and turns them into daily cartoons.

## Key Information

- Built by Sam Lessin as a personal tool
- Takes subscribed newsletters and turns them into a grid of daily cartoons summarizing what's going on in the world
- Users can pipe their own newsletters into it
- Delivers an email digest once a day, continuously updated
- First version was built end-to-end by Sam using vibe coding (Cursor, DigitalOcean, Cloudflare)
- Later upgraded by engineer friends after the initial version proved the concept
- Sam describes it as the best way he gets an overview of the news
- Available at lettermeme.com
