## Definition
Jeremiah Lowin is the founder and CEO of Prefect Technologies, creator of the FastMCP framework, and a prominent voice in MCP server design best practices.

## Key Information
- Founder and CEO of Prefect Technologies, building data automation and orchestration software for 7-8 years
- Former member of the Apache Airflow PMC (Project Management Committee)
- Created Marvin, an agent framework that served as his entry point into AI developer experience
- Created FastMCP almost exactly one year after MCP was introduced; David from Anthropic called him to say it was how people should build servers
- FastMCP was downloaded ~1.5 million times in a single day; it has become the de facto standard way to build MCP servers
- FastMCP was incorporated into the official Anthropic MCP SDK, then positioned as the high-level interface while the SDK focuses on low-level primitives
- Advocates for agentic product design: treating MCP servers as user interfaces for AI agents, not REST API wrappers
- Identifies three key dimensions where humans and AI agents differ: discovery, iteration, and context
- Proposed five actionable MCP best practices: outcomes over operations, flatten arguments, instructions as context, respect the token budget, curate ruthlessly
- Lives in Washington DC; his subway-is-on-fire example is a running joke in his talks
