## Definition
JSON Render is a declarative UI tool being built by Vercel that maps components using JSON and YAML descriptors, enabling dynamic and personalized UI interactions while remaining constrained to predefined static components.

## Key Information
- Built by Vercel
- Supports both JSON and YAML descriptors (YAML support added recently)
- The LLM generates the JSON/YAML descriptor, not the components themselves
- Still constrained to static components — the LLM doesn't generate the components
- Creates very dynamic, high-quality UI interactions
- Represented by Ruben Casas as the current "perfect balance" between flexibility and consistency in generative UI
- Falls in the declarative UI paradigm: more personalized than static UI but more predictable than generative components
