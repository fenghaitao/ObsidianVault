## Definition
AGUI Protocol is an SDK for the static UI generation paradigm where developers register client tools that map to React components. Agent tool calls pass props to predefined static components, which are then rendered to the user.

## Key Information
- SDK for registering client tools that map to React components
- Agent tool calls receive props that are mapped to predefined static components
- Represents the static UI paradigm: agent as orchestrator, components pre-built by developers
- Similar to traditional server-client rendering where the agent generates the data/props
- Referenced by Ruben Casas as an example of the current default approach to AI-generated UI
- Contrasts with declarative UI (JSON descriptors mapped to design systems) and generative UI (model writes code at runtime)
