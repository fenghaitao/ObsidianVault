## Definition
John Hughes is the author of the paper "Why Functional Programming Matters," which argued that lazy evaluation enables unusually modular program composition.

## Key Information
- His classic example: a chess program can generate an infinite tree of moves while a separate pruning/exploring program walks only the necessary parts — possible only with lazy evaluation.
- Lazy evaluation is "powerful glue" that lets two conceptually separate programs (a generator and a consumer) stay separate; strict evaluation forces them to merge.
