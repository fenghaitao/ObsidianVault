## Definition

Asset Inventory was a Knowledge Graph project built by Zach Wilson at Netflix. It described all applications, code bases, data sets, and employees at the company and how they were connected, addressing Netflix's microservices security challenges.

## Key Information

- Built by Zach Wilson at Netflix over two years
- Addressed the microservices security challenge: with 3,000-5,000 apps, Netflix needed a unified view of its infrastructure
- The system mapped all applications, code bases, data sets, and employees and their relationships
- Zach described it as "this big ass knowledge graph of everything"
- This project was what Airbnb recognized as staff-level work when they hired Zach as a Staff Engineer
- The project represented a pivotal career move for Zach, transitioning from detection work to infrastructure
