## Definition

Fern Desk is a tool that automatically generates and updates help documentation by analyzing a codebase, Git commits, and Linear tasks. It integrates with Help Scout, GitHub, Linear, and Gmail, and can update existing docs when new features are added.

## Key Information

- Auto-generates help articles by reading code, Git history, and task management data.
- Integrates with Help Scout, GitHub, Linear, Gmail.
- Can update existing documentation when new features are added — "it looked at the code and then it just figured out what to add."
- Tracks what users search for to identify documentation gaps.
- Used by Brennan Dunn for his RightMessage SaaS.
