## Definition
Chroma is a vector database used for embedding-based similarity search and recommendations, integrated into Manus-built web applications for features like related event discovery.

## Key Information
- Used in the conference event scraper demo to find similar events based on embeddings
- Manus web apps can integrate with Chroma by providing an API key
- Combined with OpenAI embeddings for semantic search capabilities
- Ivan Leo's personal preference for Chroma's brutalist website design influenced his demo aesthetics
