## Definition
Louis Knight-Webb is the founder of Vibe Canvas (Vibe Kanban), a tool for parallelizing coding agents. He also founded the London chapter of AI Tinkers and achieved placement on the SWE-bench verified leaderboard ahead of OpenAI.

## Key Information
- Founder of Vibe Canvas (product name: Vibe Kanban), a tool for running multiple coding agents in parallel
- Founded the London chapter of AI Tinkers, a community for AI events in London
- Achieved placement on the SWE-bench verified leaderboard ahead of OpenAI
- Argues that software engineering is becoming "plan and review" — the time saved from AI coding displaces into planning and reviewing work
- Coined the term "Focus Maxing" — designing interfaces that let agents run as long as possible before yielding back to the human
- Identified the 5-minute threshold for agent runtime: when agents run longer than ~5 minutes, humans must change their behavior and run agents in parallel
- Shut down Vibe Kanban live on stage at AIE CODE 2026, citing unsustainable business model ($30/user subscription vs. users spending $3,000 on Codex tokens)
- Key startup lessons: work with great people, learn what hard work really means, hire someone good at selling to enterprise
- No regrets about the journey: "It increased my value as a human by doing this"
