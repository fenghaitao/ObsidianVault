## Definition
Samuel Colvin is the creator of Pydantic, the open-source Python validation library, and founder/CEO of Pydantic the company. He also created Pydantic AI (agent framework) and Pydantic Logfire (observability platform).

## Key Information
- Creator of Pydantic, the widely-used Python data validation library
- Runs Pydantic the company, which maintains Pydantic validation, Pydantic AI, and Pydantic Logfire
- Believes AI observability is a feature, not a category — it will be absorbed by either observability or AI platforms
- Presented a live workshop at AI Engineer 2026 on agent optimization using GEPA, evals, and managed variables
- Demonstrated a complete optimization pipeline: structured-output agents → golden dataset evals → GEPA optimization → managed variable deployment
- Used the "Rest Is Politics" podcast question about UK MP political dynasties as a demo use case
- Advocates for deterministic custom evaluators over LLM-as-judge ("lunatics running the asylum")
- Vision: self-driving managed variables where Logfire autonomously optimizes agent prompts and configurations
- Acknowledges that optimization matters most for private data where models lack pre-training knowledge
- Fan of "The Rest Is Politics" podcast
