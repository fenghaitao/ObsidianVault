## Definition

Brave is a web search API that ships by default with OpenClaw. It provides programmatic search capabilities (like a "programmatic Google") — instead of going to a website and searching in a search bar, it sends an API request and returns search results and websites.

## Key Information

- Ships out of the box with OpenClaw as the default web search tool
- Provides programmatic web search as an alternative to browser-based search
- "Programmatic Google" — API-based search that returns results and websites
- More reliable for AI agents than browser-based web access
- Part of the web search API ecosystem alongside Exa and Perplexity
