## Definition
TensorFlow Lite is Google's original on-device ML inference framework and file format, now evolved into Lite RT. The TFLite file format remains the standard model format for Lite RT deployment.

## Key Information
- Original on-device ML framework from Google, now evolved into Lite RT
- TFLite file format is the standard model format used by Lite RT
- Cross-platform file format: Android, iOS, macOS, Linux, Windows, web, IoT
- Models in TFLite format are backward-compatible with Lite RT
- Rebranded to Lite RT to reflect multi-framework support beyond TensorFlow
