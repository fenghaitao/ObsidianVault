## Definition
BigQuery is Google Cloud's serverless data warehouse. Raindrop integrates with BigQuery by exporting signal-tagged event data, allowing customers to run custom experiment analysis and queries on agent observability data.

## Key Information
- Google Cloud serverless data warehouse
- Raindrop integration: exports events and classified signal tags for custom analysis
- Used by customers who want to run experiments in their own analytics infrastructure rather than within Raindrop
