## Definition
TensorRT is NVIDIA's inference optimization framework and one of the vendor-specific tools whose fragmentation MAX addresses by providing a unified cross-platform alternative.

## Key Information
- NVIDIA's first-generation inference framework for optimizing trained models for deployment
- Part of the explosion of inference frameworks that fragmented the AI deployment landscape
- Like other vendor-specific tools, requires switching between different technologies for different hardware targets
- [[MAX]] replaces vendor-specific frameworks like TensorRT with a single consistent stack that works across CPUs and GPUs
