## Definition

ZenML is an ML Ops infrastructure company founded by Hamza Tahir. Built ML pipelining and orchestration tools for machine learning workloads. Now building Kitaru, a composable agent infrastructure layer applying ML Ops lessons to the agent era.

## Key Information

- Maintains the ZenML LLMOps database cataloging thousands of production agent use cases (available as an MCP server)
- Hamza Tahir's PyAI Conf 2026 talk argues agent infrastructure is the underinvested layer
- Building Kitaru: composable agent infrastructure for enterprises
