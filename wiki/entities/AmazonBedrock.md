## Definition
Amazon Bedrock is a fully managed AWS service that provides API access to a wide range of leading foundation models from multiple providers, along with tools for model customization, RAG workflows, agent building, and responsible AI guardrails in a secure environment.

## Key Information
- **Provider**: Amazon Web Services (AWS)
- **Model Providers**: Anthropic (Claude 3 Haiku, Claude 3.5 Sonnet), AI21 Labs, Cohere, Meta, Mistral, Stability AI, and Amazon Titan
- **Unified Converse API**: Standardized API for working across different models with consistent parameters, message structures, and output formats — handles model-specific translations automatically
- **Built-in Function Calling**: Native support for tool use in models that support it, via a tool list passed to the Converse API
- **Agent Builder**: Enables creation of AI agents with custom instructions (prompt engineering), action groups, and tools — demonstrated with a Minecraft-playing agent using Claude 3 Haiku
- **Model Customization**: Supports fine-tuning, RAG workflows, and prompt engineering
- **Security**: Full control of data in a secure environment
- **Poolside Integration**: Poolside's third-generation model will be available on Bedrock starting early 2026
