## Definition
Glass is Cursor's internal interface/IDE component, part of the Cursor 3 rewrite. It provides the agent interaction surface including the editor, sidebar, and agent control panel.

## Key Information
- Part of Cursor 3's agent-first architecture
- Runs as a separate process alongside the backend services
- Agents can interact with Glass via computer-use tools to test UI changes
- Referenced in Eric Zakariasson's demo of Cloud Agents testing their own work
- Can be started via Cursor's internal dev tool commands
