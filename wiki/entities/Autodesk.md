## Definition
Autodesk is a design and engineering software company mentioned in the MCP Apps talk as an example of a company with heavy applications that would benefit from the upcoming reusable views feature, since re-rendering complex UIs each time creates a poor user experience.

## Key Information
- Used as an example of a company with heavy, complex applications
- Has the problem that re-rendering MCP App UIs from scratch each time takes too long
- Motivating use case for the reusable views feature in MCP Apps
- Represents the class of enterprise applications that need performance optimizations in the MCP Apps ecosystem
