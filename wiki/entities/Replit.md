## Definition

Replit (also referred to as "Replet" in the transcript) is an AI-powered coding platform that enables users to build applications through natural language prompts. It evolved rapidly through V2 and V3 releases, with V3 introducing agents that can debate and collaborate with each other to produce better code.

## Key Information

- Jason Lemkin is a top 1% user, having built 12 apps in 150 days despite not being able to code
- V2 improved significantly: hallucinations went away
- V3 introduced agents talking to agents — when a user encounters an issue, the agent calls in an "architect" agent and they debate/argue to find the right solution
- Lemkin's reaction to the agent-to-agent debate feature: "I just fell out of my chair"
- Replit grew from 0 to ~$200M (or similar) with no traditional sales team initially, later adding a sales team and CRO
- CEO John is reportedly okay with a smaller, more efficient sales team even if it means slightly less revenue
- Competes with Lovable and Bolt in the AI coding/vibe coding space
- Replit's growth trajectory: 0 to 200 (units unclear, likely millions) with a small sales team
- Every bit of open source software in the world is available in these tools, making previously-built things trivially easy to recreate
- Zevi Arnovitz groups Replit with Bolt, Lovable, Base44, and v0 as vibe coding platforms in the same bucket
- These tools share the same underlying models (Claude) but add abstraction layers that take guesswork out for users, trading control for ease
- Part of Lenny's Newsletter Product Pass (free one-year subscription for annual subscribers)
- Marc Andreessen's 10-year-old son independently discovered Replit and is obsessed with vibe coding Star Trek simulators using the LCARS design language
- Marc's son spends hours on Replit building games and simulators, particularly Star Trek-themed ones with Next Generation UI styling
