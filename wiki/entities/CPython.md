## Definition

CPython is the reference implementation of the Python programming language, written in C. Maintained by a core team of volunteer developers including Pablo Galindo Salgado and guided by Guido van Rossum (creator, now part-time at Microsoft).

## Key Information

- The default and most widely-used Python implementation
- Core team includes triagers and core developers who review contributions
- AI slop crisis: flooded with AI-generated PRs, security vulnerability reports, and "good first issues" claimed by bots in nanoseconds
- Policy forming: AI tools are okay, but PRs must show human involvement — no response to follow-up questions means PR gets closed after 2 weeks
- Anthropic donated $1.5M to the Python Software Foundation for security
- Guido van Rossum spent 4 years at Microsoft working on making CPython faster
