## Definition
Zustand is a lightweight state management library for React. OpenHands migrated their entire frontend from Redux to Zustand using parallel agent orchestration and scaffolding patterns.

## Key Information
- Lightweight React state management library
- OpenHands used parallel agents to migrate components from Redux to Zustand
- Scaffolding allowed both Redux and Zustand to coexist during migration, with scaffolding removed after all components were migrated
