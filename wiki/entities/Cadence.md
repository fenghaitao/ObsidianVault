## Definition
Cadence is a workflow orchestration project created at Uber that Temporal was forked from. Pretty much every application running at Uber runs on Cadence, because it allows developers to program the happy path while all durability is handled by the platform.

## Key Information
- Created at Uber as an internal workflow orchestration system
- Temporal was forked from Cadence
- Used by virtually every application at Uber
- Core value proposition: developers program the happy path, and the platform handles all durability concerns (retries, state management, crash recovery)
