## Definition
Expedia is a travel company mentioned in the MCP Apps talk as an example of a company whose branded UI could be sent as atomic chunks to chat hosts, preserving identity while enabling agents to compose travel experiences.

## Key Information
- Used as an example in the MCP Apps "new web" vision: instead of users navigating multiple websites, a personal assistant pulls UI chunks from Expedia alongside other services
- Represents the class of companies that could benefit from sending their own branded UI to chat hosts rather than being reduced to text
- Part of the argument that hosts don't need to generate all UIs — domain experts (like Expedia) have spent decades perfecting user journeys
