## Definition

Dia is an AI-native web browser built by The Browser Company of New York, shipped in early 2025. It features an AI assistant that works alongside users across all browser activities, with personalization, memory, and computer-use capabilities.

## Key Information

- Shipped in early 2025 by The Browser Company of New York
- AI-native: built with AI speed and security in mind from the ground up
- Features an assistant that personalizes, helps with tabs, and automates work through web apps
- Internal tooling (prompt editors, evals, data collection) built directly into the product
- Uses Jeba technique for prompt optimization
- Security model blends technology with UX confirmation steps for prompt injection prevention
- Predecessor: Arc browser (2022)
