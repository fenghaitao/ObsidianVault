## Definition

Cursor is an AI-powered code editor that helps developers reason over codebases and write code more efficiently.

## Key Information

- LinkedIn experimented with Cursor as one of the coding tools for the full-stack builder program.
- Like other third-party AI coding tools, Cursor could not work off-the-shelf on LinkedIn's codebase; it required a custom integration layer.
- LinkedIn is building a layer that allows tools like Cursor, Copilot, and Windsurf to reason over its codebase effectively.
- Cursor CEO Michael Turalda shared a vision on Lenny's Podcast of moving to something beyond code, including spec-driven development
- Cursor is mentioned as a competitor in the AI coding space, with Codex differentiating by aiming to be a proactive teammate rather than just an IDE assistant
- Zevi Arnovitz, a non-technical PM at Meta, uses Cursor with Claude Code as his primary development environment
- Cursor's Composer feature is "blazing fast" and keeps Zevi in flow for rapid feature implementation
- Cursor has a de-slop slash command (referenced by founders on Twitter) for cleaning up AI-generated code
- Zevi recommends a gradual path to Cursor: GPT Projects → Bolt/Lovable → Cursor in light mode → full terminal/dark mode
- Zevi uses Cursor's slash commands feature to create reusable prompts for his development workflow
- Boris Cherny briefly joined Cursor but left after 2 weeks, returning to Anthropic because he missed the mission-driven focus on safety
- Boris: "I'm a big fan of the product. I met the team and I was just really impressed. They're an awesome team"
- Boris: "They saw where AI coding was going, I think, before a lot of people did"

- Sherwin Wu references Cursor as part of the "current wave of AI" that makes programming "literally incantations" — you tell Cursor or Codex what you want and it goes and does it
- Cursor is mentioned alongside Codex as a tool that represents the shift from writing code to managing AI agents
