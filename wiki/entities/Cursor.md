## Definition

Cursor is an AI-powered coding tool that helps professionals build software faster with AI agents. It provides cloud-based coding agents with their own computers, enabling autonomous development workflows. Founded by Michael Truell, Cursor grew from 15 to 700 people in two years and now serves over 60% of the Fortune 500.

## Key Information

- **Cloud agents:** Coding agents get their own cloud computers with computer use capabilities (raw pixels in, mouse/keyboard out).
- **Onboarding agent:** Publicly available at cursor.com/onboard — explores codebases to figure out how to run them.
- **Agent Experience (AX):** Agents report their own issues via WCF (Work on the Factory) skill and iteratively improve their own workflows.
- **Computer use model:** Claude 4.7 (Opus) as the computer use model for autonomous testing and debugging.
- **Self-improving systems:** Agents validate their own fixes across eval sets before submitting PRs.
- **Partnership with Anthropic:** Deep, productive alignment between Cursor's product work and Anthropic's model capability increases.
