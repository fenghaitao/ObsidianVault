## Definition
Shigeo Shingo was a Japanese industrial engineer and a key figure in the Toyota Production System. In the keynote, his statement "value is only created when metal gets bent" is quoted as a warning against getting lost in building evaluation infrastructure without delivering actual user value.

## Key Information
- Key contributor to the Toyota Production System alongside Taiichi Ohno
- Known for developing SMED (Single-Minute Exchange of Dies) and poka-yoke (mistake-proofing) concepts
- His quote "value is only created when metal gets bent" emphasizes that tools, processes, and measurement are means to an end — only the final output for users creates real value
- In the LLM context, the message is: don't get lost building evals and calculating concept drift — make sure to "bend metal" (deliver value to users)
