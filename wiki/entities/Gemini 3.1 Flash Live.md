## Definition
Gemini 3.1 Flash Live is Google DeepMind's real-time multimodal interaction model that supports screen sharing, video feeds, and audio conversations with dynamic language switching, custom function calls, and Google Search grounding.

## Key Information
- Part of the Gemini 3.1 model series from Google DeepMind
- Supports real-time screen sharing, video feed sharing, and audio interaction
- Enables dynamic language switching during conversations (e.g., switching to Italian, Spanish, or Texan-accented English mid-conversation)
- Supports custom function calls and automatic function responses
- Integrates with Grounding with Google Search as a tool
- Can be used for robotics applications (e.g., Pupper robot)
- Accessible via AI Studio with "Get Code" for Python, TypeScript, and Java replication
