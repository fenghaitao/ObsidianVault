## Definition
Nitya Narasimhan is an observability expert on the Foundry developer relations team at Microsoft, specializing in agent tracing, evaluation, red teaming, and automated observability workflows.

## Key Information
- Observability expert on Microsoft's Foundry developer relations team
- Presented "Mind the Gap (In your Agent Observability)" at AI Engineer conference in London (2026-05-14)
- Led the SDK workshop portion covering: agent building, workflow agents, tracing (local and Azure Monitor), quality/safety/agentic evaluations, red teaming, and the emerging Observe Skill
- Demonstrated the **Observe Skill** — a coding agent that automates the eval-optimize loop: generates datasets, runs batch evals, optimizes prompts, compares versions, and rolls back to best performers
- Emphasized **trace-linked evaluations** as critical for shortening the time between detecting an issue and diagnosing it
- Described the workshop repo as a "4-hour workshop compressed into a cooking show" — designed for developers to try at home
