## Definition

Thariq Shihipar is a member of technical staff at [[Anthropic]] on the [[ClaudeCode]] team. He has authored multiple technical articles on Claude Code internals, tool design philosophy, prompt caching engineering, and HTML-based output patterns.

## Key Information

- Member of the Claude Code team at [[Anthropic]].
- Author of "The unreasonable effectiveness of HTML" (May 2026), advocating for HTML over Markdown as Claude Code's output format.
- Author of "Seeing like an agent: how we design tools in Claude Code" (April 2026), detailing tool design philosophy including the AskUserQuestion tool, Task tool, and Claude Code Guide subagent.
- Author of "Lessons from building Claude Code: Prompt caching is everything" (April 2026), detailing how Claude Code's harness is built around prompt caching.
- Author of session management and 1M context guidance (April 2026), covering `/rewind`, compact-vs-clear, and `/usage`.
- Describes himself as "far on the HTML maximalist side," having stopped using Markdown almost entirely for Claude Code outputs.
- Co-author (with Sid Bidasaria) of "A harness for every task: dynamic workflows in Claude Code" (June 2026), introducing dynamic workflows — Claude Code's ability to write and orchestrate its own multi-agent harness on the fly.
- Author of "Lessons from building Claude Code: How we use skills" (June 2026), distilling nine skill categories and internal best practices from Anthropic's experience with hundreds of skills.
