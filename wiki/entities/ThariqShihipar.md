## Definition
Thariq Shihipar is an engineer at Anthropic who works on the Claude Agent SDK and presents workshops on agent design and prototyping. Twitter handle: @TRQ212.

## Key Information
- Works at Anthropic on the Claude Agent SDK, which is built on top of Claude Code
- Advocates for the bash tool as the most powerful agent tool and the file system as a context engineering primitive
- Presented a full workshop on agent design covering the three-part agent loop (gather context, take action, verify work)
- Emphasizes that agents are "grown, not designed" — reading transcripts and iterating is the core meta-skill
- Believes the amount of code in an agent should be small (~50 lines) but elegant; the hard work is domain-specific design
- Recommends prototyping agents in Claude Code first, then porting to the Agent SDK
- Active on Twitter sharing Agent SDK content
