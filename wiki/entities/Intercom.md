## Definition
Intercom is a 15-year-old Irish-American B2B SaaS company (~1,400 people) that pivoted to become an AI company the weekend ChatGPT was released. It is a leading example of outcome-based pricing, a pioneer in AI-first engineering with its "2x" throughput doubling project, and the creator of Finn, an AI customer support agent with over 8,000 customers.

## Key Information
- **AI Transformation**: Pivoted to be an AI company when ChatGPT launched; building AI features since ~2018
- **Finn**: AI customer support agent with 8,000+ customers, revenue approaching $100M, launched on GPT-4 release day
- **Finn Scale**: ~2 million resolutions per week, now served 100% by Intercom's own model outperforming frontier models
- **Finn Customers**: Used by Anthropic, Snowflake, Linear, Glean, LaunchDarkly
- **2x Project**: Achieved doubling engineering throughput in under a year by consolidating on Claude Code
- **Platform Consolidation**: Chose Claude Code as unified AI coding platform after evaluating Cursor, Augment, GitHub Copilot
- **Skills Flywheel**: Hundreds of contributors building Claude Code plugins; session transcripts stored in S3 for analysis
- **Automated Code Review**: 17.6% auto-approval rate; SOC 2, ISO 27001, HIPAA compliant without humans in the loop
- **Tech Stack**: Ruby on Rails "majestic monolith"; engineering led from Dublin across Europe
- **Engineering**: ~1,400 people across Dublin, London, Berlin, SF, Chicago, Sydney; R&D led from Dublin
- **Developer Surveys**: Uses DX for developer productivity measurement
- **Observability**: Uses Honeycomb to track Claude Code skill invocations
- **Stanford Partnership**: Research group independently confirming code quality improvements
- **Culture**: Obsessed with shipping; "Shipping is the heartbeat of your company"
- Uses outcome-based pricing: prices based on number of tickets resolved without human need
- Builds on Stripe with hybrid pricing model
- Building internal AI infra alongside Uber, Airbnb, Meta, and Microsoft
- Featured in New York Times article about SaaS companies reinventing themselves in the age of AI
