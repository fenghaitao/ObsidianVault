## Definition
Cursor 3 is a complete rewrite of the Cursor IDE, removing the VS Code foundation and redesigning the interface for an agent-first workflow with multi-agent orchestration.

## Key Information
- Launched a couple of weeks before April 28, 2026
- Complete rewrite: no VS Code anymore
- Streamlined for agent-first workflow rather than traditional file-and-sidebar IDE
- Designed as a "control panel" for managing multiple agents
- Will support nested agents (opening one agent to see 10 sub-agents inside)
- Planned project view showing aggregated status updates across all running agents
- Built-in browser so users can stay within Cursor for all work
- One motivation: as users run more agents, they need better orchestration and introspection tools
