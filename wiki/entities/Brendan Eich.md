## Definition

Brendan Eich is the designer of JavaScript, noted by Xavier Leroy as a former Lisp person whose heritage gave JavaScript a functional core.

## Key Information

- Designed JavaScript; the episode identifies him as the (former) Lisp person behind it.
- JavaScript inherited "a little bit of heritage from Lisp" — an inner functional core that is "basically Lisp... but a very dynamic kind of Lisp."
- Leroy cites this heritage when acknowledging JavaScript's one redeeming functional property, while still disliking its extreme dynamism.
