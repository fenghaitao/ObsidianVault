# TypeScript

TypeScript is a statically typed superset of JavaScript that compiles to plain JavaScript. It adds optional static typing, interfaces, and advanced IDE support.

## Usage Context

At [[Anthropic]], data scientists use [[ClaudeCode]] to generate full [[TypeScript]] visualizations for [[React]] applications without being fluent in the language. One-shot prompting generates entire visualization implementations from natural language specifications.
