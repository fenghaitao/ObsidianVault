## Definition

Sketchpad is Ivan Sutherland's early-1960s interactive graphics program, widely seen as a founding system of computer graphics and CAD.

## Key Information

- A light-pen program that could draw like a modern CAD tool and apply constraints (e.g., "this line must be perpendicular to that line").
- Casey's "Big Oops" talk argues Sketchpad already solved the "edit one property across many objects" problem with an entity-component-system-like architecture.
