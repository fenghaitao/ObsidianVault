## Definition

Next.js is a React framework for building web applications. Jia Chen referenced Next.js as an example of a modern library she did not know when starting hackathons, and as a tech stack detail judges do not care about.

## Key Information

- Jia mentioned Next.js as one of the modern libraries she did not know when she started her first hackathon (she only knew Python)
- She cited Next.js as an example of a tech stack detail that hackathon competitors mistakenly emphasize during pitches instead of showing the demo
- Her advice: judges are often non-technical and want to see a working demo, not hear about the tech stack
