## Definition

React is a JavaScript UI library, created at Facebook, whose core concepts — components, immutability, re-rendering, and view reconciliation — let developers declare what the UI should be rather than imperatively managing views.

## Key Information

- Introduced the concepts of components, immutability, re-render-everything-when-something-changes, and view reconciliation.
- Was relatively new (even on the web) around 2014, when Adam Ernst transplanted its concepts to iOS in ComponentKit.
- Had strong credibility as a framework at Facebook on the web, which helped Adam Ernst argue the same approach would work on iOS.
- Lee Byron had done early work with React on the web before prompting the iOS adaptation.
