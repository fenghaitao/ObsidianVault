## Definition
Cloud Foundry was the early container technology on the market, incubated as an open-source project at VMware. It used container images, Linux containers, container orchestration, and eventual consistency before Docker and Kubernetes existed.

## Key Information
- Incubated as an open-source project at VMware
- Used Linux containers, container images, container orchestration, and eventual consistency
- Predated Docker and Kubernetes
- Cornelia Davis worked at Pivotal on Cloud Foundry from the early 2010s
- Was part of the early movement toward platforms supporting agile, distributed systems architectures
