## Definition
Very (very.com) is a UK-based online retailer and marketplace, used as a live demo target during Rafael Levi's talk on building web scraping pipelines. It was suggested by an audience member as a popular UK site with aggressive anti-bot blocking.

## Key Information
- UK online retailer and marketplace
- Used as an impromptu live demo target for scraper building during the aiDotEngineer talk
- Selected because it was described as aggressively blocking scrapers in the UK
- Rafael successfully built a scraper for Very.com live during the talk, extracting 90 products
- The scraper demonstrated ~62% token savings compared to full-page HTML parsing
