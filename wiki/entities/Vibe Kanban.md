## Definition
Vibe Kanban (company: Vibe Canvas) was a developer tool for parallelizing coding agents, allowing engineers to run multiple AI coding agents simultaneously across separate workspaces. It supported 8 popular coding agents, had 30,000 monthly active users and 25,000 GitHub stars, and was shut down in May 2026.

## Key Information
- Founded by Louis Knight-Webb about a year before May 2026
- Core value proposition: run multiple coding agents in parallel so that when you finish reviewing one, another has completed
- Supported 8 popular coding agents including Codex and Claude Code
- Features: multiple workspaces, diff-based code review, live preview, commenting, PR automation
- Had 30,000 monthly active users and 25,000 GitHub stars
- Shut down live on stage at AIE CODE 2026
- Reason for shutdown: unsustainable business model — $30/user subscription while users spent $3,000 on Codex tokens through the platform. Did not sell to enterprise or resell tokens, the two things that make money in the current AI tools market.
- Project continues non-commercially; team members found jobs at Agent Labs and similar companies
- Built on the insight that as agent runtimes cross the 5-minute threshold, engineers need to run multiple agents in parallel
