## Definition
Lyra 3 is a music generation model from Google DeepMind, available via the Gemini API. It can generate full songs with lyrics, including a clip model for 30-second clips and a full song model for complete tracks.

## Key Information
- Music generation model on the Gemini API
- Can generate songs with lyrics
- Clip model: generates ~30-second music clips
- Full song model: generates complete songs
- Requires a paid API key (billing account) for music generation
- Demonstrated in the Live Jukebox DJ app: a conversational agent using Gemini Live API calls Lyra 3 as a tool to generate music on demand
- Example: generated German techno Schlager about UK AI scene, and Swahili nursing techno hardcore song
