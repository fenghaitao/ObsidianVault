## Definition
Android Studio is Google's official IDE for Android development, which now includes an agent mode with offline AI assistance powered by Gemma running locally via llama.cpp or vLLM.

## Key Information
- Features an agent mode that helps developers write code and develop Android apps
- Supports an offline mode where Gemma runs locally via llama.cpp or vLLM for AI-assisted coding
- Gemma was trained with Android-related datasets and benchmarks, making it particularly capable for Android development
- Enables on-device AI assistance without requiring cloud API calls
