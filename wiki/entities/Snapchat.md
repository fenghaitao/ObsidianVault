## Definition

Snapchat is a social media app used by Butterfield as an example of how "reducing taps" is the wrong goal — the right goal is making every interaction trivially easy.

## Key Information

- Butterfield observed a teenager using Snapchat while boarding a plane, tapping 4-7 times per second for 6 minutes with complete fluidity
- Every interaction was trivially easy — no thinking required, just instinctive taps
- This illustrates that reducing the number of clicks/taps is almost always the wrong goal; the right goal is making every single interaction trivially easy and thought-free
- If Snapchat's goal had been to reduce taps, it would have been an impediment to the experience both the user and Snapchat wanted to create
