## Definition
Mehedi Hassan is a Product Engineer at Granola who spoke at the AIE Code Summit about building feedback loops for AI product development.

## Key Information
- Product Engineer at [[Granola]], a meeting notes app with real-time transcription and AI-generated summaries
- Has been coding since jQuery was popular; experienced the React transformation of front-end engineering and now the LLM transformation
- Presented "Feedback Loops are All You Need" at [[aiDotEngineer]]'s AIE Code Summit
- Advocates for building custom tracing tools and rapid testing infrastructure (web shell pattern) rather than trying to "one-shot better"
- Philosophy: make the feedback loop feel like "playing tennis with an LLM" so the end product feels like magic, not a black box
