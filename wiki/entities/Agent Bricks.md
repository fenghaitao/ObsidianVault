## Definition
Agent Bricks is a higher-level Databricks offering that packages orchestration patterns for common multi-agent use cases, so teams don't need to rebuild coordination, state management, and failure recovery patterns from scratch for every project.

## Key Information
- Higher-level abstraction on Databricks for multi-agent orchestration
- Packages common orchestration patterns so teams don't rebuild them
- Sits above LangGraph, Mosaic AI Agent Framework, and Unity Catalog
- Designed to make building production multi-agent patterns easier
- Referenced as part of the end-to-end Databricks production architecture
- Addresses the reality that most teams shouldn't need to implement circuit breakers, immutable state, and compensation patterns from scratch
