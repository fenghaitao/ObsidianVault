## Definition
Matthias Luebken is co-founder of Seven AI, a small European startup building AI agents for organizations. He presented at AIE Code Summit on embedding the OpenClaw coding agent into products using Pi as the core agent framework.

## Key Information
- Co-founder of [[Seven AI]], based in Europe
- Presented a practical system for sales RFP processing: email monitoring → per-customer agents (each with agent.md and customer.md) → session reuse → draft generation
- Advocates the architectural pattern of making systems easy for coding agents by exposing functionality via CLIs rather than complex APIs
- Emphasizes the progression from agent core (LLM + tools loop) → coding agent (adds shell/runtime) → OpenClaw (multi-channel, multi-agent)
- Key takeaway: "Coding agents are and will be a core building block for your software systems"
- References Ken Thompson's Unix philosophy ("Write programs that do one thing and do one thing well") as guiding principle for agent design
- Stresses that there are no established patterns yet — "we're in the fuck around and find out phase for coding agents"
