## Definition

Sonnet 4 is an Anthropic model that, along with Opus 4, was the first generation where Claude Code became good enough to write a lot of code. It was the inflection point for the product.

## Key Information

- Anthropic model released alongside Opus 4
- Together with Opus 4, was the first generation where Claude Code could write a lot of code
- Part of the inflection point where Claude Code adoption went exponential
- Followed Sonnet 3.5, which could only run 15-30 seconds before going off the rails
