## Definition
Make Real was a 2023 tldraw project by Steve Ruiz that allowed users to draw UI mockups on a canvas, send them to a vision model, and receive working HTML prototypes. It was one of the first AI projects to "break containment" and enable non-technical people to create technical artifacts without coding.

## Key Information
- Built in 2023 when vision models first emerged
- Workflow: draw UI on canvas → send to vision model → receive working HTML prototype
- Predated Lovable and the term "vibe coding"
- Allowed annotation-based iteration: draw on top of the output and say "make this green," "use these colors"
- One of the first projects where non-technical people could make technical stuff without coding or looking at code
- The prompt included both the old website and the new annotations, constructing a rich context
- Was considered groundbreaking at the time but seems "quaint" by 2026 standards
