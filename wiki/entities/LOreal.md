## Definition

L'Oréal is a retail-sector company using Claude for conversational analytics, letting business users query data directly in natural language instead of waiting for custom dashboards.

## Key Information

- Achieved 99.9% accuracy on conversational analytics.
- Enables 44,000 monthly users to query data directly.
- Built a [[MultiAgentSystem|multi-agent system]] with Claude at the core, orchestrating 15+ specialized agents that transform user questions into insights and visualizations for 44,000 employees across 150 countries.
