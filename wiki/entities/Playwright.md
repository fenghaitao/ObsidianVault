## Definition

Playwright is a browser automation tool by Microsoft, used for end-to-end testing of web applications. Simon Wilson mentions it as a tool that can be used by AI coding agents to simulate browser interactions for automated testing.

## Key Information

- Browser automation tool for end-to-end testing
- Can be used by AI coding agents to simulate browser interactions
- Simon Wilson: "You can tell Claude Code, 'Fire up a sub-agent that uses Playwright to simulate a browser'" for automated testing
