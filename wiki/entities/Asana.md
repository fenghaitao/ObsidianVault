## Definition
Asana is a project management and task tracking tool. It is the Kiro team's task tracker of choice and can be integrated with Kiro via MCP to pull tasks directly into spec generation.

## Key Information
- Used by the Kiro team as their task tracker
- Can be integrated with Kiro via MCP: Kiro recognizes Asana URLs and pulls task metadata for spec generation
- In the demo, Al Harris showed Kiro pulling tasks from Asana to generate requirements, design, and implementation
- Example MCP server for Asana integration: "Lofty Views" (open-sourced by Al Harris on GitHub)
