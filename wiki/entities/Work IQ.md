## Definition
Work IQ is a Microsoft-developed skill that allows developers to connect their coding agents to the Microsoft 365 (M365) suite — including Outlook, PowerPoint, and other M365 applications — bringing information from those tools directly into the terminal.

## Key Information
- Microsoft skill for M365 suite integration
- Connects to Outlook, PowerPoint, and other M365 applications
- Brings work context (emails, feature requests, documents) into the developer's terminal
- Demonstrated by Marlene Mhangami: pulled feature request details from an Outlook email directly into GitHub Copilot CLI
- Enables feature-request-driven testing: feature arrives via email, agent reads it, writes tests for it
- Recommended for developers using the M365 suite for work
