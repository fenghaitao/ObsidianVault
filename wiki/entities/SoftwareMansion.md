## Definition
Software Mansion is a Polish software company that builds Fish Jam, a WebRTC service providing easy integration with the Gemini Live API for real-time audio/video applications.

## Key Information
- Based in Poland
- Builds Fish Jam, a WebRTC service for Gemini Live API integration
- Integration partner for Gemini Live API
- Part of Google DeepMind's partner ecosystem
