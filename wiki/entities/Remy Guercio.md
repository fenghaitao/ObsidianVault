## Definition
Remy Guercio is a speaker from Tailscale who presented at the AIE Code Summit (aiDotEngineer) on the concept of using the network layer as a sandbox for AI agents.

## Key Information
- Works at [[Tailscale]]
- Presented at AIE Code Summit 2026 ([[aiDotEngineer]])
- Core thesis: move authentication (authN) and authorization (authZ) from the application layer to the network layer using WireGuard and Tailscale identity primitives
- Demonstrated [[Aperture (Tailscale)]], Tailscale's AI gateway built on network-level identity
- Advocated for keyless agent sandboxes where network identity replaces API keys
- Emphasized the value of network-layer observability for agent tool calls — you see everything because it must go through the gateway
