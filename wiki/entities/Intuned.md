# Intuned

[[Intuned]] is a browser automation platform that leverages [[Claude3Haiku]] with [[ToolUse|tool use]] capabilities to power AI-driven data extraction within its cloud platform.

## Overview

- **Type**: Browser automation and data extraction platform
- **Primary focus**: AI-powered data extraction for web automation
- **LLM partner**: Uses [[Claude3Haiku]] for optimal performance/cost tradeoff
- **Key capability**: [[ToolUse|Tool use]] for intelligent data extraction workflows

## Platform Capabilities

Intuned enables developers to:
- Build more reliable browser automations through AI-powered data extraction
- Extract structured data from web pages intelligently
- Automate complex data workflows with natural language interfaces
- Scale data extraction tasks efficiently

## Performance Characteristics

**Model choice**: [[Claude3Haiku]] selected for:
- Fast inference speed
- Cost effectiveness
- Unmatched quality/speed/price combination
- Capability for production-grade data extraction

**Impact**: Drastically improved developer experience in building and executing browser automations

**Quote** (Faisal Ilaiwi, Co-Founder):
> "Claude 3 Haiku with tool use has been a game changer for us. After accessing the model and running our benchmarks on it, we realized the quality, speed, and price combination is unmatched. Haiku is helping us scale our customers' data extraction tasks to a completely new level."

## Use Cases

- Web data extraction
- Form filling automation
- Dynamic content extraction
- Complex workflow automation
- Enterprise data pipelines
