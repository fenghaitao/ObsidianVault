## Definition
Hugo Santos is the CEO and co-founder of Namespace, a company building high-performance compute infrastructure designed to eclipse the traditional CI/CD paradigm. He previously led microservices at Google.

## Key Information
- CEO of [[Namespace]], building next-generation compute infrastructure for agentic software development
- Formerly led microservices at Google
- Presented at AIE Code Summit 2026 on why CI/CD is dead and Continuous Compute must replace it
- Works with companies at the forefront of development ([[Fall]], [[Zed]], [[Ramp]]) to understand the transition from traditional CI/CD to agent-native workflows
- Advocates for an architecture with no PRs: intent-and-plan loops with internal and external validation by agents
- Describes the Git repository as a "ledger" requiring serializability for parallel agent changes
- Proposes a "pre-merge queue" to reconcile parallel agent changes before human approval
- Predicts "The Multiverse" where agents work on multiple commit candidates simultaneously
- Emphasizes that statefulness, memory, and incremental workflows are critical for agent development speed
