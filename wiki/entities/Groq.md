## Definition
Groq is a hardware company building specialized chips for AI inference with very high memory bandwidth, positioned as intermediate specialization between general-purpose GPUs and model-specific chips like Talos. Not to be confused with Grok (xAI's model).

## Key Information
- Builds chips with very high memory bandwidth optimized for inference workloads
- In data centers, Groq chips run part of the inference pipeline paired with Nvidia GPUs
- Positioned on the hardware specialization spectrum: general-purpose GPUs → Cerebras/Groq → Talos
- Alex Cheema notes the same heterogeneous approach used in data centers (Groq + Nvidia) will happen locally (Spark + Mac)
- Nvidia's acquisition of Groq (mentioned in transcript) signals consolidation toward inference-optimized hardware
