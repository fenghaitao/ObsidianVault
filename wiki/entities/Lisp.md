## Definition
Lisp is a mostly functional programming language whose commercial hardware incarnation was the Symbolics Lisp machine.

## Key Information
- Described in the episode as "a mostly functional programming language."
- Symbolics built the Lisp machine, a commercial piece of hardware designed specifically to execute Lisp programs.
- SPJ cites plain Lisp ("in its inner basic form") as the kind of 15-year-old, untyped code that becomes almost immutable and painful to maintain.
