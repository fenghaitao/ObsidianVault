## Definition
Danilo Campos is a software engineer at PostHog and the creator of the PostHog Wizard, an autonomous coding agent that performs 15,000 successful integrations per month by skipping "2 hours of misery" and delivering working integrations in 8 minutes.

## Key Information
- Works at PostHog, building the PostHog Wizard
- The Wizard is an autonomous coding agent that integrates PostHog into users' projects
- Processes 15,000 integrations per month
- The Wizard is built using the Claude Agent SDK wrapped in a CLI
- PostHog covers inference costs via an LLM gateway, giving users free inference
- Identified six failure modes of autonomous coding agents: model rot, weird architecture, improvisation at scale, human error, security shenanigans, and code as depreciating asset
- Introduced the concepts of model airplanes (thin reference implementations), breadcrumbing (progressive task disclosure), and inference-time interrogation (asking agents what went wrong)
- Advocates for prose (markdown, documentation) over code as the primary value carrier in agent systems
- Presented at AIE CODE 2026
