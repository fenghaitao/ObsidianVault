## Definition
Morgan Stanley is a financial services company that has publicly shared its AI-assisted engineering initiatives, particularly around legacy code modernization.

## Key Information
- Built "Dev Gen AI," a system that analyzes legacy code (COBOL, mainframe, Natural, Perl) and generates specs for developers to modernize code without manual reverse engineering
- Saving approximately 300,000 hours annually through this AI-driven legacy modernization approach
- Publicly documented in Wall Street Journal and Business Insider articles
- Cited as an example of integrating AI across the SDLC beyond just code completion
