Adam Wolfe is an engineer at Anthropic who built the bash tool for Claude Code, handling complex challenges like race conditions when running parallel sub-agents. Described by Thariq Shihipar as "a legend."

## Key Information
- Built the bash tool for Claude Code, which is considered the most powerful agent tool
- Solved complex engineering challenges around running parallel sub-agents with bash, including race conditions
- Has presented or was scheduled to present at QCon about how the bash tool was built
