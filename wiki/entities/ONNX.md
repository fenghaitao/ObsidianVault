## Definition
ONNX (Open Neural Network Exchange) is an open standard for representing machine learning models and one of the inference frameworks contributing to the fragmentation that MAX consolidates.

## Key Information
- One of the first-generation inference frameworks that emerged as inference became more important than training
- Contributed to the fragmented ecosystem of inference tools alongside TensorRT and model-specific frameworks
- [[MAX]] supports ONNX as an import path alongside PyTorch and TorchScript
- Part of the evolution from training-focused frameworks (PyTorch, TensorFlow, Caffe) to inference-focused tools
