## Definition

Build New is Brian Casel's free open-source Ruby on Rails + React starter application template. It provides a pre-configured tech stack with his design system built in, allowing builders to start new apps quickly without repetitive setup.

## Key Information

- Tech stack: Ruby on Rails backend with React frontend.
- Comes with Brian's [[DesignSystem]] pre-installed, providing consistent UI components out of the box.
- Available at buildermethods.com/tools.
- Used as the starting point for all of Brian's internal tools (CRM, invoicing, content pipeline apps).
- Designed to work with [[ClaudeCode]] and other coding agents.
- Includes built-in admin area with design system documentation page.
