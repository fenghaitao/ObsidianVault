## Definition
Bitly is a link shortener company where Michael Richman leads several engineering teams and co-leads the AI coding tools strategy. The company has built its own MCP server and actively uses multiple AI coding agents in its engineering workflows.

## Key Information
- Best known as a link shortener service.
- Michael Richman leads several engineering teams there and co-leads the AI coding tools strategy.
- Has a hands-on engineering culture — leadership writes code alongside managing teams.
- Co-developed the Bitly MCP server.
- Actively trains engineers on AI skills and best practices.
- Uses multiple coding agents including Claude Code, Codex, Cursor, Gemini, and GitHub Copilot.
