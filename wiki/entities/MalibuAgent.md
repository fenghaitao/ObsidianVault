# Malibu Agent

## Definition

Malibu Agent is Poolside's second-generation AI model, trained from scratch using proprietary reinforcement learning techniques. It powers Poolside's coding assistant and is designed for software development and long-horizon knowledge work.

## Key Information

- **Generation**: Second-generation model from Poolside
- **Training**: Trained from scratch using Poolside's proprietary RL+LLM techniques
- **Capabilities**: Coding (codebase analysis, language conversion, testing, feature addition), general knowledge work, emotional intelligence
- **Interface**: Available as a VS Code extension with live diff view, plus web and desktop agent interfaces
- **Deployment**: Runs in Poolside's satellites
- **Successor**: Third-generation model coming early 2026 with significantly more compute
