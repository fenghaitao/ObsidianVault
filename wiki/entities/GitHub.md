## Definition

GitHub is a code hosting platform for version control and collaboration. In the AI vibe coding context, it serves as an export target where AI-built projects can be downloaded and imported into other tools for diagnostics.

## Key Information

- Used by Lazar to export Lovable projects for debugging in external tools like Codex
- Lovable and Cursor both allow users to own their code and export to GitHub
- Serves as a bridge between AI coding tools and diagnostic/analysis tools
