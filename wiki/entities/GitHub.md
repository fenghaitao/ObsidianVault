## Definition

GitHub is a code hosting platform for version control and collaboration. Jia Chen used GitHub activity to evaluate potential hackathon teammates, and recommended posting projects on GitHub to stand out to recruiters.

## Key Information

- Jia's team selection strategy: look at people's GitHub projects to see how active their commits are and what experience they have with the relevant use case
- This was a better method than selecting teammates based on credentials like PhD research or internships
- Jia recommended that students get their projects out of localhost and onto the cloud, noting that GitHub makes it easier to link projects to recruiters
