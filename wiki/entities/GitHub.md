## Definition

GitHub is a code hosting platform for version control and collaboration. Jia Chen used GitHub activity to evaluate potential hackathon teammates, and recommended posting projects on GitHub to stand out to recruiters.

## Key Information

- Jia's team selection strategy: look at people's GitHub projects to see how active their commits are and what experience they have with the relevant use case
- This was a better method than selecting teammates based on credentials like PhD research or internships
- Jia recommended that students get their projects out of localhost and onto the cloud, noting that GitHub makes it easier to link projects to recruiters

### Michael Bolin on GitHub's Acquisition
- Nuclide's client was built on GitHub/Atom technology, so Microsoft's acquisition of GitHub made Bolin anxious that Microsoft would deprioritize Atom (a prediction that eventually came true).
- His pushing around that risk — telling people their cheese was about to be moved — was correct in hindsight but came across too hard and delayed his promotion ([[summary-20260309 - OpenAI Codex Tech Lead： How His Career Grew And How He Uses Codex ｜ Michael Bolin]]).

### David J. Malan's Sabbatical
- Spent a sabbatical semester as "professor in residence" at GitHub, learning real-world software engineering and advocating for educational use cases.
- Didn't contribute code, but contributed issues, bug reports, and feature requests, especially speaking up for students and teachers in VS Code and internal GitHub tooling design.
