## Definition

GitHub, the code-hosting and pull-request platform, is cited by [[Dan Shipper]] as an example of infrastructure strain caused by agentic coding at scale.

## Key Information

- Dan Shipper says GitHub is "having problems right now" because the number of people (really, agents acting on people's behalf) opening pull requests is skyrocketing exponentially, as coding agents let far more non-engineers make PRs.
- Every's open-source product [[Proof]] uses GitHub as the destination for structured, agent-generated bug reports, which then get triaged and fixed by an agent.
- Given as an example of the "shape of work" prediction: the volume of pull requests any given company must review is rising sharply as more non-technical people can generate code via agents.
- Per [[Lazar]] (episode 27, professional vibe coding at [[Lovable]]): exports Lovable/Cursor projects to GitHub so he can bring in external diagnostic tools ([[Codex]], or [[Claude Code]]/[[ChatGPT]] via a [[Repomix]]-compressed export) when he's stuck on a bug — step 3 of his "[[4x4 Debugging Framework]]."
