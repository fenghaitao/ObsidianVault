## Definition
Imagen is an image generation tool integrated as a Codex skill that allows agents to generate visual assets for apps and games. It is particularly useful for creating sprites, game assets, and other visual elements programmatically during development.

## Key Information
- Available as a Codex skill for generating visual assets
- Bundled into the Game Studio plugin alongside Playwright Interactive
- Used to generate game sprites, character animations, and visual assets without manual design work
- Can generate 2D versions of user photos for custom game characters
- Demonstrated generating at least five different character sprites for a platformer game built entirely by Codex
- Part of the web and game development plugin ecosystem in Codex
