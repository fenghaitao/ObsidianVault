## Definition
Lovable is an AI app builder company. Eric Zakariasson referenced a friend at Lovable who set up a Slack vent channel for agents to complain about issues they encountered during execution.

## Key Information
- Gave agents a Slack vent tool to complain about problems
- Initially set up as a joke, but the agent complaints turned out to be highly valuable feedback
- Example: agent complained about not being able to access images → team added image reading capability → agent then complained about harness problems
- Demonstrates the principle of "letting agents be free" and listening to their feedback
