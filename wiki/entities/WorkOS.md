# WorkOS

## Definition

WorkOS is a platform that makes applications and AI agents enterprise-ready. It powers authentication for major AI companies including Anthropic, Cursor, and OpenAI. WorkOS is driving the Cross-App Access (XAA) standard for MCP authentication.

## Key Information

- **Core Product**: Enterprise readiness for apps and agents, including SSO, directory sync, and audit trails
- **AI Customers**: Anthropic (Claude Code), Cursor, OpenAI — if you've logged into Cursor with username/password or an enterprise IDP, you've used WorkOS
- **XAA Implementation**: Built support for the ID JAG flow in MCP clients, handling SSO connection, ID JAG token requests, and token exchange with MCP servers
- **Product Leadership**: Garrett Galow runs product, with nearly 15 years of enterprise developer platform experience
- **Role in MCP Ecosystem**: Enables MCP clients like Cursor and Claude Code to implement XAA-compatible SSO connections
