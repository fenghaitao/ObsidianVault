## Definition
Nano Banana 2 is Google DeepMind's image generation and editing model, available via AI Studio. It supports image search grounding for more accurate generation and is more cost-effective than previous iterations.

## Key Information
- Image generation and editing model from Google DeepMind
- Available via AI Studio with "Get Code" for Python and TypeScript replication
- Supports image search grounding (reverse image search) for tighter alignment with prompts
- Supports variable aspect ratios from 520 pixels up to 4K resolution
- More cost-effective than previous Nano Banana iterations
- Used in Genie 3's model composition pipeline
- Can combine multiple reference images with text prompts for composite generation
- Demonstrated generating a dog in a natural park setting holding a specific product
- Part of the GenMedia suite alongside VEO (video), Lyria (music), and TTS (speech)
