## Definition
LibreChat is an open-source AI chat platform that supports MCP Apps as both a client and host, rendering interactive UI from MCP servers. It exemplifies the "write once, run everywhere" promise of MCP Apps.

## Key Information
- Supports MCP Apps as a client/host
- Open-source chat platform
- Mentioned as an example of MCP Apps' cross-platform compatibility: the same MCP App codebase works on LibreChat as on ChatGPT, Claude, and other hosts
- Part of the growing ecosystem of tools adopting the MCP Apps standard
