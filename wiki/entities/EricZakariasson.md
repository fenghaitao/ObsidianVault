## Definition
Eric Zakariasson is an engineer at Cursor working on developer experience and product. He presented at aiDotEngineer on building a "software factory" using Cursor's agent infrastructure.

## Key Information
- Works at Cursor on developer experience and product
- Dogfoods Cursor extensively, running 5-10 agents asynchronously in the cloud at all times
- Built a music agent project (Ableton-like UI) using only agents, never writing code himself
- Advocated for rules emerging dynamically from agent failures rather than being pre-installed
- Created internal automations at Cursor: daily review summaries, PR comment extraction, agentic code owners, and continual learning plugins
- Described the shift from "worker to manager" as the key mindset change when building a software factory
- Recommends isolated VMs (Cloud Agents) over shared workspaces for parallel agent work
- Believes humans remain accountable for shipped code; critical systems should still be human-reviewed
