## Definition

Claude is a family of large language models and the platform built around them by [[Anthropic]]. It provides conversational AI capabilities, code generation, analysis, and a platform for building AI-powered applications.

## Key Information

- Developed by [[Anthropic]] as a leading AI assistant platform
- Available across multiple interfaces: web (Claude.ai), mobile apps, API, and IDE integrations
- Supports [[ToolUse]] for integrating with external APIs and services
- Trained using [[ConstitutionalAI]] alignment methodology
- Powers interactive artifacts for building and sharing AI-powered apps directly within the platform
- Available on Free, Pro, and Max subscription tiers, with Team and Enterprise options
- Positioned as the tool for AI-native founders across the startup lifecycle (Idea, MVP, Launch, Scale), per Anthropic's "Founder's Playbook" (May 2026), which frames the founder's role as shifting from individual contributor to orchestrator of AI-driven work
- Available on Apple platforms (iOS 27, iPadOS 27, macOS 27, visionOS 27, watchOS 27) via a Swift package that connects [[AppleFoundationModels|Apple's Foundation Models framework]] to Claude, enabling [[ModelHandoff|model handoff]] from on-device to cloud reasoning (June 2026)
