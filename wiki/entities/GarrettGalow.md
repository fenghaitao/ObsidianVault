# Garrett Galow

## Definition

Garrett Galow runs product at WorkOS. He has been building enterprise developer platforms for nearly 15 years, previously at Microsoft Azure and Cloudflare. He presented on Cross-App Access (XAA) for MCP at the AI Engineering Code Summit.

## Key Information

- **Current Role**: Runs product at WorkOS, which makes apps and agents enterprise-ready
- **Previous Experience**: Microsoft Azure, Cloudflare
- **Notable Work**: Presented the XAA (Cross-App Access) solution for MCP, built on the ID JAG spec, to eliminate consent screen fatigue in MCP authentication
- **Personal Experience**: Was personally affected by the NPM Axios package compromise, which highlighted the security gaps in MCP's current OAuth model — API keys and MCP server credentials persisted even after IT revoked his Okta sessions
