## Definition
Aparna Dhinakaran is a speaker and contributor at Arize, an AI observability and evaluation platform. She works on prompt learning, LLM evaluation, and improving coding agent performance.

## Key Information
- Presented on prompt learning at aiDotEngineer, demonstrating how English-language feedback from LLM-as-judge evals can be used to iteratively improve coding agent system prompts.
- Led experiments on Claude Code and Cline using SWE-bench, achieving 5% and 15% improvements respectively through prompt learning alone with only 150 training examples.
- Emphasizes eval engineering — crafting high-quality LLM-as-judge prompts that produce detailed, actionable explanations — as the critical factor in successful prompt learning.
