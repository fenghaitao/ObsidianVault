## Definition
Microsoft is a global technology company that invested in Arize's Series C funding round, alongside Datadog.

## Key Information
- Investor in Arize's Series C round, alongside Datadog — signals enterprise interest in AI observability and evaluation platforms
- Contributor to OpenClaw: has someone on board to help with MS Teams integration and a Windows app
- Part of the Open Claw Foundation alongside Nvidia, Red Hat, Telegram, Salesforce, Tencent, ByteDance, and others
- Has an internal AI token usage leaderboard; engineers run autonomous agents to build junk to increase token count
- Building internal AI infra alongside Uber, Airbnb, Intercom, and Meta
- **Microsoft Foundry**: Cloud agent platform (ai.azure.com) for end-to-end agent development — build, host, observe, and manage AI agents with OpenTelemetry tracing, built-in evaluators, red teaming, workflow agents, and coding agent skills for automated observability
- **Agent observability leadership**: Foundry developer relations team (Amy Boyd, Nitya Narasimhan) presented comprehensive agent observability framework at AI Engineer London 2026, including the emerging Observe Skill for automated eval-optimize loops
