## Definition

METR (Model Evaluation & Threat Research) is an AI evaluation organization that measures frontier model capability using a "time horizon" methodology: the length of real-world software tasks (as humans would need to complete them) a model can complete autonomously with a given success rate.

## Key Information

- Cited by Anthropic's Cat Wu (Head of Product, Claude Code) to quantify the pace of model improvement: when Claude Code was first built on [[Claude3.5Sonnet|Sonnet 3.5 (new)]] (fall 2024), METR measured it could reliably complete tasks taking a human ~21 minutes.
- By [[Claude4.6Opus|Opus 4.6]] (2026), METR found the model completes tasks taking a human almost 12 hours, about half the time — roughly a 41x increase in time horizon over 16 months.
- Published via metr.org/time-horizons.
