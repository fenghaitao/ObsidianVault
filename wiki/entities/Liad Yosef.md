## Definition
Liad Yosef is the co-creator of MCP Apps (the first official MCP extension for UI) and co-founder of Ergo Labs, a company focused on human agentic interfaces. He co-presented on MCP UI and MCP Apps at aiDotEngineer 2026 alongside Ido Salomon.

## Key Information
- Co-creator of MCP Apps, the standardized MCP extension for passing UI over the Model Context Protocol
- Co-founder of Ergo Labs, a company building human agentic interfaces
- Co-presented at aiDotEngineer 2026 with Ido Salomon on MCP UI and MCP Apps
- Partnered with Anthropic and OpenAI to standardize MCP Apps as the first official MCP extension
- Advocates for a "new web" paradigm where personal assistants compose experiences from atomic UI chunks rather than users navigating monolithic websites
