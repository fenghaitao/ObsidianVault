## Definition

Grafana is an open-source observability and monitoring platform for traditional software applications. It is mentioned as an established traditional observability tool that handles metrics, traces, and spans for deterministic applications, but is not designed for the qualitative and semi-structured data needs of agent observability.

## Key Information

- Open-source observability platform for metrics, traces, and logs
- Represents the established traditional observability category alongside Datadog
- Used by organizations to monitor application uptime, latency, error rates, and technical performance
- Not designed for agent-specific observability needs: unstructured text, qualitative scoring, non-deterministic behavior assessment
- Phil Hetzel cited Grafana as an example of tools companies already have, raising the question "why wouldn't this solve agent observability?" — the answer being that agent observability has fundamentally different scope and data requirements
