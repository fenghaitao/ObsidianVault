## Definition
Code OSS is the open-source base of Visual Studio Code. Amazon Kiro (like Cursor and Windsurf) is a fork of Code OSS.

## Key Information
- Kiro is a Code OSS fork, similar to Cursor and Windsurf
- The Code OSS codebase is described as "very large" and "fairly large" — one of the challenges the Kiro team faces
- Despite its size, the Code OSS codebase is reasonably well-structured, which helps agents work with it
- Kiro team used spec-driven development to build features in the Code OSS codebase they didn't understand particularly well (not being VS Code devs)
- Codebase indexing for large codebases like Code OSS is an active area of work for the Kiro team
