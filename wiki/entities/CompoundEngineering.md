## Definition

Compound Engineering is a free Claude Code plugin from Every that provides structured workflows for plan → execute → review cycles using specialized sub-agents (security sentinel, architect, strategist). It creates plans, executes them, and reviews results through parallel sub-agents.

## Key Information

- Free plugin available in the Claude Code marketplace.
- Core workflow: plan → do → review → be done (four commands).
- Review phase spawns specialized sub-agents in parallel: security sentinel, architect, strategist.
- Creates to-do files for all findings during review.
- Used by Colleen Schnettler for her LinkedIn tool development.
- Simpler alternative to more complex frameworks with 50+ slash commands.
