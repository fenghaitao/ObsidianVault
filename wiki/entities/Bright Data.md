## Definition
Bright Data is a web data platform that provides infrastructure for web scraping at scale, including an MCP with 66 tools, 150M+ IPs, captcha solving, anti-bot unlocking, remote browser infrastructure, and pre-built APIs for 500+ domains. It enables LLM agents to access any public website without getting blocked.

## Key Information
- Provides MCP (Model Context Protocol) with 66 tools for web access, including scrape as markdown, full HTML extraction, and domain-specific APIs
- Maintains over 150 million IPs for proxy rotation and geo-targeting
- In-house AI captcha solving, including click-and-hold challenges and interactive verification
- Handles aggressive anti-bot systems: Cloudflare, Akamai, DataDome
- Remote browser infrastructure: can open 1,000+ browsers on Bright Data servers from a single laptop
- Browsers mimic human behavior: pre-recorded mouse movements (no teleportation), variable typing speed with natural mistakes
- 500+ pre-built APIs for domains like Amazon — agents can get structured JSON without building scrapers
- Offers 5,000 free requests for new accounts
- Won lawsuits against Meta and Elon Musk (X/Twitter) affirming public data is public
- Only deals with public data — nothing behind login walls, does not accept terms and conditions on behalf of users
