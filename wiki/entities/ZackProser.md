## Definition
Zack Proser is a Developer Experience (DX) engineer at WorkOS on the applied AI team. He co-presented a workshop on writing and using AI agent skills at scale at the AI Engineer Summit (aiDotEngineer).

## Key Information
- **Role**: Developer Experience Engineer at WorkOS, applied AI team
- **Notable Work**: Built NanoBanana wrapper skill (static image generation → Veo video animation in ~30 seconds); built Slack-Linear automation skill (monitors Slack for new asks, deduplicates against Linear, creates tickets); used Remotion skill to create video demos
- **Skills Philosophy**: Skills are "organizational units of where to put work intelligence"; the DRY pattern for the agentic era; encode constraints rather than prescriptions
- **Non-Code Skills**: Built recruiting skill for non-technical team members using Claude Desktop connectors (Slack, Notion, recruiting software)
- **Context Switching Automation**: Automated Slack → Linear flow to eliminate context switching between communication and task tracking
- **Speaking**: Presented at AI Engineer Summit (aiDotEngineer) on skills at scale
