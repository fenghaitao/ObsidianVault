## Definition

Boris Cherny is Head of Claude Code at Anthropic. He is a self-taught programmer who studied economics, previously worked at Meta (code quality for Facebook, Instagram, WhatsApp) and Instagram (one of the top few most productive engineers), and briefly joined Cursor before returning to Anthropic after 2 weeks.

## Key Information

- 100% of his code has been written by Claude Code since November 2025; he has not edited a single line by hand since then
- Ships 10-30 pull requests per day, every day
- Born in Odessa, Ukraine; family left in 1988
- Self-taught programmer; first programming was on a TI-83 Plus calculator to cheat on math tests
- Wrote a book about TypeScript and started the world's biggest TypeScript meetup
- Briefly joined Cursor for 2 weeks before returning to Anthropic, citing the mission-driven nature of Anthropic as the reason
- Previously lived in rural Japan — the only engineer and English speaker in his town; made miso and traded pickles
- Spent one month at Anthropic building prototypes, one month in post-training, then built what became Claude Code
- Started Claude Code as a solo project; first internal demo post got "two likes"
- His post-AGI plan: making miso (teaches long time scales; white miso takes 3 months, red miso 2-4 years)
- Enjoys "coding vacations" — traveling to new cities and coding all day
- Became active on Twitter to engage with Claude Code users and fix bugs in minutes
- Favorite books: Functional Programming in Scala, Accelerando (Stross), The Wandering Earth (Cixin Liu)
- Favorite podcast: Acquired (recommends starting with Nintendo episode)
- Life motto: "Use common sense" — think from first principles; if something smells weird, it's probably not a good idea
