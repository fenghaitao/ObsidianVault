## Definition

Sebastián Ramírez (online: tiangolo) is the creator of FastAPI, Typer, and SQLModel. From Colombia. Building FastAPI Cloud.

## Key Information

### FastAPI

- FastAPI has ~95K GitHub stars and ~12 million downloads/day (~280M/month)
- Used by OpenAI (ChatGPT runs on FastAPI), Netflix, Uber, Microsoft, CERN
- Recent features (mid-2026): Pydantic Rust-core JSON serialization, streaming with `yield` (JSON lines, SSE, raw bytes), VS Code extension, bundled agent skill
- FastAPI Cloud: deployment platform in development

### On AI and Open Source

- AI slop PRs are "way worse" than before — a DDoS on maintainer attention
- Advocates for AI disclaimers in PRs: what model, what prompt, full conversation in collapsible HTML details
- Philosophy: "I don't need my PR to be accepted. I want this problem to be solved"
- Notes that lawyers often block employees from open source contributions — legal reform needed
- Panelist on "Open Source in the age of AI" at PyAI Conf 2026
