## Definition

Simon Last is a co-founder of [[Notion]], credited by [[Max Schoening]] alongside [[Ivan Zhao]] with the early intuition that AI would change a great deal about how the company should operate, well before it was obvious.

## Key Information

- Schoening credits Simon Last's early intuition (along with Ivan Zhao's) as a major reason Notion moved fast on AI, ahead of it becoming an industry-wide "every company wants to be AI native" trend.
- On the engineering side, Schoening cites a principle Simon Last talks about frequently: "any manual intervention in code is kind of bad — you probably did something wrong in the verifiability loop." Schoening treats every human intervention in an otherwise-agentic pipeline as "a bug" and a useful litmus test for how "agent-filled" a workflow really is (with an explicit carve-out that code review itself should not be reduced).
