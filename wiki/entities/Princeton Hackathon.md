## Definition

The Princeton Hackathon is a hackathon event at Princeton University. Jia Chen won the Verbar prize at this event with a lacing algorithm project for tracing NFT art provenance.

## Key Information

- Jia won the Verbar prize at the Princeton Hackathon
- The winning project was a lacing algorithm that could trace back if someone had altered an artist's NFT, tracking it back to the original artist
- The project included a UI that showed the descendant tree of edits for an NFT
- This was an example of a technically complex grand prize project that Jia pursued
