## Definition

Opus refers to Claude Opus, Anthropic's most capable model tier. In Cursor's best-of-N feature, Opus is one of the model options users can select to compete on the same coding task alongside other models.

## Key Information

- Used as one of the five models in David Gomes's best-of-N demo (alongside Kimi, Grok, Composer, and GPT)
- In the demo, Opus took longer than other models ("as expected") but produced distinctive results
- Users can ask the parent agent to combine parts of Opus's implementation with parts from other models
