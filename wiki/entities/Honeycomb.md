## Definition
Honeycomb is an observability platform used by Intercom to track Claude Code skill invocations and agent activity across their engineering organization. It enables internal visibility into which skills are being used and how frequently.

## Key Information
- Used by Intercom to hook into all Claude Code activity for skill invocation tracking
- Provides internal dashboards showing skill usage across the organization
- No private information in the dashboards — available to everyone internally
- Helps engineers understand what skills are being used and where
- Part of Intercom's observability stack for the 2x project
- Intercom also wrote a blog post called "Shipping is the heartbeat of your company" that Honeycomb made stickers for
