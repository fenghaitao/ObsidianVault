## Definition
Gemini CLI is Google's command-line agent harness that supports MCP servers. It was used in the Chrome DevTools for Agents demo to show how an agent can open Chrome, perform a performance trace, analyze results, make improvements, and validate them — all through the MCP protocol.

## Key Information
- Google's CLI-based coding agent
- MCP-capable: can be configured with MCP servers like Chrome DevTools MCP
- Used as the demo client in Michael Hablich's Chrome DevTools for Agents presentation
- Works with Chrome DevTools MCP for debugging, performance profiling, and auditing web pages
- Part of Google's AI-powered developer tooling ecosystem
- Represents the "tier 1" (local development) use case for browser agents — human in the loop
