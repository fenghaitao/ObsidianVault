## Definition
AI Studio (ai.dev, ai.studio, aistudio.google.com) is Google's free web-based platform for experimenting with Gemini models, building and deploying AI-powered apps, and accessing generative media models. It works with personal Gmail accounts and provides a "try before you buy" experience.

## Key Features
- **Model Selection**: Access to Gemini 3.1 series (Flash Live, Pro, Flash Light), Gemma 4, Lyra 3, Nano Banana 2, VEO 3.1 Light
- **Compare Mode**: Head-to-head comparison of different models side by side
- **Code Execution**: Sandboxed Python environment with pre-installed data science libraries
- **Grounding with Google Search**: Automatic search integration as a tool
- **URL Context**: Incorporate content from URLs into model context window
- **Build**: Create and deploy full-stack apps with databases (Firestore), authentication (Firebase/Google login), and custom API keys
- **Get Code**: Export experiments as Python, TypeScript, or Java code
- **Thinking Levels**: Configurable reasoning depth (minimal, low, medium, high)
- **Structured Outputs**: Constrain model output to specific formats
- **Function Calling**: Invoke external tools and APIs
- **Grounding with Google Maps**: Location-based grounding
- **Media Input**: Upload files, record audio, camera footage, YouTube URLs, Drive integration
- **One-click Deploy**: Deploy apps to Cloud Run
