## Definition

Orcus is the company behind Open-source Conductor, an orchestration platform for coordinating microservices, APIs, data pipelines, human tasks, and agentic workflows. It supports visual and code-first development with built-in compliance, reliability, and an MCP gateway.

## Key Information

- Makes Open-source Conductor, a production-grade orchestration layer
- Supports coordinating microservices, APIs, data pipelines, human tasks, and agentic workflows
- Features deterministic control flow, retries, observability, and governance
- Built for enterprise scale with visual and code-first development
- Includes a built-in MCP gateway for AI agents to safely access APIs and internal systems
- Episode sponsor of Lenny's Podcast
- Website: orcus.io
