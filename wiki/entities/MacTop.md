## Definition
MacTop is a GPU and CPU monitoring tool for macOS, created by Carson, that provides a real-time overlay showing GPU/CPU usage during MLX inference. It is the recommended tool for tracking on-device AI performance on Apple Silicon.

## Key Information
- Created by Carson (community contributor)
- Shows real-time GPU and CPU usage as an overlay on macOS
- Recommended by Prince Canuma as the easiest tool for monitoring MLX inference performance
- Displays GPU activity spikes during model inference, confirming on-device execution
- Useful for verifying that models are running on GPU (not CPU) and tracking resource utilization
- Free community tool
