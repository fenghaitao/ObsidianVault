## Definition
Dotta Bippa (also referred to as "Doda") is the creator and host of Paperclip, an open-source agent orchestrator designed as a human control plane for AI labor. He presented Paperclip at the aiDotEngineer conference.

## Key Information
- Creator of Paperclip, an open-source agent orchestrator for zero-human companies
- Goes by "Doda" as a shortened name
- Presented Paperclip at the aiDotEngineer conference in April 2026
- Uses Paperclip to manage the development of Paperclip itself (dogfooding)
- Advocates for building agent organizations agent by agent, ensuring quality before scaling
- Emphasizes that Paperclip is not just a coding tool — it's designed for running entire businesses with AI agents
- Practical philosophy: start with the agents you need, craft instructions carefully, and iteratively improve agent behavior
- Uses Twitter bookmarks to track ideas for improving Paperclip
- Demonstrated Paperclip's capabilities by creating a Remotion video celebrating 40,000 GitHub stars using the platform
