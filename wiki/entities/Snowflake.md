## Definition
Snowflake is a cloud data warehouse platform. Raindrop integrates with Snowflake by exporting signal-tagged event data, allowing customers to run custom experiment analysis on agent observability data within their own data infrastructure.

## Key Information
- Cloud data warehouse platform
- Raindrop integration: exports events and classified signal tags for custom analysis
- Used alongside BigQuery as an alternative data export target
