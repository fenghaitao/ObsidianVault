## Definition
Kubernetes is a container orchestration platform. In the OpenHands architecture, Kubernetes can be used to scale agent sandboxes to thousands of concurrent agents for massive parallel refactoring tasks.

## Key Information
- Container orchestration platform for managing Docker containers at scale
- OpenHands can run agent sandboxes in a Kubernetes cluster for large-scale parallel operations
- Enables running thousands of agents concurrently, each in its own containerized environment
- Used for enterprise-scale CVE remediation and codebase modernization
