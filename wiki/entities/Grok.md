## Definition

Grok is an LLM developed by xAI. In Cursor's best-of-N feature, Grok is one of the model options users can select to compete on the same coding task alongside other models.

## Key Information

- Used as one of the five models in David Gomes's best-of-N demo (alongside Kimi, Composer, GPT, and Opus)
- Performs well on work tree evals — stays within its designated work tree better than weaker models like Haiku
- Cursor shares feedback with model providers including xAI on agent behavior in work tree environments
