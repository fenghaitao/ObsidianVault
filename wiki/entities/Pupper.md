## Definition
Pupper is a completely open-source robot that can be 3D printed, runs on Raspberry Pi, and uses Gemini models behind the scenes for object detection and environmental response. It can also run Gemini Live for flexible robot control.

## Key Information
- Open-source robot with 3D-printable parts
- Runs on Raspberry Pi with all open-source software
- Uses Gemini models for object detection and environmental response
- Can run Gemini Live for real-time flexible robot control
- Orchestration pattern: Gemini Live builds the plan, then invokes local models on the robot for execution
- Demonstrated as an example of Gemini's robotics applications
