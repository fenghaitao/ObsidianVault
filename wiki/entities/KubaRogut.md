## Definition
Kuba Rogut is an engineer at Turbopuffer who presented benchmarks on adding semantic code search to Claude Code. He built TurboGrep, a CLI tool for chunking, embedding, and indexing codebases into Turbopuffer.

## Key Information
- Engineer at Turbopuffer, a serverless vector search database
- Built the TurboGrep CLI tool for indexing codebases into Turbopuffer
- Benchmarked Claude Code's code retrieval performance with and without semantic search on ContextBench (50 tasks)
- Found semantic search improved file precision from 65% to 87% on Claude Code
- Presented at aiDotEngineer conference (June 2026)
- Demonstrated that semantic search and grep-based search complement each other for different task types
