## Definition

WebAssembly is a portable binary instruction format for the web that runs code at near-native speed inside a sandboxed, portable runtime. Mozilla distinguished engineer Luke Wagner was one of the people most responsible for forging it.

## Key Information

- Lineage: Alon Zakai's Emscripten (compile C++ to naive JavaScript) → asm.js (a restricted, optimizable JS subset) → WebAssembly as a proper bytecode format
- Won browser-consensus against Google's plugin-like NaCl/PNaCl approach through both technical work and political coordination
- Transformed what browsers can do — cited as enabling products like Figma — and spread beyond the browser to backends and serverless via the Bytecode Alliance
- One of Bobby Holley's examples of the industry-wide impact that defines a Mozilla distinguished engineer
