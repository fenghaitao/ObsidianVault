## Definition
Hermes is a custom personal AI agent framework, mentioned alongside OpenClaw as one of the main open-source alternatives for self-hosted personal agents. Kitze juggles between OpenClaw, Hermes, and Paperclip.

## Key Information
- Custom agent framework in the same category as OpenClaw
- Kitze juggles between OpenClaw, Hermes, Paperclip, and Plenty Marks with Codex
- Represents the "custom agents" future — for tinkerers who want to self-host and own models
- Part of the ecosystem that "will never work for mainstream" but satisfies power users
- Supported as a bring-your-own-agent option in Paperclip
