## Definition

SICP (Structure and Interpretation of Computer Programs) is a classic MIT programming textbook, nicknamed "the wizard book" for its metaphor of programming as sorcery. It was the introductory programming textbook at MIT for many years and has a cult following.

## Key Information

- Full title: Structure and Interpretation of Computer Programs
- Used as the introductory programming textbook at MIT for many years
- Nicknamed "the wizard book" because it uses the metaphor of programming as sorcery throughout
- Teaches programming using Scheme, a dialect of Lisp
- Introduces functional programming concepts
- Written in 1980, but its metaphor of programming languages as "incantations" has persisted
- Sherwin Wu draws on this metaphor to describe the current state of AI programming: "it is now literally incantations because you can tell Codex or Cursor exactly what you want to do and it'll go do it for you"
- The book's sorcery metaphor connects to the Sorcerer's Apprentice analogy for AI coding
