## Definition

Nuclide is the desktop IDE that Michael Bolin championed at Facebook/Meta as a replacement for Xcode, built on the company's own React technology after a competing web-based IDE stalled.

## Key Information

- Bolin tried to build on the existing web-based IDE (built on an abandoned Google open-source GWT project) but argued the company should empower dev-tool builders with the technologies Meta was a leader in (React).
- He won the argument partly on the technology stack and partly on Nuclide being a desktop app — iOS development needs to talk to the simulator or a plugged-in phone, which a web app makes harder.
- Leadership sided with Nuclide partly on Bolin's credibility from Buck ("the last thing paid off").
- Nuclide was open-sourced but "kind of didn't really get adopted externally."
- Its client was built on GitHub/Atom technology (Electron), which became a source of conflict when Microsoft acquired GitHub, and the reasoning behind the scrapped GitHub project was that the new client built on VS Code would kill Atom (a prediction that eventually held true).
