## Definition
Gemini 3 is a large language model released by Google. Amp Code adopted it as the model powering their Smart Agent, reporting significant capability improvements after extensive optimization. The Gemini 3 Flash variant was used by Philipp Schmid as the coding model for building agents in the Interactions API workshop, demonstrating strong performance with good skills and context.

## Key Information
- Released shortly before December 22, 2025 (Amp switched to it "two days ago" from the talk date)
- Amp Code spent a week before release optimizing their Smart Agent to take full advantage of Gemini 3's capabilities
- Beyang Liu reports widely different behavior from Gemini 3 across different agent settings
- Amp Code is "absolutely loving it" despite working through some kinks as a new model
- Described as having "moved the frontier of what's possible" for coding agents
- Launched alongside Nano Banana Pro in early January 2026, the same week as the AI Engineering Code Summit
- Gemini 3 Flash used effectively as a coding model in the Interactions API workshop: "it works really well if you are providing good instructions with good skills and good context"
- Gemini 3 Flash was trained before the Interactions API was released, so all Interactions API coding was done via skills and documentation
- Gemini 3.1 Flash Live is a native audio variant released in April 2026
