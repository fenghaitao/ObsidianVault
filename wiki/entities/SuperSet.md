## Definition

SuperSet is an agentic development tool that Brian Casel currently uses as his daily driver for multitasking with AI coding agents. It features a sidebar for repos/workspaces/worktrees, native Claude Code CLI integration, and file browsing.

## Key Information

- Brian's current daily driver (as of mid-2026) for agentic development.
- Layout: left sidebar (repos, workspaces, worktrees), center (agent conversation), right (file browser/changes).
- Native Claude Code CLI integration — runs Claude Code directly, not through a wrapper.
- Git worktree support: Command+N creates a new worktree for isolated feature work.
- Default workspace is the local branch (unlike Conductor which defaults to new worktrees).
- Command+Shift+P for PR creation and merge back to main.
- Brian prefers it over Conductor (wraps Claude Code), Cursor 3.0 (no native Claude Code), and Claude Desktop (limited file browsing).
