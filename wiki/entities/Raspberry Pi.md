## Definition
Raspberry Pi is a single-board computer used as the hardware platform for the Pupper open-source robot, running Gemini models for object detection and environmental response.

## Key Information
- Single-board computer used in the Pupper robot
- Runs open-source software for robotics applications
- Hosts Gemini models for object detection and environmental response
- Part of the Pupper robot's fully open-source hardware and software stack
- Mentioned as a target device for the smallest Gemma 4 models (E2B), which can run on Raspberry Pi for on-device AI applications
