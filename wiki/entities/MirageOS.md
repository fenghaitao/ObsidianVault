## Definition

MirageOS is a library operating system (unikernel project) written in OCaml that Xavier Leroy cites as one of the systems-application projects following the Ensemble project's early use of OCaml.

## Key Information

- Mentioned by Leroy as a later OCaml systems-application project after Ensemble demonstrated OCaml's viability for systems work.
- Part of the lineage showing OCaml can be used for low-level, performance-sensitive systems, not only theorem proving or DSLs.
