## Definition

VS Code is Microsoft's code editor/IDE, which Michael Bolin cites both as the extension surface he emphasized for Codex and as the product that ultimately made Nuclide's Atom-based foundation obsolete.

## Key Information

- When Microsoft acquired GitHub, Bolin feared VS Code would lead Microsoft to make the Atom project (on which Nuclide's client was based) a victim — a prediction that "was true, which did happen."
- Bolin's conviction about the VS Code extension was that the terminal forces UI compromises; VS Code lets you build a fuller UI without as many trade-offs, and it became a key Codex surface.
- The Codex VS Code extension also introduced the ability to hand a conversation off to the cloud at the press of a button.
