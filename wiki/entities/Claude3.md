# Claude 3

Claude 3 is [[Anthropic]]'s third-generation family of large language models, representing a major advancement in capability and versatility. The Claude 3 family includes multiple specialized variants (Opus, Sonnet, Haiku) designed for different use cases and performance requirements.

## Overview

- **Generation**: Third generation of Claude models
- **Released**: 2024
- **Capability milestone**: First Claude generation with general availability of [[ToolUse|tool use]] capability
- **Variants**: Multiple models optimized for different performance/cost/speed tradeoffs
  - [[Claude3Opus]] — flagship, most capable model
  - [[Claude3Haiku]] — fast, cost-effective model
  - Claude 3.5 Sonnet — balanced capability model

## Key Features

- **Tool use**: Can interact with external tools and APIs to perform tasks
- **Extended context**: Long context windows for processing detailed documents
- **Reasoning**: Advanced reasoning capabilities
- **Multimodal**: Vision capabilities for image understanding

## Availability

Available across multiple distribution channels:
- [[Anthropic]] Messages API
- [[AmazonBedrock]] (AWS)
- Google Cloud's Vertex AI
- Claude web platform

## Model Specializations

### Opus (Flagship)
[[Claude3Opus]] is the most capable model in the Claude 3 family, featuring:
- Strongest reasoning capabilities
- Best for complex tasks and analysis
- Includes `<thinking>` tags for transparent reasoning

### Haiku (Efficient)
[[Claude3Haiku]] is the fastest and most cost-effective variant, designed for:
- Real-time applications
- Lightweight tasks
- Cost-sensitive workloads
- High-throughput scenarios

### Sonnet (Balanced)
Claude 3.5 Sonnet represents the balanced option with strong capabilities at reasonable cost.

## Capabilities

- **Tool use**: Interact with external APIs and tools
- **Code generation and analysis**: Software development tasks
- **Document processing**: Analysis of long, complex documents
- **Reasoning**: Complex logical reasoning and planning
- **Vision**: Image understanding and analysis
- **Multilingual**: Support for multiple languages
