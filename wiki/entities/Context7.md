## Definition
Context7 is an MCP server that helps AI agents look up up-to-date framework documentation, addressing the knowledge cutoff problem of LLMs.

## Key Information
- An MCP (Model Context Protocol) server
- Helps agents access current framework documentation beyond LLM training cutoff dates
- Referenced by Brendan O'Leary as an example of useful MCP servers alongside the GitHub MCP
- Like all MCP servers, adds tool descriptions to the system prompt on every interaction — should be disabled when not actively needed
