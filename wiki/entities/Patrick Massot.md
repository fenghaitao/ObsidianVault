## Definition

Patrick Massot (transcribed "Patrick Masur"/"Patrick Masu") is a French mathematician who built a natural-language-style interface for writing Lean proofs.

## Key Information

- Built a Lean extension (transcribed "Labos Labose") that renders proof steps as structured English (or French) text resembling a textbook, with a point-and-click Info View that suggests the next move.
- Did the work independently — "without asking me any questions" — despite not being a computer scientist (he has a mathematics degree).
- De Moura cites him (with Terence Tao, Jeremy Avigad, and Kevin Buzzard) as one of the mathematicians who insist dependent type theory is necessary for serious math.
- Illustrates Lean's extensibility: because Lean is implemented in Lean, users can add such extensions (or have AI write them) without touching the core system.
