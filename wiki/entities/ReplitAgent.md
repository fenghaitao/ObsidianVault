## Definition
Replit Agent is an autonomous coding agent built by Replit, designed for non-technical users to create software without needing to make technical decisions. It has evolved through multiple generations from simple React-based agents to fully autonomous agents capable of multi-hour tasks.

## Key Information
- First version launched in September 2024.
- Three generations: React-based agents, native tool calling agents, and autonomous agents (B3).
- B3 version broke the one-hour autonomy barrier, capable of running long-horizon tasks while remaining coherent.
- Uses autonomous testing via Playwright code generation to verify correctness and eliminate "painted doors."
- Employs sub-agent orchestration for context management, keeping tasks within 200K token windows.
- Next version aims for core loop as orchestrator for parallel agents, with on-the-fly task decomposition.
- Targets a "Waymo experience" where users don't need technical expertise.
