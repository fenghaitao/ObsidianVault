## Definition

Kimi is an LLM developed by Moonshot AI. In Cursor's best-of-N feature, Kimi is one of the model options users can select to compete on the same coding task alongside other models.

## Key Information

- Used as one of the five models in David Gomes's best-of-N demo (alongside Grok, Composer, GPT, and Opus)
- Available as a model option in Cursor for coding tasks
