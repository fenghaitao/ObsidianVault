## Definition
ThunderKittens is a programming-language abstraction that lets developers write GPU kernels through a small set of functions instead of arbitrary C++ — an example Vlad Feinberg gives of how PL research accelerates kernel development.
## Key Information
- It illustrates creating kernel-level abstractions so developers "move really quickly" in writing algorithms that fully utilize hardware.
- Vlad frames interest in such PL abstractions and low-level hardware as a powerful, in-demand specialization.
- He groups it with "hardware-specific domain-specific languages" like CuTe.
