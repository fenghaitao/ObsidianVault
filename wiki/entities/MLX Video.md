## Definition
MLX Video is a video generation framework built on MLX for Apple Silicon, enabling text-to-video generation completely on-device. It supports chained generation for creating cohesive video stories.

## Key Information
- Built by Prince Canuma (Neywa Labs) on top of MLX
- Generates video from text prompts entirely on-device
- Can run on MacBooks with as little as 16GB of VRAM
- Community user demonstrated chained generation: feeding previous video output as input for continuous story creation
- Chained approach produces cohesive narratives despite not being one-shot generation
- Part of the broader MLX ecosystem (MLX VLM, MLX Audio, MLX Video)
