## Definition
Prasenjit Sarkar is a speaker from Sonar who presented on LLM-generated code quality at the AI Engineer Summit, detailing Sonar's evaluation framework that assesses 53+ models across security, maintainability, complexity, and verbosity beyond functional correctness.

## Key Information
- Presented at aiDotEngineer conference on whether LLMs can generate enterprise-quality code
- Leads or contributes to Sonar's LLM code quality evaluation initiative
- Presented findings from evaluating 4,444+ Java programming assignments across 53+ LLM models
- Introduced Sonar's ACDC (Agent-Centric Development Cycle) framework: Guide, Verify, Solve
- Highlighted that LLM benchmarks (SWE-bench, HumanEval, MBPP) measure only functional correctness, missing security, maintainability, and engineering discipline
- Demonstrated that top models like Gemini 3.1 Pro High (84.17% pass rate) still generate hundreds of bugs and security issues per million lines of code
- Advocated for embedding code quality checks throughout the AI-assisted development lifecycle, not just at CI/CD
