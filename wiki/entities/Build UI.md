## Definition

Build UI is a UI component resource used by Lazar to find code templates in his parallel prototyping workflow. It allows exporting actual code snippets that AI tools can interpret for pixel-perfect design results.

## Key Information

- Part of the parallel prototyping workflow: step 4, providing code templates
- Allows exporting code snippets, not just visual references
- AI tools interpret code better than English for achieving pixel-perfect design
- Used alongside 21st Dev as a source of quality code references
