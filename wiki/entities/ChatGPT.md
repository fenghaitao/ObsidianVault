## Definition
ChatGPT is OpenAI's AI chat product that supports MCP Apps, rendering interactive UI chunks from MCP servers. It is cited as having 1 billion weekly users and recommends MCP Apps as the way to build ChatGPT apps.

## Key Information
- Supports MCP Apps as a host, rendering interactive UI from MCP servers
- ChatGPT recommends MCP Apps as the way to build ChatGPT apps
- 1 billion weekly users (cited by Sam Altman), representing a massive distribution opportunity for MCP Apps
- 160x the number of users iPhone had when the App Store launched
- Co-developed the MCP Apps spec with Anthropic and the MCPUI team
- Interactive applications seen in ChatGPT are based on MCP and the MCP App spec
