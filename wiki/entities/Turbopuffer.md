## Definition
Turbopuffer is a serverless full-text and vector search database built from first principles on top of object storage. It powers some of the fastest-growing AI companies, serving as the vector database backend for products like Cursor, Anthropic, and Notion.

## Key Information
- Serverless architecture built on object storage
- Provides both full-text and vector search capabilities
- Powers Cursor's semantic code search — one of Turbopuffer's first customers
- Also used by Anthropic and Notion
- When users interact with Cursor, they indirectly use Turbopuffer
- Designed for "multiplayer" and complex data relationships (knowledge bases, multi-modal data)
- Can handle multi-modal data (video, audio, images) that cannot be grepped
- Kuba Rogut from Turbopuffer presented benchmarking results on semantic code retrieval
