## Definition

CodeRabbit is an AI-powered code review tool that bundles Anthropic's [[ClaudeCodeSkills|claude-api]] skill (April 2026), giving its users expertise in writing production-ready Claude API code — agent-pattern selection, model-generation parameter differences, and prompt-caching guidance.

## Key Information

- One of four external developer tools (alongside [[JetBrains]], [[ResolveAI|Resolve AI]], and [[Warp]]) that bundle the open-source `claude-api` skill from `anthropics/skills`.
- The skill was first introduced inside [[ClaudeCode]] in March 2026 before being bundled by partner tools.
