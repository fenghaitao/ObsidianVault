## Definition

Rad Game Tools is a video game technology company where Casey Muratori wrote a widely licensed character animation system.

## Key Information

- Casey wrote the character animation system (released 1999) almost entirely himself.
- The ~2001 second version is still largely unchanged and is still used in Baldur's Gate 3 (Larian).
