## Definition
Fairies is a tldraw project (fairies.tldraw.com) that places multiple AI agents directly on a canvas as animated sprites, enabling visible multi-agent collaboration with spatial awareness, leader-follower orchestration, and shared state.

## Key Information
- Available at fairies.tldraw.com
- Agents appear as animated sprites (fairies) on the canvas, drawn by Steve Ruiz
- Each agent has visible state: thinking, acting, and spatial position relative to other agents
- Agents are aware of each other's actions and can work on different parts of the canvas simultaneously
- Fairies "don't like to be held for very long" — they start freaking out if grabbed
- Multiple agents can be grouped together for coordinated work
- When grouped, one fairy is elected leader: it scouts the canvas, creates a to-do list, delegates tasks, observes work, and judges completion
- Built in late 2024 (October-December), concurrent with the broader industry figuring out agent orchestration
- Agents can do real work: generate wireframes from app descriptions, build ebook readers, draw diagrams
- Has IRC integration
- Described as a great way to explore and demonstrate multi-agent collaboration concepts
