## Definition
RL Nabors (Rachel Lee Nabors) is a principal developer experience engineer at Arise, with a career spanning Mozilla (Firefox DevTools), the W3C (Web Animations API), Microsoft Edge (PM), and the React team (react.dev, reactnative.dev). She writes The Agentic Web newsletter and builds agentic web experiences including ASA (Anti-Social Social Agent), an MCP app for Twitter and BlueSky. Before her tech career, she was a web comics creator with 400,000 weekly readers.

## Key Information
- Current role: Principal Developer Experience Engineer at Arise (evals company)
- Former roles: Mozilla (Firefox DevTools), W3C (Web Animations API standard), Microsoft Edge (PM), React team (react.dev, reactnative.dev)
- Creator of ASA (Anti-Social Social Agent), an MCP app that lets users interact with Twitter and BlueSky without visiting the sites
- Author of The Agentic Web newsletter covering how agents and AI are changing browsing and content consumption
- Presented "Introducing WebMCP: Agents in the Browser" at aiDotEngineer 2026
- Built an MCP-powered web comics reader (rachelagreat.com) with MCP tools, MCP Apps, and WebMCP integration
- Core thesis: the browser is an infinite canvas; CSS and JavaScript are the language of interactive agent experiences
- Background in web comics: created comics for the iVillage Network with 400,000 weekly readers in 2006
- Spent 3 years consulting with AI startups and LLM/browser companies on web, AI, and UI
- Advocates for MCP Resources implementation and richer agent UX beyond blank chatboxes
