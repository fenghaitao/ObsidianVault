## Definition

Turbo Pascal is the first product Anders Hejlsberg worked on — an early Pascal compiler whose compiler, editor, and runtime library he wrote entirely in Z80 assembly during the 8-bit microcomputer era.

## Key Information

- Hejlsberg's first product; the compiler, editor, and runtime library were all written in Z80 assembly code.
- Built under extreme memory constraints — squeezing code into a roughly 12K EPROM, counting individual bytes ("20 bytes over budget") and hand-optimizing jumps.
- People told him it "can't be done"; he succeeded partly because he didn't know it was impossible.
- Early versions used linked lists for symbol tables; after reading Niklaus Wirth's book, Hejlsberg replaced them with hash tables, roughly doubling compile speed.
- It was a "one-man shop" product at a time when one person could still control everything, a lesson that scaling later forced Hejlsberg to learn teamwork.
