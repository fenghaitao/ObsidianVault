## Definition

Brian Casel is a software developer with 20+ years of experience who now teaches builders how to create custom business tools using AI. He runs the YouTube channel and community "Builder Methods," where he advocates for spec-driven development, agent orchestration, and building internal tools rather than renting SaaS.

## Key Information

### Background & Philosophy

- 20+ years as a software developer; by 2025 stopped handwriting code entirely.
- Core thesis: the most useful business skill isn't coding — it's building the exact tool your business needs.
- Advocates for spec-driven development over vibe coding: shape clear plans, break into milestones, direct AI with precision.
- Runs his entire business (Builder Methods) as a solo operator supported by AI agents.

### Tech Stack

- Primary stack: Ruby on Rails with React frontend.
- Uses [[BuildNew]] as his starter application template.
- Primary coding agent: [[ClaudeCode]] (CLI), with Opus as daily driver.
- Email: Resend. Payments: Stripe.
- Design system: his free Design System skill for consistent UI across all apps.
- Agent platforms: [[HermesAgent]] (routine jobs), [[ClaudeCowork]] (creative jobs), [[OpenClaw]] (previously).
- Agent chat interface: Discord (multi-channel, threaded, good markdown support).
- Runs agents on a dedicated Mac mini.
- Content capture: Dropbox-based file system with custom [[BrainDown]] markdown viewer.

### Free Tools Released

- **[[PRDCreator]]**: agent skill that walks through planning questions, creates PRDs, and breaks work into milestones.
- **[[DesignSystem]]**: agent skill that installs a living component library into the codebase with CLAUDE.md directives.
- **[[BuildNew]]**: Rails + React starter template with design system pre-installed.
- **Agent OS** and **Design OS**: earlier open-source frameworks.

### Content & Community

- YouTube channel: Builder Methods — builds real apps with AI and teaches the craft.
- Weekly newsletter: Builder Briefing (free 5-minute read).
- Builder Methods Pro: paid community with courses (Become the Builder), build kits, live Q&A.
- Podcast: The Panel (weekly).

### Workflow Evolution

- 2023: hand-coding everything.
- 2024: AI enhancement phase (tab completion, ChatGPT for copy).
- 2025: AI collaborator — spec-driven development, all creative work through agents.
- 2026: agent orchestration — multitasking across 2-4 features, agents on recurring schedules, mobile management.
