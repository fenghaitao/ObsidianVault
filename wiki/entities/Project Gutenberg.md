## Definition
Project Gutenberg is an online library of free, open-source ebooks, primarily consisting of public domain works. It was used as the source of books (The Wind in the Willows, The Adventures of Chatterer the Red Squirrel) for demonstrating GenMedia book illustration workflows.

## Key Information
- Online library offering free ebooks in the public domain
- Used as the book source for the GenMedia book illustration workshop
- Books used: "The Wind in the Willows" by Kenneth Grahame and "The Adventures of Chatterer the Red Squirrel"
- Provides easily accessible, copyright-free text content suitable for AI demonstration workflows
- Books downloaded programmatically during the workshop via the Gemini API Client File Upload feature
