## Definition

Copilot refers to Microsoft/GitHub's AI-powered code assistant (GitHub Copilot) and enterprise AI platform (Copilot Enterprise), used at LinkedIn for coding and knowledge-corpus agents.

## Key Information

- LinkedIn uses Copilot Enterprise alongside ChatGPT Enterprise for building internal AI agents.
- Like other third-party AI coding tools, Copilot could not work off-the-shelf on LinkedIn's codebase without a custom integration layer.
- LinkedIn is building a layer that allows tools like Copilot, Cursor, and Windsurf to reason over its codebase effectively.
- The original "Codex" brand at OpenAI was actually the model powering GitHub Copilot years ago; OpenAI recently reused the Codex brand for their own coding agent because "Codex, code execution" is so fitting
