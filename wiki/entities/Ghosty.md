## Definition
Ghosty is an open-source terminal emulator. One of its core contributors built the TUI framework from scratch that powers Amp Code's terminal interface. Mitchell Hashimoto, its founder, is mentioned in Mario Zechner's talk as the source of the running gag that "Claude Code is now a game engine."

## Key Information
- Open-source terminal emulator
- A core Ghosty contributor built Amp Code's custom TUI framework
- Mitchell Hashimoto, founder of Ghosty, is a notable user of Amp Code, using it to drive changes to the terminal
- Amp's TUI leverages modern terminal capabilities including color mixing (e.g., diff rendering with green blended into any background)
- Mitchell told Mario Zechner that Claude Code is "now a game engine" — part of a running gag about Claude Code's feature bloat
- The Open Claw Foundation's governance structure was "inspired by what Ghosty did" — Peter Steinberger cited Ghosty as the model for building a vendor-neutral open-source foundation
