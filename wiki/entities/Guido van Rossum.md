## Definition
Guido van Rossum is the creator of the Python programming language.

## Key Information
- Transcribed in the episode as "Gildolf and Russen" (a garbled rendering of "Guido van Rossum").
- Per Bjarne, van Rossum built Python with the explicit aim of letting "many people or even everybody" program — and succeeded.
- Contrast: Bjarne designed C++ as a serious tool for engineers, mathematicians, and serious programmers — "not the same problem."
