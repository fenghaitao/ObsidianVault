## Definition
Max Kanat-Alexander is a developer experience expert at Capital One with over 20 years of experience in the field, known for his work on improving developer productivity and his insights on how AI coding agents are transforming software engineering.

## Key Information
- Works at Capital One in developer experience
- Has been working in developer experience for "a very long time" (20+ years)
- Presented at aiDotEngineer on the topic of developer experience in the age of AI coding agents
- Core thesis: "what's good for humans is good for AI" — investments that improve developer experience for humans also benefit AI coding agents
- Advocates for "no regrets" investments: standardized environments, validation, testable codebases, documentation of intent, and improved code review processes
- Warns that without proper DX investments, organizations risk a vicious cycle of declining agent productivity
- Believes code review apprenticeship (senior developers reviewing code with juniors) is the only effective way to teach code review skills
