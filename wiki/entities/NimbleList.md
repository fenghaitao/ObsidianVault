## Definition

NimbleList is a visual workspace for planning and shaping software projects with AI coding agents. It combines markdown editors, mockups, Excalidraw diagrams, Mermaid diagrams, and data models alongside agent sessions, with everything stored as portable markdown files on the local file system.

## Key Information

- Visual editors built in: markdown, mockups, Excalidraw, Mermaid, data models.
- Planning documents and task tracking in the same place; agents can update tasks automatically.
- Everything stored as markdown on local file system — no proprietary formats, Git-friendly, portable.
- Connects directly to coding agents; full project context carries through to agent sessions.
- Available for free at nimblelist.com.
- Sponsored Brian's "Skill AI Can't Replace" video.
