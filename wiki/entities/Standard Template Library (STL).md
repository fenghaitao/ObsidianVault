## Definition
The Standard Template Library (STL) is the generic-programming library (containers, algorithms, iterators) created by Alex Stepanov and incorporated into the C++ standard library.

## Key Information
- Bjarne calls the STL the thing that "saved" C++: he released C++ before he could build a good standard library, and "everybody was building standard libraries."
- Realizing, too late, that he should have delayed release until a vector/class hierarchy existed was one of his regrets; the STL arriving via Alex Stepanov was "real luck."
- David J. Malan contrasts this with C: in Java and C++ you can "just instantiate one of those data structures" via the STL and other libraries, but in C "you're going to have to build it yourself" — a good bottom-up educational exercise.
