## Definition
Rust Analyzer is the popular Rust language-server (LSP) implementation, built on the Salsa incremental-computation framework.

## Key Information
- Charlie cites it as the proof of Salsa's design; Astral's Red-knot type checker is built on the same framework.
- Represents the incremental, lazily-computed language-server architecture Red-knot emulates.
