## Definition

Sonnet 4.6 is an Anthropic AI model that, alongside Opus 4.5 and Opus 4.6, enabled reliable AI code review — a capability that Anthropic had attempted multiple times previously but couldn't achieve with sufficient accuracy until these models.

## Key Information

- Mentioned alongside Opus 4.5 and Opus 4.6 as the models that made reliable AI code review possible
- Code review was attempted multiple times before, but "it was only with Opus 4, 5 and 4.6 and Sonic 4.6 that we felt like we are now able to run multiple code review agents simultaneously to traverse the entirety of the code base"
- The engineering team at Anthropic now relies on Claude code review to pass before merging PRs
- Multiple code review agents run simultaneously to traverse the entire codebase and synthesize real issues
