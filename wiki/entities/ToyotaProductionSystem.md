## Definition
The Toyota Production System (TPS) is the manufacturing philosophy and management system developed by Toyota that introduced Kaizen (continuous improvement) and genchi genbutsu (go and see for yourself). In the keynote, TPS is identified as the earliest ancestor of the iterative improvement cycle recommended for LLM application development.

## Key Information
- Origin of Kaizen (continuous improvement) and genchi genbutsu (real things, real places — go see for yourself)
- The genealogy traced in the keynote: Toyota Production System → Lean Startup → DevOps → MLOps → LLM application development
- Genchi genbutsu at Toyota meant sending executives to factory floors; for LLMs, it means looking at real user interaction data
- Shigeo Shingo's principle "value is only created when metal gets bent" serves as a warning against getting lost in tooling and measurement without delivering user value
- The core insight: the iterative cycle of building, measuring, and improving is not new to AI — it has deep roots in manufacturing and software engineering
