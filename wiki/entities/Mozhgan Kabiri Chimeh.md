## Definition
Mozhgan Kabiri Chimeh is a developer relations manager at Nvidia who works closely with developers building and deploying AI systems. She presented practical, data-backed benchmarks of running LLMs locally on the DGX Spark.

## Key Information
- Developer relations manager at Nvidia
- Built an automated benchmarking harness using Docker, vLLM, and the DGX Spark to measure local LLM performance
- Demonstrated that NVFB4 quantization enables a 14B model to achieve 20.19 tokens/sec on local hardware
- Advocates for bringing AI development workflows closer to the developer via local hardware, not replacing the cloud but complementing it
- Benchmarking protocol includes environment isolation via Docker, three mandatory warm-up runs, and background GPU metrics logging at 1-second intervals
