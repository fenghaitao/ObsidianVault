## Definition
Lianne is a command-line embeddings tool used by Chris Parsons for knowledge management. It runs embeddings across all text in a repository — transcripts, links, saved content — enabling semantic search across a personal knowledge vault.

## Key Information
- CLI tool for running embeddings across text repositories
- Used by Chris Parsons to search his vault of thousands of markdown files
- Indexes transcripts, links, saved content, and all text files
- Enables finding information "usefully and easily" across a large personal knowledge base
- Part of Parsons' Zettelkasten-based knowledge management system alongside Obsidian and Claude Code
