## Definition

SemiAnalysis is a research firm that published a report showing 4% of all GitHub commits are authored by Claude Code, and predicted it will be 20% by the end of 2025.

## Key Information

- Reported that 4% of all GitHub commits are authored by Claude Code
- Predicted that AI will author a fifth of all code commits on GitHub by end of 2025
- Their phrasing: "While we blinked, AI consumed all software development"
- Boris notes these are only public commits; private repositories likely have higher rates
