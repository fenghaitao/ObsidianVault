## Definition
Google AI Studio (ai.dev or ai.studio) is a web-based developer tool from Google DeepMind for trying out Gemini models quickly, obtaining API keys, and building AI-powered applications. It supports live voice conversation testing, app generation from prompts, and publishing demos.

## Key Information
- Accessible at ai.dev (redirects to ai.studio) or ai.studio directly
- Free tier available — no credit card required, only a Google account
- Provides API key creation and management
- Live voice testing: real-time voice conversation with Gemini Live API at ai.dev/live
- Can ingest webcam feeds for vision testing
- App generation: "live coach" feature that builds full-stack apps from prompts (JavaScript/Next.js/Angular/XR)
- Used to build the Live Jukebox DJ demo combining Live API with Lyra 3
- Demos can be published and shared
- Supports system instructions for voice modification and behavior customization
- Google Search grounding toggle available in the UI
- Thinking level configuration (none, low, high)
