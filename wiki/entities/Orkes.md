## Definition

Orkes is the company behind open-source Conductor, an orchestration platform for modern enterprise applications. It provides a production-grade orchestration layer for coordinating microservices, APIs, data pipelines, human tasks, and agentic workflows.

## Key Information

- Company behind open-source Conductor
- Provides orchestration for microservices, APIs, data pipelines, human tasks, and agentic workflows
- Features: deterministic control flow, retries, observability, governance
- Supports visual and code-first development with built-in compliance and reliability
- MCP gateway enables AI agents to handle reasoning while safely accessing existing APIs
- Sponsor of this episode of Lenny's Podcast
- Website: orkes.io/lenny
