## Definition
Chrome DevTools is a set of web developer tools built directly into the Chrome browser, used by millions of web developers daily to debug web pages, find errors, audit performance, and profile applications.

## Key Information
- Built directly into the Chrome browser
- Used by millions of web developers on a daily basis
- Core use cases: debugging web pages, finding errors, auditing, performance profiling
- Has a human-oriented interface optimized for visual complexity — humans need layout and color to find signal
- The team built a separate purpose-built version for AI agents: Chrome DevTools MCP (Chrome DevTools for Agents)
- The agent version returns semantic summaries and markdown instead of raw trace data (e.g., 50K lines of JSON)
- Product Manager: Michael Hablich
- Part of Google's developer tooling ecosystem
