## Definition

Kim Morrison (transcribed "Kin Morrison") is a colleague of Leonardo de Moura, a mathematician active in the Lean/mathlib community.

## Key Information

- Led a project that prompted AI to translate a C compression library (transcribed "Z lib," i.e. zlib) into Lean, make the Lean version pass the library's test suite, and prove that compress-then-decompress returns the original data — succeeding after about one week.
- De Moura calls this real (not science-fiction) evidence that AI plus formal methods can carry out end-to-end verified code translation and then hold the optimizations honest against the proofs.
- Saw OpenAI's unit-distance-conjecture result, posted it to a Lean challenge collection as "someone should formalize this," and it was subsequently formalized (disproved) with a ~1-million-line Lean proof in about two weeks.
