## Definition
Jace is an email agent built by the Viktor founding team after JCAI. It reacts to incoming emails by connecting to the user's tools and can respond not only with email drafts but also with actual tool calls (e.g., automatically processing refunds). It achieved product-market fit and is still operational.

## Key Information

- **Created**: After Sonnet 3.5 launched (2024), building on the team's "face first agent loop"
- **Approach**: Agent triggered by incoming emails, connecting to the user's tools to react with tool calls (not just drafts)
- **Key capability**: Automated tool-based responses — e.g., if someone requests a refund, Jace can automatically process it
- **Safety**: Supports approval gates for sensitive actions
- **Design philosophy**: Agent should not require users to go to a web app; should proactively come up with tasks based on context
- **Status**: Still alive and operational; achieved product-market fit
- **Legacy**: The experience of not needing a web app and having the agent proactively suggest tasks directly influenced Viktor's design
