## Definition
Liam Hampton is a Senior Developer Advocate at Microsoft and GitHub, working on the Developer Tools Advocacy team for Visual Studio Code and GitHub Copilot. He is a Go engineer who builds MCP Apps for developer tooling.

## Key Information
- Senior Developer Advocate at Microsoft and GitHub (dual role)
- Member of the Developer Tools Advocacy team focused on VS Code and GitHub Copilot
- Go engineer by background
- Presented at AI Engineer conference on building MCP Apps in VS Code
- Built a flame graph profiling MCP App that profiles Go application code using Go pprof, renders interactive flame graphs in VS Code's chat via React
- Borrowed and adapted an MCP skill from Anthropic's Model Context Protocol repository, ran it through GitHub Copilot CLI to generate MCP App scaffolding
- Demonstrated MCP App structure: tool (LLM + host), resource (bundled HTML UI in React/Vue/Svelte/vanilla JS), and link (host recognizing UI resource reference)
- Explained tool visibility options: model-only, model-and-app, or app-only invocation
