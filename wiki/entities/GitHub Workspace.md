## Definition
GitHub Copilot Workspace is an AI-native development environment that takes a GitHub issue or task description and helps developers figure out how to implement the change, bridging from the task description into a pull request and code.

## Key Information
- Announced at GitHub Universe in November (2023)
- Workflow: Issue/task → Specification → Codebase analysis → Implementation plan → Diff view → Pull request
- Human remains at the center at every step: can interact, change bullet points, and modify code
- Acts as a "pair programmer" that helps explore the codebase — especially valuable when navigating unfamiliar projects or returning from time away
- First feedback came from a program/product manager who realized they could now see what implementing a user story would mean in code
- Helps with task specificity: reveals whether a task description is actually specific enough to write code for
- Not about building autonomous agents — it is about building agents that help humans solve tasks and learn along the way
