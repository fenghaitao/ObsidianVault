## Definition
Karan Sampath is a Forward Deployed Engineer at Anthropic, the first in this role outside the United States. He works with enterprises on MCP deployments and internal use cases.

## Key Information
- First Forward Deployed Engineer at Anthropic outside the US
- Works with enterprises on MCP (Model Context Protocol) deployments
- Also works on internal Anthropic use cases
- Presented "Gateways are All You Need" at the AI Engineering Code Summit (aiDotEngineer), advocating for MCP Gateways as the solution to enterprise MCP adoption challenges
- Core thesis: enterprises need a gateway middleware layer to solve the "three-headed hydra" of observability, access control, and security for MCP servers
- Key insight: security teams should bless one platform (gateway) to establish a root of trust, enabling decentralized MCP development across teams
- Advocates for separating the agent harness from the data layer as the long-term vision for agent tech deployments
