## Definition
Chris Parsons is a CTO by background with about 30 years of professional software development experience. He has been a CEO of an agency, done agile consulting, and co-founded VC-backed startups and scale-ups. He now spends most of his time helping teams figure out how to adopt and use AI, running Ralph loops "24 hours a day" for everything from email to code to newsletters.

## Key Information
- Presented the workshop "Ralph Loops: Build Dumb AI Loops That Ship" at aiDotEngineer conference
- Runs Ralph loops for all his work: emails, calendar, content, newsletters, client work, and coding
- Has about 50 skills that he's written for Claude Code
- Runs multiple loop types: worker loop, morning loop, heartbeat loop, startup loop
- Core rule for agent autonomy: "Is this reversible without embarrassment to me?"
- Uses a VPS separate from his main machine for most AI work, with limited keys
- Uses a vault directory (thousands of markdown files) with Zettelkasten approach for knowledge management
- Uses Lianne (CLI embeddings tool) to search across all transcripts, links, and content
- Building AirSkills — a platform for packaging, managing, and sharing skills across teams
- Building Lockbox — a tool to prevent file system access after reading untrusted tokens
- Previously built complex N8N workflows but found them brittle; replaced with simple Claude Code skills in loops
- Active on LinkedIn, posts content about AI and agent workflows
- Advocates for Theory of Constraints (Eliyahu Goldratt) in AI adoption
- Cautions against spec-driven development as potential return to waterfall
- Believes "everything is a loop" — coding, project management, CEO work all follow loop cadences
