## Definition

Nitesh is an AI engineer at [[Every]] cited by [[Dan Shipper]] as fitting the "[[Forward Deployed Engineer]]" profile — a person responsible for keeping a company's shared agent working well.

## Key Information

- Spends most of his time in Slack talking to [[Claudie]], the internal agent that runs Every's consulting practice, correcting and directing it ("why did you do this dumb thing? let's fix that") rather than writing code directly, though he does also use Claude Code and other coding tools.
- Cited as an example of a new kind of engineering role that loves working hands-on with the latest agent tooling in a way that looks different from traditional software engineering.
