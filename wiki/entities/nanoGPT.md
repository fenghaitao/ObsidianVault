## Definition
nanoGPT is an open-source project by Andrej Karpathy (former co-founder of OpenAI) that provides a minimal, educational implementation of a GPT-style language model. It uses NumPy for many calculations at a lower level than typical PyTorch implementations, serving as a blueprint for understanding how transformers work from scratch.

## Key Information
- Created by Andrej Karpathy, one of the co-founders of OpenAI
- A minimal, educational GPT implementation that goes deeper into low-level calculations using NumPy
- Served as the inspiration for Angelos Perivolaropoulos's workshop on training an LLM from scratch
- Perivolaropoulos described it as "a very special project" and his first exposure to transformers and LLMs
- The workshop implementation is "a bit lower level" than nanoGPT, which goes deeper into NumPy-based calculations
- Provides a blueprint for creating a model from scratch that can be followed and adapted
