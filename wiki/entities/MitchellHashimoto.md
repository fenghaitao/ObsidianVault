## Definition
Mitchell Hashimoto is the founder of Ghosty, the open-source terminal emulator. He is a notable user of Amp Code, using it to drive development of Ghosty. He also created the "vouch" tool based on Mario Zechner's approach to filtering AI-generated ("clanker") issues and PRs from open-source projects.

## Key Information
- Founder of Ghosty, an open-source terminal emulator
- Uses Amp Code to drive many of the changes he makes to Ghosty
- Cited by Beyang Liu as an example of the type of forward-looking developer Amp Code targets
- Told Mario Zechner that Claude Code is "now a game engine" (a running gag about feature bloat)
- Created the "vouch" tool based on Mario Zechner's approach: auto-close PRs, ask for a human-written issue, whitelist accounts that respond — clankers never come back, making it a perfect filter
- Runs exactly two agents — "two is enough for me" — cited by Gergely Orosz as an example of personal preference in agent orchestration
