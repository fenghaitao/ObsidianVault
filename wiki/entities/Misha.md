## Definition

Misha is a software engineer at Iterate who co-presented the aiDotEngineer workshop on event-sourced agent harnesses with Jonas Templestein. He contributed to the workshop SDK, examples, and the Schematch Zod helper library.

## Key Information

- **Affiliation**: Works at [[Iterate]] with [[Jonas Templestein]]
- **Workshop contributions**:
  - Created the ai-engineer-workshop GitHub repo with runnable curl examples in workshop.md
  - Built example processors (hello world counter, ping-pong) in the workshop repo
  - Added abort signal handling to subscription examples
  - Pushed SDK and example updates live during the workshop
- **ScheMatch**: Created a Zod helper library used in the workshop for type-safe event payload matching in reducers
- **Role**: Supportive co-presenter who helped debug issues and run examples when Jonas's computer had performance problems
