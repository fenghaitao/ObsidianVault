## Definition

Julia is a high-level, high-performance programming language designed so that code written like Python or MATLAB can run at C-like speed. John Myles White was one of its core contributors.

## Key Information

- Created by MIT math people who wanted to get rid of MATLAB; it targeted that market more than data science initially, though White pushed it toward data science.
- Its pitch: write high-level code that runs fast, rejecting the "we can't be fast, and fast isn't important" attitude of parts of the Python/R community.
- Motivating example: R's distance-matrix function is C code (for loops) underneath; translated naively into R it runs 1,000–10,000x slower than C. Julia was about making that gap unacceptable.
- White says it has not "totally won" but is "actually doing okay" — in the top 25 programming languages by users.
- Programming languages are products in zero-sum ecosystem competition; claiming otherwise "is clearly false and just makes everyone worse."
