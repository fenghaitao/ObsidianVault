## Definition
Liam McGarrigle is a Developer Advocate at n8n who leads workshops on building AI agents with human-in-the-loop automation using the n8n platform.

## Key Information

- **Role**: Developer Advocate at n8n
- **Presented at**: AI Engineer conference (aiDotEngineer), May 2026
- **Workshop**: "Human-in-the-Loop Automation with n8n" — hands-on session building a Gmail and calendar management agent
- **Key techniques demonstrated**:
  - Building AI agents with n8n's visual workflow builder
  - Using OpenRouter for multi-model LLM access
  - Adding human-in-the-loop review nodes to intercept destructive actions
  - Configuring fine-grained tool permissions (field-level access control)
  - Tool prompting strategies (descriptions in tool nodes vs system prompt)
  - JavaScript expressions for date formatting (Luxon library)
  - n8n's native MCP server for exposing workflows as tools
  - Sub-agent orchestration pattern for scaling agents
  - Slack integration for human review in messaging platforms
- **Notable contributions**: Built n8n's entire coupon generation system as a REST API in n8n in ~6 hours
- **Teaching style**: Hands-on workshop format with notion documentation, workflow JSON provided for reference, emphasis on practical foundations
