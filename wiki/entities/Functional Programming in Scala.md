## Definition

Functional Programming in Scala is the single best technical book Boris Cherny has ever read. It teaches functional programming and thinking in types using Scala, though Boris notes you're unlikely to actually use Scala.

## Key Information

- Boris's favorite technical book
- Boris: "The single best technical book I've ever read"
- Teaches functional programming and thinking in types
- Boris acknowledges it's "very weird" because you're not going to use Scala
- Boris: "You could think of it as a historical artifact. You could think of it as something that will level you up"
- Represents the elegance of functional programming that shaped Boris's thinking about code
