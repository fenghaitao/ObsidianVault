## Definition
LLVM is a compiler infrastructure/framework that most modern programming languages use to generate code.

## Key Information
- Bjarne: "you have frameworks like LLVM that most of the modern languages use to generate decent code."
- His amusing observation: most languages that compete with C++ do so using C++ infrastructure (LLVM itself being C++ code).
