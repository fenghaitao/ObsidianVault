## Definition

Claude Tag is an Anthropic feature (the ability to tag/@-mention Claude, e.g., in a channel) for running asynchronous and recurring workflows — positioned alongside Claude Code as the tool for the rest of the software development life cycle.

## Key Information

- Thariq's framing: "Claude Code is really good at the implementation of code, and Claude Tag is for the rest of the software development life cycle" — getting feedback, code review, "babysitting," building CI/CD, and incidents.
- Natural fit for loop engineering: asking it "every day do this thing" becomes a running loop without much extra thought.
- People build unique Claude Tag setups — scheduling calendar invites (tag Claude in a channel to accept bookings), triaging email, and "multi-Clauding" (tmux-like displays of many parallel Claude instances).
- By tracking issues and running routine SDLC work, Claude Tag lets teams stay on top of work they previously could not monitor, increasing software-development velocity.
- Distinct from Claude Code's code-implementation focus, but discussed as a complement that increasingly shares the artifact/report interaction surface.
