## Definition

Opus 4.6 is Anthropic's current most capable model. It can run 10-30 minutes unattended on average, and up to hours or days. Boris always uses it with maximum effort enabled.

## Key Information

- Current most capable model from Anthropic
- Can run 10-30 minutes unattended on average
- Can run for hours or even days at a time; some examples ran for many weeks
- Boris always uses it with maximum effort mode enabled
- Boris: "4.6 is just incredible"
- With plan mode, "it's just going to one-shot it. It'll get it right the first time almost every time with Opus 4.6"
- Boris recommends always using the most capable model because it's actually cheaper in total token usage
