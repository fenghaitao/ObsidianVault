## Definition
The Browser Operator is a Manus AI feature that opens and controls browser tabs on the user's local computer, enabling authenticated platform interactions (LinkedIn, Instagram) that sandbox browsers cannot access.

## Key Information
- Launches browser tabs on the user's own computer rather than in a sandbox
- Enables access to platforms where the user is already logged in
- Supports running multiple browser instances in parallel
- Can be scheduled for recurring tasks (e.g., daily automation on a Mac Mini)
- Requires user permission and approval to prevent unauthorized tab spawning
- Not yet available through the API as of December 2025; permission system improvements planned
- Roadmap includes research browser capabilities and improved authorization flows
