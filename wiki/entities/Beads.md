## Definition
Beads is a ticketing system created by Steve Yegge, designed to work with AI agents. It operates within a project folder and provides a lightweight alternative to traditional ticketing systems for AI-driven development workflows.

## Key Information
- Created by Steve Yegge
- Works within a single project folder — installs as a small local tool
- Designed for AI agent workflows, providing a simple ticketing format that agents can read and update
- Chris Parsons recommends it as an alternative to flat markdown ticket files for Ralph loops
- Installable via `bd install`
- Lightweight compared to Linear, Jira, or other full ticketing systems
