# Hebbia

[[Hebbia]] is an AI knowledge worker platform serving financial and legal services firms. It uses [[Claude3Haiku]] with [[ToolUse|tool use]] capabilities to power multi-step customer workflows for document analysis, suggestions, and automation.

## Overview

- **Type**: AI knowledge worker platform for professional services
- **Target sectors**: Financial and legal services industries
- **Core value**: Automating knowledge worker tasks with agentic AI
- **LLM**: [[Claude3Haiku]] for fast, cost-effective task execution
- **Key capability**: [[ToolUse|Tool use]] for agentic workflow automation

## Platform Capabilities

Hebbia enables organizations to:
- Generate real-time AI suggestions for professionals
- Automate prompt writing for domain-specific tasks
- Extract key metadata from long documents
- Handle multi-step, agentic workflows
- Maintain context across complex document sets

## Use Cases

- **Document analysis**: Extract key information from legal contracts, financial documents, and domain-specific materials
- **Suggestion generation**: Real-time AI suggestions for professionals based on context
- **Prompt automation**: Automated generation of effective prompts for domain-specific tasks
- **Metadata extraction**: Intelligent extraction of critical metadata from long document sets
- **Multi-step workflows**: Complex, tool-driven automation across multiple steps

## Impact and Performance

[[Claude3Haiku]] with [[ToolUse|tool use]] unlocked:
- Faster capability deployment
- Improved reliability of suggestions
- Real-time processing at scale
- Cost-effective inference for enterprise use

**Quote** (Divya Mehta, Product Manager):
> "We leverage Claude 3 Haiku for generating live suggestions, automating prompt writing, and extracting key metadata from long documents. Claude 3 Haiku's tool use feature has unlocked capabilities and speed for our platform to generate reliable suggestions and prompts in real-time."
