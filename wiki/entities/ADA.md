# ADA

## Definition

ADA is a programming language used by government agencies to run critical infrastructure worldwide. It was featured in Poolside's demo where their coding agent analyzed an ADA codebase and converted it to Rust.

## Key Information

- **Domain**: Government and defense critical infrastructure
- **User Base**: Primarily three-letter agencies, defense contractors, and missile systems
- **Demographic**: Referenced by Jason Warner as a language known primarily by older engineers ("either has no hair or gray hair")
- **Poolside Demo**: Used as the source language for a codebase conversion to Rust, demonstrating Poolside's capability in high-consequence code environments
