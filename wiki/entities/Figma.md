## Definition

Figma is a collaborative design platform that uses Claude to power Figma Make, which translates design canvas elements into pixel-perfect code. Claude was chosen because it "clearly just seems to know code better than most of the models." Anthropic's marketing team also built a Figma plugin with Claude Code to automate ad creative variant generation.
