## Definition

Figma is a collaborative design platform that uses Claude to power Figma Make, which translates design canvas elements into pixel-perfect code. Claude was chosen because it "clearly just seems to know code better than most of the models." Anthropic's marketing team also built a Figma plugin with Claude Code to automate ad creative variant generation — this initiative is documented in both an earlier internal video transcript and a later January 2026 blog post giving the builder's name (growth marketer Austin Lau) and additional detail (a companion Google Ads copy workflow, ~45-60 minutes to build, 30 minutes → 30 seconds per ad).

At [[Brex]], content designer Andy Reed used [[ClaudeCode]] to build a Figma plugin that automatically reviews designs against Brex's internal standards.
