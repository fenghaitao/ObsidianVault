## Definition
Fish Jam is a WebRTC service built by Software Mansion that provides easy integration with the Gemini Live API, enabling developers to connect browser-based clients to the Live API with lower latency.

## Key Information
- Built by Software Mansion (Poland)
- WebRTC service for Gemini Live API integration
- Provides lower-latency connections compared to server-to-server proxying
- Part of Google DeepMind's partner ecosystem for real-time audio/video
