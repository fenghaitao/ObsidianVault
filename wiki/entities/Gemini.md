## Definition

Gemini is Google DeepMind's family of multimodal AI models. Natively multimodal — understands and outputs text, images, video, audio, and code with the same model. Available through AI Studio and the Gemini API.

## Key Information

- Gemini 2.5 Pro: flagship model with native multimodality, available for free in AI Studio
- Gemini 2.5 Flash: faster, lighter variant
- Gemini Nano: small enough to run on mobile devices or embed in Chrome
- Features: speech generation (multispeaker), live video/audio streaming, built-in web search and URL context tools
- AI Studio "Build" feature: one-click app generation with deploy to Cloud Run
- Gemma 3N (4B params): open model exceeding Gemini 1.5 Pro capabilities
- Used in PydanticAI agents (David Hewitt's Blue Sky firehose demo, Samuel Colvin's MCP sampling demo)
