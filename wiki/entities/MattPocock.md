## Definition
Matt Pocock is a software educator, YouTuber, and creator of the popular course "Claude Code for Real Engineers." He is known for his work in TypeScript education and his advocacy for applying classic software engineering fundamentals to AI-assisted development.

## Key Information
- Creator of the "Claude Code for Real Engineers" course, teaching developers how to use AI coding tools effectively
- Presented at aiDotEngineer conference with the talk "Software Fundamentals Matter More Than Ever" and a 2-hour workshop "Full Walkthrough: Workflow for AI Coding"
- Created the popular "Grill Me" skill — a prompt that makes AI interview the user relentlessly to reach shared understanding (repo has ~13,000 stars)
- Created the "Ubiquitous Language" skill — scans codebase for terminology and creates a shared language markdown file
- Created the "Improve Codebase Architecture" skill — restructures code into deep modules
- Created the "Write a PRD" skill — generates product requirements documents from grilling sessions
- Created the "PRD to Issues" skill — breaks PRDs into Kanban boards of independently grabbable issues using vertical slices
- Created Sandcastle — a TypeScript library for running parallel AI agent loops in Docker sandboxes
- GitHub repo: macpocockskills — collection of AI coding skills
- Active on YouTube and Twitter; newsletter at aihero.dev; website aihero.dev
- Argues that software fundamentals (from books like A Philosophy of Software Design, The Pragmatic Programmer, Domain-Driven Design) matter more than ever with AI
- Critiques the "specs-to-code" movement as producing progressively worse code through software entropy
- Advocates for TDD, deep modules, ubiquitous language, and designing interfaces while delegating implementations to AI
- Developed the complete AI coding workflow: Grill Me → PRD → Kanban Board → AFK Ralph Loop → QA
- Introduced the Day Shift / Night Shift metaphor: human plans during the day, AI implements overnight
- Introduced the Push vs Pull pattern for coding standards: pull for implementers, push for reviewers
- Uses Sonnet for implementation and Opus for reviewing
- Prefers clearing context over compacting, comparing LLMs to the protagonist from Memento
- Uses the Smart Zone / Dumb Zone concept from Dex Horthy as a foundational constraint
