## Definition

Brian O'Sullivan is the Facebook/Meta manager (then Michael Bolin's manager) who convened the team to build the virtual file system that got ahead of monorepo scaling.

## Key Information

- Decided to get people together to work on a virtual file system as a proactive answer to the repo's growing scaling problem.
- Assembled Michael Bolin, Adam Simpkins, and Wes Furlong to build what became the Eden VFS and, downstream, Miles file search.
