## Definition

Wiz is a cloud security company that provides the Wiz Security Graph for contextualizing cloud risk. It is a [[ClaudeSecurity|Claude Security]] technology partner, building Wiz Red Agent on [[Claude4.7Opus|Claude Opus]] for AI-powered offensive security testing.

## Key Information

- **Wiz Red Agent**: an AI-powered attacker that uses Claude Opus to reason like a human pentester across production web applications and APIs. It analyzes application logic, chains steps, and adapts to real-time server responses to surface logic-driven flaws traditional scanners miss.
- **Scale**: runs continuously across more than 150,000 production assets per week, surfacing thousands of high- and critical-severity findings, each validated with proof of exploitability and business context from the Wiz Security Graph.
- **Technology partner (April 2026)**: named among the technology partners embedding Claude Opus into their own security tools as part of Claude Security's public beta launch.
- Quote: *"Security teams are no longer limited by a lack of data, but by the ability to act on it. By embedding frontier models into Wiz Agents, we're enabling organizations to defend at the speed of AI."* — Alon Schindel, VP AI & Threat Research, Wiz.
