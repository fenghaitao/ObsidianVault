## Definition

Brennan Dunn is a SaaS founder (RightMessage) featured on Brian Casel's Builder Stories series. He built a team of AI developers using Claude Code sub-agents with custom roles (project manager, senior developer) connected to Linear for task management, and uses Fern Desk for auto-generated documentation.

## Key Information

- Founder of RightMessage, a customer data platform with 250 paying customers.
- Sub-agent system: project manager agent (business requirements) → senior developer agent (technical planning) — chained automatically.
- Custom CLAUDE.md files define each agent role.
- Linear integration: tasks flow through Linear as AI agents work.
- Uses Fern Desk: auto-generates help documentation by analyzing codebase, Git commits, and Linear tasks.
- Mindset shift: "What's the absolute best version of this feature? Claude's going to be the one building it."
- Ships fast and iterates — can throw away a feature and rebuild without the old cost concerns.
