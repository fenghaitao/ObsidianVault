## Definition
Redux is a JavaScript state management library commonly used with React. OpenHands was used to migrate their entire frontend from Redux to Zustand using parallel agent orchestration.

## Key Information
- State management library for JavaScript applications, widely used with React
- OpenHands migrated their frontend from Redux to Zustand using scaffolding patterns and parallel agents
- The migration used a scaffolding approach where both Redux and Zustand coexisted temporarily, allowing incremental validation of each migrated component
