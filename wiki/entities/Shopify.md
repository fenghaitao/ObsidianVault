## Definition
Shopify is an e-commerce platform company that uses the Gemini Live API for Shopify Sidekick, an AI-powered tech support feature that walks users through store setup tasks with real-time voice and screen sharing.

## Key Information
- Uses Gemini Live API for Shopify Sidekick
- Sidekick provides real-time voice-guided tech support
- Can see the user's screen via video frame ingestion (screen share at 1 fps)
- Example use case: helping users set up custom domains for their Shopify store
- Demonstrates enterprise adoption of the Gemini Live API for customer-facing applications
- First company to get GitHub Copilot access in 2021 — a full year before public release — by having Farhan Thawar directly negotiate with GitHub CEO Thomas Dohmke
- Gives unlimited AI tool budget to engineers; strategy is to trade churn and expense for being months ahead of competition
- CTO Mikael Paryk: Shopify's ML infrastructure is so impressive it "makes me want to be a customer" (swyx)
