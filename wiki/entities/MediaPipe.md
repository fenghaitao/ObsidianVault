## Definition
MediaPipe is Google's framework for building multimodal machine learning pipelines. It was demonstrated at AIE in the context of a hand-tracking game app built with AI Studio.

## Key Information
- Google framework for multimodal ML pipelines
- Demonstrated in a hand-tracking game app in AI Studio's gallery
- App used camera access to track hand position for gameplay
- Code for MediaPipe-based apps is inspectable and remixable in AI Studio
