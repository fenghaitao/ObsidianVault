## Definition
Snyk is a developer security company that has expanded into scanning AI context — checking prompts, skills, and agent instructions for credential exposure, third-party risks, and other security vulnerabilities.

## Key Information
- Known for developer-focused security scanning (open source dependencies, containers, IaC)
- Now scanning context (prompts, skills, agent instructions) for security issues
- Checks for credential handling and third-party exposure in context
- Part of the emerging "context security" space — applying DevSecOps principles to AI context
