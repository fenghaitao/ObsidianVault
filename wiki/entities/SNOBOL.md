## Definition

SNOBOL (transcribed in the episode as "Snowball") is a very old programming language that Roberto Ierusalimschy cites as among the first to feature pattern matching, and one he recommends studying for its distinctive ideas.

## Key Information

- Roberto recommends SNOBOL among languages to study, noting it was likely the first language with pattern matching and strong patterns.
- He values studying older languages because modern languages have become too uniform (e.g., everyone copied C's zero-based indexing), and older languages still hold interesting — even if not always good — ideas.
