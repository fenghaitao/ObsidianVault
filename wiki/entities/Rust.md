# Rust

## Definition

Rust is a systems programming language focused on safety and performance. In Poolside's demo, their coding agent converted an ADA codebase to Rust, including self-testing and iterative feature addition.

## Key Information

- **Characteristics**: Memory-safe systems language, known for its borrow checker
- **Poolside Demo**: Target language for ADA-to-Rust codebase conversion by Malibu Agent
- **Demo Features**: Agent wrote 1,152 lines of Rust code, ran tests, added a command history feature using the `rustyline` library, and handled build warnings
- **Notable Detail**: During the demo, Jason Warner noted potential `unwrap()` calls as dangerous patterns in Rust
