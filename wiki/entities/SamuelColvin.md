## Definition

Samuel Colvin is the creator of Pydantic (the Python data validation library, ~300M downloads/month) and founder/CEO of Pydantic the company. He also created PydanticAI, Logfire, Pydantic AI Gateway, and Monty.

## Key Information

### Background

Originally built Pydantic as an open-source validation library. Founded the company approximately 2 years after the library's success. Noted that "thanks to AI it is now trendy again for CEOs to write code."

### Key Projects

- **Pydantic** — the original validation library, now with a Rust core
- **PydanticAI** — agent framework emphasizing type safety and production readiness
- **Logfire** — OpenTelemetry-based observability platform
- **Pydantic AI Gateway** — unified LLM inference at the edge
- **Monty** — from-scratch secure Python interpreter in Rust for AI code execution

### Views on Open Source and AI

- Advocates for a federated reputation system to combat AI slop PRs
- Four rules for when AI can produce mergable large PRs: known internals, known interface, existing tests, no bikeshedding
- Believes the old contributor-to-maintainer pipeline is broken and something new must emerge
- Monty is largely AI-generated — would not have been possible without leading models
- On the Open Source in the age of AI panel at PyAI Conf 2026
