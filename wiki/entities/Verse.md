## Definition
Verse is a functional logic programming language being designed at Epic Games; it is Simon Peyton Jones's day job.

## Key Information
- "A very exotic language… a functional logic language," more expressive than Haskell.
- Has a static type system, but a very different one from Haskell's.
- SPJ frames it as exploring a very new point in the design space — like functional programming did back in 1980.
- Backed by Epic Games, giving it "much more muscle" than the purely academic functional-programming effort of the 1980s.
