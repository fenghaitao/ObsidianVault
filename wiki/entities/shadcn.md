## Definition
shadcn/ui is an open-source UI component library and code distribution platform built on Radix UI and Tailwind CSS. ElevenLabs Voice Engine uses shadcn-style components for its voice agent widgets.

## Key Information
- Open-source UI component library built on Radix UI and Tailwind CSS
- Components are copied into your project (not installed as a dependency), giving full control over the source code
- Referenced by Luke Harries as the style basis for ElevenLabs Voice Engine UI components, alongside Vercel's design language
- Widely adopted in the AI engineering community for building agent interfaces
