# Eiso Kant

## Definition

Eiso Kant (also referred to as "ISO") is the co-founder of Poolside. He was an early pioneer in neural code completion, having built working code completion systems using LSTMs before the transformer architecture had fully landed. Jason Warner initially tried to acquire his company in 2017 but was turned down.

## Key Information

- **Role**: Co-founder of Poolside
- **Early Work**: Built working code completion using LSTMs before transformers became dominant (2017)
- **Relationship with Jason Warner**: Met through a failed acquisition attempt at GitHub in 2017; became close friends and eventually co-founded Poolside together
- **Poolside Founding**: Initially reluctant ("Oh, god damn no"), suggesting they should "learn how to paint and sail" instead
- **Technical Vision**: Strong advocate for combining reinforcement learning with LLMs as the path to more capable intelligence
