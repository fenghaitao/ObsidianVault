# Prisma

Prisma is an ORM (Object-Relational Mapping) and database toolkit that integrates with [[Claude]] through Claude's local desktop connector ecosystem. Prisma enables developers to work with databases using an intuitive API and can be connected to Claude for database-aware development workflows.

## Integration with Claude

Prisma is available as a local desktop extension through the [[Claude]] Desktop app, allowing developers to give Claude access to database schemas and context for database-driven development tasks.
