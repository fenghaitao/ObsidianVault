## Definition

Elisa is a block-based visual integrated development environment (IDE) built by software engineer Jon McBee, 2nd-place winner of Anthropic's "Built with Opus 4.6" Claude Code hackathon, designed to give non-coders (starting with his 12-year-old daughter) access to the same agentic development power as [[ClaudeCode]] without writing code.

## Key Information

- Users design software by snapping together primitives (goals, requirements, agents, skills, rules, portals, deployments) in a visual language; a meta-planner decomposes the spec into a task graph, and AI agents write the real code behind the scenes.
- Includes a built-in teaching engine that surfaces age-appropriate explanations of the programming concepts being used, turning every build into a lesson.
- McBee's daughter used Elisa to flash code onto a microcontroller for her seventh-grade science fair project without writing a single line of code.
- Built with Claude Code in 30 hours across six days: 76 commits, 39,000+ lines of code, 1,500+ tests.
- McBee is using the $30,000 in Claude API credits (2nd-place prize) to fund classroom pilots; educators have reached out about classroom use.
- Reflects a thesis (McBee's) that software creators will increasingly work with well-defined tests and specifications rather than writing source code directly.
