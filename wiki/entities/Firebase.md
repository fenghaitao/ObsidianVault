## Definition
Firebase is Google's app development platform used for database (Firestore) and authentication (Google login) in AI Studio's "Build" feature, enabling full-stack app creation with persistent user data.

## Key Information
- Google's app development platform
- Used in AI Studio's Build feature for authentication (Google login) and database (Firestore)
- AI Studio automatically sets up Firebase when building apps requiring auth and persistence
- Enables apps to save user data and persist across sessions
- Demonstrated in the bookshelf cataloger app that saved book data per user
