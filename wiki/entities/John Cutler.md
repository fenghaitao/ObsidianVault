## Definition

John Cutler (transcribed "John Cuddler") is a product thinker credited by [[Elena Verna]] with a three-stage framework for how software categories mature: capability (what is even possible to build), value (how do users get value from it), and scale (which parts of life/work can this expand into).

## Key Information

- Verna cites this framework to argue that vibe coding is still very much in the capability-discovery stage: what's possible to build changes every one to three months as underlying models improve, which is why users and companies must constantly return to re-explore the category.
