# Claude 2

Claude 2 was Anthropic's state-of-the-art large language model released in 2023, built using [[ConstitutionalAI]]. It represented a major capability leap and was among the first Anthropic models made available on cloud platforms like [[AmazonBedrock]].

## Key Information

- Creator: [[Anthropic]]
- Release context: 2023; successor to Claude 1.3 and Claude Instant
- Training methodology: [[ConstitutionalAI]]
- Available via: [[AmazonBedrock]] (AWS managed service), Anthropic API
- Strengths: thoughtful dialogue, content creation, complex reasoning, creativity, coding
- Notable feature: long context windows valued for processing detailed documents (e.g., legal)
- Compliance: used in HIPAA and SOC II compliant enterprise deployments

## Enterprise Adoption (at launch on Amazon Bedrock)

- **[[LexisNexis]]** — legal AI capabilities; valued long context windows and data security
- **[[LonelyPlanet]]** — travel content integration; scalable and secure generative AI
- **[[RicohUSA]]** — training data generation; HIPAA/SOC II compliance
