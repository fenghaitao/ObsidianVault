## Definition
Remotion is an open-source tool for creating videos programmatically using React. It enables developers to build animations, motion graphics, and video content through code rather than traditional video editing software.

## Key Information
- Open-source React-based video creation tool
- Used by Dotta Bippa in a Paperclip demo to create a celebration video for 40,000 GitHub stars
- Paperclip has a "Remotion best practices" skill available via skills.sh for agents to use
- Enables programmatic video creation with animations, charts, and branded content
- No sign-up required to use
- Paperclip agents can be given the Remotion skill to autonomously create branded videos using company stats and brand guides
