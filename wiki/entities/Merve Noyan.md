## Definition
Merve Noyan is a member of the open source team at Hugging Face who presented at AIE CODE 2026 on the open agent ecosystem, covering self-training agents, Hermes Agent, Hugging Face Traces, Skills, and MCP integration.

## Key Information
- Works in the open source team at Hugging Face
- Presented at AIE CODE 2026 on self-training agents and the Hugging Face agent ecosystem
- Strong advocate for open models, citing GLM 5.1 as a top performer for agent use cases
- Personally uses open models in her coding setup and recommends GLM 5.1 with Hermes Agent
- Described Hugging Face Skills (LLM Trainer, Gradio, Dataset skills) as "absolute sci-fi" — the ability to fine-tune models by simply telling an agent to do it
- Has been training models for approximately 6 years and finds the skill-based automation paradigm transformative
- Demonstrated end-to-end fine-tuning workflow: ask agent to "train Qwen-2-VL on Lava-Instruct-MiX" → agent handles VRAM calculation, instance selection, and job launching
- Collaborated with Niels on OCR pipeline processing 30,000 papers using Hugging Face infrastructure
