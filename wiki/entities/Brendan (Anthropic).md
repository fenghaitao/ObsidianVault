## Definition

Brendan is a data scientist at Anthropic who was one of the first non-engineers to adopt Claude Code. He downloaded Node.js, opened a terminal, and used Claude Code for SQL analysis, shocking Boris. The next week, all the data scientists followed.

## Key Information

- Data scientist at Anthropic
- Early non-engineer adopter of Claude Code for SQL analysis
- Boris was shocked to see Brendan using a terminal product as a data scientist
- His adoption triggered all other data scientists at Anthropic to follow
- Boris: "Brendan was had a Claude Code on his computer. He just had a terminal up. And I was like I was shocked. I was like, 'Brendan, what are you doing? You figured out how to open the terminal'"
