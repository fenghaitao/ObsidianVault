## Definition

Ticketmaster is a ticketing platform, used by Butterfield as an example of a product where friction doesn't matter much because user intent is maxed out.

## Key Information

- When buying Taylor Swift tickets, users have perfect comprehension, maxed-out specificity of intent, and maxed-out degree of intent
- In this scenario, it doesn't matter if the website is slow or the payments page errors out — the user will persist
- This is the rare case where friction reduction provides less incremental value because the user will overcome any obstacle
