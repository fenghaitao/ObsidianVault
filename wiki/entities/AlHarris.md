## Definition
Al Harris is a Principal Engineer at Amazon, working on Kiro, Amazon's agentic IDE for spec-driven development.

## Key Information
- Principal Engineer at Amazon
- Has been working on Kiro since its early days, part of a very small team of 3-4 people
- Presented at the AI Engineer conference on spec-driven development with Kiro
- Has 25-30 years of industry experience building software with various practices (waterfall, XP, etc.)
- Advocates for structured workflows over vibe coding to improve code quality and reliability
- Built a demo project called "Gramps" — a dad joke generator deployed to AWS Agent Core
- Kiro team uses Asana as their task tracker of choice
- Open-sourced example MCP servers: Nobel Prize MCP and Lofty Views MCP on GitHub
