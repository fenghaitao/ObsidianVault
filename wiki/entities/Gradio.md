## Definition
Gradio is a Python library for building simple web UIs for machine learning models. It is used by MLX VLM to provide a chat interface (`mlx_vlm.chat_ui`) for interacting with vision-language models on-device.

## Key Information
- Python library for quickly building ML demo interfaces
- Used by MLX VLM for its chat UI: `mlx_vlm.chat_ui` launches a Gradio interface
- Provides image upload and chat functionality for vision-language model interaction
- Simple command-line invocation for quick demos
