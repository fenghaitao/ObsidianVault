# Claude 3.5 Sonnet

Claude 3.5 Sonnet is [[Anthropic]]'s most powerful generally available Claude model, featuring advanced vision, multilingual, and reasoning capabilities. It represents the latest generation of the Claude Sonnet family.

## Key Information

- **Creator**: [[Anthropic]]
- **Capabilities**: Vision (image analysis), multilingual support, advanced reasoning
- **Availability**: Accessible across web, iOS, and Android platforms via the Claude app
- **Access Plans**: Available across all Claude plans (free, Pro, Team)
- **Distribution**: Accessible through multiple channels including [[Google Play]] (Android)
- **Notable feature**: Most capable model in the Claude lineup, powering [[Claude Android App]] and other platform clients

## Capabilities

- Vision and image understanding
- Multilingual processing and translation
- Complex reasoning and analysis
- Coding assistance and [[CodeExecution]]
- Content creation and brainstorming
- Knowledge work and business applications
- Data analysis and processing (via [[CodeExecution]] in [[Claude.ai]])
- [[WebSearch]]: Real-time internet search with citations for up-to-date information
- **METR time horizon (as of March 2026 retrospective)**: when Claude Code was first built on Sonnet 3.5 (new), [[METR]] measured it could reliably do software tasks taking a human ~21 minutes — a baseline later benchmarks (e.g. Opus 4.6's ~12 hours) are compared against as a ~41x jump in 16 months.
