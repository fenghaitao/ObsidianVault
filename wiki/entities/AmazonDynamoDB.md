## Definition
Amazon DynamoDB is AWS's NoSQL database service. It was mentioned in the Kiro talk as a potential alternative to S3 for agent session persistence.

## Key Information
- Mentioned as an alternative AWS service for session persistence alongside S3
- Part of the discussion about not locking into a single familiar solution when better alternatives may exist
- Kiro's spec-driven workflow can research and recommend DynamoDB vs. S3 vs. other options based on idiomatic usage patterns
