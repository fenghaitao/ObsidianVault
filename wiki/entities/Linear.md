## Definition

Linear is a project management and issue tracking tool for software teams. It is included in Lenny's Newsletter "Product Pass" as a sponsor product.

## Key Information

- Project management and issue tracking tool for software teams
- Included in Lenny's Newsletter "Product Pass" alongside other productivity tools
- Claire Vo uses Linear as a "tasking substrate" for her OpenClaw agents — agents assign her Linear tickets for real-world tasks she needs to do (e.g., fax the doctor's office, do a return)
- This creates a two-way tasking system: Claire assigns tasks to agents, and agents assign tasks back to Claire via Linear
