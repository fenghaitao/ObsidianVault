## Definition
Ara Khan is an engineer at [[Cline]], the open-source coding agent company. He presented "Evals Are Broken, Use Them Anyway" at the [[aiDotEngineer]] conference, offering a practitioner's perspective on how to build, interpret, and leverage evals for improving AI coding agents.

## Key Information
- Works at [[Cline]] on coding agent development and evaluation
- Has been working on evals professionally for years
- Led Cline's transition from ignoring evals entirely to building custom evaluation datasets from real user coding problems
- Advocate for a middle-ground approach to evals: neither treating benchmark numbers as gospel nor dismissing them entirely
- Developed Cline's internal benchmark for testing models across open-source and frontier model families
- Uses [[TerminalBench]], [[Harbor]], and [[Modal]] for Cline's evaluation infrastructure
- Active on Twitter/X, open to DMs about evals and coding agent problems
