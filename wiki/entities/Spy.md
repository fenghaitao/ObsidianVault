## Definition
Spy is a terminal application that recently announced support for MCP Apps, enabling UI rendering within the terminal environment. It demonstrates that MCP Apps works beyond web-based chat interfaces.

## Key Information
- Terminal application with MCP Apps support
- Recently announced MCP Apps support, described as "amazing"
- Demonstrates that MCP Apps can render UI even in terminal environments, not just web-based hosts
- "It's like a terminal, right? But we have UI in the terminal right now"
