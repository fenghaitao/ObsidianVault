## Definition

GPT-3 is a large language model released by OpenAI in 2020. Its release directly inspired Edwin Chen to found Surge AI.

## Key Information

- GPT-3's release in 2020 made Edwin realize that "if we wanted to take things to the next level and build models that could code and use tools and tell jokes and write poetry and solve the Riemann hypothesis and cure cancer, then we were going to need a completely new solution" for training data
- Edwin founded Surge AI one month after GPT-3 launched, recognizing the gap in high-quality data infrastructure for advanced AI use cases
- Prior to GPT-3, data annotation companies were focused on simple tasks like image labeling — Edwin saw the need for something focused on advanced, complex use cases
- GPT-3 was used by Math GPT, an early prompt injection victim where attackers tricked the model into writing code that exfiltrated the OpenAI API key from the application server
