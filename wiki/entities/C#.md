## Definition

C# is a programming language designed by Anders Hejlsberg at Microsoft, where his main role was language designer and spec writer rather than compiler implementer.

## Key Information

- Designed by Anders Hejlsberg; on the C# project his job was writing the spec and designing language features, not implementing the compiler.
- Ideas pioneered in C# have spread elsewhere — Hejlsberg cites `async` as pioneered in C# and later adopted by JavaScript and other languages.
- TypeScript's origin runs indirectly through C#: the Outlook.com team approached the C# group to productize Script# (transpile C# to JavaScript for browser tooling), which prompted the "couldn't we just fix JavaScript?" question that led to TypeScript.
- C# adopted ideas from functional programming, while other languages adopted ideas from C# — "we all learn from each other" and "stand on the shoulders of giants."
