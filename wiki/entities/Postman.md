## Definition
Postman is an API development platform that supports MCP Apps as a host, rendering interactive UI from MCP servers within its interface. Staff engineer Ruben Casas has conducted generative UI research at Postman, building experimental agents that generate UI code on the fly.

## Key Information
- Supports MCP Apps as a host
- Mentioned alongside other MCP Apps hosts (Claude, ChatGPT, VS Code, Cursor, Goose, LibreChat, Spy)
- Represents the growing ecosystem of tools adopting the MCP Apps standard
- **Generative UI experiment**: Ruben Casas built a weather agent at Postman that goes to a weather API, creates a joke, and generates HTML/CSS/JS all in one tool call — demonstrating the generative components paradigm
- Casas presented the three-era framework for AI-generated UI (static → declarative → generative) at aiDotEngineer
