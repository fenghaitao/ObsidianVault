## Definition
Postman is an API development platform that supports MCP Apps as a host, rendering interactive UI from MCP servers within its interface.

## Key Information
- Supports MCP Apps as a host
- Mentioned alongside other MCP Apps hosts (Claude, ChatGPT, VS Code, Cursor, Goose, LibreChat, Spy)
- Represents the growing ecosystem of tools adopting the MCP Apps standard
