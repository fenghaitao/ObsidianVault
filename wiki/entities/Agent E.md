## Definition

Agent E is an open-source web agent developed by Emergence that can autonomously operate web browsers and automate complex workflows, functioning like a human controlling the web. It currently leads the Web Voyager Benchmark.

## Key Information

- Developed by Emergence under the leadership of colleague Tamer.
- Designed to control the web like a human would, performing tasks such as making reservations, filling forms, and automating multi-step web workflows.
- Currently the top-performing agent on the Web Voyager Benchmark.
- Integrates with Emergence's orchestrator agent, enabling complex multi-agent enterprise workflows.
- Open-source project, enabling community contributions and enterprise customization.
- Target enterprise use cases include RPA-style web automation, document processing, and claims processing.
