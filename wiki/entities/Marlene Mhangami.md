## Definition
Marlene Mhangami is a Senior Developer Advocate at both Microsoft and GitHub, working in the Core AI group that studies how developers are using AI across Microsoft and GitHub products.

## Key Information
- Senior Developer Advocate at Microsoft and GitHub (dual role)
- Member of the Core AI group, which researches developer AI usage patterns
- Presented at AI Engineer conference on functionality testing with Playwright MCP
- Advocates for a modified TDD workflow where AI agents handle red (write failing behavioral tests) and green (make them pass) phases, while developers focus on refactoring
- Demonstrated GitHub Copilot CLI with Playwright MCP server and Work IQ (M365 integration skill)
- Recommends Playwright Agents (planner/generator/healer agent.md files) for complex state management scenarios
- Emphasizes clean code bases as a prerequisite for AI productivity gains, citing Stanford study of 120,000 developers
