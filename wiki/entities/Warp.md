## Definition

Warp is a terminal/developer-tool company that bundles Anthropic's [[ClaudeCodeSkills|claude-api]] skill (April 2026), giving its users expertise in writing production-ready Claude API code.

## Key Information

- One of four external developer tools (alongside [[CodeRabbit]], [[JetBrains]], and [[ResolveAI|Resolve AI]]) that bundle the open-source `claude-api` skill from `anthropics/skills`.
