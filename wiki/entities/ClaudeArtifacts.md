## Definition

Claude Artifacts is an interactive feature within [[Claude]] that allows developers to build, host, and share AI-powered applications directly in the Claude platform without requiring external deployment infrastructure.

## Key Information

- Interactive code artifacts can call Claude via an API to create functional AI applications
- Artifacts are automatically generated by Claude based on natural language descriptions
- Code is fully visible, modifiable, and shareable through generated links
- Eliminates deployment complexity and scaling costs for shared applications
- Claude automatically handles [[PromptEngineering]], error handling, and orchestration logic
- Supports rapid iteration with Claude's built-in debugging and code improvement capabilities
- Initial launch: Beta availability to Free, Pro, and Max plan users (July 25, 2025)
- Expanded availability: Team and Enterprise plans (July 31, 2025)
- File support: Supports uploading PDFs, images, and other files into artifacts (July 2025)
