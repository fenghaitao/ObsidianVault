## Definition
Monday.com is a work management platform mentioned in the MCP Apps talk as an example of a company whose branded, interactive UI could be sent as atomic chunks to chat hosts via MCP Apps.

## Key Information
- Used as an example in the MCP Apps presentation: instead of text responses, companies like Monday.com can send their own interactive UI to chat hosts
- Represents the class of productivity tools that could benefit from MCP Apps for preserving brand identity in agent interactions
- Part of the vision where relevant UI from different companies is composed by a personal assistant
