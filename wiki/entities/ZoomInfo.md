## Definition

ZoomInfo is a go-to-market platform company that used [[Anthropic]]'s Claude prompt generation feature to accelerate the development of a [[RetrievalAugmentedGeneration]] application, achieving a production-ready MVP in days while reducing prompt engineering time by 80%.

## Key Information

- **Business focus**: Go-to-market platform providing actionable recommendations and value to customers
- **Claude adoption**: Integrated Claude models with [[Anthropic]]'s automated prompt generator feature
- **Key personnel**: Spencer Fox, Principal Data Scientist — led the RAG application development
- **Project outcome**: Successfully built a new RAG application MVP in a few days using the prompt generator
- **Efficiency gains**: Reduced time spent on prompt tuning and refinement by 80%
- **Output quality**: Improved output quality while simultaneously shortening development timeline

## Quote

From Spencer Fox, Principal Data Scientist at ZoomInfo:
> "Anthropic's new prompt generator feature enabled us to reach production-ready outputs much faster. It highlighted techniques I hadn't been using to boost performance, and significantly reduced the time spent tuning our app. We built a new RAG application and reached MVP in just a few days, reducing the time it took to refine prompts by 80%."
