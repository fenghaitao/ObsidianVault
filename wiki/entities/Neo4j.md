## Definition
Neo4j is a graph database company that provides knowledge graph technology and has pioneered the context graph architecture for AI agent memory. Its products include the Neo4j graph database, the Cypher query language, the Neo4j Agent Memory open-source package, GraphAcademy (free education), and Aura (free cloud graph database instances).

## Key Information
- Provides the foundational graph database technology used for context graphs
- Developed the **Neo4j Agent Memory** open-source package that combines short-term memory, long-term memory, and reasoning traces into a context graph structure
- Cypher is Neo4j's query language — designed to be both LLM-friendly (LLMs can generate it) and human-readable
- Offers free education through GraphAcademy with a new context graph course
- Aura provides free cloud graph database instances for learning and experimentation
- Graph embeddings (FastRP) and algorithms (Louvain) enable vector search and community detection on graph data
- Context graph architecture demonstrated with a financial services application connected to 10 MCP tools (support tickets, CRM, internal business data)
- Lenny's Podcast demo shows graph-based knowledge extraction and visualization
