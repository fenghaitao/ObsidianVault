## Definition
Meta Ray-Ban smart glasses are wearable devices by Meta. Meta has opened the SDK for these glasses, allowing developers to hook in services like the Gemini Live API — the glasses connect to a phone, which then connects to Gemini Live for real-time AI interaction.

## Key Information
- Smart glasses product by Meta
- SDK has been opened by Meta for third-party integration
- Can be connected to Gemini Live API via phone relay
- Demonstrated with OpenClaw, an open-source project using Gemini Live through the glasses
- Represents the emerging wearable AI assistant category
