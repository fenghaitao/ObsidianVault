## Definition
Tessl is a company building tooling for the Context Development Life Cycle (CDLC), implementing pieces of the Generate → Test → Distribute → Observe → Adapt loop. Founded or joined by Patrick Debois, it provides a registry/marketplace for skills and context packages.

## Key Information
- Building tooling that implements pieces of the Context Development Life Cycle
- Patrick Debois (DevOps pioneer) works at Tessl
- Provides a skills registry/marketplace where users can discover and distribute context packages
- Does specs for knowledge bases — their argument: as long as you have the right grounding docs, it should not matter what you're building, it's all informed by context
- Hosted a conference the same week as the AI Engineer conference
- Mentioned as a reference point for spec-driven development extending beyond just code
