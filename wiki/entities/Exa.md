## Definition

Exa is a web search API that provides programmatic search capabilities. It is used by Claire Vo as an alternative to Brave (the default) for giving her OpenClaw agents web access, and includes people search capabilities for finding professional biographies and information.

## Key Information

- Web search API — programmatic Google alternative
- Used by Claire Vo with her OpenClaw agents instead of Brave (the default)
- Includes people search functionality: can search biographies and professional information
- Used by Sam (Claire's sales agent) to identify whether sign-ups are decision-makers at their companies
- Part of the web search API ecosystem alongside Brave, Perplexity, and others
- More reliable than browser-based web access for AI agents
