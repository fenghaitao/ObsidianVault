## Definition

Z3 is an SMT (satisfiability modulo theories) solver created by Leonardo de Moura at Microsoft Research — a fully automatic, "push-button" solver used for test-case generation and software verification.

## Key Information

- Started about 20 years before this episode, when de Moura joined Microsoft Research.
- An SMT solver is a SAT solver plus background theories (such as arithmetic and arrays), chosen because those theories are needed for software test-case generation and verification.
- Fully automatic: unlike Lean (interactive), Z3 is "push button" — you pose a constraint problem and get an answer, with little ability to influence how it reasons.
- Its input language (SMT-LIB) is deliberately simple and meant for tools, not humans; Z3 often sits as a backend that another program drives.
- Example: encode a Sudoku puzzle as constraints and Z3 returns a solution instantly; for real applications you convert "which inputs reach this vulnerable code path?" into constraints and get back a counterexample, or "unsatisfiable" (impossible).
- Spans the complexity ladder — NP-complete, PSPACE-complete, and undecidable problems — but is very effective on bounded queries (e.g. "find a bug in the first 10 steps") because real hardware/programs "are correct for very simple reasons."
- Before AI, its heuristics were hand-coded; its main limitation was proving the *absence* of bugs, where it times out and shows "proof instability" (just reordering a formula can flip provability). This gap is exactly why de Moura created Lean.
- Z3 is not a programming language and cannot do advanced/abstract mathematics — it solves constraints and can prove only simple things.
