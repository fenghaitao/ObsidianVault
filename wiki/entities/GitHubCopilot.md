# GitHub Copilot

## Definition

GitHub Copilot is an AI coding assistant that was the last product launched from GitHub's Office of the CTO before Jason Warner left the company. It was developed by a team including Jason Warner, Nat Friedman, and others.

## Key Information

- **Origin**: Incubated in GitHub's Office of the CTO
- **Key People**: Jason Warner (CTO), Nat Friedman, and team; launched under CEO Thomas Dohmke
- **Timeline**: Started in 2020 during lockdown with early access to OpenAI's Codex (GPT-3 variant); built entirely remotely; shipped preview mid-2021; chat added early 2023 with GPT-4; Workspace announced late 2023
- **Model**: Initially powered by OpenAI Codex; evolved to use GPT-4 and beyond
- **Internal validation**: First staff ship NPS was ~72-73, unusually high for an early-stage LLM product
- **Adoption metrics**: Writing ~25% of code in enabled files by mid-2021; approximately 50% by 2024; some languages like Java have even higher acceptance rates
- **Core philosophy**: "AI for engineers, not an AI engineer" — human-centric design meeting developers where they are
- **Design approach**: Started as ghost-text auto-completion in the IDE (sidesteps hallucination concerns since developers are used to adjusting completions); expanded to chat sidebar, then Copilot Workspace
- **Significance**: Represented GitHub's transformation from code host to intelligence-infused development platform
- **Historical role**: Marked the 2022 breakthrough where AI moved from line completion to function suggestion — "for the first time it was starting to seem like maybe AI wasn't a novelty, maybe it was generally useful" (Brendan O'Leary)
- Millions of developers started using it, making it the first AI coding tool to achieve mainstream adoption

- GitHub Copilot's job titles were cited in the keynote as an example of specific, deliberate role naming (e.g., specifying exact skills needed at a particular time) to avoid the inflated expectations of catchall titles like "AI Engineer"
