## Definition

GitHub Copilot is Microsoft's AI coding assistant, integrated into VS Code and GitHub. Features Agent Mode for autonomous multi-step tasks, MCP tool access, and instruction files (Copilot instructions.md). Marlene Mhangami works on the Core AI team at GitHub building Copilot.
