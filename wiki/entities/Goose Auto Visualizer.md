## Definition
Goose Auto Visualizer is a feature of the Goose MCP client that automatically matches, organizes, and passes any type of data to a set of predefined visualization components built by the Goose team.

## Key Information
- Feature of the Goose MCP client
- Accepts any type of data, automatically matches and organizes it
- Maps data to a set of predefined components (charts, tables, etc.)
- Represents the static UI paradigm: agent passes data to pre-built components
- Referenced by Ruben Casas as an example of current static UI generation approach
- Useful for visualizing arbitrary data within the Goose chat interface
