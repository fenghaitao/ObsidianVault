## Definition
Stagehand is a browser automation library mentioned by Michele Catasta as an example of tool-based browser use for testing. It provides generic tools (create tab, click, fill forms) for agents to interact with web applications.

## Key Information
- Represents the tool-based approach to browser use, where an agent has a few generic tools exposed.
- Limitation: difficult to enumerate all interaction types; works for ~99% of cases but has a long tail of idiosyncratic interactions.
- Contrasted with Replit's approach of directly writing Playwright code, which is more expressive and creates reusable tests.
