## Definition

Devin is Cognition's flagship product, described as the first AI software engineer. It is an autonomous coding agent capable of writing, reviewing, and deploying code end-to-end with minimal human intervention, serving institutions that need to build software at scale.

## Key Information

- Built by [[Cognition]], founded by Scott Wu (former world champion competitive programmer).
- Capable of writing, reviewing, and deploying code; building software end-to-end with minimal human intervention; and collaborating with engineering teams on complex projects.
- Serves institutions including banks, health insurers, governments, and private equity firms, with a mission to help them build software 10x faster.
- Leverages [[Claude3.7Sonnet]]'s [[TokenOptimization|token optimization features]] — including [[PromptCaching|prompt caching]], cache-aware ITPM limits, and token-efficient tool use — to provide more codebase context while reducing costs and latency.
- Cognition maintains a collaborative co-opetition relationship with [[Anthropic]]: both companies build overlapping coding tools, with Anthropic remaining transparent about product plans. Scott Wu's philosophy: there won't be a single product that does all of software engineering; there is more to do together than separately.
- Vision: a world where building software is as easy as telling your computer what to do.
