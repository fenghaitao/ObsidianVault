## Definition

Consensus is an MCP server that searches over 200 million peer-reviewed academic papers, providing AI agents with citable, verified research sources instead of noisy web search results. It returns findings with line-by-line citations linking to the original papers.

## Key Information

- MCP server that plugs into Claude Code, Cursor, Codex, and any MCP client.
- Searches 200+ million peer-reviewed academic papers.
- Every finding comes with line-by-line citations to source papers.
- Two key use cases in builder workflow: (1) spec planning — validate UX patterns, security trade-offs, user behavior with research; (2) PR review — validate that implementation decisions align with actual research.
- Available at consensus.app.
- Sponsored Brian's multitasking video.
