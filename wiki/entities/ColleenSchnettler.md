## Definition

Colleen Schnettler is a Ruby on Rails developer and indie founder featured on Brian Casel's Builder Stories series. She worked at ClickFunnels, runs a SaaS called Simple File Upload, and is launching a technical marketing consulting business. She built her own voice-to-LinkedIn tool in two days after hating every paid AI LinkedIn tool.

## Key Information

- Self-taught developer; learned coding nights and weekends.
- Professional background: academic software consultancy, scheduling app, ClickFunnels (rebuilding the product).
- Current: runs Simple File Upload SaaS, launching technical marketing consulting.
- Built a custom voice-to-LinkedIn system: Super Whisper voice notes → custom app watches folder → auto-generates LinkedIn posts.
- Uses Compound Engineering plugin (from Every) for structured plan/execute/review cycles.
- LinkedIn content framework: teach me, help me, inspire me, show me.
- Multitasks with 2 Claude Code instances; switches to GPT-5 in Windsurf when Claude gets stuck.
- Still manually clicks through every feature before merging — "there is still a feel to an app that AI can easily miss."
