## Definition

Cat Wu (also known as Kat Wu) is Head of Product for Claude Code at Anthropic. She works closely with Boris Cherny (tech lead) to define and ship the product roadmap for Claude Code and Co-work.

## Key Information

- Head of Product for Claude Code at Anthropic
- Partnered with Boris Cherny: Boris sets the 3-6 month vision, Cat figures out the path from today to that vision
- Handles cross-functional work: marketing, sales, finance, capacity, ensuring no blockers to shipping
- Describes the relationship with Boris as "80% mind meld" with blurry role boundaries
- Background: engineer for many years, briefly a VC before joining Anthropic
- Almost all PMs on the Claude Code team have engineering backgrounds or have shipped code on Claude Code
- Interviewed hundreds of PMs and sees many approaching AI PM roles incorrectly — still thinking in old planning-heavy paradigms
- Core PM philosophy: set clear goals, ship in research preview, create cross-functional frameworks, enable the team to make decisions without being blocked
- PRDs are used occasionally for ambiguous features or heavy infrastructure projects, generally as one-pagers
- Weekly metrics readouts and team principles enable everyone to make decisions independently
- ~30% of time is spent pushing boundaries of what Co-work and Claude Code can do
- Spends time talking with the model to understand why it makes mistakes (model introspection)
- Believes in "just do things" — first principles thinking, figure out what you can do, do it quickly, learn from mistakes
- Used Co-work to create a 20-page slide deck for the Code with Claude conference
- Die-hard Waymo user, uses it twice daily
- Rock climber; loves Free Solo and Drive to Survive
- Post-AGI plan: move to Fontainebleau and climb, read 1-2 books per week
- Favorite books: *How Asia Works*, *The Technology Trap*, *Paper Menagerie*
- Twitter: @_catwo
