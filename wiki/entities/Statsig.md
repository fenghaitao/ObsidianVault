## Definition
Statsig is an experimentation and feature flag platform. Raindrop integrates with Statsig by piping signal-tagged data for experiment analysis, allowing customers to run A/B tests on agent changes (prompts, models, tools) and compare signal rates across experiment groups.

## Key Information
- Experimentation and feature flag platform
- Raindrop integration: customers export signal-tagged data to Statsig for experiment analysis
- Used in the agent observability workflow: ship changes to percentage of users, compare implicit/explicit signal rates against control group
