## Definition
Ruben Casas is a staff engineer at Postman who has been researching UI and generative UI for the past year, with a focus on MCP Apps. He presented a framework for understanding the evolution of AI-generated UI from static to declarative to generative, arguing that MCP Apps provides the ideal distribution mechanism for generative UI.

## Key Information
- Staff engineer at Postman
- Has been researching generative UI and MCP Apps for the past year
- Built an experimental weather agent at Postman that generates HTML/CSS/JS in a single tool call, demonstrating the generative components paradigm
- Presented at aiDotEngineer on "Beyond Components: Designing Generative UI for MCP Apps"
- Framework: three eras of AI-generated UI — static (agent as orchestrator), declarative (agent generates JSON descriptors), generative (agent writes UI code at runtime)
- Argues MCP Apps is the best delivery mechanism for generative UI due to sandboxing (double iFrame), authentication, tool calling, and message passing
- Identified GPT 5.2 and Opus 4.5 as inflection point models for high-fidelity UI generation
- Advocates for human-agent collaboration via shared artifacts (e.g., Excalidraw MCP App) as the future beyond components
- Uses Andrej Karpathy's "new computer" metaphor: we have the terminal but not the GUI yet
- Uses the "radio with cameras" analogy: early TV was radio with cameras because creators couldn't imagine what TV could do — we are similarly constrained today
