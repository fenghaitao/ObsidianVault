## Definition

MCP (Model Context Protocol) is Anthropic's protocol for giving AI models the ability to use tools. It was built by the Anthropic Labs team as part of the trajectory: coding → tool use → computer use.

## Key Information

- Built by the Anthropic Labs team (Mike Krieger, Ben Mann, and others)
- Part of Anthropic's trajectory: coding → tool use → computer use
- Gives AI the ability to use tools and interact with systems
- Boris describes the Labs team's work: "We built Claude Code, we built MCP, we built the desktop app. So, you can kind of see the seeds of this idea — it's coding, then it's tool use, then it's computer use"
- Enables Claude Code to integrate with Linear, GitHub, Slack, and other tools
