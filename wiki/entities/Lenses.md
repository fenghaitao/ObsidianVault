## Definition
Lenses is a data operating fabric that sits between agents and data, serving as the de facto streaming data layer for providing trusted real-time context to agentic AI systems.

## Key Information
- Provides governance, security, and large-scale capabilities for enterprise customers
- Has an open-source MCP server that applies production learnings from the field
- Customers span multiple industries with large-scale use cases
- Focuses on trusted real-time context for agentic AI
- Led by Tun Shwe (Head of AI) and Jeremy Fronae (AI Engineer), who present on MCP security
