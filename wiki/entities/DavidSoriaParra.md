## Definition
David Soria Parra is an engineer at Anthropic who works on the MCP (Model Context Protocol) and authored the original Python SDK for MCP.

## Key Information
- Works at Anthropic on the MCP protocol and ecosystem
- Authored the original Python SDK for MCP, which he acknowledges was superseded by FastMCP: "It's just way better than Python SDK that we're shipping, right? And that's on me because I wrote the Python SDK"
- Presented the future roadmap for MCP at aiDotEngineer, covering MCP applications, progressive discovery, programmatic tool calling, stateless transport, server discovery, skills over MCP, and cross-app access
- Advocates for a connectivity stack approach: agents should use skills, MCP, and CLI/computer use together seamlessly
- Believes 2025 was about exploring agents and 2026 is about putting agents into production
- Argues that general agents for knowledge workers need connectivity across multiple SaaS applications, not just local coding agents
- Emphasizes that MCP servers should be designed for agents, not just wrapped REST APIs
- Announced MCP reached 110 million monthly downloads, faster growth than React achieved
