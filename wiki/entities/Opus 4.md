## Definition

Opus 4 is Anthropic's first ASL-3 class model, released in May 2025. It was the inflection point where Claude Code adoption went exponential because the model became good enough to write most of the code.

## Key Information

- First ASL-3 (AI Safety Level 3) class model released by Anthropic
- Released in May 2025
- Was the inflection point for Claude Code adoption — "everyone started to use Claude Code for the first time"
- "That was kind of when our growth really went exponential"
- Before Opus 4, Claude Code was writing maybe 20-30% of Boris's code; after, it crossed 100%
