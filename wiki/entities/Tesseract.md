## Definition

Tesseract is an open-source OCR (Optical Character Recognition) library that can run in a browser using JavaScript. Simon Wilson used it in combination with Mozilla's PDF.js to build a tool that performs OCR on PDF files entirely in the browser, and later used this as an example of how AI coding agents can combine existing code from different projects to solve new problems.

## Key Information

- Can run entirely in a browser using JavaScript
- Simon Wilson combined it with Mozilla PDF.js to OCR PDF files in-browser
- Used as an example of the "hoarding things you know how to do" pattern: he told Claude Opus 3 to combine the OCR code with the PDF code, and it built a new tool that OCRs every page of a PDF
- Demonstrates the power of giving AI agents access to your past work to recombine them
