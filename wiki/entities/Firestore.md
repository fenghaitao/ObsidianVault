## Definition
Firestore is Google's NoSQL document database, used as the database backend in AI Studio's "Build" feature for persisting user data in full-stack applications.

## Key Information
- NoSQL document database from Google (part of Firebase)
- Used in AI Studio's Build feature for app data persistence
- AI Studio automatically sets up Firestore when building apps requiring a database
- Demonstrated in the bookshelf cataloger app that persisted book data across user sessions
- Works with Firebase Authentication for per-user data storage
