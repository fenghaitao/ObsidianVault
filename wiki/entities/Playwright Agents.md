## Definition
Playwright Agents is a CLI-based tool that installs three specialized agent.md files — a planner, a generator, and a healer — to help coding agents work with Playwright more effectively. It is recommended for scenarios with complex state management.

## Key Information
- Installed via a CLI command that downloads three agent.md files
- **Planner**: Plans which Playwright tests to run
- **Generator**: Generates the actual Playwright test code
- **Healer**: Fixes failing Playwright tests automatically
- Recommended by Marlene Mhangami for complex state management scenarios where standard Playwright MCP may struggle
- The agent.md files contain specialized instructions tailored for Playwright testing workflows
- One of three ways to connect coding agents to Playwright, alongside Playwright MCP Server and the CLI tool
