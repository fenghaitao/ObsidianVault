## Definition
Zed is a company building a high-performance code editor with AI-powered features including edit prediction. They train specialized small models (Zeta2) that run on every keystroke, using production data snapshots and teacher-student distillation pipelines.

## Key Information
- Builds a high-performance, collaborative code editor
- Works with [[Namespace]] on next-generation development workflows
- Cited by [[HugoSantos]] as one of the companies at the forefront of the agentic development transition
- Trains [[EditPrediction]] models (Zeta2) using opt-in production data, frontier model distillation, and settled data filtering
- [[BenKunkle]] leads the edit predictions team and presented the Zeta2 training pipeline at [[aiDotEngineer]]
