## Definition
Cristina Poncela Cubeiro is a co-founder of Earendil and a self-described "native AI engineer" — meaning AI coding tools have been foundational to how she learned and practices software engineering. She previously worked at Bending Spoons.

## Key Information
- Co-founder of Earendil alongside Armin Ronacher
- Describes herself as a "native AI engineer" — AI tools have been around longer than her engineering career
- Previously worked at Bending Spoons
- Presented at AIE Code Summit on the psychology and engineering challenges of AI-assisted development
- Identified two core problems: the psychological trap (AI addiction, illusion of productivity) and the engineering challenge (agents producing brittle, high-entropy code)
- Advocates for agent-legible codebase design: modularization of both components and code flow, following known patterns, no hidden magic
- Promotes mechanical enforcement via linting rules (no bare catch, single SQL interface, unique function names, erasable syntax TypeScript)
- Built a PyExtension for code review with human callouts for changes requiring judgment (database migrations, permission changes, dependency additions)
- Warns that agents create "months of technical debt in weeks or days"
