## Definition

Michael Terrell is the CEO of Cursor, the AI-powered code editor. He appeared on Lenny's Podcast and shared a vision of Cursor becoming the layer on top of code where people don't need to worry about code anymore.

## Key Information

- CEO of Cursor
- Vision: Cursor as what comes after code — the layer on top where people interact via agent conversation rather than code
- The agent conversation (English in a conversation) becomes the interface over code
- Appeared on Lenny's Podcast about a year prior to this episode
