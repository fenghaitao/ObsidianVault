## Core Summary

Brian Casel provides a framework for creating real jobs (not one-off tasks) for OpenClaw agents. The key insight: hire agents to fill recurring roles, not to handle ad-hoc tasks. Three systems needed: scheduling (custom dashboard), processes (skills as operating manuals), and output (markdown files as artifacts). The threshold for creating an agent role is dramatically lower than hiring a human — you can start with one or two recurring tasks.

## Key Points

- Mindset shift: delegate jobs (recurring needs), not tasks (one-off requests). A job is a recurring need on a predictable cadence.
- Agent hiring advantage: no minimum workload, no salary to justify, pennies per task in token costs.
- Two types of recurring tasks: things you're currently doing (get off your plate) and missed opportunities (things not getting done).
- Three systems needed: (1) scheduling/dispatching — Brian's custom BMHQ dashboard with Kanban, task templates, agent-specific views; (2) processes — skills as markdown files in a shared Dropbox folder; (3) output — markdown artifacts managed via BrainDown app.
- Skills are symlinked from Dropbox into OpenClaw's workspace for easy editing from any machine.
- Tasks reference skills by name rather than containing detailed instructions — skills are the single source of truth.
- Brian uses Claude Code to improve his skills: "When you're improving your set of skills, you're literally making your team of agents better at their jobs."
- BrainDown: custom markdown editor/viewer integrated with Dropbox for agent-human file sharing.
