## Core Summary

Extended coverage of Code with Claude Tokyo 2026, including the full opening keynote (Fable 5/Mythos 5 launch, Managed Agents, Claude Code updates) plus a detailed Canva presentation by Danny Wu on building Canva AI 2.0 with Claude. Canva's lessons: design is subjective (human touch matters, average design edited 110 times before publishing), latency correlates more strongly with satisfaction than quality metrics, flexible deployment (Bedrock/Vertex/Foundry) enables AWS-native integration, and Claude's visual superpowers generalize beyond front-end to presentations, docs, and printables.

## Key Points

- **Keynote content:** same as the opening keynote (Fable 5, Mythos 5, Managed Agents, Claude Code updates, customer stories).
- **Canva AI 2.0:** a complex agentic system orchestrating design agents, code agents, and hundreds of tools (image generation, background removal, etc.) behind a simple text interface.
- **Canva's Claude usage:** since Sonnet 3 days; Claude consistently delivers on quality/cost/latency trifecta; visual superpowers generalize to presentations, brand decks, docs, printables.
- **Canva lessons:**
  - Design is subjective; human steering matters more than one-shot perfection. Average design edited ~110 times before publishing.
  - Latency and responsiveness correlate more strongly with user satisfaction than quality metrics.
  - Flexible deployment (Bedrock, Vertex, Foundry) enables AWS-native integration with IAM roles, permissions, cost tracking.
  - Distributed AI team model: each product group (video, print, etc.) owns their AI features.
- **Canva Code:** lets non-coders create interactive mini-apps (maps, calculators, widgets) within designs using Claude.
