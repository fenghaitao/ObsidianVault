## Core Summary

Claude Code can be installed across multiple platforms: terminal (macOS/Linux/WSL via curl or Homebrew, Windows via PowerShell/CMD/winget), VS Code (extension), JetBrains IDEs (plugin), Claude Desktop app, and the web (claude.ai/code, GitHub repos only). The terminal receives features fastest; IDE integrations offer a more intertwined experience; desktop is good for background tasks; the web supports remote GitHub work and parallel sessions.

## Key Points

- Terminal installation on macOS/Linux/WSL uses a one-line curl command; Homebrew is also available but lacks auto-update.
- Windows supports PowerShell (Invoke-RestMethod), CMD (curl), and winget (no auto-update).
- VS Code extension is found in the extensions panel (search "Claude Code" by Anthropic, blue check verified).
- JetBrains plugin is installed from the JetBrains Marketplace.
- Claude Desktop app has a "Code" toggle at the top after sign-in.
- Web access at claude.ai/code is restricted to GitHub repositories only.
- First run walks through color theme selection, account sign-in (Pro/Max/Enterprise or API key), and directory access scope.
