## Core Summary

Claude Code is an agentic coding tool that has direct access to your files, terminal, and entire codebase. Unlike Claude AI (which requires copy-paste), Claude Code can read, edit, run commands, and integrate with developer tools autonomously. It runs in the terminal, VS Code, JetBrains IDEs, and the Claude desktop app. Key concepts include the context window (Claude's working memory), permission-based control (it asks before making changes), and the understanding that it can make mistakes.

## Key Points

- Claude Code is an AI agent: software that interacts with its environment and performs actions to complete defined goals, using an LLM in a real-time loop.
- It can read and understand codebases, execute build scripts, run tests, install packages, and search the web for documentation.
- The context window is Claude's working memory -- it can hold a lot but not everything at once, requiring strategic information retrieval.
- By default, Claude Code asks for permission before running commands or making changes; the user is always in control.
- Claude Code can make mistakes, misunderstand intent, introduce bugs, or over-engineer solutions.
