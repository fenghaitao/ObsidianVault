## Summary

Anthropic announced the Claude Enterprise plan (September 2024) to help organizations securely collaborate with Claude using internal knowledge. The plan includes an expanded 500K context window, native GitHub integration for codebases, and enterprise-grade security features (SSO, role-based permissions, admin tooling).

## Key Features

- **500K Context Window** — Expanded capacity equivalent to hundreds of sales transcripts, dozens of 100+ page documents, or medium-sized codebases.
- **GitHub Integration** (beta) — Native sync of GitHub repositories with Claude, enabling engineers to work alongside codebases for feature iteration, debugging, and onboarding.
- **Enterprise Security** — SSO, role-based permissions, admin tooling for managing sensitive data.
- **Data Privacy** — Anthropic does not train Claude on customer conversations and content.

## Capabilities

The Enterprise plan combines:
- **Projects & Artifacts** — End-to-end solution for teams (e.g., marketers building campaigns, product managers prototyping, engineers debugging).
- **Knowledge Integration** — Securely share and reuse organization knowledge across teams.
- **Cross-functional Collaboration** — Scale expertise across projects, decisions, and teams.

## Customer Examples

- **GitLab** — Uses Claude for brainstorming, streamlining internal processes, content creation and translation, and code writing. Emphasis on keeping IP private and protected.
- **Midjourney** — Uses Claude for summarizing research papers, Q&A with user feedback, and iterating on moderation policies.
