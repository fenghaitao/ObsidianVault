## Core Summary

Anthropic's recap of Code w/ Claude London 2026 (May 20–21), the European edition of its developer conference. Head of Claude Code Boris Cherny framed the event's theme around collapsing the distance between "I have an idea" and "it runs" — the same magic he felt writing TI-83 programs as a student, now returning through AI agents that can write distributed systems from natural-language descriptions. The conference also announced Claude Managed Agents now supporting self-hosted sandboxes and MCP tunnels for enterprise deployment, with customer talks from Spotify, Base44, and Legora.

## Key Points

- Boris Cherny's keynote drew a personal arc from secondary-school tinkering (TI-83 programs, HTML for eBay) to agents collapsing the idea-to-execution gap that compilers, typecheckers, and build systems widened over decades.
- Self-hosted sandboxes (public beta) and MCP tunnels (research preview) for Claude Managed Agents were announced at the conference, keeping agent execution and service access inside the customer's enterprise perimeter.
- Customer sessions featured Spotify (scaling DevEx to teams and agents), Base44 (scaling a hypergrowth engineering org with Claude Code), and Legora (what legal agents inherit from coding agents).
- Breakout sessions covered going beyond the basics with Claude Code and optimizing thinking budgets and effort levels across Claude models.
- Teams including Amplitude, Clay, and Rogo are already building on Managed Agents with self-hosted sandboxes.
- Code w/ Claude heads to Tokyo next (June 5–6), with Day 1 keynotes and breakout sessions streamed live.
