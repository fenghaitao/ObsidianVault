## Core Summary

Claude Cowork is Anthropic's knowledge work agent that runs in the Claude desktop app. It moves beyond conversational AI by reading and writing local files, working across connected apps like Slack and Google Drive, and carrying multi-step tasks through to real deliverables with citations back to source files and messages. Users describe the goal, desired outcome, and cadence, and Claude plans the steps and executes the work while keeping the user informed throughout.

## Key Points

- Claude Cowork is a knowledge work agent designed for multi-step task delegation, producing actual deliverables (decks, docs, spreadsheets, emails) rather than just conversational answers.
- It runs in the Claude desktop app and integrates with connected services including Slack and Google Drive.
- The agent reads and writes local files, providing citations back to the actual source files and messages it references.
- Users define the goal, outcome, and cadence; Claude lays out the steps and does the work with user oversight at each stage.
- The product represents a shift from conversational AI tools to autonomous work-execution agents.
