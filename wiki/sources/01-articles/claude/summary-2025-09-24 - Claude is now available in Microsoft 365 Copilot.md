## Core Summary

Microsoft announced that Claude models are now available in Microsoft 365 Copilot, bringing Claude Sonnet 4 and Opus 4.1 to enterprise users through two integration points: the Researcher agent (powered by Opus 4.1) and Copilot Studio (supporting both Sonnet 4 and Opus 4.1). The rollout begins via Microsoft's Frontier Program for licensed Microsoft 365 Copilot customers who opt in.

## Key Points

- [[Claude4Sonnet]] (Claude Sonnet 4) and [[Claude4Opus]] (Claude Opus 4.1) are now selectable model options within [[Microsoft365Copilot]].
- **Researcher agent**: Microsoft's reasoning agent for complex, multistep research tasks — reasoning over web, third-party data, emails, chats, meetings, and files — can now be powered by Claude Opus 4.1. Users select their preferred model.
- **[[CopilotStudio]]**: Both Claude Sonnet 4 and Claude Opus 4.1 are available as model options for building, orchestrating, and managing enterprise-grade agents. Supports multiagent systems and prompt tools.
- Initial rollout is through Microsoft's **Frontier Program** — an opt-in early-access program for Microsoft 365 Copilot licensed customers. Admins enable access via the Microsoft 365 admin center.
- Anthropic models in this integration are hosted outside Microsoft-managed environments and subject to Anthropic's Terms and Conditions.
- [[Anthropic]] cited the partnership as giving organizations greater flexibility and model choice for specific business needs.
