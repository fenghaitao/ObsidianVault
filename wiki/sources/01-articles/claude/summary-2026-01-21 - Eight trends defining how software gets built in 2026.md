## Core Summary

A teaser for Anthropic's "2026 Agentic Coding Trends Report," identifying eight trends across foundation, capability, and impact categories, anchored by Societal Impacts team research showing developers use AI in ~60% of their work but can "fully delegate" only 0-20% of tasks — framing 2026 as a year of active human-AI collaboration, not autonomous replacement.

## Key Points

- Core finding: engineers are shifting from writing code to coordinating agents that write code, focusing human expertise on architecture, system design, and strategic decisions — but this requires active collaboration (supervision, validation, judgment), not full delegation.
- Customer examples: [[Rakuten]] (7-hour autonomous vLLM activation-vector extraction, 99.9% accuracy); [[TELUS]] (13,000+ custom AI solutions built, 30% faster engineering code shipping, 500,000+ hours saved); [[Zapier]] (89% AI adoption org-wide, 800+ internally deployed agents).
- **2026 priority areas** flagged for organizations: mastering multi-agent coordination, scaling human-agent oversight via AI-automated review, extending agentic coding beyond engineering teams, and embedding security architecture from the earliest stages.
- Full report: "2026 Agentic Coding Trends Report" (linked PDF, not itself ingested).
