## Core Summary

Anthropic announced that Enterprise and Team plan customers can now upgrade to premium seats that bundle Claude and Claude Code under one subscription, enabling seamless movement between ideation and implementation throughout the development lifecycle. A new Compliance API was introduced simultaneously, giving organizations programmatic access to usage data and customer content for continuous compliance monitoring and governance.

## Key Points

- **Premium seats** bundle Claude (conversational AI) and [[ClaudeCode]] together under Enterprise and Team plans, replacing the need for separate subscriptions.
- Admins can assign **standard or premium seats** per user based on individual roles and requirements.
- **Extra usage** is available at standard API rates, with admin-controlled per-user spend caps to ensure flexible but predictable billing.
- Both Team and Enterprise plans include **granular spend caps**, self-serve seat management, and Claude Code usage analytics.
- The new **Compliance API** provides real-time programmatic access to Claude usage data and customer content — enabling automated policy enforcement, continuous monitoring, flagging potential issues, and selective data deletion.
- Replaces manual compliance exports and periodic reviews with an always-on integration for existing compliance dashboards.
- **[[Behavox]]** (compliance and security): rolled out Claude Code to hundreds of developers; uses it as primary pair programmer; describes its coding assistance as outperforming other agents.
- **[[Altana]]** (AI-powered supply chain network): reports 2–10x development velocity acceleration for AI/ML systems on large-scale global supply chain knowledge graphs.
- Workflow example: developers research unfamiliar frameworks through Claude conversations, then switch to Claude Code in the terminal for implementation — the same unified subscription covers both.
- Enterprise customers interested in the Compliance API are directed to contact Anthropic sales.
