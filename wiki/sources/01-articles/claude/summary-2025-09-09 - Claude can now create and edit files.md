# Claude can now create and edit files

**Published:** 2025-09-09 | **Author:** [[Anthropic]] | **Source:** https://claude.com/blog/create-files

## Core Summary

Claude gained the ability to create and edit ready-to-use files — Excel spreadsheets, Word documents, PowerPoint slide decks, and PDFs — directly in [[Claude.ai]] and the desktop app, using a private computer environment to write and execute code behind the scenes. This moves Claude from an advisor delivering text responses into an active collaborator producing finished, downloadable work products.

## Key Points

- **File types supported**: Excel spreadsheets, Word documents, PowerPoint presentations, PDFs.
- **How it works**: Claude is given access to a private computer environment where it writes code and runs programs to produce the requested files — the technical execution is invisible to the user.
- **Initial rollout (September 2025)**: Available as a feature preview for Max, Team, and Enterprise plan subscribers; Pro users were promised access in the following weeks.
- **General availability (October 21, 2025)**: Feature became GA for all paid plans, with network and egress controls added.
- **Use cases highlighted**: Customer segmentation analysis, sales forecasting, budget tracking, data cleaning, financial models, and simple reports.
- **Philosophy**: Described as completing the arc from "answering questions" to "completing entire projects" — reducing the gap between idea and execution through multi-step conversation.
- **Privacy note**: This feature grants Claude internet access to create and analyze files; Anthropic advises users to monitor chats closely when using it.
