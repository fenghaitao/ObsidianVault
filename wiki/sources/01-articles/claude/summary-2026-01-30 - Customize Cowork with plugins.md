## Core Summary

Anthropic added plugin support to [[ClaudeCowork|Claude Cowork]] (research preview): bundles of skills, connectors, slash commands, and sub-agents that turn Claude into a role/team/company-specific specialist, launched with 11 open-sourced plugins covering functions from sales and finance to legal, marketing, and biology research.

## Key Points

- A plugin bundles context (skills), data access (connectors), commands (slash commands), and delegation (sub-agents) into one shareable unit — define the context once, and Claude pulls from it whenever relevant.
- **11 launch plugins** (built and used by Anthropic's own team): Productivity, Enterprise search, Plugin Create/Customize, Sales, Finance, Data, Legal, Marketing, Customer support, Product management, Biology research.
- Every plugin component is file-based, so plugins are easy to build, edit, and share; install from Cowork directly, browse the full collection on Anthropic's website, upload a custom plugin (buildable via Plugin Create), or get them from GitHub.
- Available today as a research preview for all paid Claude users; plugins are currently saved locally, with org-wide sharing/management (private plugin marketplaces) planned for the following weeks.
