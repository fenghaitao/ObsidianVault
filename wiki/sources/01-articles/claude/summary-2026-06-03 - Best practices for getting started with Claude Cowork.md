## Core Summary

Austin Lau, growth marketing lead at Anthropic, provides a practical guide for non-technical knowledge workers getting started with Claude Cowork. He introduces a decision framework for choosing between Chat (for quick answers and brainstorming), Claude Cowork (for multi-step deliverables that touch files and apps), and Claude Code (for software development). The article presents a five-ingredient checklist for identifying Cowork-shaped tasks and concrete examples from Lau's own marketing workflows, along with a ten-minute getting-started guide.

## Key Points

- **Chat vs Cowork vs Code framework**: Chat is for answers and thinking (you bring work to Claude); Claude Cowork is for deliverables (you bring Claude to your work); Claude Code is for developers building software. All three run on the same Claude models underneath.
- **Five ingredients of a Cowork-shaped task**: (1) multiple inputs (files, folders, connectors), (2) a file output (doc, deck, spreadsheet), (3) recurring execution (scheduling), (4) you already know what good looks like, (5) the middle work (extract, compile, reconcile, reformat) is boring and automatable.
- **"Make Claude ask clarifying questions first"**: Include a prompt instruction for Claude to repeat back the ask and ask clarifying questions before starting — this surfaces unstated assumptions and edge cases, saving time and tokens compared to fixing gaps after the fact.
- **Workflow examples**: Daily Slack/email briefing (auto-runs at 6am), budget pacing dashboard (live HTML artifact from Google Ads and Meta Ads), weekly Search Console reporting (auto-scheduled, pulls queries/countries/pages into a single sheet).
- **Getting started**: Open the Claude desktop app Cowork tab, give Claude files/folders/app connectors, describe the desired outcome, start with a familiar real task, and use the clarifying-questions prompt pattern.
- **Common mistakes**: Reaching for chat for everything (never feeling Cowork's power) vs. using Cowork for one-off quick questions (wasting time chat could handle instantly).
