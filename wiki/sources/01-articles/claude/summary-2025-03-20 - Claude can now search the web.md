## Core Summary

Anthropic launched [[WebSearch]] in Claude's conversational product (Claude.ai), letting Claude search the internet to deliver up-to-date, cited responses. This is the consumer-facing launch of web search, distinct from and preceding the May 2025 Anthropic API web search tool. At launch it was available in feature preview for paid Claude users in the United States on [[Claude3.7Sonnet]], with free-plan and additional-country support "coming soon." A later update (May 27, 2025) confirms web search became available globally on all Claude plans.

## Key Points

- Web search lets Claude access the latest events and information, improving accuracy on tasks that benefit from current data.
- Responses that use web information include direct citations so users can fact-check sources, instead of users needing to search themselves.
- Initial availability (March 20, 2025): feature preview for paid Claude users in the United States, toggled on in profile settings, using [[Claude3.7Sonnet]].
- Update (May 27, 2025): web search made available globally on all Claude plans, including free.
