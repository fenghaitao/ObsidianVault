## Core Summary

Anthropic introduced **MCP Apps**, a new MCP extension letting any MCP server deliver an interactive UI directly inside a Claude conversation — building project timelines in Asana, drafting/editing/sending formatted Slack messages, or visualizing Figma diagrams, all without switching tabs. MCP Apps works across any MCP-supporting AI product, not just Claude, extending MCP beyond data/action connectivity into rich in-conversation UI.

## Key Points

- Available now for Asana, Slack, and Figma (among others) via claude.ai/directory's "featured" section; Salesforce (via Agentforce 360) is coming soon.
- Built as an official MCP extension (co-announced with the Model Context Protocol project), continuing Anthropic's open-sourcing of MCP as universal AI-tool connectivity.
- Available on Claude mobile, web, and desktop across Free, Pro, Max, Team, and Enterprise plans, and now on [[ClaudeCowork|Claude Cowork]].
