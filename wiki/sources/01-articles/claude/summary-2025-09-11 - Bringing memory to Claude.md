## Core Summary

Anthropic introduced persistent memory to the Claude app, enabling Claude to remember users' and teams' professional context, project details, and preferences across conversations. Memory is project-scoped (each project maintains its own separate memory store), user-controlled (viewable and editable via a memory summary in Settings), and accompanied by an Incognito chat mode for privacy-sensitive sessions.

## Key Points

- **Initial rollout:** Memory launched for [[ClaudeTeamPlan|Team]] and [[ClaudeEnterprise|Enterprise]] plan users on September 11, 2025; expanded to [[ClaudeMax|Pro and Max]] plans on October 23, 2025.
- **Project-scoped memory:** Each project has an isolated memory, keeping product launch planning separate from client work and confidential discussions separate from general operations.
- **Memory summary:** Claude maintains a single memory summary visible in Settings; users can view, edit, or update it at any time by chatting with Claude.
- **Work-focused:** Memory is designed to capture professional context — team processes, client needs, project details, priorities — rather than personal or sensitive topics.
- **Incognito chat:** A private mode that does not save to memory or conversation history; available to all Claude users; standard data retention settings apply for Team/Enterprise plans.
- **Safety testing:** Extensive pre-launch safety testing covered sensitive wellbeing topics, memory reinforcing harmful patterns, over-accommodation, and safeguard bypass attempts. Claude's responses were refined before rollout.
- **Enterprise admin control:** Enterprise admins can disable memory for their entire organization at any time.
- **Memory import/export:** Users can import memory from other AI tools or export it from Claude for backup or migration.
- **Phased approach:** Anthropic intentionally started with work settings to evaluate safety before expanding to broader use cases.
