## Core Summary

Claude Design has been rebuilt with a focus on staying consistent with a user's design system across projects, integrating fluidly with Claude Code for design-to-code handoff, and offering a direct canvas editor for fine-grained control. Over one million people used Claude Design in its first week, and the update adds design system imports from GitHub repos or files, bidirectional sync with Claude Code via `/design-sync` and `/design` commands, and export connectors to tools like Adobe, Canva, Miro, and Vercel.

## Key Points

- Design system import supports one or more systems from GitHub repos, design files, or raw uploads, with Claude checking its output against the design system before showing results.
- Team admin role can approve a standard design system and lock edits for company-wide consistency.
- Bidirectional Claude Code integration: `/design-sync` pulls design systems into Claude Design; `/design` in Claude Code creates, edits, and syncs design projects from the terminal.
- New canvas editor provides direct drag, resize, and align controls with hundreds of stability fixes.
- Shared usage limits across chat, Claude Cowork, and Claude Code give most users more headroom; average turns use fewer tokens with lower error rates.
- Export connectors available for Adobe, Base44, Canva, Gamma, Lovable, Miro, Replit, Vercel, and Wix, plus reliable PDF and PowerPoint export.
- Available in beta on Claude Pro, Max, Team, and Enterprise plans at claude.ai/design or in the desktop app sidebar.
- Alex Lieberman (Cofounder, Morning Brew & Tenex) praised the combination of frontier-model intelligence with design-tool functionality and the seamless prototype-to-production handoff.
