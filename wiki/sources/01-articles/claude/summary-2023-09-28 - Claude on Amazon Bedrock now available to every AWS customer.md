## Core Summary

Claude reached general availability on [[AmazonBedrock]] for every AWS customer, following a preview period announced in April 2023. The post highlights the upcoming [[AgentsForAmazonBedrock|Agents for Amazon Bedrock]] feature — built with Anthropic's involvement — which lets Claude orchestrate AWS Lambda function calls to break down complex tasks, hold multi-turn conversations, look up information, and take actions (e.g., an e-commerce chat assistant that can update orders, not just answer questions). It also notes upcoming secure customization/fine-tuning of Claude on Bedrock. The post cites early enterprise adopters gained since the April 2023 preview and features a detailed case study of [[BridgewaterAssociates]] building an AI-enabled Investment Analyst Assistant with Claude.

## Key Points

- General availability (GA) of Claude on Amazon Bedrock for all AWS customers, expanding from the April 2023 preview.
- **Agents for Amazon Bedrock** (preview): lets Claude orchestrate API calls via AWS Lambda, breaking tasks into steps, holding clarifying conversations, and taking actions — not just answering queries.
- Secure customization and fine-tuning of Claude models on Bedrock was announced as forthcoming, using customer proprietary data while limiting harmful outputs.
- Early enterprise adopters since the April 2023 preview: [[LexisNexis]], [[LonelyPlanet]], and [[RicohUSA]].
- **Bridgewater Associates** case study: built an "Investment Analyst Assistant" on Claude via Bedrock that generates Python code, produces charts/tables, works through errors, and asks clarifying questions when uncertain — described by CTO Aaron Linsky as performing like a first- or second-year analyst. It also supports in-place code editing so analysts choose when to lean on Claude vs. edit directly.
