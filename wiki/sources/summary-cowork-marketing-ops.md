## Core Summary

Ian from Anthropic's marketing ops team demonstrates how Claude Cowork automates the weekly metrics review process. A scheduled Sunday evening task reads last week's review, meeting transcripts, Slack priorities, and queries the data warehouse — leaving a folder with numbers and suggested focus areas for Monday morning. Three skills (prep, proofread, action items) capture the repeatable process. Claude flags data discrepancies (e.g., sales team reorg causing reporting mismatch) and asks instead of guessing. The workflow produces both a detailed team document and a one-slide leadership summary, with learnings saved back into skills for continuous improvement.

## Key Points

- **Scheduled prep:** Sunday evening task reads prior review, meeting transcripts, Slack, and warehouse data. Monday morning: numbers and suggested focus areas are waiting.
- **Three-skill pipeline:** Prep skill (data gathering and outline), proofread skill (every number traces to verified source), action items skill (follow-ups become Asana tasks).
- **Human steers narrative:** Claude pulls numbers; human decides focus (sales priority, product launch, quarterly planning).
- **Discrepancy handling:** When sales team reorg causes reporting mismatch, Claude flags the gap and asks how to handle — doesn't guess.
- **Iterative drafting:** Headlines agreed first, then expanded with supporting detail while preserving agreed headlines.
- **Ship workflow:** Finalize document → Slack message to team → leadership slide from same data → learnings saved to skill for next week.
- **Shareable skills:** Anyone on the team can run the same process and get consistent results.
