## Core Summary

Eric from Notion demonstrates how Claude Managed Agents powers agent orchestration within Notion. A client onboarding workflow shows 30 tasks being dragged to start, with Claude running multiple agent threads in parallel — the PM gets a snack while agents complete prototypes. Managed Agents provides the long-running task harness (20 minutes to hours) with memory management and high-quality outputs over time. Notion's vision is to be the agent orchestration platform where humans and agents collaborate, with Notion providing context (databases, task boards) and Claude providing execution.

## Key Points

- **Agent orchestration in Notion:** Drag tasks to start → multiple agent threads kick off → Claude Managed Agents sessions run in cloud → results appear in Notion.
- **Managed Agents as plug-and-play:** "If you were to roll it up yourself, it's like a mega brain engineering effort. You need like a PhD in all of this to make it work."
- **Long-running tasks:** Harness runs for 20 minutes to an hour with memory management and quality outputs — critical layer on top of the model.
- **Dual view:** Notion UI for end users; Claude platform console for developers to see traces and improve agents.
- **Iterative collaboration:** Users can talk to Claude directly within Notion to iterate on generated outputs.
