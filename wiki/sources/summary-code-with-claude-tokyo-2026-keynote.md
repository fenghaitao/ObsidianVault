## Core Summary

The Code with Claude Tokyo 2026 opening keynote announced Claude Fable 5 and Mythos 5, the fifth generation of Claude models. Key themes: Anthropic as a platform company, the growing gap between exponential AI capability and linear business adoption, and three product layers (models, platform/Managed Agents, Claude Code). Fable 5 is the most capable generally available model, with top SWE-bench Pro scores, long-horizon autonomy (days-long coherent tasks), and industry-best vision. Claude Managed Agents introduced scheduled deployments, vaults for secrets, memory, and dreaming (self-improvement from past sessions). Claude Code updates included dynamic workflows, agent view, auto mode, remote control, and routines.

## Key Points

- **Fable 5:** state-of-the-art on nearly all benchmarks; excels at single-shot correctness, long-horizon autonomy (days), code reading/outage triage, vision, and messy multi-threaded tasks.
- **Mythos 5:** same underlying model as Fable 5 but with cyber/bio safeguards lifted; available to Project Glasswing partners.
- **Safeguard system:** Fable 5 routes cyber/biology/chemistry requests to Opus 4.8 with clear labeling and Opus pricing.
- **Claude Managed Agents:** harness (brain/hands separation, sandboxes, outcome-based iteration), context (1M window, memory, skills, dreaming), infrastructure (auto-scaling sandboxes, agentic fleets).
- **Claude Code updates:** dynamic workflows (parallel agents for large tasks), agent view (fleet management in CLI), auto mode (classifier-based permission decisions), remote control (phone/browser), routines (scheduled/webhook/API-triggered sessions).
- **Customer stories:** Rakuten (biweekly releases from quarterly, PMs coordinate agent teams), Canva (Canva Code for non-coders), Spotify (1000+ PRs/month, 90% faster migrations), Mercari (90% YoY engineering output increase).
- **Developer advice:** design for the next model version, not current; make model upgrades easy with automated evals; treat model upgrades as business opportunities.
