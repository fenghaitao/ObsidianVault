## Core Summary

Brian Casel tries Google's Antigravity IDE and finds it dysfunctional despite genuinely good ideas: multi-project agent management, screen-recording review process, and centralized agent view. Execution fails: bugs, limited model selection (no Opus), confusing UI, and features that don't work. He hopes Cursor adopts Antigravity's good ideas with better execution.

## Key Points

- Good ideas: multi-repo management, multiple agents in one window, screen-recording review process, commenting on code diffs.
- Execution failures: bugs prevent completing a simple demo, limited model selection (Gemini 3 Pro, Sonnet 4.5 only — no Opus), confusing UI (alerts hidden in expandable sections).
- Forked VS Code — can import Cursor/VS Code settings and keybindings.
- Agent manager and editor are separate windows, defeating the unified workspace concept.
- No file explorer in agent manager view.
- Brian's verdict: ideas are real innovations, but execution isn't there yet.
