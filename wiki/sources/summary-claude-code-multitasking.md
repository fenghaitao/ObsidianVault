## Core Summary

Brian Casel demonstrates multitasking with Claude Code using git worktrees. Shows how to run multiple Claude Code sessions on different features simultaneously without conflicts.

## Key Points

- Git worktrees enable parallel Claude Code sessions on different features.
- Each worktree is an isolated copy of the codebase.
- Early exploration of what would become [[AgentMultitasking]] in 2026.
