## Core Summary

Brian Casel interviews Brennan Dunn, who built a team of AI developers using Claude Code sub-agents: a project manager agent for business requirements, a senior developer agent for codebase audits and technical planning, all connected to Linear for task management. He also demonstrates Fern Desk, a tool that automatically generates help documentation by analyzing code, Git commits, and Linear tasks.

## Key Points

- Brennan's sub-agent system: project manager (business requirements) → senior developer (technical planning) — chained automatically.
- Custom CLAUDE.md files define each agent role with specific responsibilities.
- Linear integration: tasks flow through Linear as AI agents work, persisting the AI's thinking.
- Fern Desk: auto-generates help documentation by analyzing codebase, Git commits, and Linear tasks. Integrates with Help Scout, GitHub, Linear, Gmail.
- Fern Desk can update existing docs when new features are added — "it looked at the code and then it just figured out what to add."
- Brennan's product (RightMessage) has 250 paying customers; he ships fast and iterates.
- Mindset shift: "What's the absolute best version of this feature? Claude's going to be the one building it."
