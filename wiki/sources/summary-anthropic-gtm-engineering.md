## Core Summary

A former startup account executive turned go-to-market architect at Anthropic describes building "Class" (Claude Draft), an internal tool that uses the Claude API to generate customer emails by combining system prompts, context from Google Docs and web URLs, and pattern matching. The tool saves 2-3 hours per day on email responses and has sent thousands of emails. The key theme is how Claude dissolves technical barriers, enabling non-engineers to design and build solutions that previously required senior engineering support, fundamentally changing career trajectories.

## Key Points

- **Class (Claude Draft):** Internal tool for generating customer emails using Claude API with system prompts, context retrieval (Google Docs, web URLs), and pattern matching.
- **Workflow:** Select role → generate system prompt → add context sources → click email → generate draft. Claude retrieves information from documentation and internal context.
- **Time savings:** 2-3 hours per day saved on email responses; thousands of emails sent through the system.
- **Career transformation:** Moved from account executive to go-to-market architect by building solutions with Claude that were previously out of technical reach.
- **Technical barrier dissolving:** Non-engineers can design products and have senior engineers help implement the final stretch.
