## Core Summary

Brian Casel argues that the question "which agent platform should I commit to?" is wrong. Instead, bet on portable patterns (skills, recurring schedules, human-in-the-loop) that work across platforms. He runs two platforms simultaneously: Hermes (on a dedicated Mac mini, via Discord) for routine jobs using GPT, and Claude Co-work for high-stakes creative jobs using Opus. He also details his intake processing system that captures all his published content and daily work into a file system his agents can draw from.

## Key Points

- Don't marry a platform — platforms change every few weeks; patterns are portable.
- Two job categories: routine (Hermes + GPT via $20/month OpenAI) and creative (Claude Co-work + Opus via Max plan).
- Hermes runs on a dedicated Mac mini with Discord as the chat interface (multi-channel, threaded, good markdown support).
- As of June 2026, Anthropic changed pricing: Max plan only covers Claude's own tools (Claude Code, Claude Co-work), not third-party platforms.
- Intake processing: agents capture all published content (podcasts, tweets, YouTube transcripts, newsletters) and daily work (journal entries, Claude Code session logs) into Dropbox, then summarize nightly.
- Claude Co-work's scheduled tasks feature is the key value — recurring background jobs with Opus.
- Content ideation skill: multi-phase process that researches, pitches ideas, reads from custom apps via API, and integrates audience survey data.
- Brian's entire content pipeline runs on custom-built apps with agent APIs — he's the only human, supported by AI agents.
