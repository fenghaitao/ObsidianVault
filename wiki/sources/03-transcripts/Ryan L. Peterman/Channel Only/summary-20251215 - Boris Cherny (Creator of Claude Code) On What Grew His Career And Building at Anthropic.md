## Core Summary

Boris Cherny, creator of Claude Code and a former Meta principal engineer (IC8), traces his career from Facebook (chats and groups, the Comet rewrite, public groups) through Instagram (the Python-to-Hack migration) to Anthropic. He distills product principles (latent demand, unshipping), engineering-culture lessons (generalists, no titles, re-earning trust), and a personal philosophy of "side quests" and automation as leverage. The Claude Code story hinges on a single insight: don't build for the model of today, build for the model 6 months from now.

## Key Points

- Promoted to senior at Meta by picking up a PM's "chats and groups" idea (bridging Messenger and Facebook), doing observational user research with cafeteria workers, and doing generalist product/design/UXR work
- Latent demand is "the single most important principle in product": watch how users hack a product and build around the intent they reveal (groups used for buying/selling → Marketplace; profile-view patterns → Dating)
- Facebook (ship fast, users/engagement) vs Messenger (reliability, performance) had polar-opposite values and org goals, which ultimately sank that pairing
- Side quests shaped his career: built Undux because Redux felt overly complicated, writing a TypeScript book and starting the SF TypeScript meetup
- "Think in types" — type signatures matter more than the code itself; his path ran CoffeeScript → Haskell → Scala ("Functional Programming in Scala") → TypeScript
- Coming in under-leveled meant lower expectations and space to explore; he cautions against pushing for level+1 when switching jobs
- E6 at Meta: volunteered Facebook Groups as the "guinea pig" for Comet, co-built shared abstractions (e.g., relay mutations), and set the quality direction via notes and tech talks
- Presenting three options in VP reviews: distant decision-makers default to the middle option (~80% of the time)
- Scoping at scale: time-box technical scoping (~30 min), give experts a straw man; ran a 3-hour two-team architecture "design competition" to crack a gnarly data-model merge
- "Public groups" (read/comment without joining) earned him IC7; he first followed senior engineer Bob's migration, then reversed it when it proved wrong — which earned Bob's respect
- Impostor syndrome while directing same-level engineers: "no one really knows what they're doing"; levels don't matter that much
- Moved to Instagram (Tokyo) for his partner; learned the craft-focused culture and "unshipping" (deleting low-usage features for the good of the majority)
- E8 promo came when his manager simply proposed it; he delegated the Python-to-Hack migration to Jake Bolam (delegate what you enjoy so you can monitor progress)
- Joined Anthropic for mission/safety; Claude Code was built on "don't build for the model of today, build for the model 6 months from now"
- Claude Code: early on he used it for ~10% of his code; ~6 months later (after Sonnet/Opus 4) it "just worked," and now most of Claude Code is written by Claude Code (80–90%)
- Impact: Anthropic tripled headcount while productivity per engineer grew ~70%; use spreads beyond coding (data scientists, sales via Salesforce)
- AI-coding philosophy: hold model and human code to the same quality bar; vibe code only for throwaway/prototypes, otherwise pair with the model or hand-write high-conviction parts
- Career advice: learn coding practically (economics degree, dropped out); use common sense against big-company inherited nonsense
