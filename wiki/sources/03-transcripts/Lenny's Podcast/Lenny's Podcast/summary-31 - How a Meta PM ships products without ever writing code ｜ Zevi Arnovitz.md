## Core Summary

Zevi Arnovitz, a non-technical PM at Meta with zero coding background, demonstrates how he uses AI tools (Cursor with Claude Code, GPT projects, Bolt, Lovable) to build and ship real products as a weekend project — including his side business StudyMate. He shares a structured, repeatable workflow of slash commands (create issue → exploration → create plan → execute plan → review → peer review → update docs) that any non-technical person can copy. The conversation also covers his innovative multi-model peer review technique, where he has Claude, Codex, and Gemini each review the same code and then debate each other's findings, and his philosophy that AI is the best thing to happen to juniors and learners, enabling anyone to become a builder.

## Key Points

- Zevi has zero technical background (did music in high school, no tech unit in the army) and learned to build by watching YouTube videos about Bolt and Lovable when Sonnet 3.5 launched.
- His journey: started with GPT Projects as a "CTO co-founder," graduated to Bolt/Lovable, then moved to Cursor with Claude Code for full control.
- The key difference between serious building and vibe coding: the planning phase. Zevi uses a structured workflow with slash commands to ensure proper exploration, planning, and review before writing code.
- Slash commands workflow: (1) create issue (captures ideas in Linear), (2) exploration phase (Claude studies codebase, asks clarifying questions), (3) create plan (markdown plan with task tracking), (4) execute plan, (5) review (Claude reviews its own code), (6) peer review (multiple models review and debate), (7) update docs.
- Multi-model peer review: Zevi has Claude, Codex (GPT-5.1 Max), and Gemini each review the code independently, then has Claude (as "dev lead") evaluate their findings — accepting, rejecting, or fixing issues.
- Model personality types: Claude = perfect CTO (communicative, opinionated, collaborative), GPT/Codex = best coder in a dark room (solves hardest bugs but doesn't explain), Gemini = crazy artsy scientist (terrifying process, beautiful results).
- He uses different models for different strengths: Claude for architecture and planning, Cursor Composer for speed, Gemini 3 for UI/frontend.
- "Time machine moments": when multiple AI agents run in parallel and he feels like he's living in the future.
- Learning opportunity slash command: primes Claude to explain technical concepts using the 80/20 rule, acting as a teacher for a "technical PM in the making."
- Post-mortems for AI: when Claude makes a mistake, Zevi asks it to introspect on what caused the error, then updates tooling/documentation so it never recurs.
- Gradual exposure therapy: start with GPT Projects (beautiful UI, simple), then Bolt/Lovable, then Cursor in light mode, then full terminal/dark mode.
- AI for interview prep: Zevi used a Claude project as his Meta interview coach, created a quiz game in Base44 for segmentation practice, used Comet (Perplexity browser) to analyze question banks, and did cold outreach on LinkedIn for human mocks.
- Zevi's brother (non-technical entrepreneur) built a full CRM and automation system replacing Zapier and AirTable, entirely on his own with AI.
- For PMs at larger companies: make the codebase AI-native (markdown docs for agents), use contained UI projects, create PRs and send to devs for finishing.
- "It's not that you will be replaced by AI — you'll be replaced by someone who's better at using AI than you."
- "It's the best time to be a junior" — contrary to popular belief, AI enables juniors to build startups and ship products independently.
- Failure corner: Zevi's first product review at Wix failed because he tried to impress rather than learn. Lesson: be a 10x learner, not a 10x PM; no one expects you to know everything.
- Sponsor: Tenweb (AI website builder, WordPress VIP coding platform), DX (developer intelligence platform).
