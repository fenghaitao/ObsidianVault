## Core Summary

[[Lenny Rachitsky]] interviews [[Claire Vo]] ([[ChatPRD]] founder, [[How I AI]] host, first-ever crossover episode) about her journey from [[Open Claw]] skeptic — her first install deleted her family calendar after 8 hours of setup — to power user running 9 named agents across 3 Mac minis. Her central practical unlock is treating each agent like a specialized human hire rather than one general-purpose assistant: partition responsibilities (a "[[Multi-Agent Household]]") to avoid context overload, and onboard each one with "[[Progressive Trust Onboarding]]" (its own email/calendar, incrementally delegated access) exactly as you would a new EA. She explains Open Claw's "[[Soul And Heartbeat]]" mechanism — a persistent identity file plus scheduled check-ins — as the reason it feels alive and proactive, walks through concrete business (a sales-outreach agent, "Sam") and family (a scheduling agent, "Finn"; a kids'-homework tutor, "Q") use cases, and shares practical setup tips: screen-sharing into a headless Mac mini, keeping a separate editable tools.md file, using Claude Code as a "surgeon" to fix broken agent configuration, and "[[Ramble Mode]]" (long voice-note onboarding) for high-bandwidth context transfer. She frames the product's real rough edges (unreliable browser automation, occasional memory loss) as a textbook sign of genuine product-market fit.

## Key Points

- Claire's first Open Claw install took 8 hours and ended with her family calendar deleted — but the underlying utility convinced her something real was there.
- Central unlock: run multiple purpose-built agents (Polly, Finn, Max, Howie, Sam, Kelly, Holly, Sage, Q), not one general-purpose agent — the main failure mode is context overload, not lack of capability. See [[Multi-Agent Household]].
- "[[Progressive Trust Onboarding]]": provision each agent its own email/calendar and grant access incrementally (read → draft → send), exactly like onboarding a human EA — never hand over your real password.
- "[[Soul And Heartbeat]]": a persistent identity.md-style file (personality, values, security rules) plus scheduled check-ins (a "heartbeat," e.g. every 30 minutes) are what make the agent feel alive and proactive rather than reactive.
- Concrete business case: "Sam" runs a daily CRM sweep identifying enterprise leads, sends warm outreach, escalates big accounts, and runs weekly cleanup — work that previously cost ~10 hours/week of contractor time.
- Concrete family case: "Finn" manages a chaotic multi-kid household calendar and pings daily about pickup logistics; "Q" is a dedicated tutor-agent for her kids' homework, seeded via conversational interview.
- Practical tips: screen-share into a headless Mac mini instead of buying a monitor; keep an editable `tools.md`; use Claude Code as a "surgeon" to fix broken agent config; use "[[Ramble Mode]]" (voice notes) for onboarding instead of structured forms.
- Frames Open Claw's real bugs/limitations (unreliable browser automation, memory lapses) as a genuine product-market-fit signal, not a reason to dismiss it.
- Notes Open Claw's conversational tone avoids the engagement-hacking patterns common to commercial chatbots (ChatGPT, Claude), since it isn't optimizing for engagement metrics.
