## Core Summary

Alexander Imbiricos (product lead for Codex at OpenAI) discusses how Codex has grown 20x since GPT-5 launched, evolving from a cloud coding agent to an IDE-integrated teammate. He argues that the current underappreciated bottleneck for AI productivity is human typing and review speed, not compute, and that the path to winning the agent race is building a super assistant that uses code as its primary interface to interact with computers. The conversation covers OpenAI's radically bottoms-up culture, the Sora Android app being built in 18 days by 2-3 engineers, and a vision where coding agents become proactive teammates that anticipate needs rather than waiting for prompts.

## Key Points

- Codex has seen 20x growth since GPT-5 launched in August 2025, serving trillions of tokens per week
- The key product unlock was shifting from a cloud-async agent to an IDE/CLI-integrated interactive agent that works locally in a sandbox
- Compaction is a critical feature enabling Codex to run for 24+ hours by managing context windows across the model, API, and harness layers
- Alex argues that the best way for any agent to use a computer is to write code, making coding agents the foundation for all future agents
- The Sora Android app was built in 18 days (to employees) and 28 days total (public launch) by 2-3 engineers using Codex, becoming the #1 app in the App Store
- OpenAI's culture is "truly, truly bottoms-up" with a fuzzy long-term aim and empirical short-term execution
- The current limiting factor for AI productivity is human typing speed and multitasking speed for reviewing AI output
- Codex is now being used for its own training runs, babysitting training graphs, and catching configuration mistakes via automated code review
- Alex predicts that starting next year, early adopters will hockey-stick their productivity, with larger companies following over subsequent years
- The team's focus is shifting to making code review easier and more fun, since writing code is the fun part but reviewing AI-written code is not
- OpenAI designers are "vibe coding" prototypes and landing PRs, compressing the talent stack across design and engineering
- The vision for Atlas (OpenAI's browser) is enabling contextual actions that surface AI help at the moment you need it, not via push notifications
- Alex's startup motto "be kind and candid" shaped his leadership philosophy, similar to radical candor
- Codex is best used by giving it your hardest tasks, not trivial ones, and working with it like onboarding a new teammate
