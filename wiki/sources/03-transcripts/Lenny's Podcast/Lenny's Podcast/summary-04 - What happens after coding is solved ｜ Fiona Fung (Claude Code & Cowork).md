## Core Summary

Fiona Fung, who leads Claude Code and Co-work at Anthropic (overseeing Boris Cherny and Cat Wu), describes what happens after coding is solved. Anthropic engineers now ship 8x as much code per quarter as they did pre-2025. Coding is no longer the bottleneck: "Everything is now possible in theory. Now, it's about how ambitious can you be?" The shift is toward verification, accountability, and agency. With high agency comes high accountability -- everyone needs a hypothesis for what they're solving. She warns about the loneliness of agent-heavy work (leading to pair-programming lunches) and the growing gap between those leaning into AI and those resisting out of fear. Her advice: "For anything there is a fear, lean in and ask, what can I do about it? What is within my control?"

## Key Points

- Anthropic engineers ship 8x more code per quarter compared to pre-2025
- "Coding is no longer the bottleneck. Everything is now possible in theory. Now, it's about how ambitious can you be?"
- High agency pairs with high accountability: everyone needs a hypothesis for what they're solving
- Not just engineers -- designers, PMs, everyone on the Claude Code team checks in code
- The shift: from planning (when engineering time was precious) to verification (when code is abundant)
- Started pair-programming lunches because agent-heavy work can be lonely
- Growing gap: people leaning into AI vs. those resisting out of fear
- "For anything there is a fear, lean in and ask: what can I do about it? What is within my control?"
- Before Anthropic: led TypeScript/Visual Studio at Microsoft, started Facebook Marketplace (100B+ GMV), built Orion AR glasses at Meta
- Journey from Vim at IBM to Visual Studio IDE to AI agents -- each wave transformed how engineers work
