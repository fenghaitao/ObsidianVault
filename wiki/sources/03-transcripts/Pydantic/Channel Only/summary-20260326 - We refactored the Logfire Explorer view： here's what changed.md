## Core Summary

A short product update on Logfire's redesigned Explorer view: now a Jupyter-like notebook interface with keyboard shortcuts, an AI assistant for writing queries, and improved column/function visibility in the sidebar.

## Key Points

- Explorer view redesigned as Jupyter-like notebook with full keyboard navigation
- AI assistant can write queries from natural language (e.g., "get me all the metric names for my project")
- Improved sidebar showing available columns, metrics, and functions
