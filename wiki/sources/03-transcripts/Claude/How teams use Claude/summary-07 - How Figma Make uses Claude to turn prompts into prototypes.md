## Core Summary

Figma describes using Claude to power Figma Make, which translates design canvas elements into pixel-perfect code. Claude was chosen because it "clearly just seems to know code better than most of the models and produces code that developers would actually want to write." The vision is making design more accessible — people with taste can enact it without needing to code. The goal is not just faster output but higher quality: more ideas, more explorations, better end results.

## Key Points

- **Figma Make:** Translates design canvas to pixel-perfect code that developers would actually want to write.
- **Claude as coding model:** "Clearly just seems to know code better than most of the models."
- **Democratizing design:** People with taste can create without coding. Design becomes a much more accessible practice.
- **Quality over speed:** Goal is higher quality — more ideas, more explorations, better end results.
- **Human + AI partnership:** Only humans can convey feeling through design; Claude is the partner that makes enactment easier.
