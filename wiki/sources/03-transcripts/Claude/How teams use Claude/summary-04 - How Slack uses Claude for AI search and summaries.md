## Core Summary

Slack describes using Claude for two core problems: AI-powered search and high-volume information summarization. The "mind meld" moment came when first search answers demonstrated Claude's ability to distill through noise. Metrics improved: query success rate up and self-reported "Slack feels noisy" down. Internally, Claude Code is used for bug fixes and accelerating team velocity. The limitation has shifted from "how to build" to "what to build" — more time on planning and architecture, less on coding.

## Key Points

- **Two core problems:** Search and summarization of high-volume information in Slack channels.
- **"Mind meld" moment:** First Claude search answers showed immediate fit for distilling through information overload.
- **Metrics improvement:** Query success rate increased; users self-reporting Slack as noisy decreased — one of the biggest improvements tracked.
- **Internal use:** Claude Code for bug fixes and accelerating team velocity.
- **Shift in work:** More time on planning and architecture, less on coding. "The limitation now is creativity and imagination."
