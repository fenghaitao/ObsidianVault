## Core Summary

An Anthropic marketer with zero coding experience describes building a Figma plugin with Claude Code that automates ad creative variant generation. Previously, creating 10 variations across 5 aspect ratios required 30 minutes of repetitive copy-paste between Figma and Google Docs. The Claude Code-built plugin reduces this to 30 seconds: select frame, paste all headline variations, and generate all variants in individual frames. The key message: the gap between "I wish this existed" and "I can build this myself" is much smaller than people realize.

## Key Points

- **Zero to builder:** Marketer had never written code, had to Google how to open terminal. Built a working Figma plugin with Claude Code.
- **Figma plugin workflow:** Select frame → identify template components → paste all headline variations → generate all ad variants in individual frames.
- **Time savings:** 30 minutes reduced to 30 seconds for ad variant generation.
- **Advice for non-coders:** Start with a very small, repetitive task. Explain the challenge clearly and concisely. Claude handles the code.
- **Mindset shift:** The gap between wishing something existed and building it yourself is much smaller than perceived.
