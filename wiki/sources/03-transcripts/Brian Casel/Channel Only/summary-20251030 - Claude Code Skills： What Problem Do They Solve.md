## Core Summary

Brian Casel explains what problem Claude Code Skills solve: they package reusable capabilities with progressive disclosure so agents only load what's needed. Skills prevent context pollution while giving agents access to specialized workflows on demand.

## Key Points

- Skills solve the context pollution problem: load short descriptions upfront, full instructions on demand.
- Skills are folders with SKILL.md + optional references and scripts.
- Progressive disclosure is the key mechanism — agents see capability descriptions first, then load full instructions when invoked.
