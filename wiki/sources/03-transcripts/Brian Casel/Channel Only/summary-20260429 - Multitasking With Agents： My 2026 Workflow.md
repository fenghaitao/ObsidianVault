## Core Summary

Brian Casel traces his evolution from hand-coding (2023) through AI enhancement (2024) and AI collaboration (2025) to agent orchestration (2026). The key shift: specs became the real output of his creative work, and once specs grew more ambitious, single-agent workflows became a bottleneck. He now multitasks across 2-4 features simultaneously using git worktrees, evaluates modern agentic development tools (SuperSet, Conductor, Cursor, Claude Desktop), blends product and marketing work in the same codebase, and manages agents from mobile. He also details his SparkDrop content pipeline where Claude Co-work agents submit ideas via API.

## Key Points

- Timeline: 2023 (hand-coding) → 2024 (AI enhancement) → 2025 (AI collaborator, spec-driven) → 2026 (agent orchestration, multitasking).
- Brian now spends ~90% of time shaping/refining specs, ~10% reviewing what agents built.
- Tool evaluation: SuperSet (current favorite, native Claude Code CLI, worktree support), Conductor (wraps Claude Code), Cursor 3.0 (agent sidebar), Claude Desktop (redesigned but limited).
- Git worktrees are essential for multitasking — each feature gets its own isolated workspace.
- Context blending: product work and marketing work now run in parallel, sometimes in the same codebase.
- Reusable skills bridge domains: an "app marketing page" skill spins up landing pages; a "plan videos from build" skill extracts video concepts from build work.
- Mobile pattern: kick off a big task before dinner/bed, review results in the morning.
- SparkDrop: custom content pipeline app where Claude Co-work agents submit ideas via API, Brian reviews and approves.
- Brian's agent team: 4 agents on OpenClaw (Gumbo for daily synthesis, etc.) + Claude Co-work for creative content development.
- Consensus MCP: plugs into agents for peer-reviewed academic paper search with citable sources.
