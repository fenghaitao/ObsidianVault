## Core Summary

Brian Casel releases Design OS, a free open-source guided design process for AI-first development. It fills the gap between product idea and codebase with three phases: product planning (vision, data model, design tokens), section design (requirements, sample data, screens), and export (production-ready components + prompts). Built on React/Vite/ShadCN/Tailwind.

## Key Points

- Three phases: (1) Product Planning — vision, data model, design tokens, shell; (2) Section Design — requirements, sample data, screen design; (3) Export — components + implementation prompts.
- Standalone project separate from app codebase; built on React, Vite, ShadCN, Tailwind CSS.
- Two implementation approaches: incremental (milestone-by-milestone) and one-shot (entire app at once).
- Export package includes: React components, README per section, sample data, test instructions, implementation prompts.
- Free and open-source at buildermethods.com/designos.
- Companion to Agent OS — Design OS for greenfield design, Agent OS for legacy standards.
