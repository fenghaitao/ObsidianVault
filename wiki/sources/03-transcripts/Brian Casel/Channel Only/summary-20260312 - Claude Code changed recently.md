## Core Summary

Brian Casel highlights three under-the-radar Claude Code features that are reshaping workflows in 2026: Auto Plan (automatic plan mode entry for substantial prompts), Auto Memory (Claude learns from corrections over time, managed by Claude itself), and Voice Mode (built-in voice dictation). He argues these aren't just quality-of-life improvements — they're fundamentally changing how we work by reducing friction and improving output quality.

## Key Points

- **Auto Plan**: Claude Code now automatically enters plan mode when it detects a substantial prompt. The product decision signals that Anthropic believes planning-first yields better results.
- **Auto Memory**: Claude maintains its own memory file, learning from course-corrections and re-prompts over time. Unlike CLAUDE.md (human-managed), auto memory is fully Claude-managed. Reduces repeating the same corrections.
- **Voice Mode**: built-in voice dictation in Claude Code. Brian already uses WhisperFlow but notes that speaking prompts produces higher detail, accuracy, and precision than typing — typing fatigue leads to self-editing and reduced ambition.
- Plan mode's "ask user question" tool also improved, making it easier to be a better product owner.
- Brian's Agent OS framework was remade in 2026 to enhance specs with plan mode, not replace it.
