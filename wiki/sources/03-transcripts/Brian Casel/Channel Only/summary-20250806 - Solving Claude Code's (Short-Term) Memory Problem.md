## Core Summary

Brian Casel addresses Claude Code's context/memory limitations and presents strategies for working around them: milestone-based building, context resets, and milestone logs for passing context between sessions.

## Key Points

- Claude Code's context window is finite; long sessions degrade.
- Solutions: break work into milestones, clear context between phases, use milestone logs.
- Prefigures later features like Auto Memory.
