## Core Summary

An announcement/promo video launching the **Dynamous × Kiro AI coding hackathon** (Jan 5–23, 2026; $17,000 prize pool; winners announced on a Feb 7 livestream). [[ColeMedin]] partners with the [[Kiro]] team — who fund only the prize pool — to get viewers building any project (web apps, AI agents, CLI tools, APIs, automations, mobile) using Kiro. Low durable-knowledge value as an event notice, but it introduces [[Kiro]] as an entity and surfaces its core workflow primitives (steering documents, prompts/commands, devlog) that map onto patterns already in this wiki.

## Key Points

- **Mechanics**: individual (non-team) submissions, one per person; register via the Dynamous community; 500 free Kiro bonus credits for new accounts plus emailed credit codes.
- **Only hard requirement**: build with [[Kiro]] (CLI preferred, IDE allowed); theme is otherwise completely open.
- **Judging criteria**: application quality, how well Kiro was used, documentation quality, innovation/uniqueness, and a 2–5 minute demo video.
- **Required submission artifacts beyond source code**: Kiro **steering documents** (Kiro's term for global rules), **prompts/commands** (markdown-defined workflows), and a **devlog** (timeline, decisions, challenges) — i.e. the AI-coding *process*, not just the result.
- **Quick-start template**: a clonable GitHub repo with a `Kiro guide` markdown, a setup command that interviews you to define steering documents, and a library of workflow commands — covering installation, the `.kiro` folder, tangent mode, cross-session knowledge management, sub-agents, and MCP servers.
