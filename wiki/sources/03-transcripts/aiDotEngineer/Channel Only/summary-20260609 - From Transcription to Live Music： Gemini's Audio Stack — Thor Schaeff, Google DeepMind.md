## Core Summary

Thor Schaeff from Google DeepMind presents Gemini's audio stack: from transcription to live music understanding. Key capabilities include EchoScript for rich audio analysis (speaker labeling, emotion, language detection, timestamps in one API call), Gemini 3.1 Flash Live for full-duplex multimodal conversation, and Gemma 4 with on-device audio understanding.

## Key Points

- EchoScript (Gemini 3 Flash): single API call extracts summary, speaker labels, timestamps, language, emotion from audio.
- Gemini 3.1 Flash Live: full-duplex sound-to-sound real-time conversational model with multimodal input (text, voice, vision).
- Gemma 4: open model with on-device audio understanding for edge devices.
- Audio understanding beyond transcription: context, emotion, pacing, code-switching, overlapping speakers.
- GenMedia audio models: video generation includes audio; Lyria for music generation.
- Thor joined DeepMind November 2025, day before Gemini 3 release.
