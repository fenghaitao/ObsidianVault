## Core Summary

Gus Martins and Ian Ballantyne from Google DeepMind present Gemma 4, the latest open model family. Gemini is for intelligence via API; Gemma is for ownership — run on your own hardware, customize, keep proprietary data local. Gemma 4 includes E2B/E4B "effective" models that use 2B/4B GPU memory but have 5B+ parameters via token mapping, enabling phone deployment.

## Key Points

- Gemini (proprietary, API) + Gemma (open, self-hosted) are complementary: intelligence vs ownership.
- Gemma 4: four sizes, E2B and E4B target mobile/IoT with "effective" parameter counts (GPU memory usage = 2B/4B, actual params = ~5B).
- E models achieve efficiency via token mapping stored in non-GPU memory.
- Multimodal: text, vision, audio input; text output.
- Released June 2026; more details in keynote by Omar and CassD talk.
- Sovereign escape velocity: owning your models means independence from external API dependencies.
