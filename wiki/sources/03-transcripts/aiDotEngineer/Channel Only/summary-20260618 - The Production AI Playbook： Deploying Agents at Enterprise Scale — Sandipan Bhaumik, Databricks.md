## Core Summary

Sandipan Bhaumik from Databricks presents a five-pillar production AI playbook: evaluation, observability, data foundation, orchestration, and governance. The common failure pattern: choose model first → build demo → leadership approves → production fails. Three gaps: observability (can't see what AI does), evaluation (no continuous measurement), governance (no accountability).

## Key Points

- Five pillars (start before coding): (1) Evaluation — define success metrics and continuous measurement. (2) Observability — trace every AI decision (required by regulators in Europe). (3) Data foundation — question data + tracking data strategy. (4) Orchestration — one agent works, many need coordination. (5) Governance — accountability, ownership, failure handling.
- Anti-pattern: choose model → build features → demo → production → "what the hell is AI doing?"
- Three gaps: observability gap, evaluation gap, governance gap.
- From AWS principal architect to Databricks technical lead, deploying AI across B2B software and regulated industries.
- Framework implemented across multiple customer organizations.
