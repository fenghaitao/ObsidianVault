## Core Summary

Zack Proser from WorkOS argues that human attention is now the bottleneck, not agents. Agents can scale infinitely, but developer nervous systems can't. Solutions: signal layers (agents filter Slack/Linear before reaching you), voice-first coding, remote control, and systems that improve themselves. Simon Willison: fires up 4 parallel agents, wiped out by 11am.

## Key Points

- Agents scale infinitely; human attention degrades under load. The bottleneck has shifted.
- Four layers for developer balance: (1) Signal layers — agents filter Slack mentions, deduplicate against Linear, only surface high-priority. (2) Voice-first flows — voice coding for 1.5 years, life-changing. (3) Remote control — Claude Code accessible from anywhere. (4) System improving itself — agents analyze message history for patterns.
- Demo: Claude Code with Slack MCP + Linear MCP fixes bug, verifies own work, posts result to Slack. Developer comes back to completed loop.
- Context switching was always expensive; with agents it's worse — tools are nuclear, nervous systems are ancient.
- Everyone needs to find their personal limits for agent parallelism.
