## Core Summary

Brendan O'Donoghue from Google DeepMind presents text diffusion — an alternative to autoregressive generation where text is generated by iteratively denoising a canvas of random tokens. It offers 10x lower latency (2,000+ tokens/sec via Gemini Diffusion) through better hardware utilization, bidirectional attention enabling self-correction, and adaptive computation. The main trade-off: lower throughput for large batches, making it more expensive to serve.

## Key Points

- Text diffusion: start with random tokens → iteratively denoise over multiple passes → clean text output. Contrast with autoregressive: one token at a time.
- Hardware advantage: autoregressive is memory-bandwidth bound (one token per weight transfer); diffusion generates many tokens per pass (10x fewer memory transfers).
- Gemini Diffusion: research demo with ~2,000 tokens/sec, comparable quality to Gemini 2.0 Flash at the time (1 year ago).
- Other advantages: bidirectional attention enables self-correction (see mistake, go back, fix reasoning); adaptive computation (more steps for harder problems); in-place editing.
- Main disadvantage: lower throughput for large batches → higher serving cost. Throughput concerns are why no one has deployed text diffusion in production models yet.
- Image/video diffusion is already state-of-the-art; text diffusion is the research frontier for language.
