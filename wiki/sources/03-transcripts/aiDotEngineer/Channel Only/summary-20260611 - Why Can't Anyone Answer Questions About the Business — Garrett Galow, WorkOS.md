## Core Summary

Garrett Galow from WorkOS presents Studio, an internal tool that lets anyone answer business questions via natural language. Instead of the slow loop (question → find engineer → write SQL → back-and-forth in Slack), Studio connects to Snowflake, Linear, Notion and lets agents query data sources to answer questions and build dashboards automatically.

## Key Points

- Current workflow: business question → find engineer → explain context → write SQL → share in Slack → iterate. Slow, doesn't scale.
- Studio: internal workspace where agents connect to data sources (Snowflake, Linear, Notion) and answer questions via natural language.
- Agent explores schemas, runs queries, iterates to find answers. Builds dashboards and apps that non-technical users can use.
- WorkOS powers enterprise auth for Cursor, Anthropic, OpenAI.
- Demo: "what content leads to the most new teams?" — agent queries Snowflake, finds conversion patterns from marketing content.
