## Core Summary

Olivier Leplus (AWS) and Yohan Lasorsa (Microsoft) present how AI has transformed web development in 2026. AI is now at every stage: coding with skills, debugging, performance tuning, browser-native AI APIs, and agents consuming web apps. Key message: skills are the difference between getting good vs poor results from coding agents.

## Key Points

- AI at every stage of web app lifecycle: coding, debugging, performance, browser-native AI APIs, agent consumption.
- Skills: lightweight text-based plugins (open spec) for domain expertise, new capabilities, and repeatable workflows. Supported by most coding agents.
- Skills use progressive disclosure: description determines when the agent loads the full skill into context.
- Demo: coding agent uses GitHub CLI skill to read open issues, implement features from issue descriptions.
- 2026: no longer "can I code with AI?" but "how to get the best results?" — it's a matter of skills (the plugins).
- Agents are increasingly using web apps alongside humans, requiring web apps to adapt.
