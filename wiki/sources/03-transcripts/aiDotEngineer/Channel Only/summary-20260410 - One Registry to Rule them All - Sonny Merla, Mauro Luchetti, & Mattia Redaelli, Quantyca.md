## Core Summary

Sonny Merla (Amplifon) and Quantyca present an enterprise-grade registry system for MCP and A2A agents. Amplifon (26 countries, 20K employees, 10K stores) launched the Amplify program with three registries: MCP registry (internal + curated public servers with enterprise metadata), A2A registry (agent card catalog), and use case registry (governance lineage).

## Key Points

- Amplify program (Jan 2025): governance (AI regulatory alignment), platform (certified infrastructure), factory (development teams rolling out solutions).
- Three registries: (1) MCP registry — custom internal servers + curated public servers enriched with enterprise metadata. (2) A2A registry — agent card standard catalog. (3) Use case registry — connects metadata for governance lineage.
- AI gateway: unified model access with Entra ID auth, budgeting (per-use-case cost limits), central auditing/monitoring.
- Problem: dozen teams across 3 continents each wiring their own connections, security models, and infrastructure → chaos.
- Built as extension of the community MCP registry with enterprise context: ownership, compliance status, approved versions.
