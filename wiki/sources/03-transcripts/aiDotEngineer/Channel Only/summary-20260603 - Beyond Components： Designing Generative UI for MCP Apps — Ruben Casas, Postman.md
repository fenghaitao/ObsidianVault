## Core Summary

Ruben Casas from Postman presents the evolution of UI in the AI era: from static components (agent as orchestrator mapping tool calls to predefined components) to declarative UI to generative UI (model generates UI on the fly). The "GUI for the new computer hasn't been invented yet" — chat is temporary, and MCP apps are a step toward the future interface language.

## Key Points

- Evolution: 2022 copy-paste from ChatGPT → 2025 inflection (GPT 5.2, Opus 4.5) producing high-fidelity UI generation.
- Three UI paradigms: (1) Static components — agent maps tool calls to predefined React components (AGUI, Goose Auto Visualizer). (2) Declarative UI — agent generates structured layout descriptions. (3) Generative UI — model generates UI code directly.
- "We have a new computer. The GUI hasn't been invented yet." — Andrej Karpathy. Chat is the '70s terminal equivalent.
- Two questions: where does UI run (super app vs chat everywhere) and what is the model generating?
- MCP apps as the super-app model: third-party UI rendered inside one agent environment (ChatGPT, Claude, Gemini).
- Consumers will decide the final paradigm.
