# Build & deploy AI-powered apps — Paige Bailey, Google DeepMind

## Core Thesis
Paige Bailey from Google DeepMind demonstrates the latest multimodal AI models (Gemini 3.1 series, Genie 3, Lyra 3, Gemma 4, Nano Banana 2, VEO 3.1 Light) and showcases how developers can build and deploy AI-powered applications using Google's AI Studio platform, emphasizing multimodal capabilities, code execution, search grounding, and real-time interaction.

## Concepts
- [[MultimodalAI]] — AI models supporting multiple input/output modalities (video, images, audio, text, code)
- [[Code Execution (Sandboxed)]] — Gemini tool providing a sandboxed Python environment with data science libraries
- [[Grounding with Google Search]] — Tool that lets Gemini models cite and use Google Search results
- [[URL Context]] — Feature allowing Gemini to incorporate content from URLs into its context window
- [[Compare Mode]] — AI Studio feature for head-to-head comparison of different models
- [[World Model Building]] — Generating navigable 2D/3D environments dynamically from text descriptions
- [[Multimodal Embeddings]] — Embeddings supporting video, images, audio, text, and code in the same space
- [[Structured Outputs]] — Gemini feature for constraining model output to specific formats
- [[Function Calling]] — Gemini capability to invoke external tools and APIs
- [[Thinking Levels]] — Configurable reasoning depth (minimal, low, medium, high) in Gemini 3.1 models
- [[Image Search Grounding]] — Reverse image search tool for grounding image generation models

## Key Highlights
- Gemini 3.1 models are multimodal for both inputs and outputs (unlike most competitors which only output text/code)
- Code execution provides a sandboxed Python environment with pre-installed data science libraries
- AI Studio's "Build" feature enables one-click app creation with databases (Firestore) and authentication (Firebase/Google login)
- Genie 3 generates worlds dynamically frame-by-frame with no physics engine, navigable via WASD keys
- Gemma 4 models are Apache 2 licensed, run on mobile devices, and available via AI Studio API for free
- Gemini Live supports real-time screen sharing, video feeds, audio, with dynamic language switching
- VEO 3.1 Light generates stock footage with audio at 720p with configurable duration and aspect ratio
- Lyra 3 generates music with configurable genres, moods, and lyrics in multiple languages
- Nano Banana 2 supports image search grounding for more accurate image generation
- AI Studio provides "Get Code" for Python, TypeScript, Java to replicate any UI experiment
