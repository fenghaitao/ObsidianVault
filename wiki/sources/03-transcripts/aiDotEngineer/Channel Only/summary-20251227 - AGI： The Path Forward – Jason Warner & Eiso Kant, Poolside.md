# AGI: The Path Forward – Jason Warner & Eiso Kant, Poolside

## Core Thesis

Poolside is building proprietary AI models from scratch that combine next-token prediction with reinforcement learning to close the gap between models and human intelligence, targeting high-consequence code environments (defense, government) with a full vertical integration approach spanning data centers, model training, and developer interfaces.

## Key Points

- Poolside's mission is to close the gap between models and human intelligence through custom-trained models.
- Their core technical insight (2.5 years ago): next-token prediction needs to be paired with reinforcement learning to make the leap to more capable intelligence.
- Malibu Agent is their second-generation model, trained from scratch with proprietary techniques.
- They demonstrated a live coding agent in VS Code converting an ADA codebase to Rust, including self-testing and feature addition.
- Poolside operates in high-consequence code environments (defense, government) where agents need strict permission controls.
- Their next-generation model will be publicly available via their own API and Amazon Bedrock in early 2026.
- They are building out a multi-gigawatt data center campus in West Texas with over 40,000 GB300s.
- Jason Warner was formerly CTO of GitHub (2017+), where he helped launch GitHub Copilot with Nat Friedman.
- Eiso Kant had working code completion using LSTMs before the transformer architecture fully landed.
- Poolside is open to partnerships for reinforcement learning and fine-tuning on top of their models.
