## Core Summary

Kobie Crawford from Snorkel presents research showing a 4B parameter model outperforming a 235B model on financial analysis tool use through RL with high-quality data. The message: stop defaulting to bigger models — use RL to make models behave, not just be bigger. Partnership with UC Berkeley RLLM lab.

## Key Points

- 4B model outperformed 235B model on tool use for financial analysis via RL training with high-quality data.
- Bigger models are a sledgehammer — RL with the right data changes behavior more efficiently than scaling size.
- Snorkel: frontier AI data lab, expert-in-the-loop data quality, working with top labs on model improvement.
- "Terence Tao effect": a brilliant generalist isn't necessarily what a specific domain task needs.
- RL is better for behavior change; supervised fine-tuning is better for knowledge.
- Enterprise use cases need cost, speed, security — smaller models deployed on-premise solve data export concerns.
