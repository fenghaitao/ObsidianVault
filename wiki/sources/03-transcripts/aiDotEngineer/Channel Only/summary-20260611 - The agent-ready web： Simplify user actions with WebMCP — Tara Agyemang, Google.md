## Core Summary

Tara Agyemang from Google Chrome presents WebMCP, a proposed web standard that lets websites define their capabilities as structured tools for AI agents. Instead of agents parsing DOM, accessibility trees, and screenshots, WebMCP provides a "menu of tools" — the USB-C of AI agent interactions. Web foundations first: semantic HTML, accessibility, performance.

## Key Points

- Agents currently do enormous work for simple actions: parse DOM → accessibility tree → screenshot → measure coordinates → click. Brittle, token-heavy, ad-layout-dependent.
- WebMCP: websites expose structured tools that agents call directly. "USB-C of AI agent interactions."
- Web foundations first: semantic HTML, accessibility standards, page performance (Core Web Vitals), good UX flows. These make sites agent-ready by default.
- Chrome extension "Model Context Tool Inspector" shows available tools on any page.
- Demo: maze escape game that can only be played via AI tools — no clickable UI.
- Google Chrome + DeepMind collaboration on web/AI intersection.
