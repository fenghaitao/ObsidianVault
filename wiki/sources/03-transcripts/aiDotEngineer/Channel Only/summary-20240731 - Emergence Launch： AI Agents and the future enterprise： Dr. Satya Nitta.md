## Core Summary

Dr. Satya Nitta introduces Emergence, an R&D AI company advancing the science of AI agents. Emergence is building two infrastructural platforms for enterprise AI: an orchestrator agent (launching August 2025) that coordinates multiple agents and LLMs in complex workflows, and Agent E, an open-source web agent that can autonomously control web browsers to complete tasks. The company's core R&D focus is self-improving agents, AI planning and reasoning, and agent-oriented programming — all targeting enterprise workflows like RPA, document processing, and claims processing.

## Key Points

- Emergence is an R&D AI company staffed by talent from IBM Research, Google Brain, Amazon Alexa, Meta, Microsoft, and other top AI labs.
- The team has built some of the most scaled AI deployments including the IBM Watson platform, Amazon Alexa, and backend recommendation engines for Amazon Prime, Amazon Video, and Twitter.
- The orchestrator agent (launching August 2025, early access live) completes the full agentic loop: plan → act → verify → remember → improve. It orchestrates across multiple agents and LLMs for complex enterprise workflows.
- Agent E is an open-source web agent, developed by colleague Tamer, that controls the web like a human and currently tops the Web Voyager Benchmark. It integrates with the orchestrator.
- The developer dashboard helps analyze prompts, optimize cost and latency, create new models with custom data, and future-proof against LLM migrations.
- Core R&D focus areas: self-improving agents, AI planning and reasoning, and agent-oriented programming for stitching agents together.
- Target enterprise use cases: RPA (robotic process automation), document processing, and access management.
