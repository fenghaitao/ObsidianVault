## Core Summary

Malte Ubl, CTO of Vercel, delivers the opening keynote at the first AI Engineer conference in Europe. He argues that AI agents represent a new application layer that fills the gap between all software that should exist and what was economically viable to build with traditional methods. He outlines four practical agent archetypes companies can build today (agent as a service, compressed research, surfacing existing information, eliminating boring work), discusses the shift toward software being consumed by agents rather than humans (over 60% of vercel.com page views are now AI agents), and argues that Europe is leading AI engineering innovation while model companies commoditize, allowing value to accrue to the application layer.

## Key Points

- Agents are a new kind of software that makes previously uneconomical automation viable, filling out the circle of "all software that should exist"
- The SaaS Copocalypse trend (companies building instead of buying SaaS) combined with software market elasticity means cheaper software leads to more software and higher demand for engineers
- Four practical agent archetypes: Agent as a Service (24/7 automation of human agent roles), Compressed Research (agent does research, human decides), Surface Existing Information (making scattered company knowledge practically usable), Eliminating Boring Work (removing toil to improve job satisfaction)
- Over 60% of page views on vercel.com in the last 7 days were AI agents; usage is shifting from dashboard UIs to APIs and CLIs
- Infrastructure must shift to support agent-written software that "has to just run" without developer oversight
- Almost all current agent harnesses have the wrong architecture by combining where the harness runs with where generated code runs; Anthropic's new agent product separates these
- Europe is the leader in AI engineering innovation: Vercel's AI SDK (10M downloads/week, led by Last Gammel in Berlin), Pi (Austria), OpenClaw (Peter Steinberger)
- Two futures: model labs win (AI stays expensive, value accrues to them) or model commoditization (prices drop, AI engineers and application layer capture value) — the latter is more likely
