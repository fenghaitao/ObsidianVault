## Core Summary

Audry Hsu from RunPod presents GPU cloud deployment without leaving the IDE. RunPod offers four product layers (Pods, Serverless, Clusters, Hub) across 30+ data centers with 500K+ developers and $120M ARR. Founded from spare crypto-mining GPUs posted on Reddit.

- RunPod: AI cloud infrastructure company, 500K+ developers, 30+ data centers, $120M ARR.

- Focus: abstract away CUDA versions, PyTorch compatibility, GPU SKU testing.
