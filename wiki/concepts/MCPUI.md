## Definition
MCPUI is the original concept and project for passing UI over the Model Context Protocol, created by Ido Salomon in May 2025. It pioneered the idea that companies could send their own branded, interactive UI to chat hosts instead of being reduced to text, and later evolved into the standardized MCP Apps extension.

## Key Information
- Created by Ido Salomon in May 2025
- Core concept: take UI and find a way to pass it over MCP, enabling both UI delivery and bidirectional communication
- Motivation: we don't need to throw away everything we know about UI and UX to enter the world of agents
- Included community SDKs for building MCP UI servers and clients
- Early adopters: Shopify (millions of stores), Hugging Face (all Spaces as MCPUI widgets)
- Evolved into MCP Apps after partnering with Anthropic and OpenAI
- The MCP UI SDK remains the recommended client SDK for hosts
