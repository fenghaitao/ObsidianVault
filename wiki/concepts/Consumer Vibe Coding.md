## Definition
Consumer Vibe Coding is the idea of vibe coding going mainstream beyond software developers — enabling people who have never thought about code as something humans create to build apps, games, and experiences using natural language prompts. It represents the "Instagram filters moment" or "TikTok moment" that hasn't yet arrived for vibe coding.

## Key Information
- Vibe coding has not yet gone consumer mainstream — current tools like Lovable target consumers but effectively build B2B SaaS apps
- Vibe coding events (evening meetups) feel like "OG hackathons" because non-developers show up and build things
- Joe Reeve observes people at these events who say "wait, people make apps? I thought they were just there on my phone"
- Non-developers don't know UI primitives (hamburger menu, accordion) — they describe what they want in natural language and get "wacky" results
- A software engineer would say "you want one of these" but the LLM just tries to build it as described
- Current tools are mostly "Lovable but on your mobile phone" — not deeply pushing boundaries
- Spielwork (TikTok-swiping mobile vibe coding for games) is one early experiment
- Joe Reeve predicts a "social vibe coding" moment analogous to the Facebook Instant Games API: social graph + simple primitives + easy creation = viral consumer adoption
- The Facebook Instant Games API template: simple JavaScript async/await primitives for user info, friends, leaderboards, key-value storage, and ads — enabled 15M users for a simple Fruit Ninja clone
