## Definition

"Code is cheap" is the observation that AI coding agents have dramatically reduced the cost and time of writing code, shifting the bottleneck from implementation to everything else — ideation, testing, quality assurance, and decision-making. This is the single biggest shock in AI-assisted software development, forcing a fundamental rethinking of how software is built.

## Key Information

- "The reason that we have to rethink how we build, how we work as software engineers, is that the thing that used to take the time takes way less time"
- Prototyping is nearly free: "I can churn out 10,000 lines of code now in the time that it used to take me to write 100"
- Simon builds three different versions of a feature to explore which direction works best — only possible because code is cheap
- "Throughout my entire career, my superpower has been prototyping... that's gone. Anyone can do what I could do"
- Simon's tolerance for verbose tests has increased because "updating 1,000 lines of tests is now the job of the coding agent"
- "I can fire up four agents in parallel and have them work on four different problems"
- The flip side: Simon has 25 years of experience estimating how long things take — "that's all completely gone. That doesn't work anymore"
- "I constantly throw tasks to AI that I don't think it'll be able to do, because every now and then it does it"
- "It used to be you'd come up with the spec and you hand it to your engineering team and 3 weeks later... they'd come back with an implementation. Now maybe that takes 3 hours"
- The new bottlenecks: ideation, testing, proving which options work, and deciding what to build
