## Definition

YOLO mode (You Only Live Once) is the unsafe mode for AI coding agents where the agent doesn't ask permission before taking actions. Claude Code calls it "dangerously skip permissions" and OpenAI Codex explicitly calls it "YOLO." This mode is transformative because it allows running multiple agents in parallel without constant supervision, but it's inherently unsafe.

## Key Information

- "Claude calls it dangerously skip permissions. OpenAI actually do call it YOLO. They've got an option for that"
- "That's the mode where the agent doesn't ask you if it should do something all the time. And that is a different product"
- "A lot of people who haven't got on board with coding agents yet, haven't tried them in the unsafe mode. They're using coding agent where it's like, 'Oh, can I run this piece of code? Can I edit this file?' And that means you have to pay complete attention to it the whole time. And it's like working with a really frustrating toddler"
- "The moment you take the safeties off, now I can run four of them and go have a cup of tea and come back and they've achieved something useful for me"
- "But it's inherently unsafe"
- Simon's safety strategy: use Claude Code for Web (runs on Anthropic servers) in YOLO mode, because his code is all open source — the worst that could happen is source code leakage, which he doesn't care about
- "If it's running on Anthropic servers, I couldn't care less. It's their computer. It's not my computer. Go wild"
