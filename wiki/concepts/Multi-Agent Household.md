## Definition

[[Claire Vo]]'s core [[Open Claw]] insight: instead of throwing every task at one general-purpose agent, run multiple purpose-built, specialized agents (she runs 9) — partitioning responsibilities the same way a company splits Slack channels by team, to avoid context overload.

## Key Information

- Diagnoses the common failure mode where people "stumble" with Open Claw: expecting a single agent to handle everything, then getting frustrated when it forgets context or loses track of tools/permissions.
- Her Slack analogy: you wouldn't put marketing, sales, and engineering conversations in one #general channel — likewise, a work-scheduling agent ("Polly") doesn't need to also track kids' soccer schedules, and vice versa ("Finn").
- Named, specialized agents in her setup: Polly (general/work assistant), Finn (family logistics), Sam (sales/SDR), Howie (podcast production), Sage (course project management), Q (kids' tutor), plus Max, Kelly, and Holly.
- Agents can share a single machine safely if occasional cross-access between them is low-stakes (e.g. a salesperson agent seeing GitHub isn't a big deal), but should be physically separated onto different machines when the boundary matters more (e.g. a family agent should not have access to work email/data).
- Explicitly rejects the "AI psychosis" framing of running many agents — reframes it as ordinary organizational hygiene, the same instinct behind splitting Slack channels or giving employees role-scoped system access.
- Complements "[[Soul And Heartbeat]]" (each agent needs its own distinct identity to specialize meaningfully) and "[[Progressive Trust Onboarding]]" (each agent's access is scoped individually, like a new hire's).
