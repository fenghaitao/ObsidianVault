## Definition
Agent Attention Filtering is a personal AI agent's ability to proactively surface what needs human attention by combining access to all communication channels with contextual knowledge from the user's knowledge base. The agent understands what is important/urgent and notifies the user, drafts responses, or takes action autonomously.

## Key Information
- One of Radek Sienkiewicz's five types of agent jobs
- The agent has access to everything (emails, notes, files, calendars) and all context (Obsidian vault with project backgrounds)
- Real examples from Radek:
  - Netflix payment failure: detected and fixed within 5 minutes
  - Domain renewal: caught an email he would have missed, notified him on Discord, renewed the domain
  - Email drafting: reads email, understands project context from Obsidian, drafts a reply and places it in the drafts folder for review
- The agent knows what's important because it has context from the knowledge base — it understands project backgrounds, deadlines, and priorities
- Proactive notification via Discord message when something needs attention
- Distinct from ambient operations (background maintenance) — attention filtering is interactive and time-sensitive
