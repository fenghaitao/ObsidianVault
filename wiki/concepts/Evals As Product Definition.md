## Definition

[[Cat Wu]]'s practice of using a small number of well-built evals — as few as ten — to concretely define what "success" means for an ambiguous AI feature, rather than relying only on prose goals or PRDs.

## Key Information

- You don't need hundreds of evals; a handful of great ones is enough to help a team quantify the goal, measure progress toward it, and see what's still missing.
- Wu personally writes evals for features she feels need more concrete product definition — the output is typically a small eval set, instructions for running them, which ones currently pass/fail, and the prompt changes used to raise the success rate.
- Value varies by feature: not every feature needs this, but some (she cites Claude's memory feature) benefit heavily from it.
- A dedicated pod on her team works closely with Anthropic's research org specifically to build evals that precisely characterize Claude Code's behavior and identify the largest areas for improvement.
- Complements the AI-native PM skill set alongside model introspection and trusted taste-testers — see [[AGI Pilled]].
