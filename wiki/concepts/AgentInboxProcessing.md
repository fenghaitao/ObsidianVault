## Definition
Agent Inbox Processing is a workflow where a personal AI agent automatically analyzes links added to an inbox (tweets, threads, articles, YouTube videos), adds tags and context, checks existing knowledge base content on the topic, and creates connections — transforming previously unused bookmarks into an actively growing, interconnected knowledge base.

## Key Information
- One of Radek Sienkiewicz's five types of agent jobs
- Workflow: user drops a link into the inbox → agent analyzes the content → adds tags → adds context → checks what already exists on the topic in the vault → creates connections to existing notes
- Surfaces forgotten knowledge: "you already had this and this about this subject, and this is how it connects. Maybe you should look at those notes."
- Transforms Twitter bookmarks (which users typically bookmark and never revisit) into an actively growing knowledge base
- The agent's contextualization helps the user rediscover forgotten connections and see new relationships
- Part of the broader knowledge base integration that Radek considers the "magic" of his setup
- Contrasts with traditional bookmarking where content is saved but never processed or connected
