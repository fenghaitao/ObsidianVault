## Definition

"Hoarding things you know how to do" is an agentic engineering pattern and career strategy recommended by Simon Wilson. It involves building a backlog of solved problems, techniques, and tools — and storing them in a way that AI agents can search and recombine them for new problems. This amplifies your effectiveness because you can draw on your entire history of learning to solve novel challenges.

## Key Information

- A key agentic engineering pattern from Simon Wilson's blog/book
- "The way you build value as a software engineer... is you build a really big backlog of things that you've tried in the past that worked or didn't work"
- "Having that sort of backlog of things you've solved in the past, of techniques that you know to work, that's what gives you enormous value"
- AI makes this easier: "I can knock out a very quick prototype that tries out this new NoSQL database or whatever. Costs me nothing to do"
- Simon's implementation: two public GitHub repos
  - `simonw/tools`: ~193 HTML/JavaScript tools, each capturing an idea or technique
  - `simonw/research`: ~75 AI-driven research projects with actual code and results
  - Plus a private research repo with ~50 more projects
- "You can tell an LLM to consult them and combine them": "Here's the code for the OCR thing. Here's the code for the PDF thing. Build a new thing that can open a PDF file and OCR every page"
- AI agents can search across your entire hard drive of past work to find relevant examples
- "It's hard to overstate how good these things are at reusing context that you can make available to them"
- Simon also has 10,000 Apple Notes but defaults to public GitHub because "it's easier for me to find later on"
- Advice: "Find a note system that you trust and that you're not going to lose. GitHub is free for private repositories... your chances of losing something on GitHub are very, very slim"
