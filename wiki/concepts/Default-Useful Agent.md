## Definition

A default-useful agent is an AI system that is "helpful by default" — it provides value without the user having to think about when or how to invoke it. This is the opposite of current AI products that require deliberate prompting.

## Key Information

- Alexander Imbiricos: "a large part of our goal with Codex is to figure out what is the shape of an actual teammate agent that is sort of helpful by default"
- Currently, AI products are "actually really hard to use" because you must be thoughtful about when AI could help
- The vision: you "plug it in" and it "just starts to do stuff without you having to think about it"
- The key challenge is validation — the agent needs to be able to verify its own work before it can be default-useful
- IDE auto-completion is the closest existing example: when it's right you're accelerated, when it's wrong it's not that annoying
- The path to default-usefulness: first land with users interactively, then configure the agent over time so it can work autonomously
- The metaphor: like onboarding a new teammate — start with side-by-side work, then gradually delegate more
