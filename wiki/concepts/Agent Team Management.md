## Definition

Agent team management is the practice of running multiple purpose-built AI agents (rather than a single general-purpose agent), each with a scoped role, clear responsibilities, and limited context. This mirrors how you would structure a human team with different specialists.

## Key Information

- **The core insight:** "Where people stumble with OpenClaw is they think they can throw any task at a single agent and get great results. And then they get really frustrated."
- **Why multiple agents:** Context window management. Each agent focuses on its domain, preventing context overload.
- Claire Vo's agent team:
  - Polly: Work EA (scheduling, email, professional project management)
  - Finn: Family manager (kids' schedules, household logistics)
  - Sam: Sales (CRM sweeps, prospect outreach, deal management)
  - Howie: Podcast producer (guest prep, analytics, comment management)
  - Sage: Course manager (project management, content organization, marketing reminders)
  - Q: Kids' homework helper (academic planning)
  - Max, Kelly, Holly: Additional specialized agents
- **Organizational design principles:**
  - "I would hire different people to do this job in real life, so I'm going to hire different agents"
  - Agents on the same machine can share tools and context if permitted
  - Physically separate machines for agents that should never cross boundaries (e.g., work vs. family)
  - "If I'm okay with every agent on the machine occasionally going into each other's space, they can all live on the same machine"
- **Analogy:** Like Slack channels — you wouldn't put everything in #general. Marketing, sales, dev, and podcast teams each have their own channel.

## Why It Matters

- Prevents context overload — the #1 reason single agents fail at complex tasks
- Enables specialization: agents can be optimized for specific domains
- Mirrors real-world organizational design, making it intuitive for managers
- Creates a "team" feeling: "It is a team helping me look better to customers, helping me honestly show up better to my family"
