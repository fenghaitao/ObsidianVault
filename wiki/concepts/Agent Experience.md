## Definition
Agent Experience (AX) is the evolution of user experience design to incorporate AI agents as a distinct user class. It encompasses the non-functional requirements of agent interfaces: efficiency, discoverability, security, stability, and more — treating agents as "our next users."

## Key Information
- Coined/presented by Michael Hablich: "User experience is evolving to incorporate agent experience"
- "An agent is just another type of user, segment of user, also with non-functional requirements"
- Key dimensions of AX:
  - **Efficiency**: tokens per successful outcome, fuel efficiency of the interface
  - **Discoverability**: schema is the UI; tool descriptions must be clear
  - **Security**: trust boundaries, friction by design
  - **Stability**: error recovery, self-healing
- "Agents are our next users — let's help them help us"
- Builds on [[Agents As Different User Class]] — agents share goals with humans but think differently
- Complements [[AgenticProductDesign]] — practical design methodology for AX
- Extends traditional UX beyond visual complexity to include context window management
