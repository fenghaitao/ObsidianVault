## Definition
SDLC integration refers to applying AI across the full software development lifecycle rather than focusing solely on code completion. Since writing code has never been the bottleneck for most organizations, the biggest AI gains come from targeting other SDLC phases.

## Key Information
- For most organizations, writing code has never been the bottleneck
- There is far more to creating software than just writing code
- Key examples of SDLC-wide AI integration:
  - Morgan Stanley: AI reverse-engineers legacy code (COBOL, mainframe) into specs for modernization, saving ~300,000 hours/year
  - Zapier: AI bots/agents assist with onboarding, reducing time-to-effectiveness to 2 weeks
  - Spotify: AI pulls incident context and pushes it to Slack channels, significantly improving MTTR
- Data from ~140,000 engineers shows AI time savings are eclipsed by context switching, interruptions, and meeting-heavy days
- The approach aligns with the Theory of Constraints: target the actual bottleneck, not just code writing
