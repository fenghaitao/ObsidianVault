## Definition
A Personal Agent is an AI assistant that the user fully owns — owning the assistant, the files, the memory, and the ability to delete sessions. It represents the shift from cloud-dependent AI to locally-controlled, self-hosted AI that works on the user's own data.

## Key Information
- Kitze's realization: "I got the power of finally owning the assistant, owning the files, owning the memory, deleting the sessions if you wanted to"
- Went "full hipster mode" — no more Gemini, ChatGPT, Claude directly
- Moved everything off cloud: Nextcloud for images, local markdown for everything requiring API calls
- "Everything has to come off the cloud. It has to be local on my NAS, on my machine, just so my agents can actually work on it."
- Switched back to Android: agent can read notifications, clear notifications, install/uninstall apps
- The value: "it felt fully local" — control over data, sessions, and infrastructure
- Contrasts with cloud agents that are "too nerfed" and don't give users ownership
