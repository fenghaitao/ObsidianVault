## Definition

The Claude Browser Extension (Chrome extension) is a tool built by Anthropic's growth team that underpins many use cases for Claude Code and Claude Co-work. It was built as a larger bet by the growth team when no one else was doing it, representing the team's philosophy of taking bigger swings.

## Key Information

- Built by the growth team at Anthropic, not a core product team
- Underpins a number of use cases on Co-work and Claude Code
- Described as "a very AI-filled product that is like a very research-heavy product"
- The growth team was "just bullish on it" — an engineer was very bullish, and the team decided "no one else is doing it, we're going to do it"
- Amol: "That's the sort of thing that I wouldn't have done at another company"
- Example of the growth team's shift toward larger bets vs. traditional small optimizations
- Used for tasks like: competitive analysis tear-downs, looking at other companies' onboarding flows, pricing pages
- Amol uses it "all the time" and calls it "amazing"
