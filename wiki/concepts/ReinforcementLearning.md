## Definition

Reinforcement Learning (RL) is the training process that turns pre-trained language models into agentic models. Coding sessions provide measurable reward signals (tests pass, code committed), making them overrepresented in RL training data. Armin Ronacher argues this is why coding agents keep improving — our collective usage shapes future models.

## Key Information

- Pre-trained models have basic capabilities; RL makes them agentic
- Coding sessions produce clear evaluation signals unlike open-ended text generation
- Our usage of coding agents feeds back into model training through RL
- This creates a feedback loop: better coding agents → more usage → more training data → even better coding agents
