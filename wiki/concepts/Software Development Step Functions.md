## Definition
Software Development Step Functions are the major paradigm-shifting epochs in the history of software development that each made the craft more exciting and accessible. Thomas Dohmke identifies AI as the latest in a series that includes the PC, open source and the internet, collaborative platforms like GitHub, and the mobile wave.

## Key Information
- Framed by Thomas Dohmke as the context for understanding AI's impact on software development
- Historical step functions identified:
  - **Personal Computer**: The Commodore 64 and PCs in the 1990s
  - **Open Source and Internet**: Before the internet, open source was distributed via CDs and DVDs in bookstores; SourceForge and later GitHub transformed how developers discovered and shared code
  - **GitHub and Collaboration**: All of a sudden, developers started collaborating globally at scale
  - **Mobile Wave**: New platforms and new development paradigms
  - **AI**: The current step function — potentially the biggest technology innovation since the internet
- Each step function made software development more exciting, not less
- The advice for developers: "embrace our nerditude" — each transformation creates new opportunities to build
- Key characteristic: each step function introduces new abstraction layers that give developers "control over our development life cycle again"
