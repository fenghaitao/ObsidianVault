## Definition

Brand visuals is Brian Casel's agent skill for generating consistent, on-brand illustrations using Claude for concept development and the Google ImageGen API for actual image generation. It maintains brand consistency across all marketing assets through defined colors, visual world references, and a creative interviewing process.

## Key Information

- Two-stage process: Claude develops descriptive concepts (with options A/B/C), then sends prompts to Google ImageGen API.
- Includes brand colors, visual world references (types of objects in the brand), and idea mapping.
- Creative interviewing process: agent asks about visual context, color selection, size/configuration before generating concepts.
- Each illustration gets its own dated project folder with a project.md documenting all decisions.
- Typically requires 2-3 iterations to dial in the final image.
- Used for: website illustrations, workshop/session thumbnails, social media images.
- All illustrations share consistent style, line work, shadows, and color palette.
