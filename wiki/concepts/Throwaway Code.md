## Definition

Throwaway code is code written with AI agents for one-time use — analysis, prototyping, data exploration — rather than production deployment. The ease of AI code generation makes throwaway code economically viable for tasks that were previously too annoying to code manually.

## Key Information

- Alexander Imbiricos notes that while Codex is built for production code, "we see a lot of throwaway code written with Codex now"
- Examples: interactive data viewers for analysis, animation editors for design work, prototypes for product exploration
- A designer at OpenAI vibe coded an animation editor, used it to create a coin animation, then checked the animation into the repo — the editor itself was throwaway
- The economics have shifted: tasks that were "too annoying to do in the past" are now "totally worth the time of just getting an agent to go do something"
- This is part of the "ubiquitous code" thesis — as code becomes easier to generate, it will be used for many more purposes
- Prototyping is often faster than writing specs — PMs and designers increasingly reach for code before documents
- The OpenAI design team maintains a "vibe coded side prototype of the Codex app" for rapid product exploration
