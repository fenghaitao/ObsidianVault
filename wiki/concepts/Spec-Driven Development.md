## Definition

Spec-driven development is an emerging software development paradigm where developers write specifications (specs) in natural language and AI agents generate the actual code from those specs. Michael Turalda (CEO of Cursor) shared this vision on Lenny's Podcast.

## Key Information

- Michael Turalda, CEO of Cursor, discussed this vision of moving "beyond code" to a higher abstraction level
- The idea: developers work at the spec level, and AI writes the code
- Already emerging in practice: people use plan-driven development with Codex by collaborating on a plan.md file, then asking the agent to execute once the plan is approved
- Having verifiable steps in the plan makes the agent work for much longer periods
- Alexander Imbiricos is uncertain spec-driven development will fully work out because "a lot of people don't like writing specs either"
- He proposes an alternative: "chatter-driven development" where work emerges from team communication rather than formal specs
- Current state: mostly "prompt to patch" — the next evolution is plan-driven or spec-driven
- Not everyone will work this way; some may prefer conversational, chatter-driven approaches
