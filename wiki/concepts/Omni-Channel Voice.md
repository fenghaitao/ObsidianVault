## Definition
Omni-Channel Voice is the paradigm where adding voice to an agent unlocks multiple interaction channels simultaneously — web widgets, phone lines, video calls (Zoom), and other communication platforms. Voice is the key that makes an agent available across all these channels rather than being confined to a single text interface.

## Key Information
- Voice is inherently omni-channel: once an agent can speak and listen, it can participate in any audio-based channel
- Examples: customer support agents can add phone lines; analytics agents can join Zoom calls to correct wrong stats
- Voice Engine provides telephony and communication integrations out of the box once voice is added
- Contrasts with text-only chat agents that are confined to a web or app interface
- Makes agents accessible to users who prefer phone calls over text interfaces
