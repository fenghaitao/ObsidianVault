## Definition

Multi-Claudeing is the practice of running multiple Claude Code or Co-work agents in parallel. Boris Cherny typically has 5 agents running simultaneously, and the practice is supported across all Claude Code interfaces.

## Key Information

- Boris: "At the moment I have like five agents running. While we're recording this"
- Boris's morning routine: "I wake up and I start a bunch of agents"
- Also uses the Claude iOS app first thing in the morning to check code
- Co-work supports running "as many tasks as you want" in parallel
- Boris's workflow: "Start one task, I have this project management thing running. Then I'll have to do something else, then something else, and then I'll kick these off. And then I just go get a coffee while it runs"
- Works across all interfaces: terminal, desktop app, iOS, Android
- Boris's code is now split: ~1/3 terminal, ~1/3 desktop app, ~1/3 iOS app
