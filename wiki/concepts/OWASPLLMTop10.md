# OWASP LLM Top 10

## Definition

The OWASP LLM Top 10 is an updated list from the Open Web Application Security Project (OWASP) that identifies the top 10 security threats specific to large language model (LLM) applications, addressing new vulnerabilities that did not exist before the AI era.

## Key Information

- **Organization**: OWASP (Open Web Application Security Project)
- **Purpose**: Identify and raise awareness of LLM-specific application security threats
- **Context**: Referenced in the Auth0 agent identity talk to illustrate that AI agents bring new challenges and threats requiring new security solutions
- **Relevance to Agent Identity**: The new threat landscape motivates the need for robust agent identity, authorization, and fine-grained access control
