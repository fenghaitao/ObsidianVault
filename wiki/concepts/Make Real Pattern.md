## Definition
The Make Real Pattern is a design-to-code workflow where users draw UI mockups on a canvas, send the drawing to a vision model, and receive working code (typically HTML) as output. Users can then annotate on top of the output to iterate. It was one of the first AI patterns to enable non-technical people to create technical artifacts without coding.

## Key Information
- **Workflow**: Draw UI on canvas → send to vision model → receive working prototype → annotate on output → iterate
- **Annotation-based iteration**: Users draw on top of the generated output with instructions like "make this green," "use these colors" — the prompt includes both the old output and the new annotations
- **Historical significance**: One of the first AI projects to "break containment" in 2023, predating Lovable and the term "vibe coding"
- **Non-technical enablement**: Allowed non-technical people to create technical artifacts without coding or looking at code
- **Prompt construction**: The prompt is constructed from the canvas drawing, any existing output, and new annotations — a rich multimodal context
- **Seems "quaint" by 2026 standards** but was groundbreaking at the time
- **Precursor to modern tools**: Paved the way for Lovable, Replit Agent, and other design-to-code tools
- Built by Steve Ruiz at tldraw in 2023 when vision models first emerged
