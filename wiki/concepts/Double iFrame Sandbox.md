## Definition
The Double iFrame Sandbox is the default containment mechanism provided by MCP Apps for delivering third-party and generative UI. It uses a nested iframe structure to isolate UI code from the host environment, making MCP Apps the ideal distribution mechanism for generative UI where models create code on the fly.

## Key Information
- Default sandboxing mechanism for third-party UI delivery in MCP Apps
- Uses a double (nested) iframe structure for containment
- Part of what makes MCP Apps the best delivery mechanism for generative UI
- Provides boundaries and containment needed when running LLM-generated code
- Combined with MCP Apps features: authentication, tool calling, message passing between UI and agent
- Ruben Casas: "If we don't trust third-party code, we should not trust code generated by LLMs"
- Enables the generative components paradigm where models generate HTML/CSS/JS at runtime
- Not just for third-party UI — Anthropic uses it for first-party UI (Claude visualizer feature)
