## Definition
The Worker Loop is one of Chris Parsons' specialized Ralph loops. It continuously processes project files, picking up the next step on each project and executing it — writing emails, checking things, producing slides, or any other project task.

## Key Information
- One of Chris Parsons' production Ralph loops
- Uses a custom Kanban-style app that Parsons vibe-coded to manage projects as files
- Each project file contains: front matter, questions for the human, contacts, decision trail, notes, feedback from previous sessions
- The worker picks up the next step on each project and executes it
- Steps can include: writing emails, checking things, producing slides, preparing workshop materials
- Stops when it reaches an irreversible action or runs out of context, then reports back by updating the project file
- Parsons is working on improving the presentation/reporting step — moving from raw diffs to structured slide-format summaries
- Part of Parsons' "everything is a loop" philosophy applied to general knowledge work
