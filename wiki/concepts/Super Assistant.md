## Definition

The Super Assistant is OpenAI's product vision of a ubiquitous AI helper that works across all contexts — work and personal — proactively helping users without requiring them to constantly think about how to invoke AI. It uses code as its primary interface to interact with computers.

## Key Information

- The original internal name for ChatGPT was "super assistant"
- The vision: an AI that you "just talk to" and it "just knows how to be helpful on its own" — you don't need to read the latest tips for how to use it
- To be a super assistant, an AI must be able to "do things" — take actions in the user's world
- The key insight: models are much more effective at doing things when they can use a computer, and the best way for models to use computers is to write code
- This leads to the conclusion that "if you want to build any agent, maybe you should be building a coding agent"
- The super assistant should be "helpful by default" — helping thousands of times per day rather than the current tens of times
- Chat is a good interface when you don't know what you're supposed to use it for (like Slack/Teams with a teammate), but domain-specific GUIs are better for deep work
- The vision spans both B2C (ChatGPT) and B2B (Codex) contexts, converging into one super assistant
