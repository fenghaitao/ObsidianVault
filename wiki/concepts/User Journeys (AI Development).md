## Definition

User Journeys is the fourth PRD in Lazar's AI development documentation framework. It describes how users navigate through the app: registration, first steps, subsequent steps, and feature flows. It ties together the design and implementation plans from a user perspective.

## Key Information

- Fourth document in the PRD framework after Design Guidelines
- Contents: "When we know how things look and when we know how we're building it, how does the user journey look?"
- Example: "A user registers and then what? And then when they register and do that first step, what's the second step and what's the third step?"
- High-level navigation description: "Just very high level again, how do people navigate?"
- Feeds into tasks.md: "If you want these user journeys and you want the backend built first, here's a set of tasks."
- The final planning document before task-level execution
