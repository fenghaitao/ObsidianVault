## Definition
The mosaic effect is a security and privacy phenomenon where combining many individually innocuous pieces of information reveals a larger, potentially sensitive picture — the same cross-referencing that makes read-only AI systems useful also makes them devastating targets for attackers.

## Key Information
- Described by Šimon Podhajský as "what keeps me up at night" about read-only AI systems
- The same cross-referencing capability that makes Fulan useful makes it a high-value target
- "My own slide copy describes the security risk perfectly" — the feature is also the vulnerability
- Applies to any system that aggregates data from multiple sources
- Even without write access, a read-only system that aggregates data from email, journal, browser, CRM, and task manager creates a comprehensive picture of a person's life and cognition
- Mitigation requires careful security posture examination and acceptance of calculated risks
