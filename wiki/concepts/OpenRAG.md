## Definition
Open RAG is IBM's open-source enterprise RAG (Retrieval-Augmented Generation) project that deploys in private, data-sensitive environments. It features a strong harness providing enterprise-level security for performing RAG operations across diverse data types including teams, calls, PDFs, and invoices.

## Key Information
- Open-source project developed at IBM
- Designed for enterprise deployment in private, data-sensitive areas
- Performs RAG operations on: team data, call transcripts, PDFs, invoices, and other internal documents
- Features a "hell of a harness" that provides enterprise-level security
- Enables asking questions with internal, very siloed data while maintaining security boundaries
- Referenced by Tejas Kumar as a real-world example of harness engineering in practice
- Demonstrates how harnesses enable reliable AI in high-stakes enterprise contexts
