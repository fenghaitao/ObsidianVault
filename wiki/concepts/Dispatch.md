## Definition

Dispatch is a feature in [[ClaudeCowork]] (and now [[ClaudeCode]]) that lets a user assign Claude a task from their phone, continue the same conversation on desktop later, and pick up the finished work — a single continuous conversation spanning mobile and desktop.

## Key Information

- Launched in Claude Cowork approximately one week before 2026-03-23; extended to Claude Code by the time of this article.
- Workflow: assign a task on the phone, turn attention elsewhere, then open the finished work on the computer later.
- Enables recurring automation: e.g., automatically checking emails every morning, pulling metrics weekly, or spinning up a Claude Cowork/Claude Code session for a report or a pull request.
- Made substantially more useful by the addition of [[ComputerUse]] (2026-03-23): Claude can now act on the desktop autonomously while the user is away, e.g. building a morning briefing while the user commutes, making IDE changes/running tests/opening a PR, or keeping a personal project moving per the initial plan.
- Requires the desktop app to be enabled and running so it can be paired with the mobile app.
