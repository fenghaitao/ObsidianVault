## Definition
Skills Governance is the organizational practice of managing, versioning, sharing, and controlling AI agent skills across teams. Chris Parsons is exploring this as a product space with AirSkills, asking whether organizations would pay for centralized skills management.

## Key Information
- Emerging need as organizations adopt AI agent skills at scale
- Current challenges: skills are hard to version (GitHub repos per skill is heavyweight), hard to share (submodules, zip files, plugin marketplaces all inadequate), and hard to govern (who can change what, which version is canonical)
- Chris Parsons asked the workshop audience: "Would your org pay for skills governance?"
- AirSkills aims to solve this by packaging skills as manageable units with automatic versioning and updates
- Key questions: who can contribute to a skill? Are changes local or global? How do you manage a backlog of skill improvements?
- Parsons describes these as "big problems we haven't figured out yet"
