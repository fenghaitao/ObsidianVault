## Definition
A Developer Advocate bridges the gap between product teams and external developers. Outwardly, they ensure developers have everything needed to work with products (documentation, code samples, demos, skills, prompt guides). Inwardly, they advocate for developers by bringing real-world feedback and common sense to internal teams.

## Key Information
- **External function**: Create documentation, code samples, demos, skills, and prompt guides so developers can start using products immediately
- **Internal function**: Advocate for developers — bring "common sense to the internal teams" and ensure products make sense in the real world, not just "developed for Google by Google"
- **Example from Google DeepMind**: Fighting for API consistency across models (e.g., making model swapping work without changing code); the Imagen brand was eventually consolidated
- **Scope at DeepMind**: With new features shipping every 5 days across all of DeepMind, Developer Advocates are constantly busy documenting and communicating new capabilities
- **Key tension**: Balancing what internal teams want to ship with what external developers actually need
