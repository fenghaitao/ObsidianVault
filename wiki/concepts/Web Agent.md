## Definition

A web agent is a type of AI agent designed to autonomously operate and control web browsers to complete tasks in the same way a human user would — navigating pages, filling forms, clicking buttons, and extracting information. Web agents are benchmarked on suites like the Web Voyager Benchmark.

## Key Information

- Web agents operate the browser as their primary interface, interpreting web pages visually or through DOM structure to make decisions and take actions.
- Agent E from Emergence is currently the top-performing web agent on the Web Voyager Benchmark.
- Key capabilities include: form filling, reservation booking, data extraction, multi-step workflow automation, and cross-site navigation.
- Web agents are particularly valuable for enterprise RPA use cases where legacy systems lack APIs — the agent interacts through the UI just as a human operator would.
- Integration with orchestrator agents enables web agents to participate in broader multi-agent workflows, handling the web-facing portions of enterprise processes.
- Related to but distinct from AI browsers and computer use — web agents focus specifically on web browser automation rather than general desktop control.
