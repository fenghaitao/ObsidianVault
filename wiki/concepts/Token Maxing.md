## Definition
Token maxing is Vincent Koc's term for the 2025 approach to AI-assisted development: burning massive quantities of tokens in long-running agent loops with minimal structure or efficiency considerations. It is characterized by brute force — throwing tokens at problems and hoping the agent produces useful output. Vincent describes this as a necessary phase that built intuition through sheer volume, but argues 2026 requires a shift toward token efficiency.

## Key Information

- **Origin**: Vincent Koc's characterization of 2025-era agent usage patterns
- **Characteristics**: Running agents in long loops (8-9 hours), burning massive tokens, minimal opinionation or structure
- **Relationship to Ralph looping**: Token maxing is essentially Ralph looping at scale — "commit maxing... smash as many commits as we can"
- **Vincent's experience**: "The sheer volume of token maxing I've had to go through in the previous year" — this built his intuition for agent reasoning
- **Necessary phase**: Token maxing was how Vincent developed the ability to "feel the reasoning tokens" and detect when agents are bullshitting
- **2026 shift**: "2025 was about token maxing. 2026 is about not wasting them. It's about token efficiency. It's about agent in the loop."
- **Analogy**: Like the early Industrial Revolution — massive, inefficient production before process optimization
