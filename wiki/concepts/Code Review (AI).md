## Definition

AI Code Review is the practice of having AI review pull requests. At Anthropic, Claude reviews 100% of pull requests, with a human review layer still existing on top. This is a response to the bottleneck created by AI generating massive volumes of code.

## Key Information

- At Anthropic: "Claude reviews 100% of pull requests"
- "There's still a layer of human review after it, but you kind of like you still do want some of these checkpoints"
- Exception: pure prototype code that isn't going to run anywhere
- Code review became the bottleneck after AI solved code generation: "All these PRs, who's going to review them all?"
- Boris still looks at the code: "I don't think we're kind of at the point now where you can be totally hands-off"
- "You have to make sure that it's correct. You have to make sure it's safe"
- This is part of the broader shift where AI is starting to come up with ideas for what to build, not just execute
