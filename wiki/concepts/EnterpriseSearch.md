## Definition

Enterprise search is a Claude feature providing a dedicated, company-branded shared project that searches across all of an organization's connected data sources in a single conversation, rather than requiring users to query each connected tool separately.

## Key Information

- Personalized with the company's name; includes custom prompts to help Claude search effectively across the org's connected tools, plus simple setup for connecting essential work apps.
- Everyone in the organization gets automatic access to the project once an admin sets it up and connects the essential tools.
- Draws from the organization's collective knowledge, not just a single user's files — e.g., a question about remote-work policy can pull from HR documents in SharePoint, email discussions in Outlook, and team guidelines from other connected sources into one report.
- Particularly valuable for: onboarding new team members, answering strategic questions (e.g., analyzing patterns in customer feedback), and identifying the right internal experts to consult on a topic.
- Enabled for all Team and Enterprise organizations (as of October 2025); admins customize the project and curate data sources before teams can use it.
- Complements per-tool [[Integrations]] (like the [[Microsoft365Copilot|Microsoft 365 connector]]) by searching across all of them at once rather than one at a time.
