## Definition
XApps is the official SDK and repository for building MCP Apps. It provides built-in skills that allow coding agents to generate MCP Apps automatically, and is always kept compliant with the latest MCP Apps specification.

## Key Information
- Official MCP Apps SDK, maintained alongside the spec
- Always compliant with the latest MCP Apps specification — both updated together
- Includes built-in skills: developers can use coding agents to generate MCP Apps without writing code manually
- Recommended starting point for building MCP App servers
- Active community with issues, contributions, and discussions
- Part of the official MCP Apps ecosystem co-maintained with Anthropic and OpenAI
