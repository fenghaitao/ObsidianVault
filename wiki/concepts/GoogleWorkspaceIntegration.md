# Google Workspace Integration

Claude's **Google Workspace Integration** connects Claude to Google's productivity suite, enabling secure access to organizational context without manual file uploads or repeated context provision.

## Connected Services

Integration includes access to:

- **Gmail** — Email threads and content
- **Google Calendar** — Calendar commitments and schedules
- **Google Docs** — Document content and context

## Use Cases

With Google Workspace integration, Claude can:

- Pull together meeting notes from email threads
- Identify action items from follow-up emails
- Search relevant documents for additional context
- Review calendar commitments to understand scheduling constraints
- Deliver inline citations for verified source tracing

This eliminates hours of manual context gathering and allows users to focus on strategic planning.

## Security and Activation

- **Individual users**: Available in beta via profile settings (all paid plans)
- **Team/Enterprise admins**: Must enable Google Workspace access domain-wide before users connect accounts
- **Enterprise cataloging**: Enterprise admins can enable Google Docs cataloging for the entire organization

Data is kept within organizational control with enterprise-grade security.
