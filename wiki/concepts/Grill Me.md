## Definition
"Grill Me" is a viral AI skill created by Matt Pocock that makes the AI interview the user relentlessly about every aspect of a plan until a shared understanding (design concept) is reached. It turns the AI into an adversary that continually pings ideas to establish mutual comprehension before any code is written.

## Key Information
- Created by Matt Pocock, part of the macpocockskills GitHub repo (~13,000 stars)
- The prompt: "Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one by one."
- Can ask 40-100+ questions before being satisfied that shared understanding is reached
- Based on Frederick P. Brooks' "design concept" and "design tree" from The Design of Design
- The conversation generated can be turned into a product requirements document or directly into issues
- Pocock argues this is better than default plan modes in AI coding tools, which are "extremely eager to create an asset" rather than reach shared understanding first
- Works well in combination with the Ubiquitous Language skill
- Designed to be used before an AFK (away-from-keyboard) agent picks up the work
