## Definition

Agent Output Reading is the practice of reading what the AI agent says (its reasoning, plans, and explanations) rather than reading the code it generates. It's how non-technical vibe coders learn what's possible and how to steer the AI better.

## Key Information

- Core practice: "I religiously read the agent output, not the code output. The syntax is not of my interest. It's what the agent tells me that matters to me."
- The agent output teaches what's possible: "Agent makes me learn how to use it"
- Contrast with reading code: Lazar never reads code; he trusts the AI's syntax output but reads its reasoning
- How it works: when the agent says "I'm going to do X, Y, Z," that's where learning happens
- "The ceiling on the AI isn't the model intelligence. It's what the model sees before it acts."
- This is the layer that comes after code — English conversation as the interface
- Ben Tossel independently uses the same approach: learning how systems work by watching agent output
- Michael Terrell (Cursor CEO) envisions this as the future: agent conversation as the layer on top of code
