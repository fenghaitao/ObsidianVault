## Definition
Agent Proactivity is the capability of an AI agent to autonomously join conversations, suggest automatable workflows, and verify claims against data without being explicitly invoked. It enables the agent to surface its value by identifying opportunities for assistance rather than waiting to be asked.

## Key Information
- Described by Fryderyk Wiatrowski as one of Viktor's most powerful features
- **How it works**: Viktor monitors conversations in channels it has access to. When it detects an opportunity — e.g., a growth team discussing A/B test results — it can check the connected analytics tool (PostHog), verify claims, run calculations, and join the conversation with insights
- **Example**: Growth team discusses experiment results; Viktor checks PostHog and says "this is not statistically significant" with supporting calculations
- **Product benefit**: When Viktor proactively demonstrates value, it gets activated more broadly in the workspace — organic growth through demonstrated utility
- **Risk and rollout strategy**: If proactivity is enabled on day one, "the security team starts raging" because Viktor DMs everyone and joins threads without warning. Fryderyk recommends:
  - Start with a few users first to build trust
  - Earn the right to be proactive through demonstrated value
  - Roll out gradually to broader teams
- Proactivity is a key differentiator from reactive agents that only respond when prompted
- Relates to the broader vision of AI as a coworker rather than a tool — coworkers proactively help, tools wait to be used
