## Definition
Model customization is the process of adapting foundation models to specific use cases and datasets using techniques including prompt engineering, retrieval-augmented generation (RAG), and fine-tuning. It is a core competency for AI engineers.

## Key Information
- Three main approaches: prompt engineering, RAG, and fine-tuning
- The choice of technique depends on the use case requirements and available data
- Amazon Bedrock integrates tooling for all three customization approaches
- Customization is part of the AI prototyping workflow after defining the use case and choosing models
- Increasingly sophisticated techniques can be applied as use cases demand more specialization
