## Definition

Programming History is the arc of how programming has evolved: from rooms of people doing math on paper, to hardware, to switches, to punch cards, to software on virtual machines (~1960s to present), and now to AI. Boris uses this history to argue that programming has always been changing.

## Key Information

- Programming evolution: pen and paper → hardware → switches → punch cards → software on virtual machines → AI
- Software on virtual machines has been the dominant paradigm since ~1960s — about 60 years
- Boris's grandfather was one of the first programmers in the Soviet Union, programming with punch cards
- Boris: "He actually never saw the software transition. But at some point it did transition to software"
- There was likely an older generation of punch card programmers who "just didn't take software very seriously"
- Boris: "I think this is a field that just has always been changing in this way"
- In some ways, you still want to understand the layer under the layer — but "pretty soon it just won't really matter"
- Comparing to assembly code: it's "just going to be kind of like the assembly code right running under the program or something like this"
