## Definition
The Agentic Web is the evolving paradigm where AI agents mediate how users browse and consume web content, transforming the web from a collection of directly-visited websites into a set of services accessed through agent interfaces. RL Nabors writes a newsletter by this name and builds tools that embody this vision.

## Key Information
- RL Nabors writes The Agentic Web newsletter covering "how agents and AI are changing how we browse and consume content"
- The web isn't dying — it's evolving from direct human browsing to agent-mediated interaction
- Agents can access the same functions and links available in JavaScript directly from web pages (via WebMCP)
- This eliminates the need for compute-intensive approaches like screenshot-based navigation or DOM traversal
- Three-client architecture: humans in browsers, humans in agents, and agents in browsers using the web on behalf of humans
- Example: ASA (Anti-Social Social Agent) lets users interact with Twitter and BlueSky without visiting the sites or being subjected to algorithms
- The browser's existing APIs (Web Speech, Animation, Audio, Canvas, WASM) become the primitives for building agentic experiences
- CSS and JavaScript become "the language of interactive experiences on agents"
- MCP Apps enable a "new web" paradigm where personal assistants compose experiences from atomic UI chunks
