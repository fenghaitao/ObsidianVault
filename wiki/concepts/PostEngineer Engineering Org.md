## Definition
The Post-Engineer Engineering Org is an organizational model where AI coding agents handle the majority of implementation work, eliminating traditional Agile ceremonies (standups, sprint planning, retrospectives) and restructuring engineering teams around a spec-driven, autonomous development pipeline. Engineers shift from writing code to designing specs, reviewing agent-generated lightweight design documents, and ensuring product quality.

## Key Information
- **Origin**: Presented by [[MikeSpitz]] at [[aiDotEngineer]], based on a case study at [[PFF]] (January–March 2026)
- **Core Premise**: Engineers are no longer the bottleneck — AI agents write most of the code, so the organization must optimize for agent speed rather than human throughput
- **Eliminated Ceremonies**: Standups (replaced by auto-updating tickets), sprint planning (replaced by spec + LDD flow), sprint refinement (happens during spec phase), retrospectives (replaced by customer satisfaction surveys)
- **New Ceremonies**: Bi-daily 30–60 minute "huddles" with engineers, product, and design for instant feedback
- **Development Pipeline**: Spec → agent interviews stakeholders → agent generates [[Lightweight Design Document]] → engineer feedback → auto-create tickets → auto-create PRs → agentic code review → autonomous QA
- **Metrics**: 25x deployment frequency, 10x blended output (tickets + code complexity), 8.6/10 customer satisfaction (up from 7–7.5)
- **Key Enabler**: [[Composable Skills]] — engineering patterns encoded as reusable agent instructions
- **Human Responsibilities**: Security oversight, product feel/brand consistency, scale/complexity governance (enforced via the LDD), system design review
- **Adoption Strategy**: [[Slow Phased AI Adoption]] — start with best engineers, experiment in non-critical systems, then scale
- **Engineer Profile**: Curious, self-directed problem-solvers thrive; engineers needing highly prescriptive specs struggle
- **Competitive Dynamic**: Small companies have an adoption advantage; compounding delays mean being a few months behind today becomes 6–12 months behind quickly
