## Definition
Steering is Amazon Kiro's persistent memory and rules system (analogous to Cursor rules) that allows developers to encode preferences, conventions, and procedures that the agent follows consistently across sessions.

## Key Information
- Analogous to Cursor rules: persistent instructions the agent follows every time
- Examples: commit style (co-author attribution), code coverage minimums (90%), deployment procedures, code style preferences
- Can be generated by asking Kiro to "write what you learned into a steering doc" after going through a painful process
- In the demo, steering docs included: how to do commits, how to deploy to Agent Core, how to run CDK commands with specific parameters
- Kiro auto-generated an "Agent Core LangGraph workflow" steering doc from deployment learnings
- Steering influences all phases: requirements, design, and implementation
- Can encode trade-off preferences (latency vs. cost, etc.) that influence generated code
