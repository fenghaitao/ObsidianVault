## Definition

Agent as a Service is one of Malte Ubl's four agent archetypes. It refers to automating human agent roles (such as support or sales agents) so they can operate 24/7 instead of being limited to human working hours.

## Key Information

- Part of Malte Ubl's Agent Archetypes framework
- First generation of this archetype is already shipping via startups like CRMs and Decagon
- Key value proposition: agents don't need to sleep, enabling round-the-clock operation
- General question to identify opportunities: "Is there a job where it would be transformative if it went from 9-to-5 to 24/7?"
- Represents the most intuitive starting point for companies thinking about agent automation
