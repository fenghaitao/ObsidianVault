## Definition
Software 2.0 is a concept coined by Andrej Karpathy describing a paradigm shift from writing explicit algorithms (Software 1.0) to specifying objectives and constraints, then letting optimization/search processes find solutions that satisfy verification criteria.

## Key Information
- Originated from Karpathy's work on autonomous driving and neural network training
- Core idea: the frontier of what AI can solve is bounded by the ability to specify an objective and search through the solution space
- Software development is a prime domain for Software 2.0 because it is highly verifiable
- Connects to specification-driven development where developers define what should be built and how it should be validated, rather than how to build it
- Referenced by Eno Reyes as foundational context for why agent-ready codebases matter
- The shift from "automation via specification" to "automation via verification" is the key mindset change
