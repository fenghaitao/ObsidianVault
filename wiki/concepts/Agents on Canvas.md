## Definition
Agents on Canvas is a paradigm where AI agents are placed directly on a shared spatial canvas as visible, animated entities rather than hidden in a sidebar or chat interface. The canvas serves as both the workspace and the shared state, enabling agents to have spatial presence, visible thinking/action states, and awareness of each other's activities.

## Key Information
- **From sidebar to canvas**: The key insight is moving agents out of the sidebar/chat and onto the canvas itself, transforming them from keyboard-stealing tools into visible collaborators
- **Visible state**: Each agent shows its current state (thinking, acting, idle) through animations and visual cues, analogous to multiple terminal windows or composer panes in coding tools
- **Spatial awareness**: Agents have position on the canvas and can see where in the project they are acting relative to other agents
- **Mutual awareness**: Agents can see what other agents are doing, enabling implicit coordination without explicit communication
- **Direct manipulation**: Users can grab, move, and group agents on the canvas
- **Multi-agent visibility**: Multiple agents working simultaneously are all visible at once, unlike sidebar interfaces where only one agent is visible at a time
- **State persistence**: The canvas preserves agent state and output, making the collaboration history visible and persistent
- Pioneered by tldraw's Fairies project (fairies.tldraw.com), where agents appear as animated fairy sprites
- Represents a shift from chat-based agent interfaces to spatial, artifact-based collaboration
