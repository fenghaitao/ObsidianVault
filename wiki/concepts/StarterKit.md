## Definition

A starter kit (or build kit) is a distributable package containing the prompts, plans, PRDs, specs, and video guides needed to rebuild one of Brian Casel's internal tools. Builder Methods Pro members receive these kits to build their own customized versions of the tools.

## Key Information

- Contains: PRD/spec, tech stack decisions, design system configuration, ready-made prompts, milestone breakdown, and video walkthrough.
- Members can follow exactly or deviate and customize to their own needs.
- Brian has an agent skill for generating starter kits from his actual codebases — it analyzes the code, builds the PRD, extracts the design system, and creates prompts.
- Examples: [[SparkDrop]] (content pipeline), [[BrainDown]] (markdown editor), tasks dashboard (agent dispatch).
- Distribution model: included in Builder Methods Pro membership.
- Each starter kit tool also gets a public marketing page (built with Brian's app marketing page skill).
