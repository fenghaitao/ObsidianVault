## Definition

[[Benedict Evans]]'s argument that AI foundation models likely lack durable network effects or differentiation between them, and so — like mobile browsers or telecom data plans — risk becoming low-margin commodity infrastructure (an "AWS," not a "Windows"), with real value and pricing power accruing instead to the application/distribution layer.

## Key Information

- Framed as a rebuttal to arguments (including [[Sam Altman]]'s "selling AI like electricity" framing) that assume model labs will capture platform-owner-style economics.
- Windows-vs-AWS framing: Windows captured durable "up the stack" leverage over decades; AWS, despite being critical infrastructure, remains a comparatively commodity, margin-competitive utility business. Evans's open question is which pattern foundation models will follow.
- Historical analogy via [[Microsoft]]/[[Netscape]]: Microsoft won the 1990s browser war using distribution to force Internet Explorer adoption over Netscape, but Evans notes winning that specific war "didn't matter" in the end because value moved further up the stack anyway.
- [[Steven Sinofsky]] (former Microsoft Windows executive) is quoted: incumbents reflexively frame disruptive new technology as "just a feature" of their existing product — "sometimes they're right, sometimes it's a feature."
- If models commoditize, the practical consequence is that [[Distribution Moat|distribution]], not model quality, decides which AI products win adoption.
