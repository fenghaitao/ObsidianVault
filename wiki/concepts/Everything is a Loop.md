## Definition
"Everything is a Loop" is Chris Parsons' core thesis that most professional work follows loop cadences — coding, project management, CEO work, and personal productivity are all loops. Recognizing this allows AI agents to be applied to nearly any domain by encoding the loop as a skill.

## Key Information
- Core thesis of Chris Parsons' workshop on Ralph loops
- Coding loop: pick ticket → implement → review → merge → release → repeat
- Project management loop: review status → identify next priority → assign → track → repeat
- CEO loop: review metrics → identify strategic priority → decide → communicate → repeat
- Personal productivity loops: morning briefing, worker tasks, heartbeat check-ins
- Parsons runs multiple specialized loops: worker loop, morning loop, heartbeat loop, startup loop
- The implication: if everything is a loop, then Ralph loops (simple AI agent loops) can be applied universally
- This leads to the existential question: which loops should humans stay in, and which should be fully automated?
