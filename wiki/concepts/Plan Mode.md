## Definition

Plan Mode is a Claude Code feature that injects a single sentence into the model's prompt: "Please don't write any code yet." Boris Cherny uses it for ~80% of his tasks and recommends it as a top tip for getting the most out of Claude Code.

## Key Information

- Implementation is extremely simple: "All it is is we inject one sentence into the model's prompt to say, 'Please don't write any code yet.' That's it."
- Boris uses it for ~80% of his tasks
- In the terminal: shift+tab twice to enter plan mode
- In the desktop app: a button
- On web: a button
- Coming soon to mobile
- Recently launched for Slack integration
- The model goes back and forth with the user to refine the plan
- Once the plan is good, the user lets the model execute
- Boris auto-accepts edits after plan approval: "If the plan works good, it's just going to one-shot it. It'll get it right the first time almost every time with Opus 4.6"
- Boris recommends using plan mode then auto-accepting edits as a workflow
