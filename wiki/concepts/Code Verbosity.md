## Definition
Code verbosity refers to the total lines of code generated by an LLM to solve a given set of programming tasks. In Sonar's evaluation, verbosity emerged as a significant quality concern: newer and more capable models generate dramatically more code than earlier models for the same tasks, correlating with higher complexity and increased maintenance burden.

## Key Information
- **Measured trend**: GPT 4.0 generated ~250K LOC for 4,444+ Java assignments; GPT 5.2 High ~1M LOC; GPT 5.4 ~1.2M LOC — a 4-5x increase
- **Gemini 3.1 Pro High**: 307K LOC — relatively concise compared to peers
- **Claude Sonnet 4.6**: 627K LOC — moderate verbosity
- **Implications**: more code means more surface area for bugs, more to review, more to maintain, and often higher cyclomatic and cognitive complexity
- **Correlation with complexity**: models that generate more code tend to also score higher on cyclomatic and cognitive complexity metrics
- **Paradox**: models are getting "better" (higher benchmark scores) while generating more code that is harder to maintain
- **Enterprise concern**: verbosity directly impacts tech debt accumulation and long-term maintenance costs
