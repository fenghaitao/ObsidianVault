## Definition
Metadata Enrichment is the process of improving data documentation, context, and descriptions to make data more understandable and usable — both for LLMs in AI systems and for humans interacting with data catalogs. Good metadata significantly improves LLM performance on data-related tasks.

## Key Information
- Northwestern Mutual discovered that what constitutes "good metadata" differs between LLM consumption and human consumption
- The GenBI research produced insights that fed into a parallel semantic layer initiative at the company
- An A/B test demonstrated measurable value: running a battery of questions against databases with good vs. poor metadata showed significantly better LLM performance with enriched metadata
- This provided concrete evidence to senior leadership that investing in metadata documentation has tangible, measurable ROI
- Metadata enrichment learnings could be applied immediately across the enterprise data ecosystem, not just for GenBI
- Understanding how to extract metadata from information using LLMs also informed how to structure metadata for human data users
- Key enabler for GenBI systems: without good metadata, LLMs cannot accurately understand data context, schemas, or relationships
