## Definition

Static single assignment (SSA) form is a compiler intermediate representation in which each variable is assigned exactly once.

## Key Information

- Casey recounts a 1960s Tony Hoare note that "pretty much describes" SSA, abandoned after Peter Naur dismissed multipass compilers as easy.
- Casey speculates Naur's dismissal may have set compiler science back ~15-20 years.
