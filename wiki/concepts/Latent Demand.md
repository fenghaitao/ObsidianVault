## Definition

Latent demand is the product principle of building features based on what users are already trying to do with existing tools, even when those tools weren't designed for that purpose. Boris Cherny considers it "the single most important principle in product."

## Key Information

- **Traditional framing:** Look at what people are "abusing" existing products to do, then build a dedicated product for that. Examples:
  - Facebook Marketplace: 40% of posts in Facebook groups were buying/selling
  - Facebook Dating: 60% of profile views were opposite-gender non-friends
  - Claude Code (Co-work): People were using Claude Code (a terminal-based coding tool) for non-coding tasks like analyzing genomes, recovering wedding photos, analyzing MRIs, and growing tomato plants

- **Modern framing (AI era):** "Look at what the model is trying to do and make that a little bit easier." In research this is called "being on distribution." The model naturally wants to use tools, plan, and act — giving it minimal scaffolding lets it do what it's naturally trying to do.

- Boris: "When you see people abusing the product in this way, using it in a way that it wasn't designed in order to do something that is useful for them, it's just such a strong indicator that you should just build a product"

- Anthropic's data scientist Brendan using Claude Code for SQL analysis was the initial signal that led to Co-work
