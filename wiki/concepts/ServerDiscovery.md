## Definition
Server Discovery is an upcoming MCP specification that defines how MCP servers can be automatically discovered via well-known URLs on websites, enabling crawlers, browsers, and agents to find and use MCP servers without manual configuration.

## Key Information
- Specifies how servers can be discovered on well-known URLs automatically
- Crawlers, browsers, and agents can visit a website and discover: "instead of just parsing the website, is there also an MCP server I can use?"
- Enables automatic discovery without manual server registration or configuration
- Announced as coming in June 2026 with the next MCP specification launch
- Part of the MCP integration roadmap alongside cross-app access
- Represents a shift toward making MCP servers as discoverable as web APIs
