## Definition
An Agent Story is the agent-oriented analog of a user story: a description of what a programmatic autonomous agent with an objective and limited context window is trying to achieve, used to scope MCP tools.

## Key Information
- Introduced by Jeremiah Lowin as a new vocabulary for MCP server design
- Distinct from user stories because "user stories everyone thinks human even though it is a user"
- An agent story frames requirements around: a programmatic autonomous agent, with an objective, and a limited context window
- Maps to the "one tool equals one agent story" principle
- Forces product thinking: "We cannot put something in this server unless we know for a fact it's going to be useful and have a good outcome"
- Part of the shift from "operations" thinking to "outcomes" thinking
