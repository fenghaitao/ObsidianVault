## Definition
Prompt engineering is the practice of designing and optimizing text inputs (prompts) to elicit desired outputs from foundation models. It is one of the primary techniques for customizing model behavior without modifying model weights.

## Key Information
- One of three main model customization approaches alongside RAG and fine-tuning
- Used in agent development: instructions for agents are prompt engineering that explains how the agent should behave
- Demonstrated in Amazon Bedrock agents where custom instructions guide agent behavior (e.g., a Minecraft bot's gameplay instructions)
- Can be applied to system prompts, user messages, and tool/function descriptions
- Also used in AI developer tools — for example, Amazon Q Developer uses prompts internally to generate code and explanations
