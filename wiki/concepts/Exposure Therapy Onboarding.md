## Definition

[[Zevi Arnovitz]]'s recommended gradual path for non-technical people intimidated by code to become AI-assisted builders, likened explicitly to exposure therapy: start in pure conversation, and only slowly work up to looking directly at code.

## Key Information

- Sequence: (1) a [[ChatGPT]]/ChatGPT-project conversation — simple, no code visible, forces the user to converse and learn rather than immediately delegate; (2) a "vibe coding" builder like Bolt or [[Lovable]] — still eager to write code for you, opinionated UI, but the user starts seeing a working product; (3) [[Cursor]] in "light mode," gradually easing into actually looking at generated code; (4) eventually a full terminal, dark-mode setup, and direct code review — "go full dev."
- Explicit framing: "if you're nontechnical like me, code is terrifying. It's the scariest thing in the world to look at. And I look at it as kind of like exposure therapy" — the point of each stage is incremental desensitization, not maximum initial capability.
- Zevi frames his own graduation between tools as need-driven, not calendar-driven: he moved off Bolt specifically once he tried to add payments and the tool "started losing it," at which point Cursor's greater control became worth the loss of Bolt's guardrails.
- Distinguishes "opinionated" builders (Bolt, Lovable, Base 44, Replit, v0 — abstract away hard technical decisions, easy to start, low control) from full-control tools (Cursor + Claude Code — same underlying models, but the harness exposes every decision to the user) — the latter is only recommended once a builder has outgrown the former's guardrails, not as a starting point.
- Applied as general advice to any newly Meta-PM-interested or non-technical listener: "start slow with a GPT project... then maybe graduate to like a bolt or a lovable and then go to cursor."
