## Definition
An Agent Knowledge Base is a personal knowledge management system (e.g., Obsidian vault) integrated with a personal AI agent, enabling the agent to search, contextualize, and connect information across all of the user's notes, projects, tasks, and research. The agent uses this context to surface connections, draft informed responses, and proactively identify what matters.

## Key Information
- Radek Sienkiewicz's Obsidian vault has ~3,000 pages/notes covering work, personal, tasks, projects, research, articles, and an inbox of links
- The agent has search and memory access to the vault, including normal search and QMD search for Obsidian
- When Radek adds a link to his inbox, the agent: analyzes the content (tweet, thread, article, video), adds tags, adds context, checks existing vault content on the topic, and creates connections
- This transforms previously unused bookmarks into an actively growing knowledge base
- The agent surfaces forgotten connections: "you already had this and this about this subject, and this is how it connects"
- Radek realized his setup was sophisticated when he read Andrej Karpathy's viral tweet about LLM knowledge bases and thought "that's exactly what I have"
- The knowledge base is refreshed nightly (3-6 AM) along with QMD and memory indexes
- Enables attention filtering: the agent knows project backgrounds, deadlines, and priorities from the vault
