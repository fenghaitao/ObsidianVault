## Definition
Compare Mode is an AI Studio feature that enables head-to-head comparison of different Gemini models running the same prompt side by side, showing differences in speed, cost, and output quality.

## Key Information
- Available in AI Studio for comparing different Gemini models
- Shows token consumption and dollar cost for each model's response
- Demonstrated comparing Gemini 3.1 Flash Light vs Gemini 3 Flash Preview on image analysis with code execution
- Flash Light completed the task faster and at lower cost than Flash Preview
- Both models produced correct results at well under a fraction of a penny
- Can be combined with code execution and other tools for comprehensive comparisons
- Helps developers choose the right model for their cost/performance requirements
