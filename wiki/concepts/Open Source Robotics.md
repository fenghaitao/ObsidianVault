## Definition
Open Source Robotics is a movement to make robot hardware and software freely accessible, modifiable, and distributable. It aims to democratize robotics development by providing affordable, hackable, and repairable platforms that anyone can build upon, contrasting with the dominant model of expensive ($50K+), closed, company-targeted robots.

## Key Information
- Current commercial robots cost $50K+ and target companies, not individuals or schools
- Open source robotics enables prototyping at accessible price points ($300–450)
- Design philosophy: ship unassembled so users learn the full hardware stack and can repair anything
- Hackability is central — users 3D-print custom parts, add accessories, create new behaviors
- Open source applies to both hardware (schematics, assembly) and software (models, agents, apps)
- Voice AI integration is a key frontier — democratizing how humans interact with robots
- Vision: prevent robot interaction paradigms from being dominated by a single company
- Reachy Mini represents the fourth open-source robot from Hugging Face
- Compatible ecosystem: SO100/SO101 arms, Kiwi mobile base
- Enables creative, non-humanoid robot forms rather than constraining to human imitation
