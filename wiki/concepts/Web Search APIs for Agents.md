## Definition

Web search APIs (Brave, Exa, Perplexity) are programmatic search interfaces that AI agents can use as an alternative to browser-based web access. Instead of navigating a website and typing in a search bar, the agent sends an API request and receives search results and websites directly.

## Key Information

- **Brave:** Ships by default with OpenClaw. "Programmatic Google" — API-based search.
- **Exa:** Used by Claire Vo (she already had an account). Includes people search for professional biographies.
- **Perplexity:** Also usable as a web search API for agents.
- These are more reliable than browser-based web access because they bypass anti-bot mechanisms
- "It's just a way to give your OpenClaw access to the web when it doesn't have fingers and can't use a browser very well."

## Why It Matters

- Web search APIs are the most reliable way for agents to access web information
- They solve the browser use reliability problem for search-based tasks
- They're the first option in the workaround hierarchy: API → Browser → Walk Away
