## Definition

Co-work (Claude) is Anthropic's agentic AI product for non-coding tasks. It can use Chrome, Gmail, Slack, spreadsheets, and other tools to act on behalf of users. It was built in 10 days using Claude Code and is growing faster than Claude Code did in its early days.

## Key Information

- Built in 10 days using Claude Code itself by Felix, Sam, Jenny, and the team
- Born from latent demand: people were using Claude Code (a terminal coding tool) for non-coding tasks
- Ships with an entire virtual machine for security sandboxing
- Can use Chrome, Gmail, Slack, Google Docs, spreadsheets, and other tools
- Boris's personal uses: paid a parking ticket, canceled subscriptions, all project management, syncing spreadsheets with Slack messages
- Weekly routine: every Monday, Co-work messages each engineer on Slack who hasn't filled out their status
- Boris's recommended workflow: 1) Start by having it use a tool (clean desktop, summarize email, respond to top 3 emails), 2) Connect tools (e.g., look at emails and send Slack messages), 3) Run multiple tasks in parallel
- Lenny's 50 non-technical use cases post was used as an eval — Co-work could do 48/50 before release
- Called a "research preview" to emphasize safety testing
- Growing much faster than Claude Code did in early days
- Available in the Claude desktop app (Co-work tab, next to Code tab)
- Jenny Wen leads design for Co-work; she shifted all her chat use cases to Co-work
- Was NOT built in 10 days from scratch — there were many internal explorations and prototypes before the final 10-day build sprint
- The 10-day narrative went viral but Jenny clarifies it was the final sprint after extensive prototyping
- Jenny's favorite use case: introspection — analyzing personal notes, interview notes, and memos to extract insights
- Jenny used it to create a design craft evaluation rubric from her interview notes
- Features include: to-do lists, multiple choice questions, teaching users use cases
- The homepage is being iterated to feel like a shared to-do list between user and Claude
- Jenny describes it as "Claude with hands" or "Claude that's really good at taking all your garbage and turning it into something nice"
- Design explorations included: different form factors for to-do lists, multiple choice questions, teaching use cases
