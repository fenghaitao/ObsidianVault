## Definition
The planning-building cycle is the paradigm that planning and building are no longer separate sequential phases in software development but a continuous, intertwined cycle. In the agentic era, alignment must happen constantly alongside implementation rather than before it, because the implementation window has collapsed and teams can no longer afford to front-load all planning.

## Key Information
- Articulated by Maggie Appleton of GitHub Next
- Replaces the old three-phase model: planning → building → review
- In the old model, alignment touchpoints were distributed across all three phases
- With AI agents collapsing the implementation window, planning can no longer be a separate upfront phase
- Alignment must happen constantly alongside implementation — not before or after
- Tools of the future need to bring planning, context gathering, decision-making, and development under one roof
- ACE implements this cycle through collaborative plan editing within multiplayer sessions
- Teams discuss plans, refine them together, then tell the agent to execute — all in the same shared space
- The agent can read the entire conversation history as context for execution
- This cycle enables the human context (business, political, product, user research, organizational history) to be shared naturally during the work, not just before it
