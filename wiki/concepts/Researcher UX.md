## Definition
Researcher UX is the third "art" axis of [[Benchmarking Agents]]. It refers to the commitment benchmark builders make to the researcher and builder experience — making it easy to run models against the benchmark, contribute new tasks, extend it, and leverage evaluation signals for RL or fine-tuning.

## Key Information
- Severely underrated factor in benchmark adoption and impact
- Key dimensions: (1) easy to run models/agents against the benchmark, (2) easy to contribute new tasks and extend, (3) easy to leverage signals for RL or tuning
- Exemplars: [[Helm]] (Stanford CRFM) pioneered standardized modular harnesses for reproducible evaluation; [[HarborEval]] (shipped with Terminal Bench 2.0) became de facto evaluation infrastructure for agent builders
- Classic product principle applied to benchmarks: make it easy to use by core users (builders/researchers)
- Open source software has made this easier, but intentional design for UX is still critical
