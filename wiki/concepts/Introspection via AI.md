## Definition

Using AI tools like Claude Co-work to analyze one's own personal notes, memos, interview notes, and writings to extract insights about oneself. Jenny Wen uses this to discover implicit patterns in her own thinking and to create structured artifacts like evaluation rubrics from unstructured personal data.

## Key Information

- Jenny uses iA Writer for a folder of local notes spanning years: one-on-one notes, random thoughts, memos, interview notes
- She uses Claude Co-work to analyze this folder and extract insights
- Practical example: she fed Co-work all her interview notes and design craft notes, and it created a rubric for evaluating design craft in interviews
- "I wouldn't have realized these things about myself that I've been putting out there implicitly"
- Jenny calls this "introspection" — learning new things about herself through AI analysis
- Lenny describes it as: "read all these things I've written and help me understand how I feel about design"
