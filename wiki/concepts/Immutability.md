## Definition
Immutability is programming with values that do not change — the absence of mutation — captured by Haskell's shorthand "Immutability changes everything."

## Key Information
- Haskell "embodies one key idea": immutability changes everything; everything else in the language is incidental.
- Pat Helland: "programming with values changes everything about the way you think about programming… not necessarily better, but different."
- Functional programming is "programming with values instead of mutation"; imperative programming's mutable cells are how computation is classically done.
