# Asynchronous Agent Operation

## Definition

The mode of operating AI agents where they work independently on tasks without real-time human supervision. Poolside's agents currently operate asynchronously for hours at a time, with the expectation that this will extend to days in the near future.

## Key Information

- **Current Capability**: Agents running tasks for hours without human intervention
- **Future Trajectory**: Tasks spanning days in the near future, longer in coming years
- **Interface**: Currently demonstrated through VS Code with live diff views showing streaming changes
- **Workflow**: Agent performs work → returns summary → human reviews results
- **Evolution**: Part of the broader progression from synchronous chat to increasingly autonomous operation
