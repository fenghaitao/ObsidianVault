## Definition

AI memory features allow AI models to remember information about users across conversations for personalization. Simon Wilson turns these off because as an AI researcher he needs to "see what everyone else sees" — he can't accurately report on model capabilities if his results are influenced by personalization. He notes this is the stickiest feature AI labs are using to retain users.

## Key Information

- "The stickiest thing is meant to be memory. Like all of them have these features where they will remember things about you"
- Simon Wilson turns them off: "as an AI researcher, I need to see what everyone else sees when I'm prompting. I don't want to say to the world, 'Oh my goodness, look, this thing works now' and it turns out it only works for me because it's based on previous conversations"
- "Maybe I'm missing out on something really important there"
- Anthropic exploited this during the OpenAI military controversy: they created a Claude onboarding page with a prompt to extract ChatGPT memories and paste them into Claude
- "I thought that was hilarious. A whole export move from one to the other just by prompting it to give you the information you needed"
- This demonstrates how memory is both a competitive moat and a vulnerability (easily exportable with a prompt)
