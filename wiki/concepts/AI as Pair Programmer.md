## Definition
AI as Pair Programmer is the paradigm where an AI system acts as a collaborative coding partner that helps explore codebases, suggests implementations, and assists with code understanding — analogous to a human pair programmer who helps navigate unfamiliar code and brainstorm solutions.

## Key Information
- Articulated by Thomas Dohmke in describing GitHub Copilot Workspace: "it gives you a pair programmer that helps you to explore the codebase"
- Core challenge of software engineering: navigating unfamiliar codebases when joining a new project, contributing to open source, or returning from vacation
- The AI pair programmer helps answer "what is implemented where in your thousand-plus files" — the first challenge before any code change
- Unlike autonomous agents, the pair programmer keeps the human at the center — the human interacts, changes bullet points, and modifies code
- Enables non-developers (PMs, program managers) to explore what implementing a user story would mean in the codebase
- Differs from autonomous AI engineer: it is about collaboration and learning, not replacement
