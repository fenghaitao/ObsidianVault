## Definition

Knowledge Work as Code is the idea (from Thariq Shihipar) that most knowledge work is reducible to code, so a technical person can describe it as code-like steps and hand it to a coding agent rather than doing it manually.

## Key Information

- "Most of the knowledge work is reducible to code and coding agents if you think about it well."
- A technical person does knowledge work very differently from a non-technical person today, because they can decompose a task into code-like steps the model can execute.
- Personal examples: Thariq does accounting with scripts and Python instead of Excel, and video editing with FFmpeg and libraries that render visuals.
- This is one of the biggest under-appreciated practices: using Claude Code for knowledge work, not just for shipping software.
- Implication: being technical remains a major advantage — you know what can be turned into code and how to instruct the agent to do it.
- Connects to the broader thesis that "coding is solved" frees software to be applied to far more domains than before.
