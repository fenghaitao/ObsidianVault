## Definition

Engineer vs Coder is the distinction David J. Malan draws between someone who understands the underlying building blocks of a system and can create the next solution, versus someone who merely outputs working code — including code that AI can now produce.

## Key Information

- Malan argues CS50's goal is "not to output programmers, but engineers and educated citizens" who understand technology from first principles.
- A "coder" outputs something "frankly AI could output nowadays"; an "engineer" has mastery of the underlying building blocks and can create "the next thing or the solution to some other problem that we haven't even yet solved."
- The distinction rests on the knowledge and principles extracted from implementation details (C, Scratch), even for tools you won't directly use again.
- Malan frames the common objection — "you don't need to know how the computer works" — as "absolutely the wrong mindset" for a full-stack engineer, who by definition should understand all the layers.
