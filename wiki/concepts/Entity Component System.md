## Definition

Entity Component System (ECS) is a software architecture that models objects as entities composed of data-driven components, enabling operations across many objects by property.

## Key Information

- Casey argues Sketchpad already used an ECS-like architecture in the early 1960s to solve the "edit one property across many objects" problem.
- The OOP era instead derived hierarchies and encapsulation via Alan Kay's reading, losing the cross-cutting-property idea — Casey's "35-year mistake."
