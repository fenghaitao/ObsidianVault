## Definition
Self-Hosting for Agents is the practice of moving all personal data off cloud services onto locally-controlled infrastructure (NAS, local machines) specifically to give AI agents full access to work on that data. It represents a shift from cloud-dependent AI to locally-controlled AI with data ownership.

## Key Information
- Kitze went from "always using cloud and stuff to annoyingly self-hosting everything"
- "Everything has to come off the cloud. It has to be local on my NAS, on my machine, just so my agents can actually work on it."
- Specific moves: Nextcloud for images, local markdown for everything requiring API calls or MCP
- "I would rather just have it local to work on all of this locally"
- Motivation: "I got the power of finally owning the assistant, owning the files, owning the memory"
- Went "full hipster mode" — no more cloud models (Gemini, ChatGPT, Claude directly)
- Switched back to Android for full phone control by local agents
- Work in progress — "the classic work in progress that I'm going to finish one day"
