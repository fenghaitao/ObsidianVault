## Definition

Agentic engineering is the practice of professional software engineers using AI coding agents to write production-ready code that they review and verify. Coined by Simon Wilson, it contrasts with "vibe coding" (where you don't look at the code) and emphasizes that getting good results from AI agents is a deep, complex discipline that requires years of engineering experience.

## Key Information

- Coined by Simon Wilson to distinguish professional AI-assisted coding from "vibe coding"
- "The art of getting really good results out of this... is never going to be easy. That's never going to be trivial. That's always going to require a great deal of depth of experience in what software how software works and how how these agents work"
- Key patterns Simon identifies:
  1. **Red/Green TDD**: Write tests first, watch them fail, implement, watch them pass
  2. **Hoarding Things You Know How to Do**: Build a backlog of solved problems and tools in public GitHub repos
  3. **Start with a Good Template**: A thin skeleton with one test and preferred formatting is better than lengthy instructions
- "Coding agents... if you describe that code well enough, it'll follow the instructions and it'll build the thing that I asked it to build"
- The goal: "I don't just want to build software that's good. I want us to build software that is better than we were building before"
- ~95% of Simon's code is now AI-generated; he writes much of it from his phone
- Simon is writing a "not a book" about agentic engineering patterns, publishing chapter by chapter on his blog
