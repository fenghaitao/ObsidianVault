## Definition
Developer Flow is the state of uninterrupted focus where developers remain in their editor writing code, rather than being constantly distracted by context-switching to browsers, search engines, or documentation. Keeping developers in the flow is a core value proposition of AI coding assistants.

## Key Information
- Articulated by Thomas Dohmke as the core feature of GitHub Copilot: keeping developers "in the flow" rather than in "constant distraction between the editor and the browser"
- Traditional development involves frequent context-switching: editor → browser → Google/Stack Overflow/GitHub → copy-paste → editor
- Even the best developers write a lot of code before getting stuck; novices get stuck more often
- Copilot's ghost-text auto-completion preserves flow by providing suggestions inline without requiring the developer to leave the editor
- Flow preservation is more important than perfect accuracy — developers already adjust auto-completions in other tools (Google Docs, email)
- The chat sidebar and Copilot Workspace extend flow preservation to higher-level tasks beyond line completion
