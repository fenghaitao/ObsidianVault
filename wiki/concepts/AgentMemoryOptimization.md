## Definition
Agent Memory Optimization is the active practice of managing and refining an AI agent's memory configuration to prevent compounding degradation as the knowledge base grows. It involves evolving from a single memory file to a memory folder, using dreaming for memory promotion, maintaining critical rules, and regularly cleaning noisy nodes.

## Key Information
- Radek Sienkiewicz warns: "bad memory compounds" — if memory isn't set up correctly and your vault/notes/memories grow to thousands, you'll have issues
- Evolution path: started with one memory file → moved to a memory folder → now uses dreaming for memory promotion
- Dreaming: a feature that reconciles memories from session logs, promotes important ones to long-term storage, and drops irrelevant ones
- Critical rules MD: a separate file for non-negotiable behaviors, mentioned high in the agent configuration to prevent forgetting
- Noisy nodes: knowledge entries that add noise rather than value — need regular cleaning
- Weak boundaries: insufficient guardrails in agent configuration files (soul.md, agent.md) — need active optimization
- Key principle: "everything is inspectable" in OpenClaw — files are plain text, editable, readable, understandable
- Memory optimization is an ongoing process, not a one-time setup
