## Definition

GitHub Integration is a native feature of [[ClaudeEnterprise]] that allows organizations to sync GitHub repositories with Claude, enabling AI-assisted work on entire codebases.

## Capabilities

- **Repository Sync** — Native synchronization of GitHub repositories with Claude.
- **Codebase Collaboration** — Work alongside codebases within Claude's interface.
- **Engineering Workflows** — Support for feature iteration, debugging, and new engineer onboarding.
- **Scale** — Enabled by expanded 500K [[ContextWindow]] to handle medium-sized and larger codebases.

## Status

- Currently in beta for early [[ClaudeEnterprise]] users (as of September 2024).
- Planned for broader availability later in 2024.

## Future

GitHub is the first of planned native integrations designed to connect [[ClaudeEnterprise]] to organizations' most important data sources, enabling more relevant and insightful assistance.
