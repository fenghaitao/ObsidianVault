## Definition

The TI-83 Plus is the graphing calculator Boris Cherny used for his first programming experience: cheating on math tests by programming answers into the calculator. When tests got harder, he wrote a solver program and distributed it to his class via cable.

## Key Information

- Boris's first programming experience: "I learned to code so that I can cheat on a math test"
- First approach: programmed answers directly into the TI-83 Plus
- When tests got harder: "I couldn't program all the answers in cuz I didn't know what the questions were. And so I had to write like a little solver"
- Distributed the program to the class via a cable: "Then I figured out you can get a little cable, you can give the program to the rest of the class, and then the whole class gets A's"
- Got caught: "But then we all got caught and the teacher told us to knock it off"
- Boris's story: "From the very beginning, it's always just been very practical for me where programming is a way to build a thing"
