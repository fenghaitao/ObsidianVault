## Definition

Project Execution is the approach to building software projects, particularly in time-constrained environments like hackathons. Jia Chen advocates for connecting frontend and backend as early as possible and iterating on the connected system.

## Key Information

- The common mistake: dividing the team into frontend and backend, each building independently, and never fully integrating at the end
- Jia's approach: within the first few hours, connect frontend and backend together in the simplest way possible, then iterate on that foundation
- This means verifying websocket streaming, checking connections, setting up ports — all early in the process
- The goal is to have a fully connected frontend and backend that works end-to-end, even if the backend is minimal
- For the highest chance of winning, having an actually working project is better than faking the backend, because it allows deeper exploration once connected
- Jia's favorite project (VR hologram with Whisper AI transcription) was built in 9 hours with this approach, allowing the team to sleep
