## Definition
The DevX feedback loop is a self-reinforcing cycle where better AI coding agents improve the development environment (validation, documentation, tooling), which in turn makes agents more effective, freeing time to further improve the environment.

## Key Information
- Described by Eno Reyes as the "new DevX loop" that organizations should invest in
- Cycle: better agents → improve environment → better agents → more time to improve environment
- Benefits all AI tools uniformly (code review, coding agents, documentation generators), not just any single product
- Shifts the mental model of engineering investment from headcount (opex) to environment quality
- One opinionated engineer can meaningfully change the velocity of the entire business through this loop
- Contrasts with traditional DevX which focuses on human developer tooling and workflows
- The more opinionated the validation gets, the faster the cycle accelerates
