## Definition

Auto Memory is a Claude Code feature where Claude maintains its own memory file, learning from course-corrections and re-prompts over time. Unlike CLAUDE.md (human-managed), auto memory is fully managed by Claude itself, reducing the need to repeat the same corrections across sessions.

## Key Information

- Claude-managed, not human-managed — distinct from CLAUDE.md.
- Learns from every course-correction: when you re-prompt or ask Claude to fix something, it records the lesson.
- Reduces instances of repeating the same mistakes across sessions.
- Benefits accumulate over time — you feel it through fewer corrections, not a visible feature.
- Complements CLAUDE.md: humans engineer rules and skills; auto memory handles learned patterns.
