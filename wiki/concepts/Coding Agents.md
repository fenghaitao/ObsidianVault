## Definition

Coding agents are AI systems that not only generate code but also run it, debug it, test it, and iterate — taking the step that traditional code generation tools (like ChatGPT) didn't. They represent the shift from AI as a code-writing assistant to AI as an autonomous software development agent. Simon Wilson emphasizes that this is the key differentiator from earlier AI coding tools.

## Key Information

- "It used to be you'd ask ChatGPT for some code and it would spit out some code, and you have to run it and test it. The coding agents, they take that step for you"
- Claude Code and OpenAI Codex are the primary coding agents
- "If you ask ChatGPT to knock out some code, that's a different thing from if you're running Codex and having it write the code, debug the code, test the code, all of that"
- Coding agents can run in YOLO mode (no permission prompts), enabling parallel execution of multiple agents
- "An open question for me is how many other knowledge work fields are actually prone to these agent loops"
- Code is the easiest domain for agents because "code is obviously right or wrong. It produces code, you run the code, either it works or it doesn't"
- The agents are now good enough that "you can tell them, 'Oh, no, rename that variable and refactor that and add this line there.' And they'll just do it. And it's faster than you typing on the keyboard yourself"
- Simon: "Today, probably 95% of the code that I produce, I didn't type it myself"
