## Definition
Agent Workspaces are shared collaboration spaces in AgentCraft where multiple humans (e.g., product designer and engineer) can see each other's agents, hand off work between humans and agents, and collaborate in real-time — enabling both human-to-human and human-to-agent collaboration in a single environment.

## Key Information
- **Cross-human visibility**: Each human can see the other's agents and what they're working on
- **Work handoff**: A product designer's agent can design a page, then the engineer's agents can pick up from where they left off
- **Cross-agent prompting**: Humans can prompt not just their own agents but also other humans' agents in the shared workspace
- **Soft collaboration via chat**: A shared chat between humans and agents where agents announce what they're working on and humans can coordinate
- **Agent file awareness**: Agents know what files each participant is changing, enabling implicit coordination
- **Real-time collaboration**: Changes from one participant's agents are visible to others in real-time
- Represents the highest level of AgentCraft's collaboration model: moving beyond single-human-with-agents to teams-of-humans-with-agents
- Ido Salomon's "favorite feature" — addresses the reality that agents aren't smart enough yet, so humans need to collaborate with each other too
