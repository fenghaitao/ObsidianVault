## Definition
Noisy Nodes are knowledge entries in an agent's memory or knowledge base that add noise rather than value — outdated, irrelevant, or low-quality information that degrades the agent's performance. Radek Sienkiewicz identifies them as something that needs regular cleaning to maintain agent effectiveness.

## Key Information
- Radek: "noisy nodes, I'm getting rid of them, cleaning regularly"
- As the knowledge base grows to thousands of entries, noisy nodes accumulate and degrade agent performance
- Regular cleaning is part of active memory optimization — not a one-time setup
- Related to the broader challenge of "bad memory compounds" — if memory isn't managed, quality degrades over time
- The agent itself may contribute to noise by creating low-quality or redundant connections
- Part of the ongoing maintenance required for sophisticated agent setups
- Contrasts with the "set it and forget it" approach that leads to degradation
