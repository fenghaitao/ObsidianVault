## Definition
The Theory of Constraints (Eli Goldratt) states that any system's throughput is limited by its single biggest bottleneck. Applied to AI-assisted engineering: an hour saved on a non-bottleneck activity is worthless; AI should target the actual SDLC bottlenecks.

## Key Information
- Originated by Eli Goldratt
- Core principle: "An hour saved on something that isn't the bottleneck is worthless"
- In software engineering, writing code has never been the bottleneck for most organizations
- Data from ~140,000 engineers shows that AI time savings are eclipsed by context switching, interruptions, and meeting-heavy days
- AI integration should target actual bottlenecks: legacy code understanding (Morgan Stanley), onboarding (Zapier), incident response (Spotify)
- The approach: find the bottleneck, fix the bottleneck, then find the next one
