## Definition
The Principle of Maximum Heterogeneity is a mathematical formalization by [[Callosum]] proving that heterogeneous multi-agent systems outperform homogeneous ones under any reasonable constraints. It draws on evidence from neuroscience, economics, and ecology to demonstrate that diversity in agent skill distributions, combined with communication topologies, produces production functions that better match diverse demand functions.

## Key Information
- Heterogeneous agents have different skill distributions (color-coded in visualizations) over a skill space
- Communication topologies (e.g., ring topology) between agents create a **production function**
- A given production function may be well-suited for demand A but ill-suited for demand B
- Homogeneous approaches can only: (1) scale a single peak (specialist matching one demand), or (2) produce a broad-but-shallow cylinder (generalist matching none well)
- Heterogeneous systems can match complex, multi-peaked demand functions
- Validated across domains: neuroscience, economics, ecology
- Formalized mathematically with constraints — under any reasonable constraints, heterogeneous systems outperform homogeneous ones
