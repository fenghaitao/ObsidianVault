## Definition

An analyst agent is an AI agent built at LinkedIn that is trained to query the entire LinkedIn graph, enabling builders to get data insights without writing SQL queries or relying on data science teams.

## Key Information

- Trained on how to query LinkedIn's enormous internal graph.
- Allows builders to get data insights directly, bypassing the need for SQL queries or data science team requests.
- Part of the suite of agents designed to automate the mechanical aspects of the product development lifecycle.
- Contributes to the hours-per-week time savings reported by PMs, designers, and engineers using the tools.
- Cannot be purchased off-the-shelf; requires deep integration with LinkedIn's proprietary data graph.
