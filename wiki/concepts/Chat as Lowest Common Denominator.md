## Definition
Chat as Lowest Common Denominator is RL Nabors's critique that blank chatbox interfaces represent the most minimal possible agent user experience, putting all discovery and cognitive burden on the user. She argues this is a transitional phase, analogous to how CLIs preceded GUIs, and that MCP Apps and richer agent interfaces are the path forward.

## Key Information
- Chat is described as "the lowest common denominator of the user experience"
- Chat is to the future of agentic experiences what the CLI was to software — a transitional interface
- The "starfish design" or "chatbox landing page": a blank input that sits there and lets the user do all the work
- Users must have significant context in their head when landing on a blank chat — they need to know what the system can do
- Works well for users already familiar with a system (e.g., knowing Linear is a ticketing system) but challenging for discovery
- Analogized to text adventure games: "It's sort of like these text games were really popular back in the day, but I wouldn't want to have to do my taxes by being like, check mailbox. Is there mail? Whose house is this?"
- Asks the customer to do too much discovery — no visual cues or guidance
- MCP Apps are the solution: rich media experiences that provide visual context and interactivity within agent conversations
- Historical analogy: programmers insisted on CLI (DOS, cd, .exe) while the world moved to double-clicking icons — agent interfaces will similarly evolve beyond pure text
