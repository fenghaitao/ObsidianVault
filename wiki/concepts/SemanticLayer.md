## Definition
A Semantic Layer is an abstraction layer that models and enriches data metadata to make it more understandable and usable for humans interacting with data catalogs and BI tools. It translates technical data structures into business-meaningful concepts.

## Key Information
- Northwestern Mutual runs a semantic layer initiative in parallel with the GenBI research project
- The GenBI team's learnings about what good metadata looks like for LLMs provided valuable input to the semantic layer initiative
- An A/B test comparing LLM performance with good vs. poor metadata proved the tangible value of metadata enrichment to senior leadership
- The semantic layer benefits from metadata enrichment research even if the full GenBI agent is never completed
- Represents a cross-pollination between AI research and traditional data engineering at Northwestern Mutual
- Good metadata for LLMs (machine-consumable context) differs from good metadata for humans (business-meaningful descriptions), but insights flow both ways
