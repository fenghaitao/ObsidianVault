## Definition
Semi-Sync Value of Depth is a framework developed by swyx that advocates keeping human attention and synchronous collaboration ("mind meld with the machine") focused on the hardest problems, while commoditized and routine work is handled asynchronously by AI.

## Key Information
- Developed by swyx as a way to fight code slop
- Core principle: keep human attention on the hardest problems where synchronous human-AI collaboration adds the most value
- Commoditized, routine work should be made async and delegated to AI
- Referenced by multiple people at the AI Engineer Summit
- Complements Greg Brockman's modularity principle: humans design the boundaries (hard problems), AI fills in between (commoditized work)
- Part of a broader set of tools swyx advocates for fighting slop, alongside Code Maps, computer use, and sub-agents
