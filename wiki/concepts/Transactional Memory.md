## Definition
Transactional memory refers to an enterprise's systems of record — ERP, CRM, SOPs, and other structured institutional knowledge — that form the baseline of organizational capability. It is characterized as a "floor, not a fortress" because every competitor has a version of these same systems.

## Key Information
- Coined by Jess Grogan-Avignon and Jack Wang of Accenture as the counterpart to living memory
- Includes ERP (Enterprise Resource Planning), CRM (Customer Relationship Management), SOPs (Standard Operating Procedures)
- These systems get you to the table — they are necessary but not sufficient for competitive advantage
- Every competitor has one version of transactional memory — it cannot be a defensible moat
- In an AI-recursive world where anything can be cloned, transactional memory provides no lasting protection
- The shift required: from relying on what you hold from yesterday to focusing on what you are learning and compounding every day
- Transactional memory is what you know; living memory is what you uniquely learn from customer interactions
