## Definition
Doubling Engineering Throughput (also called "2x") is Intercom's initiative to double the output of their engineering organization in one year through comprehensive AI adoption. It measures productivity as code changes per R&D person and was achieved in under a year by consolidating on Claude Code, building a skills flywheel, and driving organizational change.

## Key Information
- Goal set mid-2024: double engineering throughput in one year without doubling team size
- Primary metric: code changes per R&D person (acknowledged as imperfect per Goodhart's Law)
- Achieved faster than the one-year target
- Wild inflection point after consolidating on Claude Code in December 2024, rolling out January 2025
- PR throughput from Claude Code now exceeds 90%
- Code review became the new bottleneck, addressed with automated approval (17.6% auto-approval rate)
- Defects being closed faster than ever; some teams pursuing "backlog zero"
- Code quality independently confirmed as increasing by Stanford research group
- Described as "wildly ambitious" but also "wildly unambitious" given model capability trajectories
- Staffed full-time with a dedicated, growing team
- Required decisive executive guidance: updated job descriptions making AI adoption binary (adopt or not meeting expectations)
- Celebrated and rewarded AI adoption wins to drive cultural change
- Recognizes that AI adoption is unevenly distributed across the organization
