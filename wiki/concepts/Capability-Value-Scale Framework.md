## Definition

The Capability → Value → Scale framework, from John Cuddler, describes the three stages of technology adoption: first, users explore what is possible (Capabilities); then they figure out how to get value from it (Value); finally, they determine which aspects of life and work it can scale into (Scale).

## Key Information

- Created by John Cuddler
- Three stages: Capabilities (what is possible to create) → Value (how do I get value out of this) → Scale (which aspects of my life/work can this scale into)
- Elena Verna says this framework is "completely stuck in my mind"
- Vibe coding is currently in the Capabilities stage: everyone is exploring what can be built
- What's unique about the current AI era: what you can do changes every 1-3 months, so users constantly need to come back and see what has changed
- This explains why retention through constant shipping works: users return to discover new capabilities
