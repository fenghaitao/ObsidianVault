## Definition
A Golden Dataset is a reference set of input-output pairs representing the "correct" answers for an AI task, used as ground truth for evaluating agent performance. It is the foundation of deterministic evals and prompt optimization.

## Key Information
- Serves as the ground truth against which agent outputs are compared in evals
- Enables deterministic custom evaluators, which are far better than LLM-as-judge
- **Creation challenges**: Golden datasets are hard to create and rarely 100% perfect. Colvin's MP relations dataset was generated by Opus 4.6 and manually checked, but still contains edge case errors
- **Coverage requirements**: Need at least 2x the data to cover the full problem space — one set for training/optimization and one for evaluation
- **Overfitting risk**: Small golden datasets can cause optimizers to overfit to patterns not representative of the full problem (e.g., excluding uncles/aunts because they weren't in training cases)
- **Sources**: Can be bootstrapped from human annotations, generated by powerful models (then verified), or collected from user feedback (thumbs up/down, implicit signals)
- **Implicit feedback**: The best source of golden data is what users do next — "no, I mean X" is strong negative signal; "thanks" or leaving is positive
- **Privacy considerations**: For sensitive domains (legal, medical), categorical performance labels can be exfiltrated without exposing raw data
