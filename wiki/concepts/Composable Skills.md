## Definition
Composable Skills are small, reusable agent instructions that encode specific engineering workflow patterns (e.g., feature flag creation, API scaffolding with the service repository pattern, branch naming conventions). They are composed together like factory assembly line stations to form a complete autonomous development pipeline.

## Key Information
- **Origin**: Presented by [[MikeSpitz]] as the core mechanism for building the [[Post-Engineer Engineering Org]] at [[PFF]]
- **Factory Analogy**: Like a car factory where one station builds doors and another fits steering wheels, each composable skill handles one specific engineering workflow step
- **Examples at PFF**: Branch naming, feature flag creation (for trunk-based development), API scaffolding (service repository pattern), LDD generation
- **Composition**: Skills chain together to form the full pipeline: spec skill → LDD skill → ticket creation skill → PR generation skill → code review skill → QA skill
- **Consistency Guarantee**: Skills analyze past outputs to maintain consistency with the engineering org's style and ethos — preventing generic "cloud code" feel
- **Warning**: Avoid consuming other people's skills if they have strong software opinions that conflict with your org's patterns — mismatched skills cause issues
- **Implementation**: Skills are loaded as specialized agent instructions on demand
- **Scope**: Currently covers everything from spec through PR at PFF; QA is automated; self-healing fix PRs are the next addition
