## Definition

Maximum Effort Mode is a Claude Code setting that Boris Cherny always has enabled. It uses the most capable model configuration for all tasks, reflecting the principle that the best model is actually the most cost-effective.

## Key Information

- Boris: "I have maximum effort enabled always"
- Always used with Opus 4.6, the most capable model
- Reflects the Token Economics principle: the most capable model is cheaper overall
- Part of Boris's top tips for Claude Code: "Use the most capable model"
