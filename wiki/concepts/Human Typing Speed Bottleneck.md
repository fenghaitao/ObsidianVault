## Definition

The human typing speed bottleneck is Alexander Imbiricos's thesis that the current underappreciated limiting factor for AI productivity is not compute or model intelligence, but the speed at which humans can type prompts and review AI-generated output.

## Key Information

- Alexander Imbiricos: "The current underappreciated limiting factor is literally human typing speed or human multitasking speed"
- Users currently prompt AI tens of times per day, but could benefit from it thousands of times per day
- The bottleneck appears in two forms: (1) humans must think about when and how to prompt AI, and (2) humans must review and validate all AI output
- The review bottleneck is especially acute for coding agents: writing code is fun, but reviewing AI-written code is not
- This is why making code review easier and more fun is a key focus for the Codex team
- The solution involves building agents that can validate their own work and are proactive (helpful by default), reducing the need for human prompting and review
- This bottleneck is not binary — it will be resolved at different rates for different contexts (startups on modern stacks vs large enterprises on legacy systems)
