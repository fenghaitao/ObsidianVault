## Definition

Agent-oriented programming is a programming paradigm focused on composing, coordinating, and stitching together multiple AI agents to solve complex workflows. It treats agents as first-class programmable entities that can be orchestrated, composed, and made to collaborate in structured ways.

## Key Information

- Positioned by Dr. Satya Nitta as a key R&D direction at Emergence for "how agents should be stitched together in really interesting ways."
- Goes beyond simple agent orchestration — it implies a programming model where agent composition is as fundamental as object composition in object-oriented programming.
- Emergence's orchestrator agent and Agent E integration demonstrate agent-oriented programming in practice: stitching together web automation agents with orchestration agents for enterprise workflows.
- The paradigm addresses the challenge of building complex multi-agent systems where agents must coordinate, share context, and handle dependencies.
- Applied in the context of enterprise workflows like RPA, document processing, and claims processing.
- Complements self-improving agents — as agents improve individually, their compositions can also improve.
