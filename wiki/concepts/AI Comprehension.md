## Definition
AI Comprehension refers to using AI tools primarily for understanding existing codebases, architecture, conventions, and history — rather than for generating new code. Priscila Andre de Oliveira's analysis of her own AI usage revealed that 67% of her prompts were comprehension-focused, while only 2% were code generation.

## Key Information
- Priscila Andre de Oliveira analyzed 116 AI sessions and found 67% were comprehension, 2% were code generation
- Comprehension categories include: understanding architecture, conventions, feature traces, syntax, testing patterns, and code history
- This finding challenges the common assumption that AI's primary value for developers is code generation
- Comprehension includes: asking about why a product decision was made, tracking down regressions via git blame, understanding how a system works, reviewing PRs with full context
- "AI is the teammate who never gets tired of your questions. There are no dumb questions."
- Comprehension is a critical but often overlooked step in AI-assisted development workflows
- Without comprehension, developers risk shipping code they don't understand into production systems
