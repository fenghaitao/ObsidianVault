## Definition
Image Search Grounding is a reverse image search tool available for Nano Banana 2 in AI Studio that grounds image generation by pulling in visually similar reference images to improve alignment with the user's prompt.

## Key Information
- Available for Nano Banana 2 in AI Studio
- Performs reverse image search to find visually similar reference images
- Helps the model generate images more tightly aligned with user prompts
- Demonstrated generating a dog in a natural park holding a Celsius can by combining reference images with search grounding
- Works alongside sample media uploads for composite image generation
- Part of the generative media toolset in AI Studio
