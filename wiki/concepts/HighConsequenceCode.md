# High Consequence Code

## Definition

Software code that runs in environments where errors have severe real-world consequences, such as defense systems, government critical infrastructure, and other mission-critical applications. Poolside has focused on these environments for the past year, requiring strict agent permission controls.

## Key Information

- **Domains**: Defense sector, government agencies, critical infrastructure
- **Programming Languages**: ADA (used by government for critical infrastructure)
- **Key Constraint**: Agents cannot have unrestricted access; they need proper permissions and must be "ratcheted down"
- **Poolside's Approach**: Built permission controls and guardrails specifically for these environments
- **User Base**: Three-letter agencies, defense contractors, missile systems operators
