## Definition

Academic integrity is the expectation that students complete work honestly. David J. Malan describes how AI tools (ChatGPT, Copilot, etc.) make cheating easier to do and harder to prosecute, and how CS50 draws a "clean line in the sand."

## Key Information

- Off-the-shelf AI "can pretty much do your homework"; typing `#include` in a `mario.c` file in VS Code used to auto-complete the whole problem set via Copilot.
- CS50's policy: ChatGPT, Gemini, and Copilot are disallowed for assignments; cs50.ai (the "rubber duck") is allowed and is a deliberately less-helpful, syllabus-tuned tutor.
- Crossing the line — "pulling up chat.openai.com or gemini.google.com" — is "a conscious choice to be academically dishonest."
- CS50 historically disciplines 5–10% of the class each semester (an upper bound shared by peer institutions).
- Detections haven't risen, but prosecution is harder: there is no single "smoking gun" URL, since AI pseudo-randomly amalgamates training inputs; instead they rely on telltale signs (not this year's problem set, sophistication mismatch).
- Final projects explicitly welcome Claude, ChatGPT, or Gemini.
