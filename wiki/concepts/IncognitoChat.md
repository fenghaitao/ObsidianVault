## Definition

Incognito Chat is a privacy mode in the Claude app that allows users to have conversations that are not saved to memory or conversation history. It provides a clean-slate interaction for cases where the user does not want context from previous chats or does not want the current conversation to influence future ones.

## Key Information

- **Availability:** Available to all Claude users (not restricted to paid plans).
- **Memory isolation:** Conversations in Incognito mode do not add to or read from the user's memory summary.
- **History isolation:** Incognito chats do not appear in the conversation history.
- **Regular memory preserved:** Existing memory and conversation history remain untouched when using Incognito mode.
- **Data retention:** For Team and Enterprise plan users, standard data retention settings still apply even in Incognito mode.
- **Use cases:** Sensitive brainstorming, confidential strategy discussions, fresh starts without prior context, or any conversation the user prefers not to preserve.
- **Visual indicator:** The Incognito interface displays a ghost icon to indicate the mode is active.
- **Introduced:** September 11, 2025, alongside the [[ClaudeMemory|Claude Memory]] feature launch.
