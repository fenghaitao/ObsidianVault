## Definition
Focus Maxing is a design principle for AI coding agent tools coined by Louis Knight-Webb. It states that interfaces should be designed to let agents run for as long as possible before yielding back to the human, rather than encouraging patterns where the human is constantly pulled in and out of context.

## Key Information
- Coined by Louis Knight-Webb at AIE CODE 2026: "You heard it here first"
- Core insight: pulling humans out of deep focus and back into something else every 30 seconds "fries their brain" and is "no way to live"
- The principle applies to tools built for the [[Plan and Review Shift]] paradigm where engineers manage multiple concurrent agent work streams
- A Focus Maxing tool should: (1) let agents run autonomously for as long as possible, (2) yield back to the human only when genuinely needed, (3) batch human interventions to minimize context switches
- Contrasts with chat-based interfaces that encourage constant back-and-forth interaction
- Complements [[Agent Parallelism]]: while one agent runs, the human focuses deeply on reviewing another agent's completed work
- Part of Knight-Webb's wishlist for the ultimate coding agent tool, alongside task planning, QA assistance, code review, and change shepherding
