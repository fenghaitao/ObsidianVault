## Definition

Feature Engineering is the process of selecting, transforming, and creating input features for machine learning models. Evan King did feature engineering at Meta alongside ML PhDs, despite being primarily an infrastructure engineer.

## Key Information

- Evan spent time "fine-tuning hyperparameters and doing feature engineering" alongside ML PhDs on his team
- The comment signal breakthrough was essentially a feature engineering insight: adding comment text as a feature to the models
- The comment feature was "obvious in hindsight" but overlooked because the team was focused on pixel and audio features
- Feature engineering was part of the experimentation workflow: try different features, train models, check metrics, iterate
- On the Content Integrity team, "your title didn't really matter, we all did things" — infrastructure engineers did feature engineering and ML engineers did infrastructure work
