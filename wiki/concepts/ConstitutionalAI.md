# Constitutional AI

Constitutional AI (CAI) is [[Anthropic]]'s training methodology for building safer, more reliable AI models. It provides the foundational alignment approach used to train the Claude model family.

## Key Information

- Developed by: [[Anthropic]]
- Purpose: Train AI models to be safer, more helpful, and less harmful using a set of guiding principles (a "constitution")
- Applied to: [[Claude2]] and the broader Claude model family
- Published: Anthropic introduced Constitutional AI in research released alongside Claude development

## Core Idea

Rather than relying solely on human feedback for every behavioral preference, Constitutional AI uses a set of explicitly stated principles to guide model behavior during training. This allows the model to critique and revise its own outputs according to the constitution, reducing harmful outputs more systematically.

## Relevance to Enterprise Adoption

When enterprises like [[LexisNexis]], [[LonelyPlanet]], and [[RicohUSA]] selected Claude 2 via [[AmazonBedrock]], Anthropic's responsible AI development approach (grounded in Constitutional AI) was cited as a trust factor — particularly for legally sensitive and compliance-driven use cases.
