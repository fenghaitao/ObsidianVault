## Definition

Product as the Model is the design philosophy of making the AI model itself the product, with minimal scaffolding, rather than treating the model as a component within a larger application. This is the approach Claude Code took, inverting the traditional AI product design.

## Key Information

- Boris: "For Claude Code, we inverted that. We said the product is the model. We want to expose it. We want to put the minimal scaffolding around it, give it the minimal set of tools"
- The traditional approach: "I want to build this application. Model, you're going to do this one component of it. Here's the way that you're going to interact with these tools and APIs"
- The Claude Code approach: give the model tools, let it decide which tools to run, in what order
- Connected to the Bitter Lesson: "Don't try to box the model in. Don't try to give it a bunch of context up front. Give it a tool so that it can get the context it needs"
- "Almost always you get better results if you just give the model tools, you give it a goal, and you let it figure it out"
- A year ago you needed scaffolding, but now you don't
