## Definition
Ubiquitous agents are AI assistants that follow users everywhere — across rooms, devices, and contexts — providing ambient access similar to Star Trek's ship computer. The vision extends beyond phones to glasses, earbuds, smart displays, and any environment.

## Key Information
- Peter Steinberger's vision: "I want to be in any room... like Star Trek when you can say 'computer'"
- Current implementation: iPads in every room; agent uses canvas feature to project information on nearest display
- "The phone is just a very convenient input point but I kind of want to talk to it from anywhere"
- Future form factors: glasses and earbuds — "if I'm around and I have glasses I should just be able to listen in and project something on me"
- Multi-agent future: personal agent at home, work agent, and they should be able to talk to each other "in a way that both your company and you are comfortable with"
- Andrej Karpathy and Maran Dre already run OpenClaw to control their houses — "OpenClaw for homes is like a kind of underrated" use case
- Home automation is possible because "most smart devices are terrible in security, which means OpenClaw can run them"
- The agent should be aware of where the user is and use the nearest available display
